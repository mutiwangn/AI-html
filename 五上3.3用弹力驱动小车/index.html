依据五年级上册《运动和力》第3课设计。先用透视和慢放看清驱动过程，再做实物实验，把三次距离填入“实测记录”。

课堂用法

  • 透视小车：拖转车轮缠绕；箭头键或滑条同样可调。释放后可暂停、慢放和拖动进度。
  • 圈数对比：拖动预测旗；只改变缠绕圈数，让三辆相同规格的小车在相同路面运动。
  • 实测记录：同一圈数测三次，统一以车头为起终点。点数字格用大键盘录入，保留每次圆点。

模型边界

车的尺寸和放大图经过示意化处理。运动由简化的弹性驱动、牵引限制和滚动阻力共同计算，所用参数未对应某套器材。低圈数可能不足以启动，高圈数可能打滑；“圈数越多越远”需要相同条件和合适缠绕范围。皮筋停止驱动后，小车仍可继续滑行。

模型不向实测记录填入数值，也不添加随机“误差”。实测记录仅保存在当前浏览器，可导出 CSV 与圆点图。更换浏览器或清理数据后应从导出文件查阅。
