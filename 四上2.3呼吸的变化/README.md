# 四上 2.3 呼吸的变化

教科版四年级上册，第二单元《呼吸与消化》第3课。独立 HTML，浏览器打开即可，资源内嵌，推荐横屏。

四页：运动计时与60秒测量、2–4组呼吸频率对比、肺泡气体交换、脉搏与动脉。实测记录初始为空，示例频率与自定频率单独标记，不作为实测。记录仅保留在当前页面，关闭或刷新前请导出。

由教师根据学生状况及场地决定是否活动及运动量；可以只观察。不强迫运动、不憋气、不刻意加快呼吸，不适立即停止。图形及粒子为教学示意，不作诊断，不用模型判断肺活量。
