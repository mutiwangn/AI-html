# 四上 2.3《呼吸的变化》

教科版四年级上册，第二单元《呼吸与消化》第3课。深蓝解剖主题、真正 Three.js r160、1600×900 单屏整体缩放。主文件 `index.html` 约4.35 MB，脚本、模型和样式全内嵌，下载后可离线打开。无配音、无音效、无文本或数值输入框、无学校和个人水印。Three.js 包含未调用的通用音频类，但课件不创建任何音频对象。

## 教学链与操作

1. **观察计数**：同一对象的安静时、活动后、休息恢复后，分别连续观察60秒；完整一吸一呼算一次。点按计数、撤销、结束锁定；从单调时钟计时，不靠回调次数累计。计数时停止中央示意动作，避免让模型成为呼吸节拍器。
2. **模型对比**：两组原有瓶子/气球/橡皮膜模型，同起点、同60秒；示例18与30次/分只用于比较，不是正常范围。可切换为本页安静/活动后两项完整正数实测；示例和实测不会混用。1×、2×、4×只调整展示速度。可观察定性加深，不能推算肺活量或通气量。
3. **气体交换**：原呼吸器官模型、原创三维肺泡剖面和气体组成资料。氧气净移动方向为肺泡→血液，二氧化碳为血液→肺泡；红细胞始终留在毛细血管里。气体大小、数量和速率不按生理比例。通气不等于气体交换，气体交换也不只在吸气瞬间发生。
4. **研讨拓展**：四个问题先口头解释再展开参考解释；保留原动脉/心脏三维资产，脉搏计数为选做拓展。脉搏表示沿动脉传播的压力变化，而非单颗血细胞从心脏跑到手腕。

真实计数初始为空，不填默认结果。不输入姓名，不联网上传，也不写入浏览器持久存储；关闭/刷新会清空。需要留存可手动导出匿名TXT。切换状态、切页、打开说明、进入后台或主动停止，会中断当前轮次，不存为完整60秒记录；已有完整记录保留。不能把分段暂停的计数当作连续一分钟。0次结果会提示核对是否漏计，不解释为身体未呼吸，也不送入示例动画。

- [European Respiratory Society：Your lungs and exercise](https://publications.ersnet.org/content/breathe/12/1/97)：运动时消耗更多氧气、产生更多二氧化碳，呼吸随身体需要改变。本次检索摘要可读，全文访问返回403，未宣称读到不可访问的全文。
- 组成图完整沿用所核教材的近似例值：氮气78→78、氧气21→16、二氧化碳0.03→4、其他0.97→2（%），每列总和100。0.03%不是当前大气二氧化碳的精确监测值；水蒸气和其他条件会影响比例。

## 安全与模型边界

由教师根据学生情况和场地决定是否活动及活动量，可以只观察。不强迫运动、不憋气、不限制或刻意加快呼吸；不适立即停止并告知教师。不蒙头做实验；只轻触手腕，不按压颈部。课件模拟值和一次计数不用于诊断、排名、判断个人健康或肺活量。

瓶子模型不模拟肋骨运动或肺泡交换；肺泡图是切面和净方向示意，不是按真实尺寸、浓度或流体力学计算的仿真。动作幅度为课堂可见性适度放大。解剖结构是已有资产，经简化和教学配色，不是临床模型。
