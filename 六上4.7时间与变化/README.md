# 六上第四单元第7课 时间与变化

本课件围绕“科学家怎样把生物和地层留下的痕迹变成时间证据”展开。学生先观察真实材料、提出猜想，再通过年轮配准、珊瑚日纹放大与地层证据比较，把观察结果转化为有依据、有限度的解释。

课件为可直接运行的单体 HTML，使用原生 JavaScript 与 SVG，无外部字体、框架或素材依赖。下载 HTML 后可离线打开；说明窗口中的外部资料链接需要网络。主要面向课堂一体机横屏展示，也提供触控与键盘操作。

## 课程依据

- 用户提供的《【教材】六上》：第四单元“计量时间”，第7课“时间与变化”，印刷页122—126，对应所附 PDF 第126—130页。
- 用户提供的《【教师用书】六上》：本课印刷页373—383。重点是寻找生命体上有规律变化的证据，难点是建立化石组合、地层年代与古环境之间的推理关系。
- 本网页保留教材的年轮观察、珊瑚生长纹、地层化石证据三条主线。跨样本年轮配准是用于深化“证据如何用于计时”的拓展；网页中具体样本与测年数值为教学模型。

## 三个工作区及数字教学价值

| 工作区 | 学生操作 | 数字技术增加的观察与推理机会 |
| --- | --- | --- |
| 树木年轮 | 点选完整年轮、数圈比较；展开时间带，移动B样本，对照连续多年的宽窄模式 | 横截面、相对宽度条形与年份同步对应，把难以直接对比的弯曲环纹转为可对齐的时间记录；用重叠部分延长已知记录 |
| 珊瑚日历 | 拖动取样窗，点选或划过日纹计数；根据分组估计全年日数，再改变假设推算一天时长 | 将细小生长纹放大为可共同计数的证据，把“日纹数”连接到“一年中的日数”和“一天的时长”；用同一尺度比较计算结果 |
| 地层档案 | 查看剖面及形成过程，比较化石与岩层证据，结合上下火山灰测年约束中间层年代 | 把不能在课堂中直接经历的漫长过程分步呈现，让学生比较“只知道上下先后”和“得到数值范围”两种证据条件 |

教学中可只使用其中一个工作区。每页承担不同任务，不要求依次完成所有按钮操作。

## 融入40分钟课堂的建议

| 时间 | 活动安排 | 建议追问 |
| --- | --- | --- |
| 0—5分钟 | 展示真实木片、贝壳或教材照片，学生先说出能观察到什么、想知道什么 | “这些痕迹能告诉我们什么？还不能告诉我们什么？” |
| 5—15分钟 | 实物数年轮后进入“树木年轮”，比较粗细与圈数；用时间带配准解释未知样本 | “你依据的是一圈，还是连续几年的变化？B能补上哪一段时间？” |
| 15—24分钟 | 进入“珊瑚日历”，分组计数，先预测再推算古代一天时长 | “一年总时长近似不变，多分成一些天，每天会怎样？” |
| 24—34分钟 | 进入“地层档案”，先比较相对先后，再加入化石、火山灰测年证据 | “新证据让哪个判断更明确？哪一个具体年份仍不能确定？” |
| 34—40分钟 | 各组选一条最有说服力的证据，保留观察图或记录；与教材的生物时钟、非生物时钟比较 | “我们测到的是树的生长年数、生物生活的年代，还是当时一天的长度？” |

教师可把真实标本上的发现手动填入“记录”，与网页模型记录并列讨论。不要把示意图计数写成班级对真实化石的实测结果。

## 模型数据与科学边界

### 树木年轮

本页设定两块来自同一地区的完整横截面，均保留髓心和外缘，不包含缺轮或假轮。A较粗，共12个年轮，最外圈为2024年；B较细，共14个年轮，外圈年份起初未知。两份数据的连续6年模式配准后，B最外圈对应2018年。A覆盖2013—2024年，B覆盖2005—2018年，合并覆盖2005—2024年，共20年。

横截面和宽度序列是程序绘制的教学样本，不是真实木材的扫描或测量数据。两样本分别按自身平均宽度显示相对变化，因此应比较连续宽窄模式，不要求对应柱高或实际毫米数完全相等。

- 浅色早材与深色晚材共同组成一个年轮，不能分别计为两年。
- 粗细不能替代数年轮；年轮窄只提示生长受限，不能单凭一圈断言发生了干旱。
- 真实年轮研究会核查树种、地区、生长条件、缺轮与假轮，并比较多个样本。本页用清晰的理想样本展示方法。
- 配准得到的是某圈木材形成的年份。未知木样最外一圈的年份不自动等于砍伐或死亡年份。
- 课堂讨论宜使用“样本记录了多少年”。不完整、未到髓心的真实取样不能直接代表整棵树的完整树龄。

### 珊瑚日历

教材123页讨论古代一年天数与一天时数的变化，但没有给出400日或22小时的具体数据。本页参考对部分泥盆纪珊瑚的研究，采用“约4亿年前、一年约400日”的教学情境。图中年界与日纹均已约定、确认；全年按日序展开为20组，每组20条。

屏幕年带按日序归一化显示，不能用两条带的相同长度判断两块珊瑚生长了相同的实际毫米数。分组是便于课堂计数的处理，也不代表真实珊瑚总会留下同样清晰、等距、完整的纹路。

学生先以现代一年约365日作估计，通过计数修正为自己的假设；网页不预先显示完整古代日纹总数。以下数值供教师备课核对。计算采用一年总时长近似不变的条件：

```text
一年总时长（现代小时）≈ 365.2422 × 24
推算的一天时长 = 一年总时长 ÷ 假设的一年日数
当一年有400日时，一天 ≈ 21.914532小时，界面显示约21.9小时
```

“现代一年约365日”是用于阅读的简写，计算保留365.2422。改变360—420日的输入是在检验自选假设，不是在改变固定教学样本的日纹总数。非400日的结果不能当成对该样本计数所得的研究结论。

生长纹是否代表一天或一年，需要独立研究确认；本页不演示鉴定过程。“古代一年日数更多”也不表示一年总时长必然更长。

### 地层档案

本页采用未经倒转的简化沉积剖面。在这一条件下，下层形成较早、上层形成较晚。地层厚度、画面中的形成步骤和动画时长均不表示真实过程的持续时间。

依据NPS对相对年代与数值测年的解释，本模型设定两条火山灰为原始沉降的标志层，由适合测年的矿物约束其形成时间：下方火山灰设为距今约120百万年（1.2亿年），上方火山灰设为距今约100百万年（1亿年）。位于两者之间的C层因此被约束在距今约100—120百万年之间；不能由此直接选定一个确切年份。此组数值是教学案例，不对应某个已公布真实剖面的实测数据，现实测年还具有误差；搬运后重新沉积的旧岩屑也不能不经鉴别直接套用这一规则。

- 化石组合可帮助比较年代与推断古环境；单独一枚贝壳或一片植物化石不足以确定具体时代与年份。
- 海生化石组合支持“此地曾是海洋”的解释，不能仅由此确定具体水深、气温或经纬度。
- 本页数值约束来自相关火山灰矿物测年，不是对化石图标直接测年；不使用碳14测定数千万年前的恐龙年代。
- 相对年代回答“先后”，测年数据给出“数值约束”，二者可以互相补充。

## 记录与导出

各工作区可将观察证据与解释留存到“记录”。也可手动填写真实标本、教材资料或课堂观察，说明自己的解释及尚不能确定的内容。

- 当前工作区状态与已保存记录通过 `localStorage` 保存在本机当前浏览器中，不会上传，也不会自动跨设备同步。
- 最多保留30条证据记录，可逐条删除；达到上限后先导出并整理。
- “导出记录 CSV”保存工作区、来源、观察证据、解释和记录时间，可用于课后整理。CSV时间字段使用UTC。
- “保存观察图”导出当前工作区的SVG图，可重新放大或用于备课记录。它保存当前画面，不替代完整文字记录。
- 两种导出都会先打开“保存文件”窗口，再点击“下载文件”保存到设备。
- “重置本页”恢复当前工作区，已保存到记录中的证据仍保留。
- 浏览器清理网站数据、隐私模式或本地文件权限限制可能影响自动保存。重要记录应导出；课堂结束前可检查“记录”窗口底部的保存状态。

数字键1、2、3可切换工作区，Esc关闭说明或记录窗口。年轮时间带与珊瑚取样窗提供键盘控制；触控设备也可使用滑条或按钮完成对应操作。全屏、下载和本地文件保存能力取决于设备浏览器。

## 素材与模型替换接口

最终交付为单文件，内部仍按三个模块组织，便于后续迭代，而不必改动整套课堂流程。

```text
window.LessonModules.tree
window.LessonModules.coral
window.LessonModules.strata
```

模块约定：`init(root, helpers, savedState)`、`enter()`、`leave()`、`reset()`、`snapshot()`、`getSVG()`。共享接口提供坐标换算、拖拽、本机状态更新、证据记录和即时反馈。`window.TimeChangeLesson.getSnapshot()`可读取当前状态；`window.TimeChangeLesson.replaceModule(name, replacement)`可接入满足相同约定的新模块。

后续可替换为真实年轮扫描图与宽度数据、经过标注的珊瑚显微照片、具有出处的实际地层案例。替换时必须同步更新可视化、计数/匹配逻辑、数据来源、模型边界和记录文字，不能只换图片而保留不相符的预设答案。新增标本若不符合当前状态结构，应先转换保存状态或更新版本。

本版不需要三维模型。SVG绘制与教学计算相对独立，适合先完善样本和证据关系，再评估是否有引入三维的必要。
