# 四上3.8《保护听力》

三页单体互动课堂 v1.0。下载 `index.html`，用浏览器打开即可；绘图和代码全部内嵌，无外部脚本、图片、字体或三维库。课件不显示学校和姓名，保留低干扰 mutiw 水印。

## 课堂用途

1. **听见的旅程**：点选耳廓与外耳道、鼓膜、听小骨、耳蜗、听神经和大脑，逐站慢放；打开鼓膜放大窗持续比较强弱与振幅，保持频率不变。机械振动和神经信号使用不同颜色。
2. **保护的办法**：以同一参考声源比较 A/B 两种接触方式。拖远 B、降低 B 的声级、使用示例耳罩、减少接触时间，比较耳边声级、持续时间与相对声暴露；独立观察耳蜗感觉细胞损伤示意。
3. **声音地图**：切换六种生活情境，区分参考声级和实际测量。真实分贝仪记录由学生手工输入，本机最多保存40条，可请求导出CSV；浏览器不允许下载时可选中CSV文本复制。

保留真实音叉、杯口薄膜等课堂实验。本页用于解释真实实验难以观察的耳内过程，以及比较保护措施。

## 科学边界

- 耳图为简化剖面，振动和位移已放大或慢放；不按比例表现组织尺寸和振动频率。
- 振动经鼓膜、听小骨传入耳蜗，耳蜗感觉细胞转换为神经信号；不把声波直接画入大脑。
- 第二页为理想自由场点声源的持续声模型：L_B=L_A−20log10(r_B/r_A)−声级降低−耳罩衰减。
- 相对声暴露 B/A=(t_B/t_A)×10^((L_B−L_A)/10)。显示的百分比不是听力损失率、安全指数或个人损伤预测。
- 耳罩衰减15dB是模型假设，真实效果取决于产品、频率与佩戴。模型不用于冲击声、复杂室内声场或防护等级认证。
- 第三页WHO单值均为约略示例：耳语30、交谈60、繁忙交通车内85、摩托车95、警笛附近120dB。大音量耳机音乐显示NIDCD参考范围94—110dBA；刻度用范围带表示。
- 不启用麦克风，不将未校准的网页信号当作绝对dBA；不播放强声。
