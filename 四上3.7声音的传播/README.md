# 四上3.7《声音的传播》

版本：v1.0。入口为本目录 `index.html`，完整单文件，无外部脚本、字体、图片依赖，可离线运行。

## 教学价值与页面

1. **振动怎样传递**：声场切面与局部微粒视图联动。移动听音点选择观察方向，追踪一颗微粒，暂停、慢放及拖动进度回看。更换观察路径会清空本轮过程，避免把重新取样误认作同一颗微粒的位置变化。
2. **声音经过哪里**：空气、木桌、水槽、抽气罩四种装置。改变接触方式或罩内空气多少，追踪一条选定路径，保留一份模型状态作对照。抽气过程中声源继续振动，空气量只影响定性接收效果，不改变动画传播延迟。
3. **修好土电话**：直接拖动右杯或使用滑块改变间距，比较松线、拉紧、捏线。绳长固定；杯底、连接点与线端共用同一信号。可暂停、继续、复位并保留对照。

真实实验提供证据，网页补充现实中难以观察的振动传递过程。网页输出不是实测数据，不作为预设规律的独立验证。

## 科学简化

- 距离、振幅、微粒数量与时间均为绘图参数，不标示真实Hz、m/s或dB；不同装置不用于比较声速或进行跨材料的定量强弱比较。
- 空气微粒规则排列是为了追踪，未绘制随机热运动。局部质点在原位置附近往复，不随波包向远处搬运。
- 第1页的圆环是三维传播的一个切面中同一传播阶段的位置；路径页的小虚圈标示固定观察位置。
- 理想真空只研究罩内气体路径，忽略支架等其他路径。抽气按钮最低保留少量空气；滑块端点“理想真空”与真实抽气实验有明确区别。
- 木桌、水槽、土电话中突出的是一条选定路径；现实中仍可能存在空气等其他路径。
- 合成提示音为440Hz低音量示意，不模拟器材的真实音色，也不是画面慢放频率。

## 操作与兼容

- T1基础交互：HTML/CSS/JavaScript/SVG，无Canvas或WebGL要求。
- 核心功能无需网络、麦克风或摄像头；声音需浏览器支持Web Audio，并点击右上声音按钮启用。
- 鼠标和触控拖动均有实现；听音点和纸杯可用方向键，范围滑块可用键盘调整。
- 希沃及电脑横屏优先一屏布局；平板竖屏和手机改为上下排布，允许正常滚动。
- 离页、打开模型说明及切到后台均暂停动画并静音，返回后由用户继续。
