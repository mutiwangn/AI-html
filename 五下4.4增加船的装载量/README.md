# 五下4.4 增加船的装载量｜基础辅助稿
课名依已核实Notion五下目录3fa945e5f61e815b943be5fdd12e326c。教材正文与教参待核；仅为理想船体容积专题，不等同整课完成。
原创SVG直壁船对照：各自重60g、高3cm，外底面积100/150cm²；所需排水体积60+L，吃水(60+L)/面积。边界载荷240/390g，无安全余量，不是安全标准。超界停止预测，仅留边界图。忽略稳定性、变形、波浪、壁厚影响。假想独立设计，不假称同一张纸折成；不用于载人船。
科学依据：已读OpenStax §11.7 https://openstax.org/books/college-physics-2e/pages/11-7-archimedes-principle 。
验收：86组参数关系；浏览器240/250/390/420g状态、上下界按钮、复位、正误反馈及全页视觉通过。实体触屏未测。原创、无署名、无数据上传。
