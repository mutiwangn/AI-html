# 六上4.2《用水计量时间》

单体课堂互动网页 v1.0。打开 `index.html` 即可使用；HTML、CSS、JavaScript、SVG 全部内嵌，无外部运行依赖，兼容等级 **T1 基础交互**。

## 教材依据与数字价值

依据用户提供的教科版六上教材第102—105页、教师用书第323—332页及材料说明书第24—25页。本课隶属第四单元《计量时间》，后续课为《做个水钟》《改进水钟》。网页服务于真实实验后的证据比较与模型解释。

核心难点是区分两件事：连续流出三个相邻50 mL的用时，与每次恢复相同初始水量后再流出50 mL的用时。数字页面同步呈现水面到小孔的高度、体积流量、累计收水和计时，并支持暂停回看；实测记录把累计用时自动差分，辅助处理活动记录中的常见混淆。

## 两个主场景

### 01 两种测法

- 左边从200 mL连续放水，累计收集150 mL后关闭小孔；右边每次倒回量杯中的50 mL，恢复到200 mL，再独立测量，重复三次。
- 共同时间轴按流水用时对齐，倒回和等待时间不计。右边累计的是流水时间，量杯并不会凭空收到150 mL。
- 自动记录各50 mL的分段用时，可切换累计用时。拖动回放条、暂停或选择1×/4×/8×；改变两边孔径时同时重置。
- 初始记录为空，随回放进度呈现，不预先列出所有结果。

### 02 保持水位

- 从150 mL开始，连续调节外部补水0—5 mL/s，并开启或关闭侧面溢流口。
- 每10秒独立记录底孔出水量，底孔收水与溢流水分开累计；补水不足时即使打开溢流口，水位也会下降。
- 可运行、暂停或直接前进到下一个整10秒；一轮60秒。中途改变条件的区段有橙点标识，结束后改变条件会清空旧图并准备新一轮。
- 这是理解稳水条件的改进模型，并非元代四层铜壶滴漏的结构复原。可结合教材讨论古代多级补给如何减小水位变化。

## 本班实测记录

独立弹层默认六项为空：连续流出的50/100/150 mL累计时间，以及倒回重测的三次50 mL独立计时。按 `T1、T2−T1、T3−T2` 自动计算连续各段用时，并用同一比例尺的条形图比较。

输入需为正数，已知累计时间必须严格递增；缺失值只计算能够确定的区段。数据只保存在本机浏览器，支持清空、一次撤销和UTF-8 CSV导出。导出时间以北京时间标注，不上传数据、不自动注入模型数字。浏览器不允许本地保存时会提示可导出。

## 科学模型与边界

使用开口、等截面容器和固定小孔的简化模型：`Q = k sqrt(V)`，`dV/dt = Qin − Qout`。水量与水面到小孔的高度成正比，孔径按面积比例影响流量。理论依据：[OpenStax, College Physics 2e 12.3，托里拆利定理](https://openstax.org/books/college-physics-2e/pages/12-3-the-most-general-applications-of-bernoullis-equation)。代码、图形和文案为独立实现，不嵌入教材扫描图。

- 中孔的首个50 mL设为20模型秒，以便课堂比较，不是实物标定值或标准答案。
- 连续分段的模型值约为20.0、23.7、30.9秒；恢复相同初始条件的三次独立试验各约20.0秒。
- 小孔形状、瓶身变化、表面张力、管阻、温度等未纳入模型；连续场景在150 mL收水时结束，不据此预测接近流尽的精细滴流。
- 软件使用mL/s表示体积流量，不与m/s的出口速度混淆。
- 理想溢流口位于150 mL处，视为足够宽。高于此水位时打开，超过侧孔的水立即记入溢流；真实排水需要时间。界面对此有即时提示。
- 恰好补足底孔流量时，不用溢流也能在理想条件下稳定；不足以维持150 mL的补水也可能长期达到更低平衡水位。软件不把某一种装置选项直接判为正确答案。

## 后续素材与模型替换

`window.WaterModel` 为独立计算接口，提供 `compare`、`draining`、`repeated`、`createStableState`、`stepStable` 等方法；返回的时间、水量、流量和10秒测量数据与图形分离。

`window.WaterLesson.renderers` 暴露 `vesselMarkup`、`buildComparison`、`buildStable`；后续可保持元素ID和数据绑定，替换容器、管道及剖面SVG。替换装置重建函数时应同步重新绑定装置上的点击事件。`window.ClassRecords` 提供独立的 `open`、`close`、`refresh` 和 `getData`。
