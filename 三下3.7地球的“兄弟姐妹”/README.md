# 三下 3.7 地球的“兄弟姐妹”

教科版三年级下册第三单元第7课。单体离线 HTML；双击 index.html 使用，无外部资源。

## 课堂用法
1. 学生先比较八颗行星圆面的大小，从小到大点选排序。核对会显示教材直径数据，提示最早需要复查的位置；不会代替学生调整顺序。
2. 调节地球模型直径（5—30毫米），同步换算八颗行星的模型尺寸。依据尺寸制作彩泥或纸板模型，比较小行星精细制作与大行星耗材之间的取舍。
3. 选一颗行星与地球比较。查阅教材和可靠资料，填写环境证据、来源及日期，保存并导出小档案。

## 数字辅助价值与边界
- 八颗行星的圆面直径使用同一比例，不为方便观察而把小行星放大。示意色不是照片，位置仅表示距日远近的顺序，间隔不代表距离；土星光环不计入球体直径。
- 尺寸助手改变实际制作尺度而不改变各行星直径比例；屏幕并非打印尺。导出结果四舍五入到0.1毫米。
- 赤道直径数值依用户教材第76页：4879、12104、12756、6794、142984、120536、51118、49528千米。此为该教材数据口径，未静默替换成不同来源的数值。
- 环境档案不预填学生尚未查到的事实。卫星数需注明资料日期；气态行星云层温度不能直接当成地球地表温度比较。
- 大小相近不能证明环境相同，更不能证明存在生命。排序只是资料比较的起点，不替代资料研讨和实物模型制作。

## 保存与设备
- 尺寸方案需点击保存；档案可手动保存、切换行星时自动保存草稿；导出会包含当前草稿与当前尺寸。
- 排序为临时课堂状态，刷新重置；导出含当前排序并标注非标准答案。
- 浏览器本地存储，非云同步。重要结果下载文本备份。
- 桌面主要场景一屏；尺寸设置和资料侧栏可独立滚动；窄屏改为纵向布局。
- 原创 SVG + HTML/CSS/JavaScript，无 Canvas/WebGL。T1 基础交互；未进行实体希沃、平板或手机验收。

## 素材和资料
视觉图形为原创 SVG，未复用教材图片。依据用户教材第76—78页及教师用书第7课目标与实施建议；不包含教材图片或长段扫描内容。

教材明确版次尚待核实；尺寸、资料档案为辅助研究，不代替实物模型和可靠资料查证。
