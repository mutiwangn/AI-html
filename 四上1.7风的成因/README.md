# 四上 1.7《风的成因》

双筒烟迹实验与海陆风剖面互动页。打开 index.html 即可离线使用。

- 第一页以香烟示踪为主；金属风轮默认关闭，可选作辅助证据。
- 第二页先观察背景，点击“开始模拟冷热差异”再呈现温度层与气流。
- 固定 0—1 km 剖面；白天 1000 m、夜间 700 m 为浅层教学示例，不是普遍固定高度。
- 支持昼夜/同温对照、暂停、慢放、画箭头、定格记录及导出。
- 高度、温度、粒子与时间均为教学模型，不能当成真实观测；真实明火实验由教师安全组织。
