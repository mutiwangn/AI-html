# 一上1.2 观察植物

教科版2024一年级上册，第一单元《周围的植物》第2课。直接打开 index.html，无外部依赖，可离线使用。

## 课堂建议
本课以实物观察为主，网页可辅助约5–8分钟。
1. 先观察一株老师确认安全的植物，从整体到局部，口头交流。
2. 用“仔细看”同一幅薄荷示意图的整体与局部往返，比较叶的形状、边缘和纹路。植物名称默认隐藏，教师可选择揭示。
3. 植物 B 为仙人掌，只看不摸，也不靠近闻。比较显著特点，不把绿色扁平茎叫成叶片。
4. 回到真实植物，用眼、手、鼻获得信息。“我的发现”初始全空，无需打字，可多选观察词，气味栏为单选；不判分、不自动给答案。选择“别的发现”后口头补充。
5. 观察卡可调用浏览器打印；也可使用设备截图。刷新清空，不上传或自动保存。

## 教学依据
- 用户Notion一年级上册目录（2024版）：https://app.notion.com/p/3fa945e5f61e81168b2fd971717f6b05
- 《科学 教师教学用书 一年级上册》教科版24秋，印刷第48–55页：观察与比较植物外部特征；从整体到局部、从远到近；看、摸、闻的观察方法与语言表达支架；仙人掌拓展。

## 科学与安全边界
植物图为原创SVG教学示意，不是照片、显微镜图或物种鉴定依据。放大是同一植株同一幅图的裁切放大，没有凭空增加实测信息。真实软硬、气味只能通过实物活动获得。教师先确认材料安全，不尝植物、不揉碎、不拔叶；有刺、刺激性或不明植物不触摸、不贴近闻，观察后洗手。
