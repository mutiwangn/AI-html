# 二上2.2 我们的校园

教科版2025年版，二年级上册第二单元《地球家园》第2课。单文件离线互动网页，直接打开 `index.html`。

## 课堂用法
- **学会记录**：观察有缺口的叶片示意图，比较“真实特征”“美化记录”“推测原因”，先口述理由再选择。
- **我的笔记**：两份独立空白观察笔记，支持触控或鼠标手绘、五色画笔、撤回一笔、确认清空。日期、实际地点、天气、匿名小组和主题自主填写；文字可不填，也可用纸笔和口述。
- **对照再看**：并列比较两份记录，用真实、完整、细致三个维度交流，讨论日期、分类与事物联系。下载两页合并的PNG图片保存在本机。

建议40分钟：方法练习6分钟、真实户外观察20分钟、交流10分钟、整理与再观察问题4分钟。教师用书也允许分两课时组织，教师可按校情调整。本网页不代替户外观察。

## 内容与隐私边界
叶片仅为原创练习示意，没有预设真实校园数据。自然现象的变化原因不能只凭两张记录判断。记录以亲自观察为准，不把猜测写成事实，不要求透露姓名。

所有数据仅保留在当前页面内存，不联网、不上传，不申请相机和定位权限。关闭或刷新会清空，请先下载图片。不同日期的结果应保留为两份笔记，不覆盖成同一天。下载后由使用者自行保管和决定是否分享。

## 来源与兼容
依据《二年上册 科学 教师教学用书 教科版 25秋》印刷第124–132页组织：学习自然观察笔记、真实细节、记录日期、分类交流和比较修订。代码与图形原创，无外部素材、字体或依赖。

采用大按钮、响应式布局，支持触控与鼠标。已在桌面Chromium验证切页、选择反馈、笔记独立性、绘画、清空保护、对照和PNG下载；希沃及实体平板仍需设备端核验。较窄屏幕建议横放或配合纸笔。
