# 做个水钟

教科版小学科学六年级上册第四单元第3课的单文件互动网页。围绕“怎样做出能够计时、刻度合适、经得起重复检验的水钟”，连接设计、制作、标定和测试。

打开 [index.html](./index.html) 即可使用。全部核心装置、刻度和图表均为可交互SVG，图形、样式和程序都放在同一个HTML文件中，无需构建步骤或外部素材。设备能力等级为T1基础交互，面向希沃一体机全屏展示、电脑和横屏平板。

## 教材依据

- 《科学》六年级上册第106—109页，对应所附教材PDF第110—113页：制作能计时10分钟的水钟，目标为误差不超过10秒、时间刻度均匀；绘制方案、组装稳水装置、借助秒表标定1—10分钟刻度，再进行三次测试。
- 《科学教师教学用书》六年级上册第333—342页：经历问题、设计、制作、测试与改进的工程过程；通过图文表达设计思路，依据真实测试分析问题。
- 教材第107页的示例采用上层供水瓶、下层稳水杯、底部出水孔与侧面溢水管。多余水排入另一只杯中。它是开口溢水稳水装置。
- 教师用书第341页建议，课堂可先完成前2—3分钟关键刻度，完整10分钟标定与重复测试可继续完成。第342页强调，首要成功标准是做出可工作的水钟并分析误差原因，不应为追求10秒以内而改写数据。

本课网页聚焦装置运行、刻度标定和证据检验。供水容量、读数放大、浮标及其他结构的系统改进，可在第4课《改进水钟》继续展开。

## 三个探究工作区

| 工作区 | 主要操作 | 数字技术增加的观察条件 |
| --- | --- | --- |
| 看见水流 | 普通漏水瓶与溢水稳水装置同步运行；改变供水、暂停、加速、沿时间轴回看 | 同一时间比较装置剖面、液面与每分钟接水量，追踪供水不足后停止溢流、水位下降和流量变化的过程 |
| 标定刻度 | 选择普通或稳水结构、直筒或上宽下窄的接水杯；推进1分钟，在当前液面处标记，完成1—10分钟刻度 | 把时间和液面位置逐一对应，再与高度十等分的尺比较；直接检验流量和杯形对刻度间距的影响 |
| 检验计时 | 在1分钟至已完成标定的分钟数之间选择目标，以新的一次运行测试目标刻度；揭示实际用时与误差；分别记录模型试测和实物实验 | 保留标定尺，改变使用条件，比较同一把尺能否继续准确计时；将三次证据放在一起分析 |

页面中的问题用于引出预测和解释，学生可以反复操作、保留失败结果。整个课件不显示个人或学校署名。

### 看见水流

供水滑杆范围为0%—150%，允许在运行中改变。百分比表示模型中的供水设置，不是实物阀门的精密刻度。时间轴保留供水改变的历史，回看后继续播放仍按原有事件运行；在过去的时刻重新改变供水，则从该时刻形成新的后续过程。10分钟结果以每分钟接水量呈现。

溢水管的作用取决于运行条件：只有水面到达溢水口，且持续入流足够，才会有多余水排出。供水不足时，稳水杯会停止溢流，随后水位和出流可能改变。上层与下层的水分别守恒，不把溢出的水计入计时接水杯。

可追问：水持续流进来，为什么水位能保持不变？供水减慢后，最先发生变化的是哪一处？每一分钟接到的水量能支持什么解释？

### 标定刻度

选择结构与杯形后，借助模型计时完成每分钟标记。可以逐分钟操作，也可以快速完成整条标定尺。完成后在“计时标定”和“十等分”之间切换，比较刻度的位置。

“十等分”表示对高度作等距划分，是待检验的做法，不能自动视为正确时间尺。普通漏水瓶在相同初始条件下，也可以借助非等距刻度计时；稳定出流则需要配合等截面积的直筒接水杯，才能形成近似等距的时间刻度。

可追问：同样经过1分钟，液面一定上升同样高度吗？直接用尺子把高度分成10份，能否替代计时标定？改换杯子之后，原来的时间尺还能用吗？

### 检验计时

试测从新的初始状态独立积分，不直接复用标定时的时间。目标范围为1分钟至已完成标定的分钟数；完成全部刻度后可选1—10分钟。四种条件为“保持原样”“供水不足”“底孔直径增大8%”和“起始水位降低20%”。其中供水不足设置为原供水的30%，仅适用于稳水结构，普通漏水瓶下此项不可选。

水面到达所选目标刻度后停止，揭示实际用时；若模型运行20分钟仍未达到目标，则保留“未到刻度”，实际时间和误差不填成零。当前一组最多保留三条试测记录，第四次不会覆盖前三次；改变结构、杯形、时间尺或继续标定时，开始新的一组试测。

误差统一为：

```text
误差 = 水钟示值 - 实际时间
正值：水钟偏快；负值：水钟偏慢。
是否达到10秒目标：看误差绝对值是否不超过10秒。
```

例如，水钟显示10分钟，实际已过10分20秒，误差为−20秒，表示水钟偏慢。模型中保持完全相同的条件可能得到相同结果，这不能证明实物水钟没有误差。

“实物实验记录”单独打开，提供三行记录，实际时间初始为空。填写真实测得的时间后再计算误差；不会自动用模型数据填充实测记录。

## 科学模型与边界

### 出流近似

模型以小孔出流关系为基础，出流量近似满足 `Q = Cd × a × √(2gh)`。其中，`h`是水面到出水口的竖直高度，`a`是孔的面积，`Cd`合并表示出流损失。这里讨论的是单位时间流出的水量；画面中的水滴是流动示意，不能当作逐滴测量仪器。

这一近似适用于水面和出口都与空气相通、孔相对容器较小等简化条件。模型不完整模拟黏性、表面张力、滴形、孔口毛刺、管道阻力、温度、堵塞、振动及读数反应时间。页面数值用于比较因果关系，不是对某只塑料瓶实际性能的预测。

孔径增加8%意味着直径乘以1.08；圆孔面积相应乘以 `1.08²`，不能把它直接处理成流量增加8%。

### 稳水与容器形状

稳水杯遵循 `水量变化 = 流入量 - 流出量 - 溢出量`。水面低于溢水口时没有溢流；达到溢水口且入流大于出流时，多余水排出，水位近似保持。入流不足时不强行保持恒定水位。真实溢水管也有有限排水能力，模型采用理想化溢流边界。

接水杯的液面由累计接水量与杯形共同决定。直筒杯横截面积不变；上宽下窄的杯子横截面积随高度增大。同样的入流量不意味着这两种杯子有同样的液面上升速度。

普通泄水瓶经过非等距标定、并在相同初始条件下重新使用，也可以计时。它与稳水装置的差别应通过刻度、使用条件和测试证据讨论，不能直接归结为一种能计时、另一种不能计时。

### 标定与检验

标定建立液面高度和时间的对应关系；检验使用已经建立的尺，在新一次运行中比较示值与实际用时。初始水位、出水孔和供水条件改变后，原尺可能不再适用。教师用书第337页特别提示重复测试时保持漏水杯的初始水位一致。

模型试测与实物实验分别保存和导出，CSV中保留数据来源。模型结果不代替班级实测证据；空白实测值表示尚未测量，不应当作零秒。
