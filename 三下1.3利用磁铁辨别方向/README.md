# 三下1.3 利用磁铁辨别方向

教科版三年级下册第一单元第3课，单体 HTML，离线可用，无外部依赖、无需输入文字。

## 教学用途
1. 悬挂、水浮与支撑结构对比；先包住磁极标识，A/B两端不预填磁极。
2. 三次独立实测记录，方法、A/B方向与停稳状态分别选择；保留未知及异常，汇总对比；清空当前记录需两次确认，不影响其他次数。
3. 校园三个情境与排障提示、现场核查单。切换情境会重置核查单，以便重新检查。

老师先可靠标定教室方向，再让学生改变磁铁起始朝向、等待停稳、重复观察，并比较组间结果。资料按钮由教师在探究后开启；网页不自动替学生判断A/B两端。提示磁北与地理北差异，不能用作导航。校园示意图N/S只是标签，不表示屏幕左右为真实方向。
