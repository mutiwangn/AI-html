# 六下 4.3 月球探索
月球遮挡与中继视线基础专题；教材正文、版次与教参待核，不等于整课完成。目录Notion六下3fa945e5f61e81d49201da0529936503，教材目录4–5页。
二维直线段—圆距离判断遮挡，背面/正面点可选，中继示意角度可调；分别报告直连与两段中继的几何条件。两段不被挡住也不保证真实通信。天体大小距离/可调圆周为教学参数，不能视作鹊桥轨道或真实星历；忽略地形、天线、功率、地球遮挡等。
