# 怎样能看到物体

教科版六年级上册第二单元“光”第1课。打开 `index.html` 即可使用；HTML、CSS、JavaScript 与 SVG 均内置，无外部素材或网络依赖。适合一体机全屏展示，也提供触控拖动、滑块与键盘操作。

## 教学依据与数字价值

依据教材第34—37页（PDF第38—41页）、教师用书第147—157页、配套说明书第8—9页。核心问题是：光怎样进入眼睛，使我们看见光源或不发光物体？

实物黑盒提供观察证据，网页补充盒内不可见的光路、两段路径的独立遮挡，以及不同方案的同步对照。学生先提出解释，再用干预结果修正模型，最后回到实物检验。模拟结果不能单独证明现实规律。

## 三个工作区

| 工作区 | 操作与任务 |
| --- | --- |
| 黑盒探秘 | 调节孔口开度、拖动孔位、开关外部光；比较眼睛视野与可展开的剖面。分别插入挡板A、B，检查“光到物体”和“物体到眼睛”两段路径；黑暗中换贴纸，区分记忆与看见。 |
| 天窗设计 | 在相同外部漫射光下移动天窗，比较三张桌上的图案与相对受光条。先固定宽度只改位置，再解锁宽度，讨论单个位置和整体均匀性的关系。 |
| 证据对比 | 最多保存6条观察，选择两条对照；模型记录可回放，系统提示改变了哪些条件。补充实物记录，点选光源、物体、眼睛构建解释。 |

## 40分钟课堂建议

- 0—5分钟：从生活现象提出问题，辨认自然光源与人造光源。
- 5—18分钟：完成实物黑盒实验，比较全遮、部分遮和不遮透光孔。
- 18—25分钟：用黑盒剖面检验光路解释，独立遮挡两段路径。
- 25—29分钟：设计天窗，保留两次只改变一个条件的方案。
- 29—31分钟：比较证据，说明支持解释的条件与现象。
- 31—40分钟：回到实物验证、交流差异并完成记录。数字探究合计约13分钟。

## 模型边界

亮暗采用二维开口角宽的相对近似和显示映射；右壁竖直贴纸还计入正面入射方向，不是照度计数据，不输出 lux，也不等于人的清晰度测量。外部漫射光保持相同；黑盒观察孔贴紧不漏光，黑色内壁不计多次反射。天窗省略直射阳光、墙面反射、眩光和材料差异，因此不能判定真实建筑的固定最优孔位。

剖面用于显示结构，不代表眼睛所见；无光或视线被遮挡时，视野不显示目标。挡板A、B抽象表示相应整段通路被完全阻断，图示板宽不用于精确几何遮挡计算。粗糙贴纸向多方向反射光，只有进入眼睛的部分参与看见；动态虚线表示方向，不代表真实光速。

## 记录与保存

模型与实物记录分别标注；实物条件需手工填写，不生成模拟截图。CSV导出全部记录，SVG导出所选两条对比图，可用于课堂汇报。观察文字保留学生判断，不自动改成标准结论。

记录与解释链保存在当前浏览器的 `localStorage`，不上传、不跨设备同步；隐私模式或清理浏览器数据可能使记录丢失，请及时导出。重置当前实验保留记录，清空记录需再次确认。

## 后续替换接口

`apertureLight`、`wallApertureLight`、`boxModel`、`roomModel` 为独立模型函数；`stickerMarkup`、`deskMarkup` 为图形替换入口。保持输入输出结构即可迭代模型或素材。`window.SeeLightLab` 暴露只读状态快照与模型计算入口，便于后续检查；无需改动记录与页面交互。

## 验证范围

已在 Chromium 浏览器检查页面切换、孔口开度、剖面、挡板B、观察保存、回放、CSV下载、天窗滑块、直接拖拽与键盘调节。通过1920×1080、1366×768、1024×768、390×844实际CSS视口检查，主页面无横纵溢出；这些是浏览器视口检查，不是希沃或iPad硬件测试。

另直接执行HTML中的模型和导出函数，验证零光、A/B区别、开度单调、孔口范围、竖贴纸正面受光、房间镜像、快照稳定、CSV转义以及SVG XML完整性。SVG导出文件生成与解析通过，实际浏览器第二次下载过程中测试会话超时，未把该次下载计为通过。

尚未验证Safari、旧款iPad和希沃一体机的真机表现。
