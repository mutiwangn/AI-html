# 二上1.4 设计小房子
教科版2025二年级上册第一单元《造房子》。设计依据：对应教师教学用书第70–78页；任务为至少两种材料、比较稳固、明亮、通风，并考虑住户出入。

## 课堂使用
直接打开 index.html，无网络依赖、无需打字。建议两人讨论轮流操作。
- 画草图：切换屋顶、门的位置和大小、窗户数量、材料、开闭方式。
- 说一说：根据设计给出讨论提示，勾选讨论项目，可保留一版文字方案。修改后检查项清空。
- 备材料：清单随当前设计改变，逐项循环记录待核对/已有/还缺。
- 两次点击确认清空，刷新会清空全部记录。

## 教学边界
这是正面设计草图，不按真实比例，不替代纸笔自由设计或实物测试。不能由示意图断言结构稳固、采光达标或实际通风效果。纸盒与纸板均为纸类，不计为两种材料。材料备齐状态须由学生核对实物。安全提示包含不使用玻璃/尖锐金属、不拆电器、不钻密闭箱、剪切由老师指导。

## 验证
静态脚本语法检查通过。受支持云浏览器预览测试了设计切换、无窗提示、透明/不透明及开闭反馈、保存方案、修改后检查复位、备料轮转和清空、全量复位。已复测1180×757视口下三页均一屏呈现：页面滚动高度757px，第1页含重置提示时亦为757px，无横向溢出。修订后再次验证草图切换、保留方案、检查清空、备料轮转与清空、全量复位。实体希沃、平板和手机未实测。窄屏使用单列可滚动布局。

建议能力级别 T1。原创内嵌SVG，无第三方素材与外部资源。
