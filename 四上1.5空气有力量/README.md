# 四年级上册 · 第一单元第5课《空气有力量》

目录归属：四上第一单元第 5 课《空气的流动》；本资源名为《空气有力量》，2026 秋教师用书课名为《空气流动有力量》。

离线单文件互动模型。用现代 Chrome、Edge 或 Safari 打开 `index.html`，建议课堂横屏展示。

## 互动内容
- 气球吹纸杯：拖动纸杯改变距离，对照对准与偏离、轻重变化。
- 气球小火箭：调换出气方向，比较空气流动与气球运动的方向。
- 切换“看现象／看空气／看受力”；放大关键作用，显示或收起解释。
- 松开／捏住、重新开始、慢动作、暂停与单步；支持音效、音量和全屏。

## 科学说明
这是定性解释模型，不是定量仿真。蓝点与箭头是示意，不代表肉眼可见空气。两物体间的相互作用力分别作用在不同物体上；停止喷气后，物体仍可能继续运动，再因摩擦和阻力减速。气球内保留少量空气。教师说明列出摩擦、橡胶弹性及微粒简化边界。
