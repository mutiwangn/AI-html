# 一上2.7 做个“时间胶囊”
教科版2024一年级上册第二单元《我们自己》，依据教师教学用书180–189页相关教学内容。

三页：想未来（选择推测，联系现在需要留存的测量记录与健康行动）、留记录（纸上画现在与未来，真实数据和推测分开，记录日期）、装起来（实物核对、封存演示、重新检查）。无打字、无个人信息表单，身体数据只建议在纸上由老师或家长协助填写，不在网页收集或公开展示。

网页只是课堂辅助，不长期保存，不会自动在五年后开启。纸质信息由老师/家长实际封存保管，换班转学做好交接。未来预测不是保证，不比较高矮胖瘦，不把体重增加作为越多越好的目标。真实记录不由网页生成；日期勾选与封存检查同步。

## 测试
脚本语法检查通过。受支持云浏览器实测：想法与记录类型对应、健康提示、纸上日期联动、未备齐时封存提示、备齐后封存及禁用检查、重新打开、二次确认清空。封盒后隐藏内卡，避免露出盒盖。1180×757视口三页均一屏呈现，文档高度757px。实体希沃、平板、手机未实测；窄屏单列滚动。
