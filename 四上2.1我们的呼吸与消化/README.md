# 四上 2.1《我们的呼吸与消化》

新版入口 `index.html` 是约0.71 MB的独立离线HTML，内嵌Three.js；深蓝解剖风格，1600×900等比单屏缩放，中央模型、左右操作，无配音、无文字或数值输入。

## 教材范围与教学链

直接核对教科版四上学生教材印刷30–32页（PDF34–36页）及配套教参121–131页。保留本课的起始课功能：回忆生活体验，整理已有认识，形成班级问题墙，为后续健康科普收集证据；不提前要求学生记全器官。

1. **感受呼吸**：自然呼吸观察，点选鼻前气流、胸腹起伏等真实感受；可只观察同伴。模型吸/呼状态与真实体验明确分开。
2. **回忆进食**：咀嚼、吞咽、饥饿、过饱四类经历独立记录。只回忆，不安排进食或诱发不适。
3. **整理认识**：六张交流卡，标记亲身体验、以前知道、还需查证；不把学生前概念直接判为错误，也不把已有认识自动当作证据。
4. **提出问题**：问题卡按呼吸、消化、共同、暂不确定归类。可不选择，保留“其他口头问题”；课件不替代班级纸上自由记录。

所有记录初始为空，不预填学生结果；仅存在当前页面内存，刷新会清空。课堂记录可下载为本机TXT，不上传、不使用浏览器持久存储。

## 模型与安全边界

原创参数化半身模型与内层器官位置，Three.js真实网格、灯光、相机与旋转。呼吸阶段对比胸部前后径及横径变化，气流点只提示鼻前气流；内部位置为可选观察层，不是医学影像或完整解剖模型。颜色、幅度、节律均为示意。感受位置不能证明器官精确位置或病因。

不要求憋气，不比较呼吸快慢或起伏幅度，不诱发饥饿、过饱或呼吸困难；不要求现场进食、快速吞咽。不舒服应停止并告诉成人。无姓名、学校署名或个人健康数据采集。

无法创建WebGL时明确显示二维备用位置示意，关闭正面/侧面旋转按钮。二维模式仍可完成点选、分类、记录与导出，不冒充三维显示。
