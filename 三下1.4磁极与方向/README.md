# 三下1.4 磁极与方向

教科版三年级下册第一单元第4课。离线单体HTML，无外部依赖，无需打字。

## 课堂流程
1. 标好磁极的两根条形磁铁，尝试相对端N-S、N-N、S-S、S-N四种组合。两轮独立实测记录，保留异常及未知；汇总两轮时暂隐藏输入表，按钮可返回。清空本轮需两次确认，不影响另轮。
2. 两根磁铁独立翻转，先预测再看规律解释。每次翻转隐藏解释；箭头为相互作用趋势示意，非实测动画，不代表磁力、速度或距离。模型不会修改实验记录。
3. 地理极/地磁极分层概念图及推理反馈，可将整图旋转180度，强调纸面上下不等于方向本身。图形可旋转180度，标签反向补偿保持正立；磁极层及教材推理资料默认隐藏，由教师讨论后揭示。
4. 按教师引导用蹄形磁铁拓展相互作用与自由水平转动辨向实验。
