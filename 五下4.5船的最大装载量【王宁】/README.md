## 教学定位与课标依据

本课对应教材第114—117页：同船换水观察、制作简易浮标、测量比较、解释吃水与装载。网页用于小组实验记录、模型观察和证据交流。

依据《义务教育科学课程标准（2022年版）》的**科学观念、科学思维、探究实践、态度责任**四方面，以及5—6年级有关解释现象、比较与模型、证据和变量控制的要求，转化为下列目标。它们是本课教学目标，不是课标原句；密度、浮力公式计算不作为本课达标要求。

课标来源：[教育部印发通知](https://www.moe.gov.cn/srcsite/A26/s8001/202204/t20220420_619921.html)；[课程教材研究所官方课标下载目录](https://www.ictr.edu.cn/download_center/ywjy/p/1.html)（选择科学2022年版）；[教育科学出版社公开的科学课标PDF](https://www.esph.com.cn/docs/2025-04/1b6ae454bcb2413b94cab49256e1dc6e.pdf)。

| 核心素养 | 可观察的本课目标 | 课堂证据 |
|---|---|---|
| 科学观念 | 根据等体积水样数据解释同船同载荷的吃水变化；区分液体性质与风浪对装载的影响。 | 航行预测、吃水比较和安全装载建议。 |
| 科学思维 | 说清改变与不变的条件；引用本组读数支持口头判断；区分露出高度与固定浮标上的液面标记位置。 | 两种对齐图、主舞台标注及学生解释。 |
| 探究实践 | 调好能直立自由漂浮的浮标；用直尺零刻度对齐、读数并记录三种液体，必要时复测。 | 测量动作、重复读数和数据比较。 |
| 态度责任 | 如实保留不明显或看不清的结果；轮换分工；结合证据为航行安全提出建议。 | 复测过程、小组合作、装载记录。 |

**重点**：公平比较同一浮标，把测量证据用于解释。  
**难点**：联系露出高度、吃水与装载量，并将液体密度和风浪两个因素分开研究。

## 顶部四栏目怎样用

横屏以大场景和右侧信息操作栏为主，四个栏目统一放在顶部。详细说明收在帮助中。

| 栏目 | 学生操作 | 教师追问 |
|---|---|---|
| 观察 | 船依次从长江驶入海洋，再驶入浑浊黄河；先看右侧等体积水样数据，在场景下方预测，再开船观察。 | “货物没变，依据哪条数据判断船会浮高或吃水更深？” |
| 测量 | 清水、淡盐水、浓盐水三种液体；吸管无刻度，拖动独立直尺测露出长度，通过数字键盘输入；右侧保留本组比较数据。换液体时显示换杯过程。 | “应对齐直尺的边缘，还是零刻度线？哪一段才是露出长度？” |
| 比较 | 在主舞台直接查看三种液体的读数、露出长度和差异标注；切换对齐水面/对齐浮标，用图口头解释；可返回复测。 | “哪个数据支持你的判断？换一种对齐方式，事实是否改变？” |
| 装载 | 在长江、海洋、黄河间切换；选择同装载或同吃水，调整货物/目标吃水；用“统一平静”控制风浪，再比较自然情境下的安全线。 | “相同吃水谁能装更多？相同货物谁吃水更深？风浪改变后哪些量变了？” |

比较页不设文字输入框，讨论围绕舞台上的数据进行。模型中的变化较小时，可看吃水数值和局部放大，不用肉眼位移大小代替数据判断。

## 四人一平板：40分钟组织建议

每组准备平板、三杯液体、同一支吸管和橡皮泥、直尺、记号笔与擦拭用品。教师课前调试浓度和配重，保证浮标稳定、差异可观察；平板放在干燥处。

四人分别担任**实验员、读数员、平板记录员、证据发言员**。每测完一种液体轮换一次；两人先核对读数，再由记录员输入。

| 时间 | 活动 | 小组产出 |
|---|---|---|
| 0—5分钟 | 看水样数据，预测长江→海洋→黄河的变化。 | 预测及理由，保留预测与观察的差异。 |
| 5—9分钟 | 明确公平比较条件，调试同一支浮标。 | 不改配重、不碰底碰壁、稳定后读数的方案。 |
| 9—22分钟 | 实物实验与网页记录；练习直尺对齐和读数，差异不明则复测。 | 三种液体的本组记录。 |
| 22—29分钟 | 对齐比较，指着主舞台的数值和标注解释。 | 一句口头观点及支持它的数据。 |
| 29—37分钟 | 同装载/同吃水对比；控制风浪，再观察浪越船口后的过程。 | 区分两个变量的装载建议。 |
| 37—40分钟 | 展示证据图，回扣教材问题。 | “发现什么、依据什么、还有什么不确定”。 |

模型测量可以用于练习工具操作。实物实验的读数应进入“实物记录”，不要用模型值补齐尚未测得的数据。

## 测量与比较的操作要点

- 本版测量露出长度的约定是：**直尺零刻度对准液面，刻度方向朝向吸管顶端，读取吸管顶端对应的刻度**。直尺端部不一定就是零刻度线；眼睛对准读数位置，避免斜视。吸管本身不显示数字刻度。
- 同一轮使用同一浮标与同一配重。换液体前清洁并轻轻吸去附着液滴；不改变配重，不让浮标碰底或碰壁，等稳定再读数。
- “对齐水面”看露出长度；“对齐浮标”看液面标记。露出越长，固定浮标上的标记越靠下，两种图表达同一事实。
- 不同组自制浮标的质量、形状可能不同，应交流各组内部的变化关系，不直接平均各组绝对高度，也不按谁的数值大排名。
- 比较液体“轻重”需要取相同体积；同一物体自由漂浮时，水只需足够深、容器足够宽，杯中液体体积相等不是漂浮高度比较的必要条件。
- 同船同载荷稳定漂浮时，浮力均平衡总重力。液体密度较大时所需排开体积较小、吃水较浅；不要解释成稳定后浮力仍一直更大。

## 航行数据与安全装载：教师须明确的边界

### 1. 水域名称对应本次教学样本

| 本次样本 | 相同体积 | 样本质量 | 用于预测的信息 |
|---|---:|---:|---|
| 长江 | 1000mL | 1000g | 含沙较少 |
| 海洋 | 1000mL | 1025g | 含有盐分 |
| 浑浊黄河 | 1000mL | 1050g | 本次设为含沙较多 |

这些值是教学设定，不代表整个水域固定不变的实测密度。海水密度随温度、盐度等条件变化；浑浊度是光学特征，与密度不是同一个量。**不能仅凭“黄河浑浊”断言其密度一定大于海水**，本次预测应依据给出的质量数据。黄河模型还假设泥沙均匀悬浮，暂不考虑沉降。

### 2. 先分离变量，再研究安全

“同装载”保持货物质量不变，比较吃水；“同吃水”保持平均吃水不变，比较货物质量。固定吃水时可能出现非整箱货物，页面以精确质量呈现，不能取整后仍宣称吃水完全相同。

“统一平静”保持各水样密度不变，将风浪统一为零，并采用共同安全吃水4.0m，用于单独比较密度因素。恢复本次水域情境后，海洋波浪较大，需要更大干舷；本次内河较平静，安全线可更高。现实河流也可能有大浪和复杂航行条件，这不是“所有内河都更安全”的规则。

### 3. 安全线、船舷和沉没是三个不同状态

船深为**4.4m**。本次内河安全吃水为**4.0m**，海洋为**3.2m**，都低于船舷，分别留出0.4m和1.2m干舷。真实载重线还受船型、海区、季节、开口、结构和稳性等影响，本版不模拟法定核定程序。

超过安全线先表现为风险增大，船仍可能漂浮。只有波峰越过船口，或平均水面已经达到船口，才开始进水；水进入后总质量增加、吃水加深，储备浮力耗尽再逐渐沉没。**演示假设船口未封闭，时间经过缩放**。卸货不会自动清除舱内已有的水，需要复位重新实验。

### 4. 供教师核对的参数

轮船采用等截面模型：有效水线面积2000m²、空船1600t，每个货物单位100t，最多80单位。图形外形不是上述参数的精确比例图，货物单位也不是标准集装箱额定载重。

| 控制条件 | 长江 | 海洋 | 黄河本次样本 |
|---|---:|---:|---:|
| 同载3600t，吃水m | 2.600 | 2.537 | 2.476 |
| 同吃水3.2m，货物t | 4800 | 4960 | 5120 |
| 本次风浪下最大安全整箱 | 64 | 49 | 68 |
| 统一平静/安全吃水4.0m，最大安全整箱 | 64 | 66 | 68 |

浮标仍为独立的三液体实验：模型密度1.00/1.05/1.15g/cm³，露出长度约10.00/10.95/12.61cm；总长24cm、质量10g。它与第一页的三处水域不是一一对应的数据。记录范围0—24cm，实物数据由小组输入，不按理想顺序自动改正。

## 记录、迁移与课堂使用

- “模拟测量”和“实物记录”分别保存。比较页和证据图标明来源；JSON备份保留两套测量历史，以及航行预测和装载记录。
- 旧版浏览器记录、旧版JSON及单套浮标记录均可迁移。旧文字观点保留在记录中；旧版三液体的船舶装载和换水观察单独归档，不改名混入新版水域数据。
- 新版航行记录最多48条、装载记录最多24条；每种液体最多保留10次读数。重复测量保留历史，比较时注意当前呈现的是哪一次读数。
- 记录保存在本机浏览器；换设备、清理浏览器或使用不同浏览器后，应通过JSON导入恢复。PNG证据卡用于展示，JSON用于保留完整数据。
- 本版不跨组实时同步。修改组号只是重新标注本机当前记录，不自动生成另一份小组档案。
- 使用Canvas 2D，无WebGL和外部CDN依赖；需完整加载同目录文件。本版没有离线缓存安装功能。
