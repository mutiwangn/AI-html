## 修订
- 保留整体→局部放大，补眼的标签、头部下方口的位置小图（明确示意，不冒充照片）。
- 新增自由绘画画板，不预画标准答案；鼠标/指针绘画、撤销一笔、二次确认清空，鼓励依据实物。
- 教材三项反应观察：轻声说话、放菜叶、棉签轻触，各自真实记录和汇总，不播放刺激动画、不代填反应。未观察、没看清、跳过分别保存。
- 教师指导一次轻碰身体，不碰眼触角，缩回即停，不反复刺激、不喊叫拍手敲桌；可跳过。无变化不能用于断言听觉。
- 透明板/树枝上的运动独立记录，安全低位、观察盘内、让蜗牛自行移动，防跌落不翻扯。
- 记录与图画仅本次打开有效；无上传、无外部依赖，保留 T1。
