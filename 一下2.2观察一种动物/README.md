## 课堂设计
第一页面：原创蜗牛侧视示意，整体、壳部、头部、腹足位置分别放大；名称默认隐藏，显示名称时回到整体，避免局部标签被裁切。数字放大服务于全班辨认，学生仍需对照真实动物。

第二页面：三类实物记录，分别记观察清晰度、本段时间移动和触角状态。未观察、没看清、暂时不动均可保留，网页不自动生成动物反应。课堂建议先观察真实蜗牛，学生指认、画主要特点，再用示意回看，不用现成图代替学生画图。

## 科学与动物照护边界
图示为常见陆生蜗牛外形的简化示意，不是所有蜗牛的通用精细解剖模型，也非透视或真实照片。头部两对触角，较长触角顶端有眼；口在头下，本侧面图没有画出。腹足用深绿色条带标位置，并非实际颜色，不是几条小脚。观察腹面要隔着教师准备的安全透明板，不翻扯蜗牛。

本稿没有模拟移动、固定的反应时长、触角触碰游戏或食物偏好结论。暂时不动/缩回也是有效观察。刺激与食物反应的完整活动需教师结合匹配教参与动物状况组织，不据本网页认定已经覆盖全部教材活动。

教师准备安全洁净观察盘，儿童不碰触角、不拉捏或敲壳、不用盐、热水、强光刺激。未采用浸水强迫活动方式。不安排捕捉、购买或野外放生，照护、食物与去向交教师负责，活动后洗手。

## 实现与测试
单体离线HTML，SVG/CSS/JS，无第三方脚本/字体/图片，无打字、上传或个人数据。记录仅内存，刷新清空；清空记录二次确认。

JS语法通过。受支持云浏览器1180×757已验证两页一屏，整体/三个局部切换、名称显示返回整体、实物三项选择、跨页状态及二次清空；修正局部标签裁切问题。真实希沃、平板及其他尺寸未测，窄屏单列可滚动。
