# 制作独轮车：版本与记录

默认入口 index.html 保留 v1.2（24 块砖、20 米、5 秒休息及原星级门槛）。v1.3、v1.4 保留为 200 砖归档版，v2.1 保留为并列版本；本次不改变游戏规则、模型、单位或许可。v1.4 的历史时间是工地分钟，其他版本为秒，不应直接混比。v2.1 内嵌 Three.js 的 MIT 许可原样保留。

## 记录隔离与旧数据
四个页面现在各有独立存储键。旧共享键只读，不自动迁移、不覆盖或删除。升级后未显示旧设计或成绩不代表数据已删除，请在“记录与备份”中主动选择旧缓存恢复，或导入先前导出的备份。

恢复须确认，只载入当前版本兼容的规则历史，并告知未载入数量；完整旧数据仍保留在原键并可原文备份。恢复后仅在当前页面，需明确点击保存才写入该版本的新键。不再自动截断到最近五条成绩。

无效数据整体拒绝，保留缓存和当前设计。读取、写入或配额失败会显示保护提示；可导出原始记录及当前草稿。备份后替换需确认下载可找到。不同标签已发生的数据变化会触发只读保护，但 localStorage 不是原子事务，不能保证完全消除同一瞬间并发写入。

## 验收与限制
已在浏览器检查四版保存/刷新隔离、真实文件恢复与坏文件拒绝、备份下载、同版标签冲突，以及默认版完整 24 砖运输和旧成绩比较。游戏测试用时包含操作等待，不是性能或教学效率基准。异常缓存与配额故障采用隔离测试，未向真实用户缓存注入故障。
