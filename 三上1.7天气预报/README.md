# 三上 1.7《天气预报》

## 打开与使用

直接用浏览器打开 `index.html`。单文件、无外部运行依赖，可离线使用。核心交互为 T1：HTML、CSS、JavaScript、SVG。

课时依据：教科版三上教师用书《天气预报》（印刷83—90页，对应教材20—22页），以及仓库 `curriculum.js` 的课时目录。活动、图形、界面与示例数据为原创设计，不复制教材插图，不标注学校或教师姓名。

## 40 分钟课堂安排

1. **0—10 分钟，读懂预报。** 区分地点、预报时段与发布时间；辨认天气符号，理解最高/最低气温和风向风力。各字段的解释由点击后显示，不预先给出结论。
2. **10—22 分钟，沿时间观察。** 将一天的分时预报展开为天空示意、气温折线和天气/风的同步读数。支持播放、暂停、逐时刻查看、A/B 留帧比较。离开该工作区或切后台自动暂停。
3. **22—34 分钟，对照观测（核心任务）。** 同日同地并排比较一次观测的15℃与全天预报9～18℃、当时天空与“多云转阴”等表达。切换上午、下午记录，认识一次观测不能代表全天。支持输入真实记录及对应预报；未测项目留空，预报来源、发布时间和实际适用时段分别记录。
4. **34—40 分钟，小小天气播报。** 总结预报与观测的关系。课后比较同一天不同地区的预报；时间充足时展开“预报更新”拓展，保留先后想法与依据。

## 本课独特的互动价值

- 同时展开时刻、气温、天气和风，避免把全天符号理解为整天不变的天气。
- 固定地点与日期，突出“瞬时观测”和“全天范围/先后变化”的差异。真实记录与示例分开；没有测到的数据不自动补值。
- 可选拓展固定同一活动时段，对比两个发布时间的预报。第一次想法不会被第二次覆盖。
- 更新与观测逐层揭示，留下“信息—决定—修改依据”的证据链，不替学生自动选答案。
- 支持 SVG 证据卡和 CSV 记录导出。文字在本机保存，不上传，不需要账户或定位权限。

## 数据与科学边界

**“青禾镇”、示例日期、天气值及“观测记录”全部为课堂虚构数据。不是历史天气资料，也不是实时预报或真实实测。** 不应将本页用于真实出行决策。真实活动请关注当地气象部门最新预报、预警及学校安排。

- 预报时段与发布时间不同；全天最高/最低气温不是全天每个时刻的气温。
- 东南风指从东南方向吹来的风；2～3 级是风力等级，不是米/秒。
- 天空中的云形和雨滴只是天气符号的可视化，不代表真实云型、降水量或风速。
- 折线连接离散预报时刻，不提供所有中间时刻的精确气温。24:00 表示该天结束，即次日 00:00。
- 课堂“观测”例子包括与预报相同和不同的项目，但不能用一个例子评价真实预报准确率。
- 本页不根据一朵云或单个观测点计算未来天气。预报工作流程的介绍只是“广泛观测—计算分析—预报会商—发布与更新”的简化说明。

参考：
- [中国天气网：天气预报是怎么做出来的](https://nmg.weather.com.cn/zt/tqzt/2079291.shtml)，核对预报工作流程。
- [中央气象台：国内天气预报](https://www.nmc.cn/publish/forecast.html)，供教师联网查询真实信息。本页示例不会跟随该网站更新。

## 保存、导出与维护

- 主任务真实资料键：`aihtml-weather-comparison-v1`；可选拓展键：`aihtml-weather-forecast-v1`。两个拓展情境分开保存；“重做当前情境”会确认，且不影响另一情境。
- 真实记录要求核对预报覆盖地点、时段与观测地点、时刻；不自动验证数据来源。预报有效时段按来源填写，不强制转换为00:00—24:00。
- 本机存储不可用时会提示导出，不影响核心课堂操作。浏览器清除数据、无痕模式结束或更换设备可能导致记录丢失。
- SVG 导出对用户输入转义，CSV 防止公式注入。使用时间戳文件名，避免新旧记录混淆。
- 不建议输入学生姓名等不必要的个人信息。页面不发送网络请求；仅“参考资料”和“返回目录”链接会在点击时导航。
- 示例数据常量为 `TIMES`、`TEMP`、`WEATHER`、`FORCE` 与 `CASES`。若改成真实资料，必须同步修改来源、地点、发布时间、预报时段、单位和虚构标记，不应只替换数值。
