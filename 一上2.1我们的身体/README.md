# 一上 2.1 我们的身体
独立重制辅助稿，教材正文及教参待核。无学校/真实姓名，无外部图片或程序依赖。全程点选，HTML中没有input或textarea。

活动：衣着人体外形SVG部位突出；常见成对部位卡片与数量辨析；看、听、轻触与推测的证据辨析；实际完成观察的点选记录。真实身体可能不同，提供看图与讨论替代动作，不给学生做身体评价。

范围：只做外形和证据观察，不含内脏剖面或解剖模型，不声称完整覆盖教材。只轻触自己，不进行身体检查，不采集照片或健康信息。观察同伴须同意，不触碰、不脱衣。数据只在页面内存。

验证：JS语法；云端Chrome部位突出、鼻子数量反馈、看/听证据反馈、点选新增撤销计数、0输入框、桌面截图。实体触屏、旧浏览器、教材教参对齐与课堂尚待验收。
