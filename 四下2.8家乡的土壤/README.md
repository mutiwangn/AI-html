# 四下 2.8 家乡的土壤
观察布点与结论范围基础辅助专题，不等于整课完成。教材正文、版次与教参待核。目录已核：Notion 四下页 3fa945e5f61e81c18ffcf72c902c07f3，《【教材】四下.pdf》目录 4–5 页。
三类区域、九个原创假想观察点；点选/键盘激活显示外观卡，集中或分散布点方案、揭示全部、四题证据辨析、重置。不是宁波实测或任何真实地点，不推断肥力、污染、土壤类型；点数不是面积覆盖率。
方法参考：https://www.extension.umd.edu/resource/soil-testing-and-soil-testing-labs ，阅读不同区域分别取样、代表性相关内容。本页是课堂布点演练，不是专业采样规程。
