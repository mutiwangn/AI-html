# 四上 1.4《空气有质量吗》

版本：4.1-classroom-20261107。单文件离线课件，保留简洁碰撞与回弹版的两视图设计。

- 打气与称量：每筒对应 8 个模型小点，沿软管逐个进入皮球；放气反向移动；称量前自动移开气针。
- 按压与比较：相同按压力、碰撞慢镜、回弹和合成拍球音效。初始 0 筒表示未额外打气，不表示无空气。
- 所有质量数值、微粒、音效和回弹均为模型示意，不替代真实实验。质量以称量证据研究，硬度或声音不是空气有质量的直接证据。
- 真实打气不超出皮球标注压力；气针由教师安装；绿豆不可入口。

## 使用

在现代 Chromium / Edge / Safari 浏览器中打开 index.html。支持鼠标、触屏、键盘、全屏。音效需首次操作解锁，可在教师设置中调节音量。网页无外部运行资源，不申请麦克风权限。模型参数仅保存在本机浏览器，课堂状态不自动保存。

本次维护加入圆角 Canvas 绘制兼容分支、ResizeObserver 缺失时的窗口 resize 回退和课堂安全提示。实际希沃硬件和 iPad 仍建议课前快速检查。
