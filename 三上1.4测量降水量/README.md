# 三上 1.4 测量降水量
独立重制辅助稿，无学校/真实姓名，无第三方素材依赖；HTML与app.js须在同一目录。教材正文及教参待核，非整课验收。

直筒宽度不同但均匀降雨下水深相同的模型；明确开口与水平截面积相同、无蒸发漏水溢出等条件。毫米读数练习、厘米与毫米换算、真实三次观测。非等截面容器需专用标定，不照搬内部水深。

记录区分有效零、未测量、溢出或损坏无效；记录时段独立，未自动算总量、强度或雨量级别。范围0—500mm最多一位小数只是录入约束，不代表仪器量程。内存保存、CSV导出、防公式执行，不上传。

验证：JS语法、40mm同深图形与对照线、17mm练习反馈、零/无效/未测量三态、CSV下载、501mm拦截、桌面截图。实体触屏、旧浏览器、课堂和教材对齐待核。
