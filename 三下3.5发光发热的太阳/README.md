# 三下3.5 发光发热的太阳

教科版科学三年级下册，第三单元第5课。单文件，无网络依赖，全部原创SVG。

## 使用
- 第一页选择白球、镜子或电灯，分别改变外来照明和电灯电源，区分自身发光与反射光。电灯只有通电发亮时才在此模型中作为光源。
- 光路为概念示意，非光度计算。关闭照明后仍保留轮廓，仅为说明位置，不能解释为无光时能看见物体。
- 第二页输入同一时刻、同地表材料、同仪器方法的向阳/背阴实测温度。每组自动计算温差并绘制配对图；不预设向阳温度一定高。
- 保存发现并导出记录。记录仅存在当前浏览器，不跨设备同步。

安全：不直视太阳，不用望远镜或放大镜直接看太阳；不要触摸热表面，测温仪激光不指向眼睛。

本工具聚焦光源判断与地表测温，不替代完整的太阳资料搜集、维恩图比较或水变化实验。最多6组测温，支持修改。图中连线连接同一组两次测量，不表示时间趋势。
