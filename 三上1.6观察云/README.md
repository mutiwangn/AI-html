# 三上 1.6 观察云
独立重制辅助稿；HTML与app.js须放同一目录。无学校、真实姓名，无外部依赖。不复用旧版图像代码。教材正文与教参待核，不算整课验收。

八等份平面天空覆盖面积模型，可改变云量、分布和格线；直边白块不是实际云形，不模拟真实天空曲面。团块、层状、丝缕三种独立SVG外观线索，仅用于描述，不能据此正式鉴定云属或预测天气。没有擅自把比例划入晴、多云、阴分类。

三次真实记录区分未观察、遮挡、零云量；模型数据不填入实测表。汇总及CSV下载，冲突云量/无云选择会阻止导出。内存保存、不上传、不收集位置。避免直视太阳或雷雨外出。
