# 三上 1.1《我们关心天气》

三工作区单文件互动课堂，适用于教科版三年级上册第一单元“天气”第1课。入口为 `index.html`，无外部运行依赖，T1 基础交互，可下载后离线打开。页面及标题无学校或教师署名。

## 教学安排（40分钟参考）

1. **看天气，约12分钟**：先用自己的话描述，再展开气温、云、风、降水四类线索。保留 A 时刻并拖动时间，看同地点六个时刻的变化。另一“冬日校园”情境用于讨论晴天是否一定暖和。
2. **找位置，约8分钟**：选择风、云、雨、雪，观察地表和周围的大气及空气运动箭头，可暂停。强调人也在大气中，常见天气发生在靠近地面的一层大气。
3. **记今天，约20分钟**：在教师组织下安全观察，填写地点、日期、时刻和实际观察线索。气温可不填；填写数值时必须说明来自气温计实测还是天气资料。选两条记录进行同地点跨时间比较。

## 数字交互的作用与边界

- 同一场景、同尺度 A/B 留影与时间滑动，使短时天气变化可以并排、回看和逐项比较。
- 云、气温、风与降水是需要分别观察的维度。示例特意保留“阴而未下雨”“雨停地湿”“晴而寒冷”，避免把晴等同于热、云多等同于正在下雨。
- 所有情境画面和数值为教学编排，明确标注非实测、非天气预报，不进入本班记录。两个情境不是同一天，不应拼成连续观测数据。
- 气温旁的简化装置只用来表示“需要测量”，不是气温计刻度读数训练。旗面仅表示风的观察线索，不标定真实风级。天空云形与云量也不用于定量分类。
- 大气示意图的高度、厚度和物体比例经过夸张，箭头仅表示空气运动。没有演示成云、成雨的全部条件，也不表示空气一运动就会下雨。云是小水滴或小冰晶组成的可见集合，水汽本身通常看不见。
- 记录中的“未观察”不作为“没有”参与比较。不同地点、同一时刻、不同温度来源会出现提醒。几次记录不能证明气候或长期规律。
- 户外观察不直视太阳；雷雨、大风等危险天气留在室内。

## 本机记录与导出

- 真实记录初始为空，最多60次，只存当前浏览器 `localStorage`，不上传。
- 支持修改、取消修改、删除确认、CSV导出和两条记录的SVG对照图导出。
- SVG图的备注最多显示前三行，完整文字保留在CSV中。CSV包含温度数值来源，并对可能触发表格公式的文本前缀作保护。
- 无法本地持久存储时会提示，当前页面仍可填写和导出。私密模式、清除站点数据、本地 `file://` 的浏览器策略等会影响恢复；换设备前请导出。没有云同步与自动采集。
- 不需要摄像头、麦克风、定位或联网天气API。使用系统字体与SVG。
