# 水珠从哪里来 · 二维互动版 v1.0

教科版三年级上册第二单元第2课。独立单文件 `index.html`，无需联网资源、Three.js、WebGL 或三维模型。与三维版并存，不覆盖原版本。

## 教学内容

- 观察现象：冬日窗户，调节温度、湿度，观察并擦拭水珠。
- 对比实验：盖不盖玻璃片、是否滴红色色素、预冷空杯与冰水杯。选择A/B杯，开盖后加色素，移走冰块或换入冰水，擦除外壁水珠。
- 凝结原理：宏观玻璃杯与二维杯壁局部模型联动；微粒可隐藏，明确水蒸气实际不可见。
- 生活应用：冰镇饮料、冬季车窗、眼镜、浴室镜面；先预测再反馈。

教学依据为教材33—35页及教师教学用书123—130页；微观视图、可调温湿度及动态水珠为补充解释性模型。生活场景沿用本项目此前制作的素材，不包含教材扫描页。

## 操作

点击“开始观察”，再次点击暂停。点击杯子选择A/B，杯口或按钮开合杯盖。打开“擦拭”后在表面拖动。右下角 − / 适屏 / ＋ 调整画面大小；不依赖多指缩放。右侧滑块改变条件。底部“记录”保存模拟观察并可导出CSV。

模拟时间、凝结速度、水珠尺度和回温速度均为教学简化，不是实测数据；记录明确标为“模拟观察”。范围为0℃以上，不模拟结霜。

## 技术与兼容性

T2 二维绘图：Canvas 2D、JPEG/PNG、普通JavaScript及鼠标/触摸事件。全部素材已内嵌；可用完整浏览器打开单文件。iPad可优先使用Safari访问发布后的网页地址，Android使用其完整浏览器；附件预览器不等同于完整浏览器。

已在Chromium中禁用WebGL，验证无WebGL调用、无外部资源请求、四页核心交互及7种视口尺寸。受运行环境策略限制，本轮浏览器验证以完整HTML注入方式进行，未验证本地文件导航或GitHub Pages在线地址。未在真实旧iPad、Android平板或希沃一体机上实机测试，不以系统版本直接保证兼容。

标准视口：1920×1080、1366×768、1024×768、768×1024、820×1180、390×844、844×390。建议课堂使用横屏。

## 维护

随发布包提供的 `source/` 包含HTML模板、CSS、JavaScript与图片data URI清单。运行 `python source/build.py` 可重新生成单文件。`WATER_ASSETS` 是独立素材替换入口。记录仅保存于当前浏览器本地，无账户、无上传接口。
