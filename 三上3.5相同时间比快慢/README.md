# 三上3.5 相同时间比快慢

预测—同时间4秒模型—真实三次实验链。可选同起点、不同起点、相反方向，改变实际路程；明确位置刻度与路程区别、统一时间条件和单向直线假设。反例终点靠前不等于更快；相反方向也可同样快。真实记录共同用时和三次路程，0为真实未移动、空白为未测；缺项和不同方向结果均提示核对，不伪造实验数据。CSV导出，仅内存不上传。
