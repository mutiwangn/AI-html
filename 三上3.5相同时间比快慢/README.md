# 三上3.5 相同时间比快慢

单体互动课堂 v1.0，对应所提供教材第70—72页及教学用书的相关活动。用于希沃一体机全屏展示，也可由学生在电脑、平板上操作。

## 三个场景

1. **交通工具**：观察六种交通工具1小时的路程，从快到慢排序。支持拖动名称、点选两个名称交换、键盘上下调整及排序检查。动画把1小时压缩为8秒，也可拖动0—60分钟的时间条；所有轨道使用相同比例尺。
2. **一起走**：两人从同一起点向相反方向脚跟接脚尖行走，3秒准备后同时开始。可选共同用时4、6或8秒，分别调节两人的步伐节奏，也可点“一起停”提前同时停止。结束后拖尺身对齐零刻度，再拖读数标记对准脚跟；两人都量好后记录，保留最近3次模拟结果。
3. **追逐跑**：拖动②的起点，设置0—8米间隔；改变共同用时和两人的节奏，或切换预设情境。停止后判断谁更快，再点“对齐路程”查看同一时间内各自走过的距离。追上后仍继续运行到共同停止时刻。

## 科学边界

- 交通工具数据采用教材给出的概数，用于比较；演示按匀速处理，不表示真实交通工具始终保持这一速度。
- 共同计时必须覆盖同一段运动时间；不以谁先按下按钮或谁先到某个位置代替相同时间的比较。
- 脚跟接脚尖行走时，以起始和停止时的脚后跟位置作为测量基准，尺的零刻度应对齐起点。
- 行走模型将每次完整落脚前进简化为0.2米，两人步长相同，改变的是落脚节奏；距离取到停止时最后已落地的脚跟。尺上的米数是模拟距离，不是屏幕的物理长度。
- 相反方向行走时，比较的是各自走过的距离大小；方向不能使路程变成负数。
- 不同起点的最终位置不能直接用于比较快慢，应从各自起点测量运动距离。
- 本课以“时间相同，比较距离”的证据推理为主，不要求学生学习速度计算公式。
- 追逐跑采用匀速示意，不包含起跑加速、疲劳等变化；屏幕记录均为模拟结果，不应当作课堂实测数据。

## 运行

打开本目录的 `index.html` 即可使用。HTML 内含样式、脚本与 SVG 素材，无外部库、网络字体或在线资源依赖；下载后可离线打开。

最低技术需求为 **T1 基础交互**，包括 HTML、CSS、JavaScript、SVG。支持鼠标与触控；浏览器全屏功能依设备支持情况使用。

运行中切换场景、打开课堂说明或切到后台会暂停，返回后点“继续”。准备倒计时期间切换会取消本次准备。提示音可关闭；浏览器不支持音频时仍可看倒计时和停止提示。

最近3次行走记录匿名保存在本机 `localStorage` 中；存储不可用时本次页面仍可操作。页面不上传记录。

作者署名仅在仓库首页课时目录展示，课件内部不显示学校和姓名。

## 素材替换接口

全部图形位于 HTML 顶部的内联 SVG `<defs>` 中。保留 `symbol` ID、`viewBox` 和定位约定，即可替换素材而不改运动模型。

| Symbol ID | `viewBox` | 对应素材 |
| --- | --- | --- |
| `vehicle-plane` | `0 0 140 80` | 喷气式客机 |
| `vehicle-train` | `0 0 140 80` | 高速列车 |
| `vehicle-speedboat` | `0 0 140 80` | 汽艇 |
| `vehicle-car` | `0 0 140 80` | 汽车 |
| `vehicle-ship` | `0 0 140 80` | 轮船 |
| `vehicle-bicycle` | `0 0 140 80` | 自行车 |
| `walker` | `0 0 100 140` | 行走、追逐跑人物 |

交通工具默认朝右，图标大小不代表实际物体比例。人物默认朝右，脚跟定位参考点为 `(50, 130)`，向左行走时由 `useSymbol()` 水平镜像；服装使用 `currentColor` 接收两组颜色。地面脚印由 `shoe()` 单独绘制，测量坐标与人物外观分离。

现有交通工具复用 `l35-body-white`、`l35-body-blue`、`l35-glass` 三个渐变。替换图形时保留所引用的定义，或使用独立且不重名的渐变 ID。

## 只读模型接口

`window.ScienceSameTime` 提供模型核对与后续开发所需的读取方法，不提供修改内部状态的入口。

| 成员 | 返回内容 |
| --- | --- |
| `version` | 当前版本字符串 `1.0` |
| `transport` | 交通工具教材数据副本；每项包含 `name` 和 `oneHourKm` |
| `walkDistance(seconds, pace)` | 给定时间及行走节奏的模型距离，单位为米；按已完成落脚次数计算 |
| `runDistance(seconds, pace)` | 给定时间及跑步节奏的模型距离，单位为米 |
| `snapshot()` | 当前页面、交通排序、行走和追逐跑状态的深拷贝；修改返回值不会改变页面内部状态 |

`pace` 使用0—4的整数档位。行走频率依次为每秒0.5、0.75、1、1.25、1.5次完整落脚；跑步模型速度依次为每秒1、1.25、1.5、2、2.5米。这些数值用于开发核对，学生界面只展示直观的节奏调节与运动证据。
