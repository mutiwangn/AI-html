# 四下 3.5 导体和绝缘体
低压典型样品比较与接触检查专题，不等于整课完成或专业绝缘检测。教材正文、版次与教参待核；目录来源 Notion 四下页 3fa945e5f61e81c18ffcf72c902c07f3，教材目录 4–5 页。
四个典型样品（裸铜、裸铝、干燥普通塑料、干燥普通橡胶），两端接触与开关。通电时锁定材料/接点，换样品后清空接触；明确灯不亮不能单独证明绝缘，更不能证明市电安全。无人体/液体/市电/短路测试。
