# 四上 1.2 空气能占据空间吗

教科版 2026 年四年级上册第一单元第 2 课，单文件离线互动网页。直接打开 `index.html`，不需要联网或安装依赖。

## 课堂使用

- **观察水位**：拧紧瓶盖后缓缓下压半截瓶；保持瓶子位置，拧开瓶盖；密封连接打气筒并注气。小球作为水位标记，空气与流向可按需显示。
- **证据记录**：预测、实验证据、自己的解释均默认留空。填写真实实验的观察，不把模型输出当实测。记录只保存在本机浏览器，可打印。
- **排水挑战**：一次改变一个条件，比较瓶口密封与否、排水管是否伸入水中的结果。使用打气筒，不用嘴吹。

建议 40 分钟：5 分钟预测，15 分钟真实实验与记录，10 分钟用模型解释，10 分钟排水挑战与交流。

## 科学与安全边界

模型用剖面、颜色和放慢变化解释空气进出及水位变化；不是压力、流速或体积测量工具。橙点只代表看不见的空气，不是空气真实颜色与大小。封盖下压时保留少量进水，避免暗示空气绝对不能压缩。模型不代替真实实验。

半截塑料瓶由成人预先制作并包好切边，轻压慢放，避免溅水。保持瓶身不挤压，区别“注入空气排水”和“挤瘪瓶身排水”的原因。

## 适用范围

本页按教科版的半截瓶、小球、开盖与注气连续实验设计，不将其他版本《吹气球》的四实验整体等同于本课。网页无学校或个人署名，无外部资源依赖。


## 2026-11 科学模型与记录保护修订

依据本课教师用书的半截瓶、开盖、注气与排水活动修订：开盖等待内外水面相平后，原深度再次盖紧保留当时空气量，不再跳回首次封盖下压的水位；连接气泵不自动注气，各状态均可缓慢提起或下压。

采用等温、等效直筒与静水压平衡的定性模型，忽略瓶肩形状、惯性、漏气和温度变化。尺寸、压力及每次气量仅为示意，动画不是实际瞬态或测量结果；仍须真实实验验证。

原有有效记录键和格式保留，不迁移。无法解析或不兼容的原记录保持只读，当前填写为未保存草稿；可导出启动时原始字符串和当前草稿。读取失败在导出中标明 readOK=false；配额或权限失败不提示保存成功。备份不支持自动导入，异常数据需人工恢复。请在关闭已有页面前自行导出、打印或复制未保存内容，本更新不强制刷新旧页。
