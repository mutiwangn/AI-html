# 四上 1.2 空气能占据空间吗

教科版 2026 年四年级上册第一单元第 2 课，单文件离线互动网页。直接打开 `index.html`，不需要联网或安装依赖。

## 课堂使用

- **观察水位**：拧紧瓶盖后缓缓下压半截瓶；保持瓶子位置，拧开瓶盖；密封连接打气筒并注气。小球作为水位标记，空气与流向可按需显示。
- **证据记录**：预测、实验证据、自己的解释均默认留空。填写真实实验的观察，不把模型输出当实测。记录只保存在本机浏览器，可打印。
- **排水挑战**：一次改变一个条件，比较瓶口密封与否、排水管是否伸入水中的结果。使用打气筒，不用嘴吹。

建议 40 分钟：5 分钟预测，15 分钟真实实验与记录，10 分钟用模型解释，10 分钟排水挑战与交流。

## 科学与安全边界

模型用剖面、颜色和放慢变化解释空气进出及水位变化；不是压力、流速或体积测量工具。橙点只代表看不见的空气，不是空气真实颜色与大小。封盖下压时保留少量进水，避免暗示空气绝对不能压缩。模型不代替真实实验。

半截塑料瓶由成人预先制作并包好切边，轻压慢放，避免溅水。保持瓶身不挤压，区别“注入空气排水”和“挤瘪瓶身排水”的原因。
