# 四上 2.8 呵护我们的器官

## 呼吸与消化统一主题版 · 2026-11-10

保持“四年级上册 → 第二单元 呼吸与消化 → 第8课”原入口。主页面沿用2.6的深蓝灰背景、暖珊瑚强调色、居中观察区、左右渐进操作、右上设置与全屏。运行代码只在单个 `index.html`，无需外部资源，不含文本输入、姓名、学校或个人健康资料采集。

### 教材对应

已核对2026版教科版学生教材印刷页51–53（PDF55–57）及教师教学用书本课正文：
- 调查、统计与分析：使用**人为编写的虚构8人一周资料**比较四类不适的记录人数，不收集学生真实病史。明确可重复计入不同类别，不能相加为总人数，也不能据此诊断或证明病因。
- 结构与功能：原创二维鼻腔剖面，点选观察鼻毛与黏液减少部分尘埃、黏膜内丰富血管参与调温、湿润黏膜增加湿度。
- 比较模型：两条虚拟通道输入一致；加入模拟鼻毛与黏液后部分颗粒停留，仍有部分通过。粒子数与运动速度人为设定，不是真实过滤率。无吸灰、憋气、探鼻腔实验。
- 习惯与依据：六个可修正的虚构情境，覆盖烟雾、手部卫生、专心进食、多样饮食、口腔清洁、适宜活动与不适求助。
- 科普活动：呼吸防护、消化保护、共同呵护三种科普卡，鼓励用自己的话说行动、理由和边界。

本课重在行为选择与结构功能关系，二维剖面/比较模型比旋转3D更便于课堂判断，因此不机械复用2.6的三维模型。不把“吃冷食”“出汗吹风”当成疾病的简单病因，不要求统一强度或挑战极限。

### 旁白和字幕

每阶段有中文讲解与始终可见的同文字幕。点击后才尝试设备Speech Synthesis，仅选择浏览器标记 `localService === true` 的中文语音，优先zh-CN。不调用在线语音服务。设备无中文语音、合成报错、2.5秒启动超时或30秒保护上限均有文字提示。浏览器的本机标记不是对操作系统网络行为的独立审计。

暂停、切换、弹窗、隐藏页面取消旧朗读；旧回调隔离，重播从本句开始。开关、答案和科普主题仅存于当前页面内存，刷新清除。不上传或写入持久存储。

### 科学与健康边界

鼻腔防护有局限，不能使污染空气安全。健康习惯能降低部分风险，不能保证不生病；不同器官共同维持身体活动。不按身体差异评价学生，不作医学诊断或给药建议。明显不适停止活动并求助成人，紧急情况立即求助成人和当地急救服务。
