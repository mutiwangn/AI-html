## 数字增益
可切换球状、方块状、圆柱状；圆柱可站立/横放，显示平面/曲面接触。逐步点击移动，通过跟踪标记点区分滚动和滑动，可回起点。横放圆柱采用端面视角，明确长轴朝屏幕内。模型只呈现一种可能运动；实际受施力、方向、摩擦等影响，不宣称方块不可能翻滚或站立圆柱不会倾倒。
第二页用真实安全物体轻推与摆放，独立记录滚动/滑动/倾倒翻滚/其他不确定；不自动填实验结论。二次确认清空。
