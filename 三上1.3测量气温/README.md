# 三上 1.3《测量气温》

独立单体 HTML 课件，打开 `index.html` 即可使用。无需联网、账号、安装或外部字体/脚本。技术等级：T1 基础交互。页面及数据均在本机运行。

## 课程对应

依据教科版三年级上册教师教学用书第1单元第3课，印刷页52–59（提供文档的转换页80–89），围绕同一室外地点、同一天的五个时点开展真实测量、记录、图示与分析。

旧路径 `三上1.3测量气温【王宁】/index.html` 是既有《认识气温计》读数练习。本目录是独立的新课，未改动、覆盖或删除旧文件及其署名。

## 三页活动

1. **规范测量**：选择室外阴凉通风处、距地面约1.5米、不触碰玻璃泡、液柱稳定后读数、视线与液柱顶端齐平。明确保持干燥，教师指定安全地点；简易测量与专业百叶箱观测有区别。图形仅为示意，不按实物比例绘制。
2. **记录气温**：默认8、10、12、14、16时，可按学校作息改动。填写同一天的日期、同一室外地点、可选小组名与气温；标记小组实测/教师代测，漏测如实留空。实际测量通常延续到第二天或周末，不伪装成一课时内完成一天测量。
3. **画图研讨**：依照记录涂液柱，核对后连接顶端；允许教师自动绘图。所有模型使用同一刻度，时点按实际时间间距绘制；漏测处断线，不插值填空。最高/最低明确限定为“已记录时点中”。

## 数据真实性

- 默认实测记录为空，不自动生成或填充。
- 教学示例有三组：先升后降、持续降温、含零下与零度。始终显示“模拟”，并与实测隔离；切换、绘图、导出均不把示例写入实测。
- 网页不是测温仪，不读取传感器，不获取天气，不代替实测。课后须使用真实气温计。
- 五个时点不足以确定全天最高、最低气温；不宣称每天必定先升后降。比较不同小组时先核对时间、地点、仪器和方法。
- 数值范围检查为-60至60℃、最多1位小数，含0℃与负数。超出范围须核对仪器、单位，不能直接记录。
- 五个时间必须有效、严格递增；重复、倒序时暂停绘图并提示修正。

## 使用与保存

- 大屏可点“全屏”；支持触摸、鼠标和键盘。标签页支持左右箭头。
- 实测自动保存到当前浏览器本机存储。清理浏览器、隐私模式或存储禁用时可能丢失；存储失败会提示及时导出。
- 导出CSV保留来源、状态、时间、地点，明确实测/模拟；防护文本单元格的公式解释。
- PNG导出保留来源、图形与真实记录。尚未核对的液柱图会明确标注“可能与记录不同”。
- 清空实测、把已有数值改为漏测均需确认，可取消。示例不受清空影响。
- 建议先导出，再开始另一天的实测。本版只保存一份实测，不做多日档案或云端同步。
- 课后拓展在成人陪同、安全前提下进行，不要求学生熬夜测量；最低气温可查阅当地天气资料。
