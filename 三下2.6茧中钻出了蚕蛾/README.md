# 三下2.6 茧中钻出了蚕蛾

三年级下册，第二单元“动物的一生”，第6课。离线单体HTML，不依赖外部图片、脚本或网络。

## 课堂用法
- **结构对照**：切换“蚕蛾×蚕蛹”与“蚕蛾×蝴蝶”，按整体、头与触角、胸与足、胸与翅、腹部同步定位。用同一部位寻找联系或差异；不是羽化动画，不演示内部发育。
- **用特征分类**：蚂蚁、蚊子、蜻蜓、蜘蛛、虾、蜈蚣六种对象，先保存初判和依据，再展开资料、修订。每种动物保留第一次保存的判断，计数表示记录覆盖量，不是正确数。
- **生命活动**：交流真实的羽化、交尾和产卵记录，明确家蚕成虫通常不取食，不把蝴蝶吸蜜概括给家蚕成虫。

原创蛾、蝶、蛹结构示意并非实拍；视角、大小和颜色用于说明，不能作为实测数据。足在翅的遮挡关系作了教学简化，强调三对足都连接胸部。蝴蝶是典型结构示意，未指定种；不依据图中颜色或飞行习性作分类。

分类针对成体主要结构：身体头胸腹三部分、头部一对触角、胸部三对足。不能仅看是否有翅、是否能飞。虾的附肢描述限定常见真虾；不要求把所有附肢误当步足。

## 保存
一套六种动物记录；首次判断保留，理由与当前判断可更新，不保存历次修订历史。切换动物或页面保留未保存输入；刷新只恢复已保存记录。每个对象展开资料后，须再保存才会将“已读资料”状态写入本地。

记录存在当前浏览器当前地址，不跨设备同步。下载HTML只包含已保存内容，可阅读、不支持导入。未提供重置、删除或多小组账户。请下载备份；浏览器清理缓存可能丢失本地数据。
