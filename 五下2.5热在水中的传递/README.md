## 互动与科学边界
8步跟踪一小团水：底部受热、上升、上部散开与向较冷环境散热、密度相对增大后下沉、底部回流。点击或滑块推进，支持路线隐藏。另设上暖下冷分层比较，较轻暖水已在上部，不预设贯穿水深循环，但不声称完全无局部运动或传热。

该路线是预设教学路径，不是流体仿真、实测速度或温度。圆圈不是气泡、染料团或单分子；真实水会混合，不能把同一水团永久视为完整个体。传导仍参与能量传递。底部图假设持续局部供热与上部散热，不模拟起流条件及边界流动。

适用普通淡水、高于约4°C、无沸腾结冰、无盐度差与外力搅拌。不能将暖水密度较小推广到所有水温/溶液。模型不供实际加热指导；不自行接触热水、蒸汽或加热密闭容器。
