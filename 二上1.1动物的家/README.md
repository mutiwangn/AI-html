# 二上1.1 动物的“家”

教科版2025年版二年级上册，第一单元《造房子》第1课。直接打开 `index.html`，单体离线运行，无外部资源。

## 课堂使用
1. 看看里面：比较燕巢、蟹洞、蚁巢、松鼠树枝巢，切换外观和剖面，口述地点、形状、材料。
2. 找材料：并列比较两种巢的材料，辨别自然物与人造物。
3. 人也能用吗：认识早期人类的地穴、树屋、泥屋，讨论自然材料的取用与改进。

建议配合实物、可靠动物照片和口述交流使用；网页主要帮助看见被遮挡的空间，并不是自然照片或真实观察记录。建议40分钟：聚焦5分钟、观察比较15分钟、材料观察10分钟、研讨拓展10分钟。所有操作为点击，不要求打字；刷新会回到初始状态，不储存或上传学生信息。

## 科学与安全边界
- 剖面和古人住所均为原创简化示意，不按实际尺寸，也不代表所有物种或所有地区。
- 一些蟹在泥地挖洞，许多蚂蚁在地下筑巢；不概括为所有蟹或蚂蚁都如此。
- 鸟巢主要与繁殖有关，不把它说成鸟一年四季的卧室。
- 房屋性能与材料处理、结构、施工和维护相关，不把自然材料一概说成不牢固。
- 观察动物须远观，不掏洞、不拆巢、不抓动物，不让动物参与试验。

## 依据及验证
按《二年上册 科学 教师教学用书 教科版 25秋》印刷第40–47页的教学目标及活动设计组织。课名、册次及单元与2025年版目录核对。代码与SVG图形原创，无第三方素材。

桌面Chromium验证了三个环节、四种巢的剖面及材料提示、两种材料选择反馈、纸的辨别提示、三项建家讨论。1180×757浏览器视口中三页无纵向溢出。窄屏采用纵向布局；手机、实体平板、希沃一体机尚未真机验证。无WebGL依赖，建议归为T1基础交互。
