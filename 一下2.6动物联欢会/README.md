# 一下 2.6《动物联欢会》

一年级下册第二单元第六课课堂辅助网页。打开 index.html 使用；单体 HTML，无需登录、输入文字或外部资源。

## 用法

1. **做准备**：选择角色（也可自行选择其他动物并口述），回忆真实特点，在共用画板设计头饰。切换角色不会清空画板，提供撤销及确认重画。真实纸质头饰仍需动手制作。
2. **演与评**：把准备的角色放入节目，隐藏角色让同伴猜，记录特点、依据和安全表达三方面讨论。三个节目独立保存；放入/更换角色会重置当前节目评价，清空仅影响当前节目。不是自动打分。
3. **找共同点**：逐条讨论动物、植物和我们共同的生命特征，再展开提示。避免把植物说成完全不会动，避免把植物制造养分等同于人吃饭。我们也是动物。

表演“说人话”属于创作，不是动物事实。剪裁由教师协助，头饰不挡视线、不勒紧；不追逐、扑咬，不带活体动物上台。允许坐姿手势或口述替代危险动作。
