原创课堂辅助探究稿；教材教参细节待核，不冒充完整教材验收。

## 探究链
先预测挤压袋可证明什么，观察两步机械混合；区分小肠内消化与跨肠壁吸收；对比平滑面与绒毛；记录来源、现象、解释和局限。

## 科学与安全边界
袋不是胃，水不是胃液；机械变碎不能直接证明化学成分变化或吸收。胃液的酸和酶参与消化；小肠为主要消化吸收场所。大分子分解模型不适用于水、无机盐等直接吸收的物质；营养吸收路线不同。绒毛不是筛网，图示不用于真实数量、面积、速度或诊断。
