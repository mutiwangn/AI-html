模型与科学依据

以公开资料约束结构

NIH / NIDDK：消化系统如何工作 ↗
胃的混合与排空；小肠继续消化、吸收大部分营养。

NCI SEER：胃的结构 ↗
不对称囊体、内外弯曲、较窄出口与胃液。

NCI SEER：小肠的结构 ↗
皱襞、绒毛与微绒毛有助于增大吸收表面积。

爱丁堡大学：小肠解剖与组织学 ↗
起始段的弯曲连接；绒毛朝向肠腔，内部有血管和淋巴管。

Blender 建模，不是医学扫描

使用 Blender 4.3.2 Python 脚本建立器官、剖面、皱襞与绒毛，导出同一组网格供本 HTML 显示。没有使用 Blender MCP 连接，也没有下载许可不明的器官模型。

切面是观察窗口，不是真实开口；模型数量、位置、颜色、运动速度和颗粒轨迹都是定性示意。分子图另行放大，与器官不在同一尺度。

消化是在分解，吸收是跨过内壁。只以葡萄糖进入血液为例，不把所有营养物质画成同一路线。蓝色仅区分血管支路，不代表血液是蓝色。

WebGL 可用时使用硬件绘制；否则投影同一组 Blender 网格作兼容显示，帧率与光影会不同。实际教室设备、触屏与系统缩放仍需实机验证。Three.js r160，MIT 许可。
