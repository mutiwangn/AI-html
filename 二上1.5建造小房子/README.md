# 二上1.5 建造小房子
教科版2025二年级上册第一单元《造房子》，参考对应教师教学用书80–88页。

## 使用
打开 index.html，无需网络和打字。三页分别辅助真实课堂活动：
1. 照图制作：搭框架、标门窗、制作门窗，分步骤记录实际完成情况，交换两人分工，安全求助提示。
2. 遇到问题：连接松开、门洞、窗户、材料问题的讨论和修改计划，记录纸上改图及实际改做。切换问题或改法会清除该次标记；一次记录一个问题。
3. 对照交流：对照实物与设计图，分别记录一样/修改/未完成；讨论剩余材料再利用。

所有进度与实物情况均由学生自行报告，不自动检测，也不推断物理性能。按钮不会通知教师；需放下工具举手求助。修改应先标设计图，再制作、观察。示意图不是学生作品。剪切工具须教师指导，开孔、厚材料由教师帮助，不用玻璃或尖锐碎片，不对模型实施重物加载。

记录仅本次页面内保存，刷新清空；全量清空须点两次。建议结合纸质图纸、真实模型操作并截图留存记录。

## 验证
脚本语法检查通过。受支持云浏览器真实预览验证：步骤切换、独立进度、分工与准备状态、求助提示、问题选择与改法、图纸标记/实作记录、切换问题清空、实物对照状态、尖锐材料提示、全量复位。1180×757视口三页均文档高度757px，一屏呈现；第三页复位提示亦无溢出。实体希沃、平板及手机未测试，窄屏单列可滚动。

建议能力级别 T1；原创内嵌SVG，单体HTML，无外部依赖。
