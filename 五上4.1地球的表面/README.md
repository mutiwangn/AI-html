# 五上4.1《地球的表面》v2.2

世界球体 → 中国地形案例 → 五大地形的三页互动课堂。单体HTML，无外部运行依赖；支持球体旋转展开、15案例、5类教学及5份来源模型、剖切描摹、卡片分类、PNG/JSON导出和进度导入。

中国页是**非地图的案例索引与西高东低总体趋势示意**，不表示国界或行政区划，宽高不按比例，非实测DEM。原地图未取得可核验的公开使用与审图依据，没有包含于本版。地理定位应结合教材的合规地图。

教学模型不是15个地区的实测复原。AI插图及底座土层不代表实测地质。来源GLB的河谷、环形坑、台地组合不作为教材分类答案。CC BY 4.0作者、原作、许可与修改说明见网页“素材与说明”和THIRD_PARTY_NOTICES.txt。
