# 五上3.2《用重力驱动小车》

三页单体HTML互动课堂 v1.0，主入口 `index.html`。内联SVG与ES5 JavaScript，零外部图片、字体、脚本依赖；按本项目标准标为T1基础交互。页面无校名与姓名署名。

## 课堂活动

1. **重力实验室**：点击或拖拽垫圈调整悬挂数量；不推车、直接释放。支持暂停、四分之一速度慢放、力的方向、等时间位置点与拖动回看。正常完成60厘米测量后自动记录，车辆继续运行；垫圈落地后绳松，小车滑行减速或被挡停。提前松绳用于观察，不加入同条件测量。
2. **比较与记录**：独立保存模拟和实物数据，保留三次原始用时、平均值及同刻度条形图；不足三次明确标注已测次数；未起动不计为零秒。不同距离、车质量分组保存，不混合求均值。可导出UTF-8 BOM CSV。数据保存在当前浏览器，存储不可用时仍可操作与导出。
3. **3秒到站**：在高架实验台让小车行驶1米，在3秒内尽量接近3秒。可改垫圈数和小车载荷，自动保留尝试；2.85–3.00秒显示精准到站。计时线与车头对齐，经过计时线后动画继续。

## 模型边界

采用轻绳、理想定滑轮和水平路面模型，忽略滑轮转动惯量、细绳质量及空气阻力。悬挂物质量为m，小车与车载物质量为M。牵引阶段 `a=(m*g-f)/(M+m)`，`T=M*a+f=m*(g-a)`，所以加速时绳张力不等于悬挂物重力。另设静止起动阻力阈值。

实验室：空车200克，垫圈每个10克，重力加速度9.8m/s²，起动阻力0.14N、运动阻力0.10N，测距0.60m、下落空间0.65m、车位移止挡0.78m。当前模型1个垫圈不能起动，不代表所有实物器材都如此。

挑战：总车质量200–800克，每次10克；阻力随总车质量成比例缩放。测距1.00m、下落空间1.15m、止挡1.22m。计时按解析轨迹计算，与画面帧率、慢放倍率独立。相同条件重复模拟得到相同结果，不添加伪造实测误差。

## 后续素材替换接口

- `window.GravityPhysics.create(options)`：纯物理模型；返回 `summary` 与 `stateAt(t)`。
- `window.GravityArt.cart(...)`、`window.GravityArt.scene(state, physicsState)`：SVG渲染接口，与物理计算独立。
- `window.GravityRecords.mount(...) / addTrial(...) / getData() / getCSV()`：记录接口。
- `window.GravityApp.showPage('lab'|'records'|'challenge')`：活动导航。

如替换小车、滑轮与垫圈外观，应保留车头计时基准、绳的固定连接点、同一场景横竖相同位移比例，以及悬挂物落地/松绳后的运动阶段。
