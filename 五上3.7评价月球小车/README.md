# 评价“月球小车”

五年级上册 · 第三单元《运动和力》 · 第7课

本课件用于学生完成实物小车制作之后的测试、诊断、改进与交流。通过剖面观察、视频慢放和数据对照，帮助学生把“车没有顺利通过”的现象转化为可以讨论的证据，再提出改进方案，回到实物测试中检验。

## 教材依据

- 《科学》五年级上册，第7课《评价“月球小车”》，教材印刷页90—93。本课包含“测试和改进”“展示和交流”两个板块，要求检查作品与设计方案的一致性、共同制订评价标准、开展测试、分析问题、改进并交流。
- 前一课《制作“月球小车”》，教材印刷页86—89。示例任务为：材料价格不超过100元，小车质量不大于100克，载1块橡皮，在10秒内通过测试沙坑。教材明确允许按学校实际调整指标；100元只是示例，实际价格应依据调查。
- 《科学教师教学用书》五年级上册，“第7课 评价‘月球小车’”。教学重点是依据评价表开展测试，难点是从测试中发现的问题分析可能原因并提出解决方案；调整后应再次进行实地测试。
- 《义务教育科学课程标准》相关5—6年级要求：“13.1”关注工程的限制条件和验收标准；“13.3”要求利用工具制作简单实物模型，根据实际反馈结果进行改进并展示。

上述依据来自本项目提供的教材、教师教学用书和课程标准文件。本目录仅记录来源与设计依据，不包含教材全文。

## 三个工具

| 工具 | 学生可以做什么 | 补充的观察与思考条件 |
| --- | --- | --- |
| 剖面诊断 | 改变小车条件，观察车轮、车身运动及受力关系，保留对照并反复观察 | 放大现实中难以同时看清的接触与传动过程，区分动力不足、打滑等现象，为改进提出可检验的解释 |
| 慢镜取证 | 导入本组实物测试视频，暂停、慢放并回看关键时刻 | 让一闪而过的走偏、空转、停滞等过程可以重复观察，围绕同一段证据交流 |
| 实测评价 | 整理真实测试结果，对照任务要求，比较改进前后表现 | 将多次测试和不同版本放在一起比较，关注是否达标、结果是否稳定以及成本和质量等限制 |

模拟现象用于帮助理解和提出假设；实测记录与视频用于讨论真实作品。两者应分别标明，不把模型计算当作学生真实测得的数据。

## 课堂中的使用方式

本课件适合40分钟课堂中的阶段性使用，教师可以按实际问题自由切换工具，不必按页面顺序完成固定流程。

1. **测试前**：结合上节课的设计与材料清单，共同确定质量、价格、载荷、通过时间等标准，并约定测试场地与光照条件。网页默认的100克、100元、10秒、1块橡皮只是教材示例，应以班级协商后的任务为准。
2. **实物测试时**：学生分工完成释放小车、计时、记录和拍摄。保留未通过的试次，同时记录当时的场地、光照和载荷等条件。
3. **遇到问题时**：先用真实视频慢放寻找现象，再借助剖面模型讨论可能机制。引导学生说明“看到了什么”“可能是什么原因”“准备改动什么”，避免根据一个现象直接认定唯一原因。
4. **改进之后**：在尽量相同的条件下重复实物测试，比较改进前后的记录。展示所依据的证据、改动及其效果，也讨论增加成本、质量变化等取舍。

团队合作和外观装饰等评价需要师生结合实际表现协商判断，不能由模拟速度或通过结果代替。展示交流应允许多种方案，不将“最快”直接等同于“最好”。

## 科学模型的适用范围

- **地球课堂条件**：场景是地球上的小车模型与模拟沙坑，未模拟完整月球环境。100克物体在地球上的重力约为0.98牛，可近似看作1牛；质量与重力不能混用，不能将这一对应关系直接套用于月球。
- **教学模型，尚未按实物标定**：模拟参数用于表现变量之间的关系，不能预测某一套真实材料的准确用时、牵引力或通过能力。具体结果还会受到材料、电机、安装、光照与沙地状态等因素影响。
- **区分转动与前进**：车轮转动不代表车身一定按相应距离前进。驱动轮受到地面的摩擦作用可以推动小车向前，不能把所有摩擦作用都解释为阻力。
- **区分可能原因与结论**：调整太阳能板、马达或车轮是一种待检验的改进方案。模拟可以帮助分析，但方案是否有效需要实物复测；同一种失败现象也可能有多个原因。
- **公平比较需要相同条件**：光照、载荷、路线和沙地状态发生改变时，前后结果不能简单归因于某个零件的改动。未通过不等于用时为零，也不能只保留成功试次。

## 运行与视频处理

课件采用单体HTML，必要的样式、脚本与图形内嵌，不依赖外部字体、第三方库或在线素材；下载后可直接在浏览器中打开，断网时也可使用核心功能。

“慢镜取证”读取用户主动选择的本地视频，在当前浏览器中播放和处理，不将视频上传到服务器。视频文件不会被打包进课件；关闭或重新打开页面后，需要重新选择视频。能否播放取决于设备浏览器对该视频编码的支持，建议使用设备常用浏览器可直接播放的MP4文件。

希沃一体机可使用浏览器全屏展示；学生也可在平板上操作。设备、浏览器与视频格式的实际兼容性以发布前和课堂前的运行检查为准。

## 视频替换保护修订
新视频在独立元素中读取，首帧可读、时长和画面有效后才替换当前槽；失败保留旧视频和起终点。成功替换只清该槽标点，并暂停共同回放。新选择、标点或切页可取消待载任务；后续解码出错会提示并保留标点。首帧有效不等于全片无损。视频仍仅在内存，刷新须重新导入。

真实浏览器验证有效MP4、播放标点后损坏替换仍保留旧片；双槽同步、PNG对照导出和实测表传入亦已检查，但这些扩展流程在最终增加提交暂停前执行，最终仅重测单槽播放/标点/损坏替换。精准竞态、超时、替换失败等为隔离测试；大文件、所有编码和真机未验。

**本次没有修复实测表本机缓存保护，该风险仍待处理。** 不将视频替换保护等同于实测数据全面安全。使用前请保留重要实测资料副本；旧版保留于 Git 历史。
