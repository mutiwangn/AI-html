# 五上1.5《观察细胞》

单体 HTML 互动课堂 v1.0，配套本项目提供的五年级上册第一单元“微小世界”第5课。

- [打开课件](./index.html)
- [下载版本文件](./五上1.5观察细胞_v1.0.html)
- 技术需求：**T1 基础交互**；核心为 HTML/CSS/JavaScript/SVG，无外部运行依赖。照片压缩和 PNG 导出按需使用 Canvas。
- 课件页面与浏览器标题无学校、姓名署名；只保留低干扰 mutiw 水印。

## 教学定位

依据上传教材印刷页18—21（PDF第22—25页）及教师用书《观察细胞》相关章节：从洋葱表皮到多种动植物细胞，边观察边画图，再比较形态和结构。真实显微观察仍是课堂主体，网页适合穿插使用。

数字技术重点补充两种困难：学生轮流看镜后不易稳定并排比较；显微照片中的二维特征不易与细胞的立体结构建立联系。不重复上一课显微镜调焦训练，不自动生成观察结论，不搬入作业本题目。

## 两个工作区

### 观察与记录

- 内置洋葱表皮、口腔上皮、叶片叶绿体、神经细胞、保卫细胞、根尖细胞及食盐晶体7张教材参考小图，分别标明资料来源。
- A、B 可独立选材料、移动、缩放、圈画；切换材料保留各自的笔迹和视图。
- “A 留作 B 对照”保留当前 A 的底图、位置、缩放、透明度和笔迹；然后可在 A 换材料比较。
- “底图”连续淡化后留下学生自己的描画，也可选择“我的观察图”空白绘图。问号只标记观察中的不确定，不自动判断结构。
- 可导入本机显微照片；图片不会上传。导入照片标注“本机导入照片 · 尺度未校准”。大于1920像素的图片可能在本机等比例缩小以控制内存。
- 支持撤销、清空、复位和 PNG/SVG 导出。存在观察记录时，复位会先提示；关闭或刷新页面前请导出记录，未承诺跨次自动保存。

### 立体与切面

- 洋葱鳞片叶内表皮、叶片细胞、口腔上皮三种简化结构模型。
- 直接拖动虚线平面、滑动“切面位置”或使用方向键，联动观察立体模型上的交线与二维理想切面。
- 保留 A 后，可改变当前 B 的层位或物种。A 保持原条件，可替换或清除。
- 默认隐藏结构名称；点击结构或“显示名称”才展开，避免开场堆满细胞器标签。
- 支持复位和完整 PNG/SVG 结构图导出。

## 科学模型与边界

1. **这是几何切面，不是显微镜焦面。**模型用于解释二维截面与立体结构的关系，不模拟普通光学显微镜的成像。实际可见性还受透明度、染色、焦深等影响。
2. 细胞核是球体，截面半径按 `sqrt(r²-(z-z0)²)` 计算；液泡、叶绿体采用椭球，二维截面与立体投影共用参数，结构相交面积连续变化。没有切到某结构，不代表整个细胞没有它。
3. 植物细胞壁、细胞膜分开；洋葱鳞片叶内表皮模型无叶绿体，所示叶片细胞有叶绿体；口腔上皮模型无细胞壁、叶绿体或中央大液泡。只呈现少量与本课比较相关的结构，未画出所有细胞器。
4. 模型颜色、厚度和大小是教学示意，不按真实比例，不输出虚构微米测量。植物最上/最下薄层只显示外壁；动物细胞外形以扁椭球简化。
5. 资料照片未统一尺度；画面缩放不是显微镜光学倍率，不能据屏幕显示大小比较真实细胞尺寸。参考图分辨率有限，放大不会增加细节。
6. 不以“未看到细胞核”判定非生物；食盐晶体用于比较规则边界，不设置形状自动分类。未将土壤概括成没有细胞或没有生物的材料。
7. 模型呈现预设关系，不能当作独立验证自身规律的实验证据。应与实物观察、教材资料和学生记录相互核对。

科学核对资料：

- [Ohio State University at Lima：Cell Organelles Microscopy](https://lima.osu.edu/biology-microscopy/organelles)（染色增强核的可见性；部分叶细胞图像中核不常可见）
- [Ohio State University at Lima：Plant Anatomy Microscopy](https://lima.osu.edu/biology-microscopy/plant-anatomy)（保卫细胞、气孔及叶绿体区别）
- [OpenStax：Eukaryotic Cells](https://openstax.org/books/concepts-biology/pages/3-3-eukaryotic-cells)（典型动植物细胞结构）

## 图像来源

内置7张小图节选自用户向本项目提供的教材《五上》相关页面：洋葱表皮为第18页；口腔上皮、叶绿体、神经、保卫与根尖为第20页；食盐晶体为第21页。只提取相关小图，未包含教材整页，保持原有像素尺寸并压缩嵌入，不做AI补绘或增添不存在的观察细节。原图权利归原权利人，本课件不将这些图像重新授予开放许可。

结构图由代码绘制，属于明确标识的示意模型。后续可在 `CELL_ASSETS` 替换内置图片，在 `CellObserve` 调整记录交互，在 `CellStructure` 的 `MODELS` / `sectionGeometry` / `sectionFeatures` 调整科学参数与同源绘制。

## 验证记录

- 浏览器运行：Chrome，实际运行验证页面切换、材料切换、移动/圈画、问号、淡化底图、保留对照、本机文件导入、结构层位调节、平面拖动、名称开关、A/B对照、复位与图像导出。
- 布局：1366×768课堂横屏、1024×768平板横屏均无页面整体溢出；390×844窄屏按上下重排并允许滚动。尺寸检查使用浏览器中的固定尺寸测试框，非实物设备测试。
- 导出：已实际生成并打开观察图 PNG 和结构图 PNG；SVG独立包含图像、来源与当前记录。
- 科学一致性：核投影、液泡连续截面、三种细胞0—100%层位有限值检查通过；教材照片标签与原页核对。
- 无外部脚本、样式或图片加载依赖；不使用 WebGL、摄像头或麦克风。
- 未在希沃实机、Safari或旧版iPad上实测；触控采用 Pointer Events，旧浏览器结构区可使用原生滑杆。此等级表示技术需求，不是全部设备的实测保证。
