# 三上3.6 运动和能量
独立重制辅助稿。原创SVG，HTML与app.js同目录，无学校/真实姓名署名、第三方素材或可见技术层次。教材教参待核，非整课验收。

同一斜面两释放标记的三阶段示意，不伪造速度/碰撞位移。预测、五项公平与安全条件、同球两高度各三次木块位移实测；零与未测分开，组间范围不交叠/重叠/反向情况分别解释；保留预测与条件确认数导出CSV。生活联系运动物体对其他物体作用。

模型不计算精确能量，不把木块距离作为直接能量读数。只在同球、同装置、自然释放、摩擦条件可比时讨论高度趋势。记录仅内存，不上传。

验证：node语法；Chrome释放高度/阶段切换、作用证据反馈、计划0/5到5/5、缺测与0、两组三次不交叠与重叠提示、CSV下载。修复SVG标注重叠及结论不应默认用户预测正确的文案。截图复核。实体触屏、旧浏览器、课堂验收与教材教参未核。
