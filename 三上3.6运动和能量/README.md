# 三上 3.6《运动和能量》

[打开互动网页](./index.html)

单体 HTML 课堂互动初稿，面向希沃一体机全屏展示及学生平板触控。SVG、CSS 和 JavaScript 均内置，无须联网加载素材或第三方库；技术需求为 **T1 基础交互**。

## 课堂任务

| 页面 | 操作与观察 |
| --- | --- |
| 斜面实验 | 调整斜面坡度，让小球从顶端自然释放；观察撞击和木块滑行，测量并记录木块移动距离。 |
| 比较证据 | 从各次碰撞后同步回看木块运动，在同一把尺上比较滑距，再根据现象讨论运动能量。 |
| 生活中的能量 | 观察足球、水车和风车，寻找运动物体使其他物体发生变化的证据。 |

课堂可先让学生预测，再操作观察、重复比较；科学结论由师生依据证据讨论形成。真实小球撞手的触觉体验仍用课堂实物进行，网页不代替触觉或真实实验记录。

## 教材依据与科学边界

依据本项目提供的教科版三年级上册《科学》第三单元第6课《运动和能量》（教材印刷页 **73–75**），及配套《教学用书》本课内容设计。

- 核心实验保持同一小球、同一斜面长度与材料、同一木块及接触表面，并让木块每次回到相同起点；小球从斜面顶端静止释放，不额外推一把。
- 固定斜面长度后，改变坡度也会改变小球的起点高度。讨论应限定在当前装置与控制条件下，不能把“坡度越大”单独表述为普遍的能量规律。
- 木块的移动距离是比较实验中的**间接证据**，单位为长度；它不是能量的单位或精确能量读数。比较时量取木块同一边缘前后的位移。
- 运动物体具有能量。比较同一物体的运动快慢时，应保持其他相关条件一致，不使用不同质量物体的运动速度直接判断谁的能量更大。
- 页面显示的数值来自简化模型，属于**模拟数据，不是学生实测结果**。它用于观察变量关系，不能替代真实实验的测量、重复和讨论。

生活页封装为 `window.LifeEnergy`：`init()` 初始化，`tick(dt)` 由主动画循环传入秒数，`pause()` 在离开页面时停止输入，`reset()` 重置当前情境。足球、球网、水车和风车的 SVG 替换入口依次为 `life-football`、`life-net-mesh`、`life-water-wheel`、`life-wind-wheel`；替换球网时须保留球心接触高度与网边形变同步的关系。

## 模型与图形接口

`MotionEnergyModel.create(angle)` 与 `sample(model, time)` 分离物理和画面；`EnergyArtwork.ball(x, y, angle)`、`EnergyArtwork.block(x, y)` 是实验页图形替换入口。物理量使用米、秒，界面转换成厘米。

同一实心球沿固定0.60米斜面滚下，进入水平段后减速，与木块中心碰撞。碰撞后木块滑动减速；球保留自转，短暂滑动后反向滚动停止。模型使用固定参数（球0.03千克、木块0.15千克、恢复系数0.80、木块摩擦系数0.06）；这些数值仅用于定性教学模拟，不对应某套真实器材。坡底接头按理想瞬时转向处理。

比较页只同步碰撞后的木块滑行，不表示各次小球同时抵达木块。实际课堂仍应完成真实测量与讨论。
