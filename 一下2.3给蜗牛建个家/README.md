# 一下 2.3 给蜗牛建个“家”

一年级下册第二单元《常见的动物》第三课课堂辅助网页。打开 index.html 即可，单体 HTML，无登录、外部依赖或文字输入。

## 课堂流程

1. **画个计划**：学生自由画家，选想准备的材料，向同伴解释休息、活动和通风安排。选择不是标准答案或自动建造。
2. **一起建家**：真实搭建后逐项核对，按钮依次切换“还没检查 / 已检查 / 需要调整”。容器图仅为示意，不代表实物检查结果。
3. **观察照顾**：三次独立记录身体活动、所在位置和进食情况，跨次汇总方便比较。不预填动物反应，不从静止或缩壳自动判断环境好坏。

在教师指导下使用清洁、安全、适合的材料；保持湿润但不积水，通风且防止爬出，避开太阳直射，清理腐烂菜叶。不要硬拉蜗牛或把它放入水中，操作后洗手。观察结束由教师送回原来找到它的地方，不随意放到新地点。
