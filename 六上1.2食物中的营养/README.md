# 六上1.2《食物中的营养》

三页单体互动课堂 v1.0。SVG、CSS 与原生 JavaScript，核心运行无外部请求，下载 `index.html` 后可以离线打开。技术等级 T1。

## 教材定位

依据本项目提供的教科版《科学》六年级上册第一单元《健康生活》第2课：教材印刷页6—9，配套教师教学用书印刷页51—63。

保留线下的昨日食物调查、阅读营养资料、分组检验和实物包装阅读。网页主要用于实物探究后的证据比较、时间回看和数量换算。

## 三个探究任务

| 页面 | 主要交互 | 数字技术增加的视角 |
| --- | --- | --- |
| 碘酒找线索 | 拖滴管或点样品；纯淀粉、清水与米饭/馒头/白砂糖/熟蛋清并排比较；检验后再打开成分线索 | 将检测结果与成分资料放在同一画面，辨析“未检出淀粉”与“没有营养” |
| 油迹时间机 | 水、食用油和食物样品同步涂抹；拖动时间、播放/暂停；迎光观察；花生米/黄瓜切换 | 可倒回干燥前，保持纸张和观察条件一致，比较随时间改变与保留的斑迹 |
| 标签放大镜 | 三份教学模拟标签；调节实际食用质量；100克/整包快捷设置；数字与同尺度条形联动 | 将每100克的数据即时转换成实际一份，比较不同单位与未标示信息 |

建议将网页分段嵌入课堂，合计约10—15分钟，不必从头连续演示。碘酒和油迹模拟应与学生真实实验相互核对。

## 科学边界

- 碘酒用于检验淀粉，不是全部糖类或全部营养的检测器。未出现蓝紫色表述为“这次没有检出淀粉”。接触处局部变色不表示整份食物全部变色。
- 成分资料只列部分成分；图形、符号不表示真实分子外观或含量，不能由图标个数比较营养多少。
- 油迹是定性线索；干燥速度受条件影响，因此时间轴不标真实分钟，也不由斑迹大小、深浅推算脂肪克数。
- 黄瓜显示“未见明显油迹，不能证明完全没有脂肪”。
- 标签全部为教学模拟，不指向任何真实品牌或营养数据库。所有分量以质量克为基准；能量用千焦，钠和钙用毫克。三个样品的克数条形共用同一尺度。
- 换算公式为“每100克标示量 × 这一份质量 ÷ 100”。未标示项保留未知状态；未列出不等于没有。碳水化合物不等于白砂糖。
- 不做食物好坏排名、个人膳食需求计算或下一课的配餐任务。

## 记录与操作

右上角记录按钮可查看模拟记录，另有实物观察补录区域。两种来源分别标注，保存在当前浏览器本机，支持逐条删除和 CSV 下载。最多保留最近60条。不上传任何观察记录。

顶部三项切换探究任务；右上角可进入全屏。支持鼠标、触控与键盘；Alt+1/2/3切换任务，Escape关闭弹层。切页及页面不可见时暂停油迹自动播放。

## 后续替换接口

- `FoodVisuals.render(id)`：替换碘酒页的SVG食物和器材图形。
- `IodineLab.samples`：独立的样品名称、定性检验结果与成分资料配置。
- `OilLab`：油迹页的独立状态与绘图模块；`init/reset/pause/getState`。
- `FOOD_LABELS` 或 `LabelLab.setProducts(array)`：替换每100克数据与包装质量；未知值用 `null`。`LabelLab` 另提供 `init/reset/pause/getState`。
- `NutritionLesson.getState()`：读取当前页面与记录；记录与图形分离。

## 验证

在 Chromium 153 中完成1920×1080、1366×768、1024×768、390×844的三页布局与中文截图复核，主界面保持一屏。完成鼠标拖滴管、触控点击、样品切换、阴阳性对照、成分展开、时间回看、迎光判断、播放暂停、份量换算、标签说明、全屏、记录补录、刷新保留和CSV实际下载检查。离线 `file://` 核心流程通过，运行中无外部资源请求、无页面脚本错误。

实体希沃一体机、旧版iPad Safari及不同设备的全屏/下载行为仍需真机核验。截图使用测试环境的中文系统字体；课件本身没有字体下载依赖。
