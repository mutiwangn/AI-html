# 六上 1.2 食物中的营养
原创课堂辅助探究稿；教材教参细节待核。

## 探究链
预设淀粉碘液概念检验：先判断，再看待测甲，补已知淀粉和清水对照；比较水/油纸迹湿润与干燥；虚构营养标签按25–200g份量换算，并保存蛋白质比较；独立记录来源、条件和现象解释。

## 科学与安全边界
颜色不是实测或反应时间。设定甲含淀粉，模型不能识别实际食品。阴性不能排除低含量/取样/干扰，淀粉不等于全部糖类或营养；油迹只是线索，非定量或成分特异分析。真实示范由教师按学校规程组织，试剂实验材料不入口触眼，不要求自行配置或试吃。
标签数据人为编写，非完整法定标签，不代指食品或推荐份量；A每100g蛋白8g、B5g，50gA为4g而200gB为10g，须区分密度和份量。钠mg与其他g不直接相加。无个体营养、体重或医疗评分，不收集真实饮食、过敏病史或姓名。
记录仅内存，手动CSV下载；模型结果不自动进入实测表。
