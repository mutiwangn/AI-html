## 两个观察视角

| 场景 | 核心操作 | 数字技术补充的观察条件 |
| --- | --- | --- |
| 看进地底 | 拖两侧箭头或加载条；改变挤压/拉伸；切换破裂范围；拖动A观察点；暂停、慢放、回看和震前轮廓 | 已有断层暂时锁住，周围岩石积累弹性形变，随后突然滑动；同步观察永久错位、向外传播的能量示意和岩石标记的局部往返振动。 |
| 追踪河谷 | 改变坡体条件、拖动河道；保持模型震动相同；留作对照A并在同一进度回放 | 从震动触发滑移、坡脚减速、停积位置和河道的相对关系，一直追踪到堵河后的蓄水与越顶出流，比较并非必然发生的连锁变化。 |

“保存这一刻”最多保存4幅当前模型画面，可在证据夹预览，并导出带条件与观察阶段的 **SVG证据图**。它保留观察依据，不自动填写学生的解释。

## 课堂使用

实物活动后，先让学生比较实验能看见什么、地下还缺少哪些观察条件。第一页可在错动之前暂停，再回看地面开始晃动的时刻；用“震前轮廓”区分短暂往返振动与留下的错位。拉伸和挤压改变运动方向；地下破裂与地表破裂是两种示意条件，不必都操作完。

第二页可先观察“易滑动坡体＋河道7.6格”，保留对照A，再只改变河道位置或坡体条件。对照A保存的是该组条件的完整模型过程，并与当前时间轴同步显示，避免用不同阶段作比较。强调水从上游持续流入，蓄水过程可能在短时震动结束后继续。真实蓄水时间通常远长于震动，本页压缩了这种时间差。

## 状态规则

- 改变挤压/拉伸或破裂范围，会重新开始第一轮模型；复位恢复本轮初始状态。初次“开始加载”设定一组默认加载目标。暂停恢复保留自选加载目标；亚临界加载完成后，按钮明确显示“继续加力”。
- 第一次突然错动后冻结远端加载，便于观察释放和传播；再次施力需要复位。第一条时间轴只回看已经发生的过程，播放到已记录末尾后可继续未完成的模型。
- 河谷改变条件会回到震前，保留对照A；本页“复位”恢复默认条件并清除A。拖动时间轴可观察任意模型阶段。
- 切换场景、打开说明或证据夹、页面隐藏时暂停播放。所有观察记录仅保留在当前会话，刷新清空。

## 科学模型与边界

### 地下断层

`EarthquakeModel` 是单次事件的等效弹簧与摩擦滑块模型。锁定期间弹性力与相对形变相关；达到静摩擦阈值后停止远端加载，求解带动摩擦、阻尼的滑移，第一次速度降到零后再次锁定。能量在弹性储能、运动和未细分的不可逆转换之间核算，停稳后留下永久位移。

挤压和拉伸使用相同的标量机制，渲染方向不同。岩块的相对位移沿同一倾斜断层；未到地表时，近地表错位通过平滑权重减弱。该表达用来区分“地下突然错动”和“是否出现明显地表错断”，不预测真实地表变形。释放量不全部等于地震波能量，摩擦热等未单独表现。

波前与A点记录是带传播延迟、衰减的可视化示意，不是实测地震图，不区分P波与S波。岩石标记只在原位置附近往返振动，不随波传播到远方。并非每次地震都有地表裂缝，褶皱也不是每次地震的必经阶段或可用预兆。

### 滑坡与河流

`ValleyModel` 比较两种初始均稳定的等效坡体，保持震动输入相同。较低的静摩擦条件可被本次震动触发；滑移后计算沿坡加速和水平段摩擦减速。滑落物采用固定宽度，只有启动并停稳后完整横跨河床才判为本模型的堵塞；部分覆盖保留通水路径。

固定来水量与出流量的差累积为新增水量。水位超过模型堰顶后出现越顶出流，水位上升逐渐减缓。示意省略碎屑破碎、反弹、复杂侵蚀、渗漏、三维堆积、分流与溃坝。

**两页的距离、形变、加载、时间和能量均为模型量，不能换算成真实米数、牛顿、震级、地震时长或灾害概率；也不能把模拟输出当成独立验证其预设规律的自然证据。**

## 运行与维护

直接在浏览器打开 `index.html`。样式、SVG和脚本均内嵌，无外部库、图片或字体依赖，核心功能可离线使用；资料链接需要联网。课件无学校姓名署名，只保留低干扰 `mutiw` 水印。全屏不支持或请求失败时有提示。

| 入口 | 作用 |
| --- | --- |
| 第一段脚本 `EarthquakeModel` | 断层加载、摩擦、阻尼、滑移与延迟振动的纯模型 |
| 第二段脚本 `ValleyModel` | 坡体滑移、河道覆盖和水量连续性的纯模型 |
| 第三段脚本 `P` / `Q` | 场景状态、播放与回溯、观察点和同步对照 |
| `faultSVG()` / `mapRock()` | 岩层与断层资产、标记和波前表现；替换材质时保留模型输出 |
| `valleySVG()` / `debrisPath()` / `lakePath()` | 河谷、堆积体、水流、蓄水和越顶出流表现 |
| `EarthquakeLab.getState()` | 只读状态审阅入口 |

## 已验证范围

- 纯模型：检查亚临界加载与卸载、阈值触发、7种步长、能量核算、传播延迟与复位；河谷5组条件共4205帧检查同一震动输入、停积位置、河道覆盖与水量守恒，水量误差约2.94×10⁻¹⁴。
- 浏览器实际运行：挤压/拉伸、两种破裂范围、暂停与继续、回溯、复位、A点直接拖动、坡体与河道条件切换、同步对照及证据夹保存。
- 浏览器视口：1363×936、1280×720、1024×768横屏无整体滚动；768×1024和390×844竖屏按纵向重排，无横向溢出，允许纵向滚动。
- 证据图合成与预览已运行，导出SVG结构已通过XML解析和唯一ID检查；当前测试浏览器未返回下载完成事件，因此未把设备上的下载落盘列为已验证项。保留可再次点击的下载链接与独立预览入口。
