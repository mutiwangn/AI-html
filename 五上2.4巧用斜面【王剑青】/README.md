# 巧用斜面：搭建与投影比较

五年级上册第二单元第4课的并列版本。本次修订保留原有材料、搭建与相机交互；目录中原有署名不变。

## 面积口径
侧视标尺、右栏、真实俯视图和3D小窗统一使用全部已安装斜板与桥墩的地面投影轴对齐包围矩形。计入空隙、板端余伸、板厚投影及未接入路线的已安装材料；不计固定高台、地面、未安装平放素材和拖动预览。这不是实体投影并集，也不是实际安全通道面积。

不再显示未经同口径比较的“省地百分比”。转弯或折返不保证省地，需在同高度、负载及坡度等条件下比较具体方案。俯视图按真实横向坐标投影，上层可能遮住下层。

## 保存与恢复
搭建更改仍需主动保存或导出。保存、读取及覆盖会确认；无效或无法读取的缓存不会被普通保存覆盖，可导出原始缓存和当前草稿。恢复备份先完整验证、确认后替换当前搭建，不自动写入本机缓存。明确替换受保护缓存前须备份并确认下载可找到。写入失败不会报告成功。

新保存保留平放木板。旧文件曾遗漏的平放木板无法自动找回。原始缓存导出为最近成功读取或保存的快照，不支持跨标签自动合并。

## 兼容与验收范围
T2：Canvas 立体小窗配合 SVG/DOM 搭建，无需 WebGL。浏览器已检查四个示例、面积一致性、保存/刷新/读取、真实文件导入导出及坏文件保护。故障缓存、配额失败和模型角点对照采用隔离测试，不等于真实浏览器配额故障验证。最终库存及保存状态提示调整后复查了示例，未重新跑完所有导出流程。旧 iPad、希沃真机及所有拖拽/并发文件选择组合未实测。

本版本原文件保留于 Git 历史，可恢复。其他并列版本不受此修订影响。
