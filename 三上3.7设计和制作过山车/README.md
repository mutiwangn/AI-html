# 三上 3.7《设计和制作“过山车”》

[打开互动网页](./index.html)

双页单体 HTML 互动工坊 v1.0。面向希沃一体机全屏展示、电脑与学生平板触控。内置 SVG、CSS、原生 JavaScript，无联网字体、第三方脚本或模型，技术需求 **T1 基础交互**。单独保存 `index.html` 即可离线打开。

## 课堂任务

| 环节 | 学生操作 | 形成的证据 |
| --- | --- | --- |
| 设计路线 | 接入直轨、弯轨；拖动圆点；点击一段轨道切换形状；沿轨道测长 | 有起点和终点的俯视设计图，平面路线长度与直曲组合 |
| 搭建试跑 | 上下拖动支架，或用滑块、加减按钮调高度；从静止放球；暂停观察、回到起点、修改再试 | 是否能自动到终点，停滞、接口折角、轨道相撞或凸顶失去支持的位置 |

初始路线长约 1.79 米，故意保留“还需要延长”的设计任务。接入一段弯轨可得到约 2.53 米的平面路线；默认高度下实际轨道约 2.58 米，能够自动跑通。学生可以继续改变路线与高度，不使用固定关卡、竞速计分或自动给出全部科学结论。

设计在当前浏览器本地自动保存；可撤销操作，也可在“课堂使用”中恢复起始方案。下载按钮导出包含接点编号、支架高度和小组记录空格的 SVG 设计图，用于指导实物制作。合作表现、实际搭建质量由师生观察，网页不自动评分。

## 教材依据

依据项目提供的教科版三年级上册《科学》第三单元第7课，教材印刷页 **76–78**（原 PDF 第78–80页），以及配套《教学用书》第7课正文。

任务要求为：轨道在 2 米以上，同时有直线与曲线，小球从高处自动滚完全程且不脱轨，小组合作完成。设计图应标起点与终点，接口需平滑通畅，终点宜保留在底座边缘，实际搭建可由低处终点向高处起点推进。第8课《测试“过山车”》的系统测时、快慢与能量比较不在本课展开。

本网页是设计和改进的辅助工具。教材中的合作搭建、真实器材连接、测量与反复试跑仍应在课堂完成；不把网页操作等同于完成实物工程任务。

## 测量与物理边界

- 设计页显示 **俯视平面路线弧长**；搭建页显示 **含高度起伏的三维轨道中心线弧长**，不是屏幕投影长度，也不是起终点的直线距离。设计图中的格线间距为 20 厘米。
- 小球从静止释放，不施加额外推力。采用实心球无滑动滚动模型，重力切向加速度系数为 `5/7`，重力加速度 `9.81 m/s²`；滚阻模型为 `μmg cosθ`，固定 `μ=0.012`。这些参数用于定性教学，不代表某套真实材料的测定值。
- 小球沿离散轨道采用分段解析运动，避免不同帧率凭空增加能量。平坦或上坡起点不会自行出发；无法翻越的后方高坡会在能量耗尽处暂停，便于学生观察改进。本稿暂停失败画面，未继续模拟回滚。
- 支架附近使用单调 Hermite 插值连接高度，保持支架位置的准确高度，避免插值产生不存在的高峰。弯轨的俯视曲线采用连续 Bézier 路径；明显的水平接口折角会标记并暂停试跑。
- 开放槽轨道的竖向失去接触使用支持力判据，与局部曲率和速度共同相关，不按“起点太高”随机触发。侧壁的侧向约束作理想化处理，未模拟侧翻、横向飞出或真实材料形变。实际防脱轨需要实物测试。
- 交叉处按当前模型的 6.5 厘米轨道高度间距检查空间碰撞，这只是本稿轨道外形的约定，并非通用器材安全值。高低分离的跨越在俯视图中显示上实下虚。
- 动画按 `0.38` 倍物理时间慢放，便于全班观察；页面不显示真实测时数据。本课不用模拟结果代替第8课的秒表测量。
- 小球与接点手柄为便于后排观察而放大绘制；它们的像素大小不是测量尺寸。

## 后续替换接口

最终可运行内容全部位于 `index.html`，两个脚本模块内嵌：

- `CoasterPhysics.prepare(points, options)` 接受米制 `{x,y,z}` 轨道采样点，其中 `y` 为竖直高度；`createRun(track)`、`step(run, dt)`、`pointAt(track, s)` 与图形无关。
- `CoasterApp.getDesign()` 返回 `{version:1,nodes:[{x,z,h}],kinds:[...]}`；`setDesign(design)` 可载入有效方案；`buildGeometry(design)` 生成轨道、长度、交叉与接口信息。`nodes` 为支架位置，`kinds` 为相邻支架间的直/曲轨类型。
- `CoasterArtwork.support(node,index)`、`CoasterArtwork.ball(point,angle)` 是独立图形入口。后续使用精细模型时可保留设计数据与物理引擎，仅替换绘制和投影，不改变测量基准。
