# 五下 2.6 哪个传热快｜基础辅助稿
按已核实的五下目录第二单元“热”第6课归档。匹配版教材正文与教参待核，不宣称完全覆盖教材实验。

原创二维稳态导热桥：假想材料甲k=1、乙k=4；B厚度1–8倍；面积相同、两端温差相同，或选择同温。比较同一时间通过热量，帮助区分材料导热性质和厚度造成的整体传热差别。包含控制变量反馈，不保存或上传用户数据，无外部依赖、无署名。

模型 q=k*dT/L；稳态、一维、均匀、侧面绝热、两端保持恒温，忽略接触热阻。参数为任意教学相对值，不是实际材料数据。箭头不表示速度，色带不表示物质流动。不能据此预测瞬态升温或熔蜡时间，瞬态还涉及密度、比热等。
