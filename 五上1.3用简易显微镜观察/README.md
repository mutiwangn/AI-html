## 教材依据与使用位置

根据本项目所附教材印刷页10—13及教师教学用书“第3课 用简易显微镜观察”核对。核心是用肉眼、放大镜和手持式简易显微镜对比观察同一物体，记录图像、细节和观察范围的变化。本课使用手持式简易显微镜；不混入下一课台式光学显微镜的操作训练。未提供作业本，网页不预设作业本题目或答案。

适合在实物观察与研讨之间阶段性使用，不替代学生打开LED、稳住观察口、转动调焦环和亲眼观察的过程。

## 两个工作区

| 工作区 | 操作及教学增益 |
| --- | --- |
| 定位与扫描 | 选择昆虫足、餐巾纸或彩色印刷；在全貌中拖动取景圆，右侧同步显示对应局部，也可直接拖动右侧图像。整体、放大镜、简易显微镜三档共用同一观察中心。调焦与照明独立可调；“比较范围”显示相对视野。“留住视野”最多保存6处，缩略图可返回原位置；“已看区域”把保存时的图像放回全貌，连接局部与整体。 |
| 对照与记录 | “同点对照”保留当前中心的三档示意图。学生可以画图、圈注、撤销和写自己的发现；也可用空白观察单，分别导入本班肉眼、放大镜和简易显微镜实拍。PNG同时保留三栏图像、圈注、来源和文字；较长记录会自动增加导出高度。 |

可用的问题：“这块局部在整个物体的什么位置？”“只看这一处，足够描述整个物体吗？”“要找另一处相同结构，你会怎样移动？”“需要把图像继续放大，还是先把焦调清？”网页保留证据，不自动填写结论。

## 科学模型与简化

- 三个内置样本均为程序绘制的**结构示意**，不是显微照片。昆虫足不指认具体物种；餐巾纸用不规则纤维交织表示；彩色印刷展示一种简化的CMYK半色调方式，不代表全部印刷工艺。
- 每个样本在1000×1000的统一世界坐标内确定性绘制，再缓存同一张底图。全貌、局部、扫描快照和同点对照都裁切这张底图，切换档位不会随机更换纹理。
- 相对显示尺度为1、4、12，对应固定显示窗口中模型宽度1000、250、1000/12。它们用于可视化图像大小与覆盖范围的关系，**不是器材铭牌倍率，也不是某台手持式显微镜的标定数据**。模型没有毫米、微米标尺。不同器材的实际视野还与视场数和光学结构有关。
- 换档保留中心；观察中心允许移动到样本边缘，超出模型底图的区域以中性背景表示。图像方向保持一致，未模拟不同型号可能出现的倒像。
- 调焦通过与示意最佳焦点的偏差改变模糊程度，LED通过亮暗改变照明，两者不改变显示尺度。采用单一观察平面近似，未模拟完整光路、像差、不同高度结构与景深。
- 保存视野冻结当时的取景、档位、焦点与照明；“已看区域”使用这张快照的实际清晰度和亮暗，不把模糊或暗光记录自动修复成清晰图像。
- 数码放大已有图像不会增加原图中没有的细节。模拟结果不能作为独立验证自身预设规律的实验数据。真实照片未经过尺度校准，不能用画面大小推算实际长度或仪器光学倍率。

- [Nikon MicroscopyU：Useful Magnification Range](https://www.microscopyu.com/microscopy-basics/useful-magnification-range)

## 记录、离线与设备

课件打开和内置模型不需要联网。照片仅在浏览器本页处理，不上传；支持JPG、PNG、WebP、BMP，单图不超过25 MB，导入时将长边压到1600像素。HEIC请先转为JPG。

记录与扫描只保留在当前页面内存，刷新或关闭会清除，请先保存观察图。清空、替换或更换带扫描记录的样本时有确认；主屏复位只恢复取景与调焦，不删除已留住的视野及观察单。记录页不提供含混的复位按钮。

PNG提供生成预览与下载链接；不支持自动下载的设备可以长按预览图保存。全屏由浏览器能力决定，不能开启时有文字反馈。触控采用Pointer Events；旧版浏览器仍需实机确认。

## 验证范围

已在云端Chrome实际运行并检查：

- 三个样本切换、鼠标拖动取景、方向键移动、三档切换、焦点调整和LED开关；变化后视野与全貌位置对应。
- 扫描保存、6处上限、撤回、返回快照及已看区域；改变主视野后取消旧快照高亮。
- 同点三栏、圈注、真实PNG测试图片导入、记录保护确认和取消；照片与模型分别标记来源。
- 1800像素宽PNG生成预览；含七行文字的测试导出高度为1223像素，七行全部可见，圈注和照片均出现在正确栏。自动化浏览器限制了data URL下载读取，因此不宣称已验证下载文件落盘。
- 1280×720与1024×768横屏中主屏、记录页无页面溢出；768×1024竖屏主屏重排，390×844窄屏纵向布局无横向溢出。窄屏切页回到顶部。
- 页面运行无应用脚本错误；一次浏览器扩展自身日志与课件代码无关。全屏请求被云端浏览器拒绝，已核验失败反馈，未宣称成功进入全屏。

以上为Chrome中的实际运行及固定尺寸页面检查，不代表实体希沃一体机、iPad、Safari或旧版设备已经实测。画笔与触控事件机制已实现，未做实体触屏测试。

## 后续修改入口

单文件内分为 `MicroSpecimens` 样本渲染器、`MODES`/状态参数、主观察交互、记录与导出、响应式样式几个部分。替换样本时需保持统一坐标和稳定几何，避免为不同档位分别绘制互不对应的图片。若接入真实仪器视频或标尺，应先增加清晰的来源标记与实测尺度校准。
