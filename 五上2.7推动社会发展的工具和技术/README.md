# 五上2.7《推动社会发展的工具和技术》

v1.0 · 两个工作区 · 单体 HTML · T1 基础交互 · 无外部运行依赖。

## 课题核对与教学增益

依据用户提供的教科版五年级上册教材印刷页58—61（PDF第62—65页），以及对应教师教学用书第7课。教师用书章标题仍写“社会发展与工具和技术”，本课使用教材正式标题“推动社会发展的工具和技术”，同步修正该课首页教材目录标题。未据此假设任何作业本题目。

- **追踪技术**：从独轮车、电动汽车、中国空间站的部件入口，联动查看材料与结构、连接组装、轮与转动、杠杆、电源储能、自动控制、感知探测等技术类别。再选择其他工具，把单向气泡图转为跨工具关系。保留学生猜想、资料状态和可选依据，不自动代写结论，不以连线数量评分。
- **印刷试验场**：同一通知任务下比较雕版、活字、桌面激光打印。调整最终印数、中途改字数量、版或文件是否已备以及供电，使用同一绝对模型时间回放准备、旧版印刷、修订、最新版印刷；支持暂停、拖动回溯、三次记录及对照。模型可压缩课堂难以实际进行的大批量重复过程，让学生分析准备成本、重复复制和内容修订。

实物独轮车观察与制作经验、资料调查和学生口头解释仍应保留。网页提供示意结构、关系追踪和可反复修改的模型条件。

## 使用

打开 `index.html`，或下载同目录的版本文件。两个工作区可自由切换。

关系图可保留最多8条关系；印刷任务可保留最多3条记录。记录保存在本次页面的内存中，刷新或关闭前请导出 SVG。导出文件包含当前条件和学生保留的信息。外部资料链接需要联网；课件本身不需要联网。

## 科学与模型边界

1. 技术包括方法、程序和产品，不等同于实体零件。示意图中的线表示技术应用关系，不是发明时间线；空间站和民用工具共用技术类别，不代表具体装置相同或民用技术由空间站发明。
2. 轮轨高速列车与磁浮列车区分；轮轨列车不能被当作以动力电池为主要牵引能源的汽车。自动控制不等于无人驾驶。未选入某项资料不等于现实中绝对不存在该技术。
3. 印刷准备时间、每份时间及每改一字时间都是可编辑的课堂假设，单位为分钟，保留两位小数；不能用模型结果独立验证现实效率或历史速度。所有方法均不计设备制造与采购，活字假定字库已备；时间模型也不评价质量、技能、耗材、能源消耗及环境影响。
4. 雕版可修版、补刻，并非每改一字都整版重刻。活字需要检字、换字、固定与校验。激光打印通过感光鼓曝光、碳粉转印和热压定影，不是激光在纸上刻字。桌面打印机只代表现代技术的一种例子。
5. 中途修改在各方法印出原任务一半旧版后发生，随后重新印齐全部最新版。旧版单独保留，不自动改变。准备或修订阶段不增加纸张数。印面为镜像，纸上为正字；1—3字修改对应实际字符差异。
6. 无电条件不提供备用电源，激光打印不能开始；人力印刷不需要电源，但仍有人的能量投入。

计算：无修订时 `T = P + N × c`。修订时 `b = floor(N/2)`，`T = P + b × c + k × r + N × c`。`N`为最新版目标份数，`k`为一次修订的改字数，`P`为准备时间（已备版或文件时为0），`c`为每份时间，`r`为每改一字的修订时间。三条流程共用绝对时间轴，保留记录深拷贝当次参数。
