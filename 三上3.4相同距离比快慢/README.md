# 三上3.4 相同距离比快慢
独立重制辅助稿。HTML+app.js，原创SVG，无外部素材、学校和真实姓名署名、无可见技术层次。教材教参待核，非整课验收。

探究链：预测谁先到是否更快；同程6米模型自主设置甲乙用时、乙出发延迟；统一时钟和各车运动用时分离，等待与到达后不累加；“先到却更慢”反例，结束后核对出发/到达/用时证据。设置改变复位。真实两车三次记录共同路程与用时，缺项不当0，范围/逐次配对研讨，不从一次或混合结果强定胜负。CSV导出，仅内存、不上传。

模型匀速，不冒充实测或秒表，不用动画时间代替真实记录。实际计时与释放条件/误差需教师组织核对。

验证：node语法；Chrome错时模型5秒乙未出发用时0、8秒甲到达且乙用时2、10秒乙到达用时4；最大延迟和10秒时可到16秒。实测0秒阻断、共同路程缺失阻断、缺测保留、甲4/6/5对乙5/5/5得分歧提示、CSV下载、桌面截图。实体触屏、旧浏览器、教材正文与教参待核。
