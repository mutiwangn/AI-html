探究问题

谁先到，谁就一定更快吗？

两辆小车都从起点走到同一个终点，路程相同。一辆先出发，另一辆晚一些出发。

先选自己的想法，模型中可以再修改。

把比较条件说清楚

  1. 两车比较的路程相同。
  2. 各自从越过起点开始计时，到达终点停止。
  3. 可以同时出发，也可以分开测量。
  4. 比较每辆车实际运动的用时，不混入等待时间。
相同距离下，用时较少的平均运动速度较大。只知道谁先到，而不知道出发时刻，证据不够。

比较真实小车：三次测量

在安全平直桌面或地面标出相同起终点。轻推方式保持一致，分别计时；不要让同学冲跑，不用电脑滑块时间充当实测。

未测量的格子保持空白，不当作 0 秒。

如果三次结果不稳定，检查计时起止、起终点、释放方式和测量误差，再重复。这里不自动把一次较快判为“这辆车总更快”，也不把模型答案写入记录。

记录不含姓名、不上传，仅本页内存保存，刷新清空。允许 0.01—600 秒、最多两位小数；这是输入范围，不是仪器精度。
