# 二上 2.7 夜晚的月亮

对应教科版2025年版二年级上册第二单元《地球家园》第7课。

打开 index.html 即可离线使用，无外部依赖，无须打字。

- 看变化：八种代表性亮面示意，可保留一张比较；明确不是连续八晚、不是当天预报。
- 记一晚：点选日期、时间、地点和天气，用手指画实际看到的亮面；没有看见和没有观察分开记录，不自动补画。
- 找证据：按时间排列自己的观察记录，可选两张比较、下载离线记录页、打印。记录只保存在当前浏览器，请下载备份。

建议课前持续观察1～2周；本课关注描述形状的渐变，不要求记专业术语或解释成因。成人陪同、安全观察，不熬夜、不攀高。月亮有时白天也可见，并非每晚一定可见。
