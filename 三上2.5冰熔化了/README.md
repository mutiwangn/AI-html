# 冰熔化了 · 希沃全屏互动版 v1.0

教科版三年级上册，第二单元第5课。单文件 HTML，无外部字体、脚本或素材依赖。

## 三页用途

1. **熔化实验**：敲碎、吹气、手焐的方法示意；1、2、3、5分钟统一计时；师生填写真实观察，区分整块冰、碎冰、冰与少量水、冰与较多水、全是水，导出 PNG 记录。
2. **看见变化**：点按或长按加热、冷却，观察冰、水、水蒸气的变化；可切换实物和微粒视图。微粒模型保持36个示意点，液态点可相互移动。
3. **生活挑战**：预测并观察蜡受热熔化、冷却凝固；同页切换保冰挑战，比较裸放与袋外包干毛巾的相同冰块，并查看内部变化。

## 使用

打开本目录的 `index.html`，点击“全屏”；浏览器限制全屏时，可使用浏览器全屏菜单或 Windows 的 F11。键盘1、2、3切换页面，Esc关闭教学提示。

默认供教师在希沃一体机上组织课堂；少量学生可上台点按、长按、选择预测或填写观察。第一页计时器也可指导全班同步开展实物实验。三个主页面均采用单屏布局。

下载单个 `index.html` 后，可以直接在本地浏览器离线打开。观察记录仅保存在当前浏览器，不上传学生信息；“重置”清除本页计时和记录。

## 教学依据与模型边界

依据2025版教科版《科学教师教学用书》三年级上册第148—155页，对应学生教材第42—44页《冰熔化了》。用书的重点是比较熔化快慢与分析原因，难点是冰、水、水蒸气是同一种物质。

动画已加速，内部参数不是实测温度、热量或时间。三种方法的演示不生成实验排名，课堂记录由师生按实际现象填写。水在常温下也会蒸发，宏观水蒸气不可见。蜡冷却后在容器内成形，不还原最初的碎块形状。干毛巾减慢热量传入，不能使冰永远不熔化。

科学模型补充核对：[ACS Changing State—Melting](https://www.acs.org/middleschoolchemistry/lessonplans/chapter2/lesson5.html)。
