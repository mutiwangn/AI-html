# 二上1.6《“小房子”展示会》
教科版2025二年级上册第一单元《造房子》，参考对应教师教学用书89–95页。

## 课堂使用
单体离线HTML，无需打字。请把真实作品和纸质设计图放在旁边。
- 介绍作品：按墙体、屋顶、门、窗介绍材料及选择理由；图是提示，不代表实际作品。
- 相互评价：五项标准与教材对应，独立自评/同伴评，待核对/是/否循环；明确分歧高亮提示讨论，不算总分。
- 反思改进：选择目标、回顾合作贡献，口头说明受到启发的想法，并补充纸质改图；植物摆放拓展提醒具体光照需求。
四个展示组的评价、改进和介绍记录独立。一次同伴评代表一位或一组同伴的本次意见，并非全班投票。更多组可用纸质表或先保存再复用。本组清空须二次点击，其他组记录不变。刷新页面清空全部记录，可截图留存。

## 教学边界
实物未核查保留待核对；网页不判断材料种类、稳固性、采光或任何真实性能。教师先约定统一且安全的核查方式并现场指导，不让学生自行加重或挤压作品。纸盒与纸板都属纸类。植物需要适宜光照，不主张全部强光直晒或关在模型内实验。
