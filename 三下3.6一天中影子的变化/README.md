# 三下3.6 一天中影子的变化

恢复已有课堂大屏版，保留实验前练习、实验后自由模型、聚焦演示和原轮廓投影功能；修复手工输入时间未可靠提交的问题。

## 使用
- 默认实验前模式：练贴纸、校准、立杆和记录动作，不显示影子结果。
- 完成相应真实实验后由教师确认，进入实验后模型。
- 改变时间、阻挡物、物体高度、光源位置，切换立体/俯视/光路侧视；留痕和CSV均为模型数据。
- 默认北纬30°、春分/秋分，使用当地太阳时，不是北京时间；不能用于预测当天实地影长。
- 聚焦演示收起设置；需要调整时展开设置。设置较多时仅侧栏滚动，主舞台保持一屏。

单文件离线运行。记录仅限本次页面会话，刷新会清空记录并回到实验前；重要模型记录先导出CSV。

不直视太阳，不把手电照向眼睛。此工具不代替真实实验。太阳图标大小仅为课堂可见性，不按真实比例；模型忽略半影、大气折射、云层及地面反射。

## 资料与兼容性
依据本课教材印刷第73–75页及配套教学用书核对；教材明确版次尚待核实。画面由程序几何与 SVG 图标绘制，不含教材照片或外部素材依赖。

技术需求为 **T2（Canvas 二维）**，不是 T1。已作桌面浏览器核心流程检查，手机、平板与希沃真机尚未验证；部分辅助文字较小，可用聚焦演示放大主体。未逐一复测全部形状、纬度季节、手绘轮廓与 PNG 导出。
