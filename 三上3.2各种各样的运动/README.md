# 三上3.2 各种各样的运动
独立重制辅助稿。原创SVG，无第三方资源、学校或真实姓名署名，无可见技术层次。HTML与app.js同目录。教材与教参待核，非整课验收。

直线平移与绕固定轴转动的阶段模型，中心/边缘标记点切换，轨迹显示开关与预测反馈。明确轨迹属于某一点，转盘中心不动不代表整体静止；边缘回起点不代表中途未动。不模拟滚动轮缘，不计真实速度。两次真实实物记录，物品/标记点完整性检查、未观察和不清晰区分、CSV导出。只内存保存，不上传。

验证：node语法；Chrome直线末端x=440、转动四分之一圈y=310、中心(300,200)不变、模式切换复位、解释反馈、记录缺项阻断及补全下载；修复SVG轨迹被实体遮挡并截图复核。实体触屏、旧浏览器与教材教参待核。
