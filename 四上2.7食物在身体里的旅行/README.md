# 四上2.7《食物在身体里的旅行》互动课堂 v1.0

[在线打开课件](https://mutiwangn.github.io/AI-html/四上2.7食物在身体里的旅行/) · [返回四年级上册目录](https://mutiwangn.github.io/AI-html/#book-4-up)

单体离线 HTML：直接打开 `index.html` 使用，无外部脚本、图片或字体运行依赖。面向希沃一体机全屏演示，也支持学生使用平板或鼠标操作。

## 三个探究场景

| 场景 | 认知任务与操作 |
| --- | --- |
| 画旅行图 | 先在人体轮廓上自由画出预测路线、拖动器官贴纸；点击“对照看看”呈现参考路线，可用另一种颜色修正，保存前后图像 |
| 食物旅行 | 将食物送入口腔，观察沿消化道前进；播放、暂停、拖动时间进度、点击不同器官查看局部放大变化，并重新观察 |
| 呼吸与吞咽 | 对照呼吸和消化器官的位置；用侧面剖视示意观察吞咽时会厌区域与空气、食物路径的配合 |

## 科学表达与课堂应用

- 食物依次经过**口腔、咽、食道、胃、小肠、大肠、直肠、肛门**；肝、胰等参与消化但不是食物依次经过的管道。
- 消化道示意强调器官的连接关系、机械与化学消化以及吸收现象，不按解剖比例或真实消化所需时间模拟；网页中的运动速度属于教学压缩示意。
- 小肠继续完成消化并吸收大部分营养物质；大肠进一步吸收部分水分。营养物质的示意颗粒和动画不代表真实尺寸与精确吸收效率。
- 吞咽时呼吸通道受到保护。剖视动画为功能示意，不代表儿童可自主控制会厌，亦不可作为医学诊断图。
- 建议保留课前真实画图及教材实物观察；网页用于暴露猜想、观察人体内部不可见过程、反复比较与修正解释。
