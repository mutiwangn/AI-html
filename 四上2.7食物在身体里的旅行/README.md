# 四上2.7《食物在身体里的旅行》

四年级上册 → 第二单元《呼吸与消化》 → 第7课。2026-11-11 Three.js仿真版。

## 使用

打开本目录 `index.html`。单体HTML内嵌Three.js、模型、样式、逻辑及MIT许可，无CDN、字体、媒体或外部模型依赖；小于10MB。联网只用于主动点击科学来源链接。无学校、真实姓名、文字输入、个人健康采集或持久化存储。

16:9单屏自适应，中央模型、左侧探究阶段与视角、右侧当前操作，右上设置和全屏。深蓝灰背景、珊瑚消化通路和青蓝呼吸通路延续本单元2.6基准。已取消应用中的全部配音API、监听、状态和控制界面，保留过程文字。

## 教学流程与真实三维

1. **先画猜想**：在人体轮廓自由画路线，或点选器官；不提前判对错。进入观察时独立保存原稿。
2. **观察与修正**：口腔→食管→胃→小肠→大肠→肛门六站，播放、暂停、重播；另栏画或点选修正路线，标记资料依据，不覆盖原稿。可导出PNG对照记录。
3. **叠加呼吸器官**：切换正侧面或拖动旋转，颈部局部放大观察气管在前、食管在后；比较食物与空气的不同去向。
4. **系统协作**：区分吸收后的运输与残渣路线，讨论跳绳时多个系统协作，保留学生自己的选择。

Three.js r160直接接管器官BufferGeometry网格、透视相机、深度、物理材质与多方向光照，不是把二维图片贴到三维平面。原创参数化模型包括连续消化管道、胃形曲面、盘曲小肠、环绕的大肠、气管支气管与肺。食管局部显示沿通路移动的管壁收缩/舒张；胃内颗粒在简化空间内混合推进；小肠营养离开管腔进入体内运输示意，残渣继续。

模型是基于科学事实的定性教学仿真，不是人体扫描、医学精确解剖、流体力学求解或健康诊断。形状、比例、间距、速度与颜色均简化。动画时长不是消化时间；协作虚线不是直接相连的解剖管道。

## 渲染与兼容

- 支持WebGL的浏览器默认使用Three.js实时三维。设置中可手动切换同网格Canvas投影，用于较弱设备；状态会明确区分。
- WebGL初始化失败或图形上下文丢失时自动降级，不清空猜想与修正。真实三维恢复后沿用课堂记录。
- Canvas兼容模式不等于WebGL通过，不使用“三维已启用”等误导状态。
- 全屏不可用时提供浏览器全屏提示。PNG生成与下载仍取决于设备下载功能。

## 教材与科学核对

教材：教科版《科学》四年级上册，第二单元第7课，学生教材印刷48–50页（PDF52–54页）；配套教师用书本课181–189页。课程目录标注2026版。保留“猜想→观察资料→修正→叠加呼吸→研讨协作”的任务链，不嵌入教材/教参扫描原件。

- [NIH/NIDDK 消化系统如何工作](https://www.niddk.nih.gov/health-information/digestive-diseases/digestive-system-how-it-works)：管道连通、食团后方收缩与前方舒张、小肠吸收、胃逐渐排空和残渣去向。
- [NCI SEER 咽与食管](https://training.seer.cancer.gov/anatomy/digestive/regions/pharynx.html)：食管在气管后方、吞咽是多个协调动作。
- [NCI SEER 小肠与大肠](https://training.seer.cancer.gov/anatomy/digestive/regions/intestine.html)：小肠吸收，大肠和直肠关系。
- [NIH/NHLBI 肺](https://www.nhlbi.nih.gov/health/lungs)：呼吸获得氧气，与运输系统配合。

食管接咽，气管经喉与咽相连；不把会厌简化为可拨动的单一开关。肝胰参与消化但不是食团站点。小肠也吸水，直肠属于大肠，吸收后的营养不随粪便走完全程。刚吃下的食物不会立即到达肌肉。
