# 四上 2.7《食物在身体里的旅行》

2026-11-10，深色解剖观察版。对应教科版四年级上册第二单元“呼吸与消化”第7课。沿用本单元2.6的深蓝灰、珊瑚色与中央观察布局，围绕本课的完整通路、猜想修正与系统联系重新设计，未改动2.5、2.6、2.8。

## 使用

打开同目录 `index.html`，不需要安装、联网或外部模型资源。1600×900设计舞台等比缩放居中，右上角设置与全屏。HTML小于10 MB，无文本输入、学校、真实姓名、外部字体或追踪代码。

1. **先画猜想**：在人体轮廓里自由画器官与路线，或直接点选器官顺序。先保留而不判对错，离开时锁定原稿。
2. **观察修正**：旋转整体消化模型，逐站追踪口腔、食管、胃、小肠、大肠与肛门。辨认营养吸收与残渣继续前进的不同去向。打开并列记录，保留原猜想，独立绘画与点选修正，选择实际使用的证据。
3. **共同协作**：在同一身体中叠加呼吸器官，侧面放大观察气管在前、食管在后；追踪两条通路，讨论运输与跳绳时运动、呼吸、循环、消化、神经系统的协作。
4. 在对照记录中下载PNG。空白表示未记录，不自动填成答案；下载包含两阶段图画、点选路线、所选依据及活动协作点选，不收集个人健康资料。刷新页面会丢失未下载记录。

## 模型与科学边界

本课为原创参数化三维坐标模型，使用Canvas二维上下文投影与面排序显示立体结构。可旋转真实三维坐标，但不是Blender模型、医学扫描或医学级解剖仿真。无需WebGL。

- 胃在人体左上腹，正面看位于画面右侧；食管位于气管后方；小肠连接大肠起始段，直肠归于大肠末段。
- 不将肝、胰或肺放入食团经过的路线。蠕动推动食团，不只是重力。吞咽有多个协调动作，未简化为唯一会厌开关。
- 亮点表示路线与去向，不表示真实食物颗粒数量、完整食物穿壁、实际运输速度或消化时间。营养吸收后离开肠腔，残渣继续前进。小肠和大肠均可吸收水。
- 呼吸演示为吸气方向，呼气反向；食物与空气分别追踪，不以动画示范边吃边呼吸的操作。运输连线是系统联系示意，不是直接解剖管道。
- 比例、间距、形状、颜色和运动速度经过教学简化。无实际进食、憋气、倒立吞咽等实验。
