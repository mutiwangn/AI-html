# 网络状态机（v1.2.3）

## 统一访问名

```text
http://muti.local/
```

当前日志显示 `STA connected: 1101 IP=192.168.2.246` 时，设备已经进入 STA-only，配置热点关闭属于正常行为。

## 启动和恢复

```text
有保存的 SSID → STA-only 连接 20 秒
                 ├─ 成功：局域网 + muti.local，配置热点关闭
                 └─ 失败：AP-only 配置热点
无保存的 SSID → AP-only 配置热点
```

默认配置热点：

```text
SSID：Muti-10.2
密码：无
IP：192.168.4.1
信道：6
最大客户端：4
```

设备页面可手动执行“开启配置热点”或“连接已保存局域网”。AP 启动时显式配置 192.168.4.1，并最多重试三次。AP+STA 不作为长期模式。
