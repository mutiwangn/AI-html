# 三上 3.8《测试“过山车”》

面向小学科学课堂的单体 HTML 互动网页，以“观察运动—公平比较—改进验证”辅助实物探究。依据《科学》三年级上册第三单元第 8 课（教材印刷第 79—81 页，任务集中于第 80—81 页）及配套教师教学用书，衔接上一课的设计、制作与项目评价。

## 三个任务页

| 任务 | 可操作内容 | 教学关注点 |
| --- | --- | --- |
| 观察运动 | 沿轨拖动小球，查看位置线索与沿轨距离；运行、观察运动；手动点选四项三星评价 | 以起点为参照描述位置；观察直线、曲线运动及快慢变化；测量小球实际经过的路线 |
| 公平比较 | 比较预设 A、B 轨道；选择“相同路程比时间”或“相同时间比路程” | 两条轨道总长不同，先确定相同条件，再依据数据比较；不按全程用时排名 |
| 改进验证 | 对照固定原方案 A，改变副本的支点高度，运行并观察终点小球推动木块的距离 | 保留俯视线路，最后两个支点固定且等高；在同球、同木块、同表面条件下验证改进 |

观察页的四项评价对应教材：轨道总长在 2 米以上；有直线轨道和曲线轨道；小球能滚完全部轨道、不能脱轨；与同学合作完成。每项最多三颗星，由学生或师生共同评价，网页不代替合作表现评价。

在同一浏览器、同一网站下，可读取第 7 课保存在 `aihtml.coaster.design.v1` 的有效方案；没有可读记录时使用示例。读取方案用于观察页；公平比较使用预设 A、B，改进验证使用固定原方案 A 及其副本。

## 课堂使用建议

可按观察与评价 8 分钟、公平比较 12 分钟、改进验证 12 分钟、实物复核与交流 8 分钟组织。先让学生预测，再操作和记录。描述位置时区分方向、高低与沿轨距离；测量路程时沿轨道量取，避免把起终点的直线距离当作小球路程。比较快慢前让学生说明保持什么相同；改进时建议一次改变一个支点高度，再解释证据。保留学生自制作品，用细绳、软尺、秒表和小木块复核想法。

## 离线运行

直接打开交付文件 `index.html` 即可运行。样式、SVG 图形、运动模型和交互脚本均内嵌，不依赖外部字体、图片、CDN 或构建工具；兼顾鼠标与触控。第 7 课方案接续依赖浏览器的本地存储及网站来源，不能跨浏览器或跨设备自动同步。

## 模型假设与限制

轨道长度采用包含高度变化的空间弧长。小球从静止释放，按实心球无滑动滚动、重力与简化滚动阻力计算；不额外施加起步推力。水平起步、无法越过的坡段、接口折角、轨道相碰和失去支撑等情况可能导致未完成，不能把未完成时间当作成功成绩。

木块位移使用小球**到达终点时的瞬时速度**计算，与全程用时和平均速度分开。动画以 0.4 倍速度播放，读数使用模型中的物理时间。默认小球 30 g、木块 80 g、恢复系数 0.5、木块滑动摩擦系数 0.18；先计算一维瞬时碰撞，再计算木块在水平面上的匀减速滑动。改进页锁定末段水平，并固定球、木块及表面参数，因此可在该模型条件下比较推动效果；未到达终点则不生成碰撞结果。

碰撞后展示小球短时间的水平回退；每个木块停止后，该侧画面定格，便于比较移动距离，此时不表示小球已经自然停稳。

模型用于观察关系与讨论证据，数值不是实物器材的标定结果。它简化了轨道侧向约束，不模拟侧向翻出、轨道变形、真实接缝振动和复杂碰撞中的转动能量交换；上坡停住后定格供观察，不继续模拟倒滚。改变高度也会改变实际轨道长度，讨论原因时应同时关注这些变化。

## 模型与美术替换接口

计算层为 `TestCoasterModel`，与绘图、存储和动画播放分离；交付 HTML 已内嵌其代码，模型代码在 HTML 中以 `TestCoasterModel` 独立模块封装。

- `presets()`、`validateDesign()`、`designProblem()`：读取示例并校验 `{version, nodes, kinds}` 方案。
- `buildGeometry()`、`simulate()`：建立轨道并生成运动记录。
- `sample(sim, time)`、`atDistance(sim, distance)`：按时间取位置，或按路程取到达时间；未达到的路程返回 `reached: false`。
- `impact(sim)`、`blockAt(result, time)`、`ballAfterImpact(result, time)`：根据终点速度计算碰撞、木块滑动及小球回退。

图形替换入口为 `TestCoasterArtwork.support(node, project)`、`.ball(projectedPoint, id, distance, draggable)` 和 `.block(endPoint, displacement, project)`。精细化时可替换其 SVG 美术实现，保留方法签名、交互命中区域、坐标映射及上述模型接口；展示素材不负责决定测量数值。

## 已完成验证

模型检查通过：预设 A、B 均能到达水平出口；空间弧长不小于俯视弧长；相同 2 米路程取时、相同 1 秒取路程有效；木块最终位置与碰撞计算一致；平轨静止起步不产生碰撞结果；只改变全程用时字段不会改变木块位移。这些是模型检查，不代表已在希沃实机完成验证。


预设基准：沿轨道共同 2 米，A 用时约 1.98 秒、B 约 1.77 秒；共同 1.5 秒，A 约走 109 厘米、B 约 143 厘米。A 原方案推动木块约 22.9 厘米；起点由 42 厘米调至 62 厘米后约为 36.2 厘米。它们是固定参数模型的比较结果。


浏览器交互检查通过：三页切换、沿轨拖动小球、位置与测量开关、同步释放、两种比较条件、支点拖动与键盘调高、恢复方案、高坡停滞和失去支撑反馈、手动星评、读取上节方案。已检查 1366×768、1024×768、390×844、844×390 的布局；核心操作和读数位于单屏内，窄竖屏采用上下对照。未进行希沃或实体平板硬件测试。
