# 四上 1.8 自制打气筒

教科版四年级上册，第一单元《空气》第8课。课堂修订版 8.0。

## 使用
打开 `index.html`。网页、脚本及三维资产均已内嵌，无需联网加载。第四页三维画面需要支持 WebGL 2 的浏览器；不支持时会明确提示，前三页及新增碗形阀剖面仍可使用。

- **教材实验**：塑料瓶挤压、回弹、堵孔与开孔，观察瓶盖气球皮和空气路径。
- **改装比较**：直接套气球、气球皮漏气、瓶身回弹差等条件对比。
- **六类装置**：第三页以二维等效气路比较手持、立式、双缸脚踏、风箱、叶轮气球泵及电动活塞泵。装置类型不等于所有产品都采用同一内部结构；立式泵真实皮碗旁通结构另见第四页。
- **三维结构**：保留皮碗式落地泵整体、剖视、拆解和四类单向阀网格；旋转、放大和关键阶段回看。
- **碗形硅胶阀**：第四页入口打开独立轴向剖面。对比正向送气、停气回弹、反向压差；固定碗底，观察碗沿形变。可暂停、重置并调节示意压差。

## 模型边界与安全
第三页和碗形阀为二维教学示意，不是三维产品扫描，也不代表具体品牌参数。模拟数据、微粒、流速、尺寸和形变均不替代实测。碗形阀约 1 cm 标注表达装配关系，图不按比例；虚线支架在剖面以外，空气从支架间隙通过。

叶轮泵工作时同时进出气，不虚构通用止回阀或保压功能。双缸脚踏示意采用同踏板同步驱动；电动轮胎泵示意采用单活塞，不声称适用于所有型号。

实物由教师按器材说明操作，避免过量充气，勿将气嘴对准人、对口吹气或自行加大压力。三维模型中的止回阀展品不表示全都装在主泵上。

## 验证范围
本版通过内联脚本语法和独立静态科学审查，并在桌面浏览器实际检查四页切换、教材挤压/回弹、改装切换、六类示意切换、叶轮开启/停机、碗形阀三种压差、暂停冻结及重置。桌面 1180×757 无页面横向溢出。

测试浏览器禁用 WebGL，因此仅确认三维降级提示正常，未验证本版三维 GPU 画面；三维内嵌模块及资产与既有版本保持一致。未作真实希沃、iPad或手机实机验证，首次上课前应在目标设备检查触控、布局和 WebGL 支持。
