# 四年级上册 · 第一单元 · 第8课《自制打气筒》

## 自由组装实验台 v8.5

[打开本课件](./index.html) · [打开原课堂修订版8.0](../index.html)

本课件与原课堂修订版8.0并列，侧重材料自由装配、瓶盖与瓶身开孔、长条气球皮固定及按压充气观察；原版的装置比较、实际泵结构和阀门剖面内容仍保留，不以版本号大小替代原版。

### 使用
- 材料可拖动，也可先点材料，再点实验台上的操作位置。
- 直接点按瓶身试验，按住可保持；放大窗口和空气微粒默认关闭。
- 瓶身上、中、下部可选一处打孔。每只瓶子只保留一个侧孔，换位置须重置。
- 撤回装配或取回材料不修复已打出的孔；重置会恢复完整材料。
- 装入长条皮后再对瓶盖打孔，会把长条皮一并穿孔。
- 真实打孔应由教师协助，模拟不能代替实物探究。

### 模型边界
这是定性教学模型。微粒、形变、气流与阀片运动均作放大示意，气量和压力参数不作为真实测量数据。不同装配的效果受按压与回弹时间影响；无阀或侧孔一直打开不等于任何情况下都绝对无法充入空气。应比较持续充气、回流、漏气与瓶体回弹，不用模型数值代替实验结论。

### 运行与依赖
单文件约86 KiB，无外部CDN、网络资源、字体、纹理或模型下载依赖；几何与缩略图在本地生成。主渲染为WebGL1，另有Canvas2D回退。建议近期版本Chrome或Edge。未发现需要随包保留的第三方资源许可证；文件中的定性模型提示保留，个人水印已移除。
