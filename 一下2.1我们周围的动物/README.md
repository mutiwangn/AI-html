# 一下 2.1《我们周围的动物》

一年级下册第二单元第一课的课堂互动辅助网页。打开 `index.html` 即可使用，无需登录或输入文字，无外部资源依赖。

## 课堂使用

1. **并排看一看**：选择两张动物示意图，比较外形。四张图只是例子，不是校园动物全集，也不代表本次实际发现。
2. **画下发现**：寻访后画下真实看到的动物，选择草地、树旁等环境类别。九张画分别保存，支持撤销及二次确认清空当前记录。更多发现请继续在纸上记录。
3. **合起来看**：教师帮助辨认，相同种类使用相同编号，页面按编号合并统计；不确定的保留为“待辨认”，不自动判断种类。点击画卡可继续修改。

只记录环境类别，不填写学校名、住址或精确位置。安静观察，不抓、不追、不伤害，不碰陌生动物，不靠近水边；活动范围由教师确定。

## 教材对照与范围

已对照所提供一年级下册教材印刷第 28–31 页（PDF 第 33–36 页）的校园寻访、生活地点记录、九格绘画记录、种类汇总和特征交流活动。教材具体出版年份、版本及教师用书仍待核验。图像是外形示意，不按真实比例绘制，不能替代现场观察。

## 数据与技术

- 技术需求：T1 · 基础交互。
- 记录仅保存在本次打开的网页内存中，刷新或关闭后清空；需要留存请同步使用纸质记录。
- 不上传绘画和观察记录，不收集个人信息。
- 种类汇总仅依据师生选定的编号，不是自动物种识别，也不按动物只数统计。
