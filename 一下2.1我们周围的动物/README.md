## 教学设计
两页辅助工具：
- 双图对照：蚂蚁、蜗牛、蝴蝶、金鱼四张原创SVG外形示意，可独立替换左右两图，观察提示默认关闭。学生先指出看到的部位，再揭示提示作对照，不只背名字。
- 实际寻访：各动物独立标记未记录、这次看到、这次没看到、待辨认，汇总只列真实勾选“这次看到”的对象。其余动物鼓励纸上画图、由老师补记，不将四个例子视为完整动物名单。

数字增益是保留两幅图方便对照，以及汇总真实寻访记录；图卡不是现场照片，不应把图中动物计作现场发现。鼓励学生口述观察地点和特征，网页不收集儿童位置。

## 科学与保护边界
SVG为简化外形，非鉴定图谱、不按真实尺寸比例，不展示所有解剖细节和物种差异。蚂蚁和蝴蝶示出六足，蝴蝶示两对翅膀；蜗牛是常见陆生有壳蜗牛示意，金鱼是单尾型简化侧视，不能据此说所有个体外观相同。未依据颜色或“会动”单独定义动物。页面说明人也是动物。

没看见不意味着没有，未辨认不等于没有。图卡不声称校园必定存在金鱼或其他动物。寻访需教师带领，限定安全范围；不抓、不追、不踩、不翻家、不碰陌生动物、不靠近水边，不布置捕捉任务。
