# 三下2.2 动物的繁殖

教科版三年级下册第二单元《动物的一生》第2课。依据所提供教材第33—35页和本课教师教学用书整理，扫描件版权版次尚待核实。

## 单文件使用
直接打开 index.html，全部样式、脚本及原创SVG示意图内嵌，无网络素材依赖。

两页可独立使用：
1. 对照繁殖过程：鸡与猫按“出生以前／来到外界／照顾幼体”切换对照，解释层按需打开。左右不是相同时间，图示不是实拍、解剖或数量比例模型，不展示真实生理模拟。
2. 用证据分类：猫、金鱼、鸽子、蛙、大熊猫五项资料；记录首次判断与当前判断，阅读证据后可修正，最初想法保留。每种动物独立保存理由、判断和资料阅读状态，下载HTML记录。

教材照片中的“鱼”在本课件具体化为教材资料也提到的“金鱼”，避免暗示所有鱼均卵生。“蛙”限于本课水中产卵案例，不推广到所有两栖动物。

## 教学增益
同步对照帮助区分“在何处发育、怎样来到外界”与“如何育幼”；分类板保留判断变化与依据，避免只给一个对错分数。预置资料是教材与教参的课堂概述，不是学生调查记录；支持先口头讨论再写简短依据。

“交流与保护”回应教材关于雌雄共同参与的讨论。特别区分母鸡产卵与受精卵发育：未受精鸡蛋不能孵出小鸡。观察不掏巢、不触碰卵或幼体，不干扰繁殖。

## 数据与边界
状态仅在当前页面内存，刷新或关闭会丢失，请先下载或截图；不上传信息、不调用AI，不把资料分类表声称为实地观察。
