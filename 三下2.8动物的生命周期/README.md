# 三下2.8 动物的生命周期

三年级下册，第二单元“动物的一生”，第8课。单体离线HTML，无外部依赖。

## 课堂使用
- **外形怎样变化**：常见蛙类六阶段与金鱼四阶段独立前后切换，可把一侧停住对照另一侧。配合外形、呼吸环境、出生繁殖三条线索比较。两边不是同龄、同时间轴，也不是等比例图；换页不表示瞬间变形。
- **用证据找共同点**：四个问题分别调出鸡、金鱼、常见蛙类、人四份资料。学生在比较出生方式、发育变化、繁殖与生存条件后，保存自己的归纳。讨论提示可显隐，程序不自动给主观结论评分。
- **生命与保护**：连接人的生命阶段、动物需求与保护，建议形成注明来源的科学小报。不需要收集学生照片、年龄、身高或家庭资料。

原创SVG概念示意不是实拍，也不是形态测量模型。金鱼幼鱼/成鱼采用相同的典型结构图，以文字区分阶段；不能据图推断生殖成熟时间。常见蛙类模式不涵盖全部蛙类，金鱼的卵生不能概括全部鱼类。成体繁殖产生下一代，不是原个体重新变成卵。

种群通过繁殖延续，不是每一个个体都会繁殖；人的生育与否不决定生命价值。生命有开始、生长变化和结束，具体变化与环境需求不同。
