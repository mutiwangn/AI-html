# 一上1.3 植物长在哪里

教科版2024年版一年级上册，第一单元《周围的植物》第3课。对应教师教学用书第56–64页的观察不同环境、观察根的位置、水生植物与无土栽培，以及土壤/餐巾纸种绿豆拓展。

## 使用
直接用浏览器打开 index.html；单文件，无外部脚本、字体或图片依赖。触屏点击即可，无需学生打字。

- 看环境：依次选择花盆、荷花、浮萍、无土栽培，先口头表达，再打开剖面。
- 真实观察：土壤与餐巾纸两组记录初始空白，14次观察互相独立；每边选一项主要发现，可再次点选取消。其余细节口头表达或纸笔记录。
- 记录只在当前打开的页面内保留，刷新/关闭后丢失；打印仅打印当前一次。请及时保存纸质记录。

## 科学边界
图形是简化结构示意，不是照片，大小不按真实比例，不用于识别具体植物或替代实物观察。荷花根扎在池底泥土中；浮萍根垂在水里；无土栽培需要配制的营养液和适宜环境，不等于仅有清水即可长期生长。萌发与长期健康生长不同，课堂记录不预设实验结论。

建议教师另用本地实物/照片展示田野、山地等环境，组织胡萝卜与荷花的真实特征比较。本网页重点辅助理解遮挡下的根与环境关系，不包含本课所有教学活动。
