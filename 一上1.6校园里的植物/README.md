# 一上 1.6 校园里的植物

教科版 2024 年版，一年级上册《周围的植物》第6课。版本：课堂实地观察工具 v1.0。

## 定位与使用

双击 `index.html` 即可离线使用，无外部字体、脚本、图片或账号依赖。服务于真实校园观察，不替代实地活动，也不提供自动植物识别。

- 出发前：整体到局部观察提示、安全约定。插图明确为方法示意，非校园实景。
- 画下来：两株植物的空白整株/细节画图区，三色笔、撤销、二次确认清空；地点、叶子和观察花的结果用点选表达，不要求一年级学生打字。
- 比一比：并列自己的记录，按叶子、茎、地点表达相似/不同/暂不能确定；不自动判分，不把株数冒充种数。
- 可选择本机 JPG/PNG/WebP 植物照片，每张不超过15 MB。照片仅显示于当前浏览器内存，不上传；不请求相机权限。
- 保存画图会导出单张 PNG（含观察选项，不含照片）；打印使用浏览器打印功能。照片请保留原文件。

所有记录仅在当前页面内保留，刷新或关闭会清空；浏览器支持时会提示离开。请先保存需要的记录。更换照片会移除旧图的页面引用。适配桌面与窄屏，真实触摸设备体验以现场检查为准。

## 教学建议

一课时可参考：准备5分钟，校园观察与绘画20分钟，比较交流12分钟，提出新问题3分钟。教师划定安全观察范围，小组一起行动，不采摘、不拔起、不品尝、不随意触摸；远离池塘、电线和带刺植物。也可用纸笔在户外记录，返回教室再共同整理。

“没看到花”不等于“这种植物不会开花”。校园植物的名称应由真实对象和可靠辨认支持。可以先编号、画特征，再请教师帮助辨认。

## 范围说明

本文件是本课实地观察核心工具，不是《植物探索镜 v2》拓展闯关的完成版，不包含其10组五级连续对位图片资产。

## 技术与核验

单体 HTML / CSS / JavaScript / SVG / Canvas，分类 T2（触摸绘画、本机照片）。无网络请求、上传或后台存储逻辑。已在桌面 Chromium 验证三页切换、绘画、撤销、清空确认与取消、观察点选、并列展示及修改后重置比较。打印、照片选择与 PNG 导出尚需目标浏览器复核；真实希沃和 iPad 未实测。
