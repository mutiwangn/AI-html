# 四上3.3声音的高低学生端 v1.1

**横看高低，竖看强弱。** 首页保留声音观察区和录音主操作；点击“更多”展开波形、Hz、选频发声、录音回听与保存，适合学生个人或小组探究。

## 如何读图

- **横向音高**：范围为 **100～3000 Hz**，采用对数位置，相邻八度占用相同长度。录音显示稳定性检查后的估计音高；颜色是人为约定的标记。
- **纵向强弱**：取最近 **50 ms** 的有效 PCM 采样，去除直流分量后计算均方根（RMS），按固定刻度绘制高度。尺度不随每帧或每段录音自动归一化，可比较同一设备、位置和发声方式下的相对强弱。
- **未确定音高**：有声音但暂时无法可靠估计音高时，用灰色侧条保留输入强弱，避免把杂声误解为“没有声音”。

RMS 表示设备收到的数字音频幅度，受麦克风、距离、方向和设备处理影响，未经校准，不能直接作为声压级（dB）或跨设备测量结果。

## 波形、回听与选频发声

展开“更多”可打开实际 PCM 的 **20 ms 波形**及 Hz 数值。“稳定触发”只选择连续采样中的显示窗口，不改写采样、不跨周期平均，也不将复杂声音替换为正弦波。不够稳定时保留原始波形。

“定格”保留当前波形与时刻，录音和彩条继续更新；“继续”恢复波形观察。**×1、×4、×16** 仅改变波形显示倍率，不改变录音、音高、音量或纵向 RMS 刻度。

单次录音最长 **30 秒**。“更多”区支持回听、拖动“声音足迹”回看、下载 WAV 和清空。“用这个音高”可将有效识别值带入选频设置；开始试听前会结束当前录音并释放采集流。

| 预设音色 | 发声方式与合成近似 | 默认时长 |
|---|---|---:|
| 铝片琴 · 敲 | 敲击条片的模态与衰减 | 2.6 秒 |
| 钢尺 · 拨 | 拨动悬臂薄片，较快衰减 | 1.6 秒 |
| 金属管 · 敲 | 敲击管体，高阶模态和较长余音 | 3 秒 |
| 装水试管 · 吹 | 吹奏管口，以水面上方空气柱为主，带轻微气声 | 3 秒 |

四种声音均为**电子合成近似，并非实物录音**。设置的是 **100～3000 Hz 的目标主音频率**；复杂敲击音可含非整数倍振动模式，不保证整段声音具有共同基频。试听时显示“目标主音”，麦克风输入显示“估计音高”。本页不模拟改变水量，也不表示同一件真实器材能够覆盖整个选频范围。

## 使用、权限与离线

建议先在较安静环境持续、平稳地哼唱单音，再分别改变高低和强弱。噪声、多人同时发声、短促敲击及复杂音色可能暂未识别，或出现倍频、半频等误判。本工具用于课堂观察与比较，未作专业测量校准。

`index.html` 自含依赖，无外部素材或运行时网络请求，可离线打开并发声。录音建议使用 **HTTPS 链接**并允许麦克风；本地 `file://` 能否录音取决于浏览器权限。音频仅在当前页面本地处理，不上传；刷新或关闭页面会清除，需保留时下载 WAV。切到后台会停止录音和播放。

## 已验证范围

本轮自动检查已通过：**760 项音高算法检查、168 项触发窗口检查、11 项合成及回放输出检查**。测试输入为数学生成的 PCM 和模拟音频接口，覆盖频率边界、触发取窗、四种音色与播放生命周期。

云端 Chromium 已运行页面并检查：极简首页、展开/收起后保留观察选择、四种音色输出及 100/3000 Hz 端点；以 Web Audio 虚拟流经过实际录音接口验证 100、440、3000 Hz，440 Hz 两档强弱、噪声拒判、定格、停止、回看起点及等待取消后释放采集流。两档 440 Hz 输入的 RMS 约为 0.02475 与 0.12728，横向位置相同、彩条高度不同。此环境测试录音使用 ScriptProcessor 兼容路径，不代表实体麦克风测试。

浏览器视口检查覆盖 **390×844、390×667、844×390、1024×768、768×1024、320×568、667×280**；主图和录音按钮保持可见，极小屏幕的展开工具区可独立滚动。这些是布局模拟，尚未逐台验证真实手机、平板、系统浏览器及其麦克风和扬声器表现。
