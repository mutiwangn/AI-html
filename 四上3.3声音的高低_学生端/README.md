# 四上3.3声音的高低学生端 v1.0

[打开学生端](./index.html) · [打开教师版](../四上3.3声音的高低/)

面向学生个人或小组操作，把真实声音的音高变化转换为可观察、可回听的记录，配合教师版的钢尺振动模型使用。

## 主要功能

- **录下声音**：在浏览器本地采集单声道 PCM，单次最长 30 秒；估计相对稳定的基频，不确定时不显示有效音高。
- **看音高色带**：范围为 **50～1600 Hz**，采用对数位置，相邻八度占用相同长度；可按需显示 Hz 数值。
- **看波形**：可选固定 **20 ms** 时间窗，显示增益为 **×1、×4、×16**；增益仅改变波形显示大小，不改变录音、播放音量或音高。
- **回听和保存**：回放录音、拖动播放位置、导出 WAV；“用这个音高”可把有效识别值带入发声频率设置。
- **自选频率和音色**：纯音、木片、金属、琴弦均为电子合成示意，泛音全部采用基频的整数倍。纯音持续约 6 秒，木片约 0.9 秒，金属约 2.5 秒，琴弦约 2 秒。

## 使用与运行

点击录音并允许麦克风，先尝试持续、平稳地哼唱一个音，再改变音高。停止后可回听、拖动进度，或用识别到的音高试听不同合成音色。开始试听时会先结束当前录音并释放采集流。

`index.html` 为自含依赖的单体 HTML，无外部素材或运行时网络请求。音频在当前浏览器本地处理，不上传；需要保留时导出 WAV。麦克风功能建议通过 **HTTPS 页面**使用并授予权限，具体要求见 [MDN getUserMedia 文档](https://developer.mozilla.org/en-US/docs/Web/API/MediaDevices/getUserMedia)。本地 `file://` 打开时能否申请麦克风权限取决于浏览器；页面离线可打开，不代表所有设备都允许离线录音。

## 科学说明与适用边界

- 本工具用于课堂观察与比较，未经专业仪器校准，不作为专业调音或测量仪器。
- 识别面向单一、较稳定的周期性声音，持续哼唱较合适。噪声、多人同时发声、短促敲击或复杂泛音可能出现暂未识别、倍频或半频等结果；有显示值也不代表已经确认真实基频。
- 色彩是帮助比较音高的**人为标记**，不表示声音本身具有可见颜色。
- 波形呈现录音 PCM 电信号幅度随时间的变化，不是发声物体的实际位移。其幅度受麦克风、距离、设备处理及显示增益影响，不能直接当作校准声压级（dB）。
- 木片、金属、琴弦使用不同谐波配比和衰减包络模拟音色，并非真实材质录音。改变音色时保持所选基频，不能据此推断真实乐器的全部振动机制。

## 已验证范围

数值及模拟接口检查已通过：**554 项音高算法检查、24 项录音接口检查、8 项输出接口检查**。模拟接口检查不等同于实体设备测试。

云端 Chrome 中，已用真实 Web Audio 虚拟音频流经过实际 ScriptProcessor 采集和音高算法，验证 440 Hz 及带强泛音的 220 Hz 稳定识别、噪声不显示有效音高、30 秒自动停止、录音与试听切换、模拟权限拒绝，以及取消后迟到虚拟音频流的释放；异常处理后上一段录音仍可回听和保存。完成约 7.616 秒录音的回放、拖动、音高复制与 WAV 导出；导出文件已解析为 **44100 Hz、单声道、16 bit、335872 个采样帧**，频谱峰约为 440 Hz。

布局已完成 **390×844、390×667、844×390、1024×768、768×1024、320×568、667×280** 的 DOM 尺寸检查，未发现页面溢出。尚未在 Safari、Android 实体机或实体麦克风上实测；AudioWorklet 路径仅完成模拟接口检查，未在本次云端浏览器中实跑。
