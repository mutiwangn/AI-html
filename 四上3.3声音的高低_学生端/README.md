# 电子拾音器 · 学生端 v2.0

[打开学生端](./index.html) · [教师接收端与启动说明](./teacher.html) · [下载局域网启动包](./classroom-lan.zip)

用于四年级上册第三单元 **3.2《声音的强弱》与 3.3《声音的高低》**。两课共用本目录的同一份学生工具；原有[强弱教师课件](../四上3.2声音的强弱/)与[高低教师课件](../四上3.3声音的高低/)继续保留。

## 开始观察

1. 用 HTTPS 链接打开网页。已获授权且浏览器允许音频运行时会尝试自动拾音；首次使用或音频被暂停时，轻触“启用麦克风”并允许访问。
2. 对着麦克风持续、平稳地发一个单音，观察波形、振幅与 **100–3000 Hz** 的估计音高。实时拾音不需要先录制；暂时没有可靠音高时，仍显示真实输入波形。
3. 红色按钮只保存最长 **30 秒**的片段。停止录制后继续拾音，并保留该片段中稳定出现的特征频率；没有稳定单音时不强行给出特征频率。可回放、拖动回看、定格，或在设置中保存 WAV 与测量数据 JSON。
4. 回放和电子发声时暂时释放麦克风，结束后恢复拾音；部分浏览器需要再次轻触启用。切到后台会暂停拾音。需要保留的片段应在刷新或关闭页面前下载。

## 怎样读图

横轴是时间，纵轴是麦克风数字信号的相对振幅。**红点固定在 x=0，纵向位置取最新真实采样；左侧是已经采集的历史。** 时间窗可选单侧 5、20、50 ms。波形不代表发声物体的直接位移测量；屏幕刷新会使红点的快速运动看起来变慢，应结合时间刻度和频率数值判断振动快慢。

设置中的“预测正弦波”默认关闭。打开后，右侧虚线根据当前可靠频率与最近采样拟合，只是一种可比较的模型；它不是未来实测声音。音高不可靠或拟合不足时不画预测。复杂音色的实测波形与正弦模型可以不同。

默认输入增益 **×8**，可选 ×1、×4、×8、×16、×32，用于观察和临时回放放大；**原始 PCM 与原始 RMS 不随增益改写**，测量数据另存增益及变化记录。显示超出范围时会提示截顶，可降低增益。比较强弱应保持同一设备、位置、方向与增益；RMS 未经声压校准，不能当作分贝或跨设备响度比较。

v2.0 已降低原始弱声门限，并只在音高分析的私有副本中做归一化，避免直接排除较轻的真实单音；仍保留周期一致性与稳定性检查。提高增益不会改善信噪比，噪声、多人同时发声、短促敲击或复杂音色仍可能无法识别，或出现倍频、半频误差。

## 选频发声

目标主音可在 **100–3000 Hz** 内选择，也可带入当前音高或录音保留的特征频率。

| 预设 | 合成情境 |
| --- | --- |
| 铝片琴 · 敲 | 敲击条片的振动模式与衰减 |
| 钢尺 · 拨 | 拨动悬臂薄片的较快衰减 |
| 金属管 · 敲 | 管体敲击的振动模式与余音 |
| 装水试管 · 吹 | 吹奏管口，近似水面上方空气柱并带轻微气声 |

四种声音都是**电子合成示意，并非实物录音**。复杂敲击声可以含非整数倍振动模式，目标主音不表示整段声音必有共同基频，也不表示同一件实物能覆盖整个频率范围。页面区分“合成输出”与麦克风实测。

## 局域网课堂

教师下载并解压 [classroom-lan.zip](./classroom-lan.zip)，在装有 **Python 3.10 或更新版本**的电脑上运行包内启动脚本，再用终端提供的本机教师链接打开接收端。学生与教师处于可互相访问的网络，点击“课堂”，输入教师给出的完整课堂码及小组或座位号，再主动连接。

连接后发送实时频率、保留的特征频率、原始相对 RMS、增益和一小段真实波形；**完整录音只在学生点击发送按钮后提交**。未连接课堂时，本地观察与录音不上传。数据交给教师电脑，GitHub Pages 本身不接收或保存班级数据；教师应在关闭并清空课堂前导出需要保留的数据。

GitHub HTTPS 学生页连接本地 HTTP 接收服务，需要浏览器支持并允许本地网络访问。遇到不支持、权限限制或 iPad / Safari 等环境，应使用学校管理员配置的**可信 HTTPS 同源学生入口**，具体步骤见启动包内 README。普通 `http://192.168…` 学生页不是跨设备麦克风的安全入口；不要通过跳过证书警告或关闭浏览器安全功能解决。访客网络隔离、学校防火墙或设备策略也可能阻断连接。[MDN：麦克风安全上下文与权限](https://developer.mozilla.org/en-US/docs/Web/API/MediaDevices/getUserMedia)

[teacher.html](./teacher.html) 单独从 GitHub 或本地文件打开时提供启动说明，不能代替正在运行的教师服务。启动包包含学生页、教师页、Python 服务和操作说明；配置好可信 HTTPS 与局域网名称解析后，可在课堂网络内运行。单独的 `index.html` 自含脚本和样式，但麦克风仍受安全上下文、授权和音频启动策略约束。[MDN：Web Audio 启动建议](https://developer.mozilla.org/en-US/docs/Web/API/Web_Audio_API/Best_practices)

## 验证范围与文件

已在浏览器中用真实 Web Audio 合成流经过采集、音高算法和页面，验证峰值 0.001 的 100、440、3000 Hz 弱输入；未按录制时持续显示数值，手动停录及 30 秒自动停录后继续拾音，录音特征频率独立锁定。另验证回放释放输入、回看位置、噪声不强行给出音高、定格与原始采样不变的增益切换。此浏览器走 ScriptProcessor 回退；AudioWorklet 的采集与边界通过代码测试。

浏览器布局检查覆盖 320×568、390×844、844×390、768×1024、1024×768、1366×768、1920×1080 的首页与展开设置，核心坐标区和录制按钮均留在视口内；小屏的辅助设置区允许独立滚动。

学生浏览器与真实接收服务已联调两个独立身份加入、错码提示、实时数据发送、4 秒 WAV 提交和退出。教师 API 的接收、CSV、权限、容量、清理和可信 TLS 路径通过 13 项本机服务测试；云端预览代理不属于教师电脑的 loopback 来源，因此未验证完整教师浏览器管理流程，未放宽该限制。

此外，音高算法执行 1121 组数值案例；采集生命周期 17 项、坐标与预测绘制 21 项、音频输出 11 项、课堂客户端竞态 11 项检查通过。这些测试不代表实体麦克风、手机、平板、希沃、Safari 或教室跨设备网络均已通过；使用前应在实际设备与课堂网络中核对拾音、回放和连接。

发布文件为 `index.html`、本说明、`teacher.html` 与 `classroom-lan.zip`。开发用虚拟音源、QA 面板和自动测试不放入学生页面。资料与源码：[GitHub 项目](https://github.com/mutiwangn/AI-html)；音高分析参考 [YIN（2002）](https://doi.org/10.1121/1.1458024)，本项目自行实现保守判定。
