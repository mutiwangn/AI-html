颜色表示什么？

声音的高低也叫音调。色带从左到右表示音高由低到高，范围为 50–1600 Hz。颜色是我们约定的标记，声音本身没有这些颜色。没有识别到稳定音高的片段以灰色表示。

波形和 Hz

“Hz”显示估计的基频；1 Hz 表示每秒振动 1 次。“波形”显示音频信号在固定 20 毫秒内的变化，显示倍率可切换。波形高度不是经过校准的音量分贝值，也不是空气振动的实物照片。

用自己的频率发声

拖动色带或直接输入 50–1600 Hz，选择纯音、木片、金属或琴弦音色再试听。“用这个音高”可以把刚识别到的音高带到这里。材质音色是电子合成的近似示意，不能代替真实材料的声音。

什么时候会“暂未识别”？

这个工具适合观察单一、持续的声音。杂声、多人同时说话、极短的敲击声或复杂音色可能无法确定音高，也可能出现倍频判断误差。识别只是音频分析的估计，不是专业测量仪器。

设备与录音

录音需要 HTTPS 页面和麦克风权限；可在 Safari 或 Chrome 中直接打开。浏览器和设备可能处理输入音量，检测效果会随环境改变。试听电子音会先结束录音；录音结束后可以回听。切到后台会停止录音与播放。

录音只保存在当前页面的内存中，不会上传。刷新或关闭页面会清除；想保留时请先点击“保存”。下载的单文件可以离线试听电子音；离线录音能否使用取决于浏览器的本地文件权限。
