先在教师电脑启动课堂服务

这个静态页面不能接收全班数据。下载启动包，在同一课堂网络内的教师电脑上运行本地服务，再打开终端显示的教师链接。

下载教师启动包
  1. 安装 Python 3.10 或更新版本，解压启动包。
  2. Windows 双击 start-windows.bat；macOS / Linux 在终端运行 bash start-macos-linux.sh。
  3. 在这台电脑打开终端中的“教师链接”，把学生连接码发给学生。

近期支持“本地网络访问”权限的 Chrome 可从 GitHub HTTPS 学生页连接教师 HTTP 服务。iPad / Safari 或不支持该能力的浏览器，请由学校配置可信 HTTPS，使用同源学生入口。详情见包内 README；不要忽略证书警告或关闭浏览器安全功能。

每名学生保留最新一幅波形，以及最多 3600 条约 1 秒间隔的数值记录。RMS 是当前设备输入信号的相对幅度，不能当作校准分贝或跨设备比较响度。关闭课堂会清空全部数据；先下载需要保留的 CSV 和录音。
