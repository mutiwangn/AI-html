# 健康成长的信息

教科版六年级上册第一单元第1课 · 单体 HTML 课堂互动初稿

## 教学立意

本页配合时间胶囊、真实测量、实物比较与课堂讨论使用，不替代教学 PPT。依据教材第2—5页、教师教学用书《生长发育的信息》第40—50页，将分散的成长记录放到同一时间轴和比例尺上，帮助学生区分“观察到了什么”“还能知道什么”。数字探究重点是：相同首尾数据可能对应不同历程，单项指标只能提供部分信息。

## 三页操作

1. **成长叠影：** 选择记录 A 或 B，拖动年级或播放历年记录。同一基线和比例尺呈现身高，身高、体重、肺活量、右眼裸眼远视力四项读数同步变化。可打开“记录”录入资料；缺失项留空。
2. **成长轨迹：** 默认两组身高、体重首尾相同。先只看首尾作猜想，再展开中间记录，拖动标尺或用左右方向键比较相邻学年。可切换四项指标，讨论需要补充哪些证据。
3. **信息解读：** 从两组六年级记录开始，保持体重相同、改变身高，观察 BMI；切换男、女生参照，再点“再看肺活量”加入第二项证据。滑块只改变实验数值，“还原记录”恢复原记录，不反写成长档案。

## 40分钟课堂穿插建议

课前准备时间胶囊和近期体检记录。0—10分钟打开胶囊、核查或测量数据；10—17分钟结合叠影，用数据描述变化；17—25分钟先猜测、再展开轨迹，用记录支持解释；25—33分钟比较 BMI 与肺活量，讨论单项信息的局限；33—40分钟回到真实记录，交流影响生长的因素和可以改进的习惯。各段保留纸笔记录、小组表达和实物体验，不要求全程操作网页。

## 模型与参考标准

默认假设各学年同一时期测量，一年级至六年级为5个间隔。缺失数据不补造、不按0处理，折线遇缺失处断开；连线不代表期间每天的实测。人物仅按身高缩放，不表达胖瘦。视力统一使用右眼裸眼远视力的5分记录，不计算增长百分比或换算近视度数。

BMI 按“体重（kg）÷身高（m）的平方”计算，保留一位小数后对照教材第4页的六年级标准：男生正常范围14.7—21.8，女生14.2—20.8，完整类别见页内教学说明。肺活量按达到的等级下界比较：男生1500／2500／3000 mL、女生1200／2100／2300 mL，分别对应及格／良好／优秀。不计算体质总分，不进行体质排名，不自动诊断或预测真实生长。

标准出处：[教育部《国家学生体质健康标准（2014年修订）》](https://www.moe.gov.cn/jyb_xxgk/xxgk/neirong/fenlei/sxml_twyjy/twyjy_tyws/tyws_xgzc/201407/t20140708_171692.html)。

## 数据与离线使用

默认数据全部虚构，不代表平均水平。编辑记录需自行核对来源；未修改的示例仍是虚构数据。页面不收集姓名，输入仅存于当前页面内存，不上传；刷新会恢复示例，需要保留时先导出 CSV。

下载 `index.html` 后直接用浏览器打开；图形、样式、脚本均已内嵌，无需安装或联网，仅标准来源链接需要网络。建议课堂横屏、全屏使用。

## 后续替换与验证

数据入口为 `DEFAULT_RECORDS`、`METRICS`、`STANDARD`；图形接口为 `personMarkup`、`renderTime`、`renderChart`、`renderCasePerson`。替换人物素材时保留基线与身高比例，不改变数值关系。署名放在目录首页，课件内部无署名。
