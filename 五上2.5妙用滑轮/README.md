# 五上2.5《妙用滑轮》——观察与改装工坊 v2.0

## 课堂定位
以真实实验后的研讨、应用和开放改装为主。保留教材中的器材观察、组装、测量和记录，不把网页计算结果当作新的实测证据。四个入口可独立进入，无闯关或解锁顺序，不要求一节课用完。

推荐一次课堂只围绕一个问题，例如：保留单动滑轮的省力作用，怎样改成向下拉？先让学生标出预测或说出改动，再操作，保留修改前后的方案进行解释。

## 四个入口
- 生活观察：升旗、工地吊装、井口提水、车间吊装；自动运动、暂停、进度回看、聚焦、机构隔离、拆解、轴心留痕与判断。
- 定滑轮：改变负载、安装位置和向下/斜下/水平拉动方向；直接拖绳，按需显示模型读数与运动箭头。
- 动滑轮：与直接提升同步对照，分别选择同样上升高度或同样拉绳距离；学生选择承重绳段后再检查。
- 改装工坊：添加同一种滑轮，选择挂到横梁或连接货物；选择绳头固定处，按顺序穿绳并测试；支持撤销、位置复位、任务限制、设计导入导出和最多三个方案的对照。

“画方向”“描绳路”用于学生表达预测和解释。右上角“说明”包含完整模型边界。

## 运行
`index.html` 是自包含单文件，无外部脚本、字体、模型或贴图请求。保存后用现代浏览器打开。优先使用 WebGL2，创建失败时回退到 Canvas 软件三维；最低技术标注 T2，硬件加速路径为 T4。旧版浏览器的语法支持与实机速度仍须现场检查。

手机纵屏采用上下布局；一体机及平板横屏采用三维舞台＋学生操作区。打开“特写”可同步放大选中轮体，注意该小窗随轮轴移动，位置变化应看主舞台的轴心标记。

直接链接可用 `#life`、`#fixed`、`#moving`、`#builder` 进入相应页面。

## 科学模型与适用范围
绳绷紧且不可伸长，忽略绳、滑轮、吊架自重及摩擦，按缓慢提升计算。研究页中的定滑轮有三种自由端方向；动滑轮采用两段绳向上的常见接法。

工坊限定一根绳、最多四个滑轮、同一个移动吊架、上下交替绕法；根据实际绳路判断支承关系，不按滑轮总数判断。机构自动对齐竖直绳段，不是任意空间交叉绕绳或多级独立吊架的物理引擎。理想计算为 F=G/n、s=nh；教材核心之外的位移比较与限制挑战属于拓展。

自由探索拖动的是位移，读数表示所需拉力；限制任务先判断最大可用拉力，力量不足时保持原位。鼠标拖速和触屏按压不是力的测量；不模拟加速、绳断裂、掉落和真实人体力量。模型计算不能独立验证其预设规律。

## 资产
本版使用可替换的程序化三维几何，参考黄橙色实心轮与深灰双钩外观。研究舞台轮体外径按4 cm设置，坐标单位为5 cm；生活场景为缩放后的机构示意。未取得和导入用户的 Blender GLB，不能宣称已集成该模型。未使用生成效果图冒充可操作3D模型。

## 发布复核（2026-11-07）
复用已交付 v2.0，不重做课件。复核中补齐：播放/暂停按钮与运行状态同步，尊重系统减少动态效果偏好，添加仓库标准最低 T2 角标。其余教学模型保持不变。

本轮通过 JavaScript 语法检查和 19 项自动性质检查：定滑轮、动滑轮、一定一动、两定两动的力与位移关系；移动端固定形成三段支承；未穿绳轮子不改变倍率；无效、重复、不完整绳路拒绝；力量/行程限制；直接调用实际绘制绳路检查不同方案与斜向拉动时绳长守恒。

本轮在受支持的浏览器预览中实际运行 Canvas 软件三维后备：生活观察和工坊入口、模型读数、提升与复位、添加和挂接滑轮、重新穿绳、方案保存与对照，以及真实 JSON 下载后重新导入。最终修复后再次验证“测试提升→暂停→测试提升”按钮状态与位置保持，并确认 T2 角标显示。

原版 2026-11-07 交付记录另报告通过 Chromium 29 项交互检查与 1920×1080、1440×900、1366×768、1024×768、820×1180、390×844 布局检查；这些历史结果不能等同本轮完整复测。

没有实测 WebGL2 硬件加速、希沃一体机、iPad Safari 或低性能电脑，帧率需课堂实机检查。当前环境不允许 file:// 导航，因此未把实际双击离线打开列为已通过；单文件依赖检查确认不请求外部运行资源。
