## 教学内容
1. 同一观察点面南校园全景，清晨/中午/傍晚对照。明确示意不是当天实测轨迹；日出日落不总是正东正西。
2. 俯视十字方向游戏，转身再揭示前后左右，避免“屏幕左永远西”的机械记忆。
3. 真实记录：日期、地点、记录人、固定参照物、朝向，三时段的实际时间、天气、是否观察到、点击图画和文字。未观察到禁止补画太阳。可保存本机/恢复、打印PDF、确认后清空。
4. 不直视太阳/不望远镜观察的持久安全提示；宁波正午在南方天空限定及北京时间12点不等于当地正午；太阳位置和气温不简单同步。跨课时实际观察，不假装40分钟完成一天。
