# 四上 3.2《声音的强弱》

依据项目提供的教科版《科学》四年级上册第三单元第 2 课，教材印刷第 61—63 页及配套教师教学用书，制作面向课堂使用的单体 HTML 互动网页。核心任务是把同一物体的振动幅度与声音强弱联系起来，并保留真实实验声音供反复观察、比较。未使用或改编未提供的作业本题目。

## 两个任务页

| 页面 | 主要操作 | 教学价值 |
| --- | --- | --- |
| 看清振动 | 上下拖动钢尺端部后松手；调节相对拨动距离；原速听声音、静音慢放、暂停与拖动进度；分别保留 A、B 并叠加振动范围、依次回听 | 呈现肉眼难以分辨的振动过程，保持同一物体、同一长度和相同显示比例，比较起始振动幅度的差异 |
| 录音比一比 | 分别采集两段 2 秒声音；在同一比例下显示接收信号；单独或依次回听；统一调节两图显示增益 | 将真实实验中转瞬即逝的声音留下来，便于比较和讨论证据，同时区分声源位移模型与麦克风接收信号 |

先让学生使用真实材料轻、重拨动或敲击同一物体，再根据需要观察模型或保留录音。比较时保持物体、伸出长度或敲击位置、麦克风距离和设备音量等条件相同。网页支持反复操作与比较，不提供预填的实验结论或作业答案。

## 模型与声音

模型把钢尺简化为固定长度的单频衰减振动，频率为 196 Hz。起始位移采用 0—100% 的相对刻度，不表示毫米，也不是器材的实测标定值。

幅度按 `A(t)=A₀·exp(-2t)` 衰减，位移按 `y(t)=A(t)·cos(2π·196t)` 计算，`t` 的单位为秒。改变拨动距离只改变起始幅度，频率与衰减规律保持相同。原速展示和合成声音的观察窗口为 2 秒；到达窗口末端的展示结束，不表示真实钢尺恰在 2 秒停止振动。

原速振动难以在屏幕刷新率下直接呈现，页面用虚影表示快速振动；暂停时显示模型中的瞬时位置。慢放显示起始 60 毫秒，时间放慢 80 倍，慢放时静音，避免把慢放画面误认为音调也随强弱改变。A、B 小图均显示起始 30 毫秒，使用相同横纵比例。范围叠加显示两次起始振动的上下包络。

发声由 Web Audio 合成，音调固定，幅度随模型衰减，不是钢尺的实录。模型用于解释和检验学生表述的一致性，不能作为独立证据证明它预设的规律。

## 真实录音的含义与限制

录音页显示麦克风采集的接收信号，不是钢尺或其他声源的直接位移，也不是经校准的声压级或分贝值。它可以辅助同一设备、同一设置和相同距离下的比较，不能据此比较不同设备的绝对响度。

两图共用显示增益。改变显示增益只放大图形，不改变保存的录音样本或回听幅值，不对每段录音分别归一化。页面请求浏览器关闭自动增益等处理，但浏览器、驱动或麦克风硬件可能仍执行相关处理；因此实际波形不一定完整保留声源强弱比例。

录音仅暂存在本页内存中，不上传到服务器，也不调用外部服务。切换页面可保留本次会话中的记录；刷新或离开页面后清空。每次录音需看到“正在录音”后再发声，使用正常音量即可。

## 运行与兼容条件

`index.html` 内嵌 HTML、CSS、SVG 和 JavaScript，无外部依赖、字体、图片或 CDN。模型和图形可离线打开；播放声音另需 Web Audio 支持并由用户操作触发。

技术等级为 **T1 基础交互**。录音另需麦克风、浏览器授权与安全页面，建议从发布的 HTTPS 地址打开。本地文件、应用内置浏览器或设备策略可能限制麦克风访问；页面提供不可用、拒绝授权等反馈。麦克风不可用不影响第一页模型探究。

全屏由浏览器支持情况决定。适配鼠标与触控操作，不依赖悬停。课件内不显示学校和姓名。

## 验证范围

已执行浏览器交互检查：拖动尺端与发声状态变化、A/B 记录保留、两次范围叠加、慢放和暂停。以上为浏览器环境验证，不代表已在希沃一体机或实体 iPad 完成硬件测试，也不等同于真实麦克风、扬声器的声音测量验证。已检查 1366×768、1024×768、390×844、844×390 四种浏览器视口布局，核心对象、记录与操作位于单屏内；短横屏录音图区已单独调整。另验证调整距离后的记录保护、逐帧到末端、零幅值、复位、页面切换、共用图形倍率及非安全环境的录音反馈。模型关系与音频模块已通过定向检查；音频API的PCM采集、取消和迟到授权清理使用模拟接口验证，未替代实体录音测试。

## 后续维护

单体文件内部将 `SoundModel`、`SoundAudio`、交互状态与 SVG 画面分开组织。替换钢尺视觉素材时保留坐标映射、端点拖拽区域和模型参数对应关系；修改音频时保留 A/B 统一比例、固定音调与记录原始幅值的原则。
