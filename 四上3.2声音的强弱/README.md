# 四上 3.2《声音的强弱》v2.0

面向小学科学课堂的三页单体 HTML 互动网页。围绕“同一段声音的强弱比较—看清物体的细小振动—在生活中选择适当音量”组织操作。依据项目提供的教科版《科学》四年级上册第三单元第 2 课，教材印刷第 61—63 页及配套教师教学用书。

## 三个任务页

| 页面 | 主要操作 | 观察与讨论 |
| --- | --- | --- |
| 同一段声音 | 从头播放同一段 5.6 秒合成旋律；切换较弱、适中、较强，或连续调节音量 | 旋律、速度和音高保持相同，播放强弱发生什么变化 |
| 看清振动 | 选择钢尺、鼓面或音叉，调节拨动或敲击力度；添加纸团、纸屑或悬挂小球；慢动作、暂停、恢复和复位；保留与重放 A/B 力度设置 | 同一物体轻、重操作时有什么不同，轻小物体怎样帮助看清原本细小的运动 |
| 生活中的声音 | 切换城市禁鸣路段、图书馆和教室，调节与停止无关噪声；暂停传播示意，选择显示空气微粒 | 什么音量适合当前活动，过强或无关声音怎样干扰交流、阅读与休息 |

教师可按课堂需要自由切换，不要求依次完成固定流程。真实钢尺、鼓和音叉实验仍提供观察证据；网页用于放大、慢放、保留条件和迁移讨论，不把模拟结果当作独立证明预设规律的实验证据。

## 第一页 同一片段只改变增益

各档播放共用同一段 5.6 秒合成旋律，播放速率固定为 1。改变音量只调整输出增益，不改变片段内容、音高或节奏；连续调节时也不重新生成另一段旋律。

百分比是网页内的相对设置，不是分贝，不表示主观响度必然按同样比例变化。比较时保持设备音量和听音位置不变，先将设备音量调到舒适水平。画面中的扬声器和传播线条属于声音强弱的示意，不是对扬声器实际位移的测量。

## 第二页 振动与接触放大

钢尺保持夹紧点和伸出长度不变，悬空部分连续弯曲；鼓框和鼓面边缘保持固定；音叉的两臂相向、相离振动，柄部相对稳定。调节力度用于同一种器材内的比较，不把不同器材的频率和音色差别当作强弱比较结果。

- 钢尺上的小纸团先受尺面接触带动，离面后再落回。此操作是观察辅助的拓展设计，不是教材必须完成的操作。
- 鼓面上的纸屑先受接触带动，再跳起、落回，帮助观察鼓面的振动。
- 音叉一侧轻触悬球，敲击另一侧叉臂；接触使球沿固定绳长摆开，再回摆。

这些轻小物体放大的是可见现象。纸屑跳起高度、小球摆角都不是声源振幅的直接读数，不能换算成分贝。模型的尺寸、时间、材料与接触参数经过教学简化，不用于定量预测真实器材。

慢动作默认静音，关闭慢动作可听对应的合成示意音。合成音不是真实钢尺、鼓或音叉的录音。A/B 保留的是同一器材的操作力度设置，用于重复比较；柱条不表示实测振幅。

## 第三页 生活情境与传播示意

城市画面特指设有禁鸣要求的路段，关注反复鸣笛对周围交流和休息的干扰。图书馆需要保持安静，同时允许必要的轻声交流。教室应按听讲、阅读、讨论或展示的任务选择音量，不把所有学生始终不发声作为统一目标。

圆弧表示声音向外传播，线条明暗表示相对强弱。同一场景改变音量时，传播速度保持不变；此图不提供实测声速、分贝或安全距离。空气微粒在原位置附近往复运动，不是从声源一路飞向听者。情境反馈围绕打扰、分心与听不清，不把一次普通大声说话演成听力损伤。

## 素材、运行和现有工具

五幅 AI 生成背景分别用于听音角、实验桌、城市、图书馆和教室，均为示意素材，不是实物实验照片。器材、轻小物体和声波由 SVG 与 JavaScript 动态呈现。图像、样式和脚本全部内嵌在 `index.html`，无需 CDN、外部图片、字体或构建工具，下载后可离线使用。

技术等级为 **T1 基础交互**；声音另需浏览器支持 Web Audio 并由用户点击触发。本课不申请麦克风权限、不录音、不上传数据。全屏功能由浏览器支持情况决定。

设置中提供现有[电子拾音器 · 学生端](../四上3.3声音的高低_学生端/)的入口，用于另行观察真实声音。该工具与 3.3《声音的高低》共用，保持独立，不随本课改版覆盖。打开其在线入口需要联网；拾音器的麦克风与课堂网络条件见[该工具说明](../四上3.3声音的高低_学生端/README.md)，不属于本课离线运行的依赖。

## 维护

`LessonAudio` 处理合成声音与播放增益，`VibrationLab` 处理 SVG 器材与轻小物体的运动和接触。主交互层负责页面、力度、A/B 对照与生活情境。替换背景图不应改变实验对象坐标、接触关系或传播方向。

保留本课原网址 `四上3.2声音的强弱/index.html`，保留首页同一课次下的电子拾音器资源以及稳定反馈ID。课件内不显示学校、姓名。
