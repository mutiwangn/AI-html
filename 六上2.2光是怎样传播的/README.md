# 六上 2.2《光是怎样传播的》

单体 HTML 互动初稿 v1.0。技术等级 **T1 · 基础交互**：HTML、CSS、JavaScript、SVG，无运行时外部依赖。下载 `index.html` 即可离线打开。署名仅显示在总目录列表中。

## 教学定位

依据本项目提供的六年级上册教材第 38–41 页、教师用书第 158–167 页与实验说明书对应活动。

教师用书把“根据光斑的位置推理光路，并用箭头图记录”作为本课的重要学习困难。网页用于实物探究之后的解释和比较：把实物中只能局部观察到的亮斑，与不可直接看到的完整光路同步呈现。

### 第一屏：追踪光路

- 三张卡纸可直接拖动，也可选择卡纸后用滑块微调。
- 卡纸可以移出和放回；手电筒可开关，方向可以连续调整。
- 默认隐藏解释用光路。学生先画预测线，再打开透视，比较预测与模型。
- 根据有限孔径逐孔计算通光区间。轻微错位可能部分透光；不把“孔中心不同高度”直接判定为完全无光。
- 光线停在首次遇到的不透明卡纸处，相应卡纸的受光部位和右侧纸屏同步更新。
- 正视光斑使用光源圆锥与纸屏的截面，再由各个圆孔的投影逐层裁切；与主场景的中央截面一致。

### 第二屏：小孔成像

- 点击烛焰上、下部 A/B 两点，分别追踪从该点发出的光；可以同时比较两条代表性光路。
- 展示向不同方向发出、被孔板拦住的代表性光线，以及穿过小孔到达纸屏的光线。
- 直接拖动纸屏或烛焰，剖面光路、正视倒像与像高同步改变。
- 用物距固定、改变屏距的对比解释像的大小变化，不加入不必要的透镜调焦或折射内容。

## 证据板

保留最多四组模型状态及预测线，任取两组并排比较。每组可恢复到实验场景，或单独删除。

“模型结果”由几何计算给出；“实物观察”默认为未记录，由学生根据本组真实实验自行填写。支持简短解释、当前浏览器本地保存，以及 SVG 记录图和 UTF-8 CSV 表格导出。模拟不冒充实测。

## 建议课堂使用

1. 用真实手电筒、三张打孔卡纸和纸屏完成对齐、错位、移出的比较。
2. 选择一组有分歧的现象，在第一屏还原；学生画出预测路线，再打开透视解释。
3. 保存对齐、错位与移出时的证据，在证据板补充实物观察与解释。
4. 以小孔成像迁移同一光路模型：先追踪 A/B，再保持物距不变连续移动纸屏。
5. 回到“排队”和“影子”的生活问题，要求学生用今天获得的证据作解释。

网页用于课堂关键探究环节，不需要覆盖整节课的全部流程。

## 科学模型边界

- 均匀空气中的几何光学模型，不模拟折射、散射、衍射和卡纸的反射。
- 卡纸为无限延伸的不透明理想薄板；图中的有限边缘用于辨识卡纸，不模拟从卡纸外缘绕过的光。主场景是俯视截面。
- 手电筒采用点状等效光源和半角为 8° 的光束模型，不用于标定真实手电筒的发散角或能量。
- 小孔成像采用理想点孔，画面中的孔口被放大。物距为 `u`、屏距为 `v` 时，像高为 `6v/u` cm，物点相对光轴的位置映射为 `-v/u` 倍。
- 烛焰高 6 cm 是教学模型尺度。只绘制烛焰成像，不把未照明的烛身当作自发光体。
- 红、蓝是来源标记。每条光线经过小孔前后保持共线，光在小孔处不拐弯。
- 屏幕明暗是帮助观察的示意，不是照度计。忽略有限孔径引起的模糊和衍射，不由本页面推出“孔越小，像永远越清楚”。
- 透视光路线是解释叠加，不表示在干净空气中能直接看到完整光束，也没有用慢速动画冒充真实光速。

## 操作与兼容

- 触控/鼠标：直接拖动卡纸、方向点、烛焰和纸屏。
- 键盘：Tab 聚焦；卡纸用上下方向键微调，Delete 移出/放回；手电筒方向点用方向键；烛焰和纸屏用左右方向键。Esc 关闭对话框或退出画线。
- 一屏布局；支持全屏按钮；低高度和窄屏有独立 CSS 适配。
- 优先使用 Pointer Events，缺少时回退到鼠标/触摸事件。不使用 WebGL、摄像头、麦克风、外部字体或外部脚本。
- 本地存储不可用时仍可运行、比较与导出，并提示及时导出。
- 真实希沃一体机、旧款 iPad 与 Safari 的设备兼容性需要现场核验；T1 是技术依赖等级，不是实机认证。

## 后续素材替换接口

内嵌脚本按职责分离：`Optics.benchModel`、`Optics.traceRay`、`Optics.pinholeProject` 负责计算；`benchSVG`、`pinSVG`、`screenSVG` 负责展示；`flame` 负责烛焰素材；`sceneSVG` 为统一场景入口。替换素材时须保持源点与光轴坐标、几何比例和成像映射。
