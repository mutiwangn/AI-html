# 六上1.4 身体的“总指挥”

用于六年级上册第一单元《健康生活》第4课的单文件互动课件。接续真实的“你做我猜”和短时记忆活动，聚焦“动作发生时，身体内部怎样协同？”以及“回忆结果能让我们发现什么？”两个问题。

## 数字技术增加了什么

把一瞬间完成的看、想、做、听与调整放慢，联动观察人物动作和脑的协作示意，让学生讨论肉眼看不见的内部过程。记忆任务统一观察时间，遮挡材料后保留独立回忆阶段，最后才展示原材料供学生核对；结果用来交流策略，不作为能力排名。

网页与真实活动交替使用。学生仍需做动作、观察同伴、纸笔或口述回忆，并用自己的体验解释图示。

## 两页功能

| 工作区 | 主要操作 | 讨论依据 |
| --- | --- | --- |
| 指挥回放 | 完成真实的“你做我猜”后，在网页放慢和回看动作过程，对照外部表现与脑协作示意。 | 看词卡、思考动作、控制身体、听取答案和调整动作之间的关系；脑的不同部分持续协作。 |
| 记忆实验 | 准备后开始观察12项词语或图片30秒；材料隐藏后，用60秒纸笔或口述自由回忆；随后揭示原材料，自评勾选并记录本轮结果。 | 原材料、自己的回忆和核对结果；分类、联想等方法如何影响自己的操作体验。 |

记忆页准备阶段不提前显示材料；自由回忆时不以备选项提示答案。核对阶段的勾选是学生自评，并非网页自动读取纸面答案。切换工作区或页面进入后台时暂停计时，返回后手动继续。界面最多保留4轮课堂结果，不设置排行榜。

## 40分钟课堂建议

| 时间 | 实践与讨论 | 网页的作用 |
| --- | --- | --- |
| 0—7分钟 | 两名学生完成一轮“你做我猜”，其余学生观察哪些身体部位参与。 | 先不展示内部解释，保留学生原有想法。 |
| 7—17分钟 | 回顾一个具体动作：从看到词卡到同伴说出答案，哪些过程实际观察到了，哪些属于解释？ | 放慢同一情境，将动作、感觉信息与脑的协作示意联系起来。 |
| 17—27分钟 | 按30秒观察、60秒自由回忆的规则开展记忆活动，再对照原材料核对。 | 统一时间、及时遮挡，避免材料持续可见或选择题提示改变任务。 |
| 27—34分钟 | 交流分类、联想等记忆方法；需要时再做一轮，说明材料或熟悉程度是否改变。 | 保留当次结果供对照，支持依据证据讨论，不宣布某方法一定更好。 |
| 34—40分钟 | 回顾一天中脑参与的活动，提出一项健康用脑的生活做法。 | 回到生活解释：脑不仅参与显眼的动作，也参与思考、记忆及基本生命活动的调节。 |

## 模型与任务边界

- **内部过程是教学示意。** 人体轮廓、脑的图形和移动信号不来自脑扫描、神经电生理或学生个人数据；慢放时间不能换算成真实神经传导速度。
- **脑的各部分协同工作。** 大脑、小脑和脑干不能排列成“大脑先做完、小脑再做、脑干最后做”的流水线。图示可以依次突出关注点，但不表示其他部分停止工作。小脑参与动作协调和平衡，脑干参与呼吸等基本生命活动的调节。
- **感觉路线应符合所示情境。** 看和听所涉及的信息由相关神经通路传向脑，不能画成先绕到脊髓才进入脑。人物与通路图是概括模型，不承担精确解剖定位。
- **不存在一个包办记忆的固定小格子。** 页面不依据某一闪光位置推断记忆由一个孤立脑区完成，也不引入“左脑理性、右脑艺术”的性格分类。
- **回忆与识别分开。** 必须先在看不到原材料和候选答案的条件下回忆，之后才揭示材料并核对；核对阶段选择了多少项不等于系统验证了多少正确答案。
- **单轮结果不能评价智力。** 注意状态、材料熟悉度、识字程度、观看距离、回忆方法和表达方式都会影响表现。学生不应因一次结果被贴上“记忆好或差”的标签。
- **不同轮次未必是严格对照实验。** 重复原材料会产生熟悉效应，不同材料可能有不同难度；比较时需要说明条件，不能只用数字变化断言某种记忆方法有效。

## 使用与兼容性

下载本课完整的 `index.html` 后，用浏览器直接打开。页面的样式、脚本和SVG示意图均包含在同一文件内；核心功能无需联网、账号、摄像头或额外三维库。

本课登记为 **T1 基础交互**，表示核心技术由HTML、CSS、JavaScript和SVG组成。该等级不等同于所有实体设备都已实测。课堂结果用于当次交流；需要长期保存时，可用纸笔或学校设备截图保留。

在希沃一体机和学生平板首次使用前，重点核对全屏后的主场景与重点文字、最后一排的可读性、触控操作，以及计时暂停和继续的状态。老款iPad是否支持网页全屏取决于设备及系统版本，可在横屏浏览器中使用。

## 后续素材替换

首稿以二维SVG表达人体、脑和任务材料。后续精修可以替换图形、词语或图片内容，但应保留相应元素标识、事件绑定及任务状态关系。

替换脑图或通路时，需要同时核对标签、信号终点和动画时序，保持协同工作的科学含义；不能仅增加解剖细节却改变信息路线。更换记忆材料时应继续使用12项、30秒观察与60秒自由回忆的课堂规则，避免预览、替代文字或其他界面内容提前泄露答案。

## 教学依据

- 用户提供的六年级上册教材：第一单元《健康生活》第4课《身体的“总指挥”》，印刷第14—17页，对应PDF第18—21页。
- 用户提供的六年级上册教师用书：本课印刷第76—86页；其中第85页关于重演“你做我猜”并分析脑的参与，第86页关于记忆活动重在交流方法而非比较胜负。

教材和教师用书用于核对教学目标、活动与科学边界。本课未嵌入这些资料的扫描页面。

## 当前实现与替换接口

- 预设“投篮、游泳、刷牙”三个动作情境；点词卡轮换。它们是预设重演，并非录制或识别学生动作。
- 时间线六段为“看信息、想动作、做动作、听答案、作判断、改动作”。可慢放、暂停、选段与拖动逐帧回看。初始保留问题，点“查看过程”才显示该步解释。
- 脑部两视图由 `window.BRAIN_ART.side` 与 `.top` 提供，均为适用于 420×300 视框的SVG内部片段。主图标签另在 `refreshBrain()` 中绘制。`window.BrainLesson.replaceBrainArt(view, svgMarkup)` 可更新图形；保留 `data-brain-part` 的 `cerebrum`、`cerebellum`、`brainstem` 绑定。
- `window.BrainLesson.getState()` 用于检查当前回放状态；`.pause()` 暂停；`.setPage('replay'|'memory')` 进行完整生命周期切页。
- 记忆模块的 `ART`、`WORDS`、`GROUPS` 分别定义SVG、名称与四组材料，共48项；图像观察时不显示词语标签，核对时才出现名称。
- `window.MemoryLab.enter()/leave()/reset()/getState()` 是记忆页接口；`reset()` 保留当次课堂历史，`reset({clearHistory:true})` 全清。记录只在当前页面会话中保留，刷新即清空，不写入浏览器持久存储、不上传。
- 第五轮循环到第一组时提示材料已用过；不声称四组等难度，也不把图像/词语的单轮差异解释为因果结论。
