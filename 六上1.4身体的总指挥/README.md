# 六上 1.4 身体的“总指挥”
原创课堂辅助探究稿；教材教参细节待核。

## 探究链
看见杯子伸手的感觉、信息整合、神经传递、肌肉与反馈五步流程；讨论脑、脊髓、周围神经协同及反射边界；自愿不计时的六图形顺序练习，可分三对、遮住、回忆、撤回、对照和再看；区分任务表现与智力健康判断、重复练习与策略因果。

## 科学与隐私
概念流程不是脑区定位、神经速度或真实解剖图。动作有持续反馈，部分反射无需先经意识思考，不意味着脑完全不知情。禁止疼痛、烫、惊吓或憋气等验证。图形练习不是认知测验，无智力评分、排名、倒计时或个人数据输入，不保存成绩，不推断健康。
使用固定序列，因此反复练习熟悉程度改变，不能用于证明策略因果；可随时跳过。状态仅页面内存，刷新清除，无上传。
