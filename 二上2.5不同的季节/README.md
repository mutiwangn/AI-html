## 三个独立活动
1. 同地点四季并排对照，任意选择两季，提示默认隐藏。原创SVG。特别对照常绿树与落叶树，不把积雪作为冬季必要特征。
2. 12张季节图卡，自选放入多个盒子，可移除；不设错误的单季唯一标准答案。交流地点、现象和证据。
3. 真实观察独立记录，无需输入文字；保存当前浏览器，可打印。与示意图明确分开。

这是课堂探究工具，不替代教师解释，不涵盖教师用书动物过冬拓展的完整资料。图卡表情为系统字符，不同设备字形可能不同；文字标签始终存在。SVG/代码原创，无第三方下载素材，无姓名校名。
