# 六下 4.5 八颗行星
平均日距与赤道直径比较基础专题，不等于整课完成。教材正文、版次与教参待核。Notion 六下目录3fa945e5f61e81d49201da0529936503，学生教材扫描目录4–5页。
八条共用线性尺：日距单位亿千米，0–50总览/0–3内侧放大，外侧超界箭头。逐个选中行星；另窗以同一比例对比该星与地球赤道直径。每次选星重设直径窗缩放，定位点不是球体大小。平均日距差不是行星实际间距，不表示真实排列或实时星历。
