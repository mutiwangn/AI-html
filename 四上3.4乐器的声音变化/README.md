# 四上3.4《乐器的声音变化》

两页单体互动课堂，v1.0。入口为 `index.html`，无外部运行依赖。

## 本课的数字观察价值

教材的真实吉他、排箫操作应保留。网页补充有效振动部分、统一倍率慢放、空气柱透视与可保留的同刻度比较，帮助学生把乐器结构、变量与听到的声音联系起来。

- **吉他的弦**：点选六条模型琴弦；拖动按压点、调节松紧，或直接拖弦后松手。粗细、有效长度、相对张力、拨动幅度分别可调。
- **排箫的管**：点选八根管吹奏；拖动管底或滑条改变空气柱长度，调节气息；透视空气沿管轴往复运动。
- **对照**：每页独立保留条件 A，与当前 B 用相同 10 毫秒时间窗、相同振幅刻度比较。可依次试听、预览并下载 SVG 对照图。
- **课堂控制**：透视开关、暂停慢放、当前乐器复位、静音、全屏；支持鼠标、触控和键盘替代操作。

## 科学模型与边界

所有频率与轨迹均为模型计算，声音为合成示意音色，不是麦克风测量或真实乐器录音。不能以模型结果作为独立验证模型预设规律的实验证据。

### 弦

`f = (1 / (2L)) × sqrt(T / μ)`，`μ = ρπd²/4`。

- 六根弦使用相同模型材质（密度 1150 kg/m³），基准张力为 45 N；直径依次为 0.50、0.60、0.72、0.86、1.03、1.24 mm。
- 它用于控制变量，不复制真实吉他的材料组合和标准定弦。
- 有效长度范围 32.5–65 cm；按压点至琴桥的部分参与所示主振动，左侧灰色段不触发主段拨弦。
- 相对张力 0.50–1.50 倍。改变拨动幅度不改变基频，是小振幅模型简化。

### 排箫

上端开口、下端封闭，`f = 343 / (4L)`，L 以米计。忽略端部修正，图中长度不作为制作实物的精确下料尺寸。

- 初始空气柱长约 32.8–16.4 cm，接近 C4–C5；每根可在 12–40 cm 范围调节。
- 设 y 从开口量向封闭管底，纵向位移形状为 `cos(πy/(2L))`；开口位移大，封闭端为零。粒子在原位置附近往复，没有贯穿封底管的单向气流。
- 气息在同一基音状态下只改变示意振幅；真实过强吹奏可能造成音高偏移或激发其他共振。

### 声音与画面

- 声音保持模型基频；图示统一以 1/120 速度循环慢放、放大位移，不演示振幅衰减。
- 轨迹只画基频分量。不同乐器的示意振幅不能直接当作同样的响度。
- A/B 依次试听时，主舞台冻结并标明保留的是当前 B，对应轨迹按试听时段突出显示，避免 A 声音与 B 动画混淆。

## 使用与兼容

T1 基础交互：SVG、普通 DOM、Web Audio，不使用 WebGL/Three.js。打开 HTML 即可使用；音频在首次用户点击后启用，不请求麦克风、不上传数据。来源链接需联网，运行本身不需要。

横屏采用同屏主舞台与控制区；平板竖屏、手机按空间重排，窄屏允许纵向滚动。浏览器不支持全屏或音频时会提示，模型仍可操作。对照图提供可见预览与显式下载链接，文件保存方式取决于浏览器。
