# 四上 1.6 我们来做热气球

教科版四年级上册第一单元第 6 课，离线单文件互动课堂。

打开 `index.html`，按“实验与观察 → 微粒解释 → 活动记录”使用。四个观察时刻支持直接回看、画袋子轮廓、记录冷暖与文字，并导出记录图片。参考示意默认隐藏，不自动填写学生答案。

- 技术等级：T2（Canvas 二维绘图、SVG、可选 Web Audio）。无需联网加载脚本、字体或模型；仅科学说明中的外部参考链接需要网络。
- 微粒颜色、速度和演示时间是教学示意，不是真实测温或加热操作参数；相同体积空气比较与整袋浮力、总重力解释相区分。
- 真实明火实验须由教师按教材及学校安全规范组织；纸筒不是防火装置，不触摸发烫部位，不自行放飞孔明灯。
- 课堂记录只存于当前浏览器，未上传。公用设备使用后及时导出并清空记录；清除浏览器数据会使未导出记录丢失。
- 保留原有三页课堂结构，补全年级、单元、课号标识。实体希沃、iPad 和离线文件模式尚需实机核验。

已在桌面 Chromium 检查加热入口、微粒/浮力切换、冷却说明、三页导航、文字及冷暖记录与参考显示。手绘、PNG实际落盘和独立手机视口尚待核验。
