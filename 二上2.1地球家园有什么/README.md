# 二上2.1 地球家园有什么

教科版2025年版，二年级上册第二单元《地球家园》第1课。单文件离线互动网页，直接打开 `index.html`，不需要联网、注册或安装。

## 课堂用法
- **发现**：先口述，再点击原创景色示意图收集景物。整片景色、树林与河边放大视图使用同一场景，支持回看位置与周围环境。可选显示名称、整理生物／非生物自然事物／人造物品。
- **联系**：自主选择两个事物讲述联系，支持交换顺序和更换卡片；线索仅辅助表达，不作唯一答案或自动评分。
- **家乡**：选择本机照片并讲述两三种事物的联系；真实观察记录默认留空，可保存为文字文件。照片不上传、不包含在导出文件中。刷新后本次记录清空。

建议结合40分钟课堂：实物地球仪整体观察与寻找中国5–8分钟，景色观察与发现8–10分钟，小组联系故事10分钟，家乡交流与新问题8–10分钟。网页是交流工具，不替代地球仪或真实环境观察。

## 内容边界
景色为原创概念示意，不是地理地图、真实照片或等比例图。空气不能由图画直接证明，需联系真实体验。土壤作为自然事物整理，同时提示土壤中生活着生物。保留真实观察与讨论线索的区别，允许“还不知道”，不强迫编造联系。

## 来源与兼容
依据《二年上册 科学 教师教学用书 教科版 25秋》第115–123页及对应教材课目组织：从整体到局部观察、整理地球家园的事物、讲述自然事物与人类生活的联系。代码和示意图原创，无外部库、素材、字体或网络请求。

按钮至少48px，支持触控和键盘；图景按钮可用Tab聚焦、回车或空格激活。窄屏单列，可使用浏览器全屏。实体希沃与平板硬件尚需设备端核验。需要显示本机照片时，建议使用JPG/PNG，文件上限20MB。
