# 三上1.8 天气的影响
独立重制辅助稿，HTML与app.js同目录，无学校/真实姓名，无第三方素材依赖。天气图标用系统字符。不复制旧版内容。教材及教参待核，非整课验收。

四个情境：晴热活动、雨天出行、雨后花盆、大风晾晒。选择后给出理由及尚需条件，不将晴雨简单分好坏。区分观察、预报、推测。两条真实观察点选记录、并列比较、CSV下载。无文字输入，不上传，仅内存保存。

不模拟当地天气，不自动证明植物状态的天气因果，不提供健康或气象预警判断；恶劣天气听从官方预警、学校和成人安排。

验证：JS语法；云端Chrome情境切换、正确选择和条件提示、观察证据分类、记录1与空白记录2独立、CSV下载、桌面截图。教材、课堂、实体触屏及旧浏览器待核。
