# 一下1.2《给物体分类》教材核对修订

## 核验范围
已直接阅读用户提供《【教材】一下.pdf》扫描原页：PDF第7页（印刷2页）为前一课九种物体；PDF第10–12页（印刷5–7页）为本课。核心要求：同一批九物编号，选择一个特征分成两类，换特征再分并记录，同伴猜分类依据，讨论同一特征下结果是否不同；拓展观察体育器材摆放。

本次已按这些学生教材核心活动修订。教师用书及明确版次版权页仍未核验，不称整课教参验收。网页不包含教材截图、儿童照片或整页复制，仅使用原创简图。

## 改动
- 原六个颜色/形状组合图形改为教材同九物：1小木块、2作业本、3红砖、4塑料笔筒、5乒乓球、6圆柱橡皮、7长条橡皮、8钢尺、9塑料尺。编号是本网页自己的固定编号，不复制教材活动照片中的贴签顺序。
- 每次只有两个类别。提供形状、软硬、材料三份独立分法记录；这些是可选分类维度，不声称教材指定三种唯一标准。
- 分类者先对实物观察并口述两类的具体要求，再点卡片放入第一/第二类。保留改放、拿回、切换标准、二次确认清空当前分法，其他分法不受影响。
- 检查仅判断是否九物都分完、是否分为两个非空组。不凭简图替学生判断实物软硬/材料，不把所有分完都说成答案正确。
- 第二页用两椭圆框记录物体编号，隐藏特征供同伴猜测；揭开后仍要求说明两类具体标准。可前后切换三份记录。增加编号意义、同一特征下具体要求不同的研讨，以及体育器材拓展。

## 课堂使用边界
先实际观察九件物体，再用网页帮助记录、回看与交流。教师可在黑板写下两类具体要求；本工具不要求一年级打字。形状、软硬、材料不是由系统预设类别成员，学生按所选实际标准讨论，如“塑料制成/不是塑料制成”；分类维度与具体分组标准不可混淆。缺实物时只能做示意讨论，不据图判轻重/软硬。

图卡不按实物比例，颜色形态是示意；尺刻线不作测量工具。教师负责红砖、钢尺安全，不抛、不敲、不尝。记录刷新清空，需留存请同步纸笔记录。
