## 功能
六个原创示意物体按两种可见特征分类：两种颜色、三种形状。先点物体再点类别，不需要拖拽或打字；可改放或拿回。两种标准各自保存，明确提示一次只按一个标准。检查反馈区分未分与错放，不自动搬动物体。对照页展示学生自己当前的两种结果，讨论同一物体在不同标准下归属不同。

练习图形不是教材原图，也不能据此判断真实物体材质、软硬、轻重。建议之后由老师组织安全实物分类。刷新清空；二次确认仅清当前标准，不清另一种。
