# 四上 2.2 认识呼吸器官

2026-11-11 深蓝解剖主题 · 无配音 · Three.js原创教学模型。

## 使用

直接打开本目录 `index.html`。运行所需Three.js、脚本、样式和MIT许可全部内嵌，约0.72MB，无CDN、字体、图片或模型下载依赖。16:9（1600×900）舞台按可用窗口等比缩放。四个主题、十二个渐进步骤，中央观察，左右操作，只显示当前活动所需按钮。无需文本输入，无姓名或健康资料收集，无配音、音效或持久存储。来源外链只有主动点击时才联网。

- **感受呼吸**：舒适自然呼吸，提出猜想；用点选区分观察来源和胸部外部现象，未观察不自动补填。
- **空气的通路**：鼻腔→咽→喉→气管→支气管→肺内细小分支与肺泡。胃和膈肌不属于正常空气通路。肺泡是肺内结构，不与肺并列为另一器官。
- **器官的协作**：吸气、安静呼气、完整一轮。同步改变膈肌拱形、胸廓宽度、肺的体积及气道中的空气标记。可暂停、重播、观察端点、叠加轮廓和切换低动态逐帧方式。
- **用模型解释**：瓶体/管子/气球/橡皮膜对应关系，拉下与松回底膜，讨论固定瓶壁和外力拉膜等局限，并提供鱼、蚕、人的呼吸拓展。

## 科学与教学核对

依据用户提供的教科版2026版《科学》四年级上册印刷33—35页（PDF37—39页）和《科学教师教学用书》本课132—141页。教材主线为体验、猜想、模拟、解释与修正认识。未打包教材扫描页或教材照片。

2026-11-11核对的公开来源：
- NIH/NHLBI 呼吸过程：https://www.nhlbi.nih.gov/health/lungs/breathing-benefits
- NIH/NHLBI 呼吸系统：https://www.nhlbi.nih.gov/health/lungs/respiratory-system

吸气时膈肌收缩下降、肋间肌等参与扩大胸腔，肺被动扩张，肺内气压暂时低于外界，空气进入。安静呼气主要依靠肌肉放松后的弹性回缩；不把肺画成主动收缩的肌肉，不用向管口吹气代替吸气过程。

图形为原创参数化结构示意，不是扫描模型或真实解剖标本。前方组织、胸膜、完整肋间肌及肺叶细节省略；左右肺略有区别，但不是可用于诊断的精细解剖模型。肺内分支数量大幅减少。空气粒子只是方向标记，不表示单独氧分子、浓度、数量或真实速度。模型的时间、幅度与体积均非人体测量。

瓶式模型仅表达空间变化和空气出入的部分关系。瓶壁固定，不能表达胸廓运动；外力拉橡皮膜不同于膈肌主动收缩；气球内部也不同于真实肺。人体与装置分开显示，标签明确“示意”。

## 安全与隐私

保持舒适呼吸，可只观察演示或教具，不要求每个人练深呼吸；不憋气、不竞赛、不强迫反复用力深吸，不触碰别人，不把课堂现象用于医学诊断。不适立即停止并告诉成人。点选记录只保留在当前页面内存，刷新清除，不上传。
