# 四上2.2 认识呼吸器官

独立原创课堂辅助探究稿，教材教参细节待核，不代表整课验收。

鼻腔→咽喉（合写）→气管→支气管→肺内分支与肺泡逐步连接，误选食管胃膈肌有解释。明确嘴也可通气，呼出气不是纯二氧化碳。原生SVG不是人体比例或诊断图，不使用第三方解剖模型。

吸气与安静呼气胸廓/肺/膈示意、另一状态轮廓对比。膈始终位于肺下方，说明胸膜肋间肌等被省略，肺不是主动收缩肌肉。瓶子气球模型局限明确。

匿名观察区分来源、外部现象和解释。不采集姓名、学校、身体数值或疾病；仅舒适正常呼吸，可改用教师演示，不憋气或强迫深呼吸。CSV本地导出，数据仅内存。

已验：JS语法、误选通路、全路径、撤回；修正膈与肺的示意位置后复核吸呼截图；空白/完整模型观察、导出和清空。实体触屏、旧浏览器、教材教参及完整课堂验收待完成。
