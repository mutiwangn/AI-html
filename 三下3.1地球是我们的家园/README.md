# 三下3.1 地球是我们的家园

三年级下册，第三单元“只有一个地球”，第1课。离线单体HTML，无外部网络资源。

## 本课是单元启动，不是最终海报制作
1. **建立地球档案**：五条教材/教参可核对的资料，每条带具体出处，配合太阳—地球—月球关系示意。最多选3条进入计划，练习聚焦而非堆满知识。
2. **海报研究计划**：填写研究方向、小标题、待研究问题、研究办法、材料和任务。预览会提示资料可能是主题线索还是背景；这只是规则辅助，不自动判定科学正确或主题质量。
3. **检查与下载**：准备检查只看是否填写，必须由师生进一步讨论。下载计划保留资料全文与来源，并把“待研究问题”单列，避免误当已知结论。

图中大小、距离、位置均为概念示意，不按比例，不表示轨道运动；球面网格不是海岸线，不可据此量海陆比例。大气圈示意不表示实际厚度或边界。

每年4月22日是世界地球日，本页不提供未经核实的当年官方主题。教材约15℃为概括性示例，不作为当前气温展示。完整科普海报留待本单元第8课，当前文件是研究计划草案。

## 操作与保存
最多选3条资料；在计划页“移出”后可回第一页重新选入。五条基础资料不支持修改或外部上传，标题、问题和准备可自由填写。

保存一份当前计划到本浏览器，包括资料选择和五个输入项；允许不完整草案保存。切页保留草稿，刷新恢复上次保存值。下载为**当前计划**，不要求先保存，含不完整项提示；导出HTML可阅读，不支持导入。

不跨设备同步，无多组账户、删除全部或版本历史；重新保存覆盖上一份。无需填写学生姓名。请下载备份。
