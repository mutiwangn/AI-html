# 一上1.1 我们知道的植物

教科版2024年一年级上册，第一单元《周围的植物》第1课。离线打开 `index.html` 即可，无外部字体、脚本或图片依赖。

## 课堂使用
- **找一找**：先说认识的植物及特点，再点选。四处植物各计一次；长椅、石头不计入。名称默认隐藏，可放大同一示意对象，来回对照整体。
- **我的发现**：教师放入本地校园或植物照片，孩子用手指圈画，无需打字。支持照片平移、缩放、撤销和导出 PNG；圈画与照片坐标绑定。导出的是完整照片与圈画，而不是被放大后裁掉的视窗。
- 照片仅在本机处理，不上传、不自动保存；刷新或关闭即清除。建议使用没有学生人脸、姓名的照片。先保存记录图，再更换照片。
- 课堂应以实物观察和交流为主，网页辅助约10分钟。课后可选择当地、当季适宜植物种一盆，持续照料、观察。

## 教学依据与边界
依据《科学 教师教学用书 一年级上册》（教科版，2024秋），第41页聚焦情境、第44页教学实施建议：交流认识的植物，描述特点，在校园图片中圈出植物，认识花、草和大树都是植物。

公园画面及植物图均为原创 SVG 示意图，不作物种鉴定依据；小草不是一个具体物种。放大不增加真实观测数据。真实照片记录初始为空，不以模拟结果代替学生发现。

## 设备
适合现代 Chromium / Edge、希沃浏览器与平板浏览器。主要按钮至少52像素；窄屏改为上下排列。照片圈画使用 Canvas 和 Pointer Events，归类为 T2。旧设备请使用最新版浏览器；文件选择、下载位置与全屏由设备浏览器管理。
