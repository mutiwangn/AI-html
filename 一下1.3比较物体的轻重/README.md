# 一下1.3《比较物体的轻重》教材修订

## 核验范围
依据用户提供《【教材】一下.pdf》PDF第13–15页（印刷8–10页），已直接视觉核读第14、15页核心活动与记录表；结合只读教材核对报告。学生教材活动为玻璃球、乒乓球、空盒子、小木块四件实物，猜、掂、称三次排序，比较三次结果，说清轻重的比较对象；拓展是形状大小相似的纸杯和塑料杯。

本次已补以上核心任务及拓展引导。教参、出版版次仍未核实，页面仅标“已核学生教材核心活动”，不声称教参全文验收。

## 由旧版改进
- 主活动由抽象A/B/C预设模型改成教材四件实物，猜一猜/掂一掂/称一称独立记录，支持反复修改而不覆盖之前轮次。
- 数字排位1至4表示从较轻到较重，不是质量值。允许并列排位，以便如实记录本轮判断一样重；明确不能用并列代替分不清。
- 未记录显示破折号，暂分不清显示问号；与相同排位分开。保留原有“不确定不等于一样重”“外观大小不能决定重量”和依靠真实比较的优点。
- 三轮对照表只标出已有记录的变化，不判断哪轮自动正确，也不预设玻璃球/球/盒/木块的实际重量顺序。逐轮清空须确认，其他轮次不变。
- 加入天平先检查空载平衡、稳定后观察、近似平衡的工具边界，及两种相似大小杯子的实测拓展。原理想三样品模型不再作为主活动，避免其预设结果被当作教材实物答案。

## 使用建议与边界
学生用真实四物完成每轮，再点选图卡与排位。教师统一说明排位方向；若出现并列，可共享同一排位，不要求强行区分差异。排位变化反映判断更新，不等于质量改变。网页不能自动检验每次实物称量的准确性。

先猜并记录，再掂并记录，最后借助教师准备的简易天平两两比较。即使称过仍分不清，也可保留问号继续调查。教师指导小球和玻璃器材安全，避免入口、滚落、撞击。图卡不按实际大小比例，不替代真实质量测量。

三轮记录仅保存在本次网页内存，刷新清空；长期留存同步纸笔。无打字、上传、个人信息、外部脚本字体图片。
