## 数字辅助
理想等臂模型设定三份样品A/B/C，内部相对量2/4/3，无单位，不映射具体材料。A画得较大但较轻，说明外观大小不足以决定轻重。先想后比较，可换配对和左右位置。空盘已平衡、左右等臂，倾斜只示意较重端较低，不显示力矩大小或真实动态。模型锁住时水平不代表一样重。
第二页将实际安全物体的猜想、手掂/工具方法及发现独立记录；分不出轻重不等于一样重。无自动实物测量，无伪造实验数据。
