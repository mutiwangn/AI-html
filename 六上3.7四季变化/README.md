# 六上3.7 四季变化

[打开互动课件](index.html)

本课对应教科版六年级上册第三单元第7课《四季变化》，依据教材90–93页及教师用书289–298页设计。围绕“为什么会夏热冬冷”，把手电筒光斑实验、地球仪公转模拟与数字模型连接起来，让学生用观察证据解释变化。

## 三个探究页面

1. **光照的秘密**：拖动太阳改变高度，观察固定光束在地面的投影与竖杆影长。光束始终包含12份示意能量，斜射时分布面积变大，单位面积相对光照随之变化。留存一次状态，与当前状态比较。
2. **跟随地球**：沿圆轨道拖动地球，地轴方向保持平行；同步查看南北纬30°观察点的当地正午太阳高度、影子与昼长。在春分、夏至、秋分、冬至主动记录，逐步形成四站证据表。
3. **改变地轴**：将23.5°倾角与自选0–45°倾角放在相同公转位置比较。选择南北纬30°、赤道或南北纬70°，观察全年正午太阳高度曲线，主动记录所选时刻的对照结果。

“证据”中最多保存6组记录，可删除、填写解释，并导出SVG证据表与CSV观察数据。记录保存在当前浏览器；导出的是已记录的观察点数据，不是整条年度曲线。第1页的光斑对照用于当前探究。

## 数字技术增加了什么

实物实验容易观察光斑大小，却难以直接看见同样总量的能量怎样分散；固定数量的能量标记与地面网格补足这一视角。全球公转与地面观察联动，帮助学生把“地球在轨道上的位置”转换为“当地天空中的太阳高度”。

改变倾角的对照允许保持其他条件一致，检验“只要地球公转就会有同样四季变化”的解释；南北半球同时比较，则为检验“离太阳近所以是夏天”提供证据。四站记录和全年曲线服务于学生的描述、比较与推理。

## 科学模型边界

- 倾角以公转轨道平面的法线为参照。23.5°相当于地轴与轨道平面约成66.5°；公转时轴向基本不变。
- 圆轨道用于控制日地距离，突出倾角的作用；并非声称真实轨道是正圆。日地大小、距离与运动速度均不按真实比例显示。
- 能量标记表示同一束光的等量份数，光斑面积变化不代表总能量增加。相对光照是理想几何模型，不是温度计或真实光照测量值。
- 北纬30°夏至正午太阳高度约83.5°，仍未达到直射。赤道与高纬地区的周年规律也不能套用同一组“春夏秋冬温度”标签。
- 正午太阳高度反映照射角度，昼长反映照射时长；实际气温还受天气、海陆差异与热惯性影响，夏至不必是最热日。模型不计算摄氏温度。
- 昼长采用几何日照模型，忽略大气折射、地形与太阳视直径；高纬度需区分极昼、极夜。曲线与导出数据属于模型结果，不能当作实测气象记录。

## 文件与素材替换

入口为单体`index.html`，使用内嵌SVG、CSS与ES5脚本，无外部资源依赖，可下载后离线打开。界面以横屏一屏呈现为目标，支持鼠标与触控操作，不含校名和署名。

模型与绘图预留独立接口：`window.SeasonsLab.Model`负责太阳位置、太阳高度、影长、昼长等计算；`window.SeasonsLab.Renderers`负责轨道、地球、地面场景与曲线绘制。后续替换地球纹理、人物或场景素材时，应保留模型单位、坐标约定与交互状态，避免视觉更新改变科学计算。
