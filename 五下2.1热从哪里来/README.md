# 五下2.1 热从哪里来 · 基础辅助稿

课名已核 Notion 项目五下目录（学生教材 PDF 第4—5页目录录入，版次年份未定）；匹配版教材正文、教参待校，不声称完整复刻教材。

## 互动
- 阳光：移入/移开遮光板，显示直射路径的改变。
- 电热：闭合/断开图示开关，显示电能输入；灰色不代表已冷却。
- 摩擦：滑块或左右按钮使手掌相对移动；静止接触不等于持续摩擦做功。
- 普通衣物：穿/脱对照，区分身体产热与衣物减慢散热。
- 各场景可揭示能量路径、回答辨析题并阅读理由。

## 模型局限与安全
不计算温度、热量、效率。移动次数不是做功量或温升；颜色不是热像。衣物场景假设周围较冷，不代表完全停止散热。电热器只表示电阻式加热，不包含热泵；外形不是接线图。关闭过程不代表立即冷却。不要直视太阳或聚光点火，不接市电、不短路电池、不触摸电热器；真实轻搓手不适即停止。无上传、账号、持久保存。
