2. 杯/碗/瓶静止截面并列示意，切换水体边界与水平线；真实换容器观察记录。图示明确非实测水位、不表示等量；蓝色不是水本色。
3. 保留原先密封半瓶水横竖放、并排比较、水平线的数字增益。
4. 汇总真实记录，另记透明性、静止水面和横竖放形状。保留不确定；不自动判定正确答案。
5. 教材拓展相同杯、同体积水油实际称量；检查空杯，不预设重量结果，约一样重与没看清分开。
