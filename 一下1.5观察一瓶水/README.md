## 课堂使用
1. 学生先观察教师准备的清水和透明塑料瓶，提出换放法后水的形状会怎样的猜想。
2. 数字页可并排保留同一瓶水竖放、横放的静止定格，显示水面参考线。回到实物换放法后再次比较。
3. 实物记录颜色、透视图卡、形状变化。无需打字，允许未观察和不确定，不根据模型自动生成结果。建议教师先在实物页观察，再展示模型，避免答案代替探究。

## 科学边界
- 蓝色只标示水的位置，不表示清水本身呈蓝色。
- 简化的半瓶水模型采用中心对称瓶身；旋转前后下半部分面积一致。瓶子封闭、未漏水，同一份水量不变。展示放稳后的静止状态，不是流体动力学模拟，不描述实际晃动时间、流速、弯月面。
- 并排两图是同一瓶水的两个时刻，不是把水分成两瓶。横竖图统一比例、无伪造读数。
- 无色与透明分开讨论。不饮实验用水，不闻不明液体；塑料瓶、托盘、洒水及时擦干。
