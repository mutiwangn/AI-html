# 六上4.1《时间在流逝》

教科版六年级上册第四单元《计量时间》第1课，三页单体HTML课堂互动，v1.0。

## 打开与运行

- `index.html` 为完整课件。直接打开或从GitHub Pages访问，无外部脚本、字体、图片、CDN或接口依赖。
- 课堂一体机优先使用横屏全屏；支持电脑鼠标、键盘与平板触控。主界面一屏显示。
- 最低技术等级：**T1 · 基础交互**（HTML、CSS、JavaScript、SVG），核心功能不使用Canvas/WebGL。
- 页面及首页入口不添加学校、姓名和“原创”署名。

## 教材依据与教学定位

依据项目提供的《教材》六上第98—101页，以及《科学教师教学用书》六上第313—322页。本课核心是体验过程计时、分析等长燃香区段用时，并在一定条件下推测整炷香的时间。

保留真实课堂实验。本网页补充传统实验不易获得的同一时刻双过程对照、时间压缩与反复回放、累计记录拆分，以及同一前段证据在不同后续条件下的预测检验。它不提供某种香的标准燃尽时间。

## 三个任务

### 1. 燃香时间尺

两支香的测量区均为20厘米、十等分。先同时观察前3格，动画会自动暂停；交流预测，点击“用前3格推算”留下预测，再继续后7格。A保持原速度，B可在后7格改为原速度的0.6—1.4倍。到两支均完成后，可拖动时间轴回看或换一个后程条件。

- 前3格每格120秒为显式**模型假设**，非真实测量值。
- A模型整炷20分；B若后段0.6倍速度，整炷29分20秒；若1.4倍，整炷16分。
- 曲线横轴是累计时间，纵轴是已燃格数。速度越快，曲线越陡。
- 40倍/120倍只改变播放速度，不改变模型实验结果。浏览器切到后台或离开该任务时会暂停。
- 预测闸门保留首次前段观察；即使一帧跨过多秒，仍会在第3格停止。

### 2. 实测与推算

从测量区起点开始计时，录入燃到第1、2、3格的**累计用时**（分钟、秒）。起点为0:00。

设累计时间为T₁、T₂、T₃，每格用时依次为T₁、T₂−T₁、T₃−T₂。整炷预测为T₃÷3×10，取前三格平均用时外推。各格用时差异原样保留，不设置“低于某误差就一定均匀”的通用阈值。

- 校验空值、负数、非整数、秒数超过59及累计时间非递增；错误数据不能保存或导出为有效证据。
- “填入示例”使用累计110、224、335秒，对应分段110、114、111秒，预测约18分37秒。示例编辑后仍标为示例；通过“新建实测”清空后进入真实记录。
- 最多保存8组，保留每组数据来源、原始累计值及保存时间。存储在当前浏览器，不上传数据。支持单组删除与CSV导出。
- 可导出当前组的SVG证据图，包含累计值、分段计算、预测值、来源与前提，可离线查看或打印。
- 仅预测整炷时间，不把预测表述为整炷实测结果。前三格接近不能保证后七格继续相同。

### 3. 日影追踪

将一天的太阳高度与竖杆地面影子同步显示。拖动太阳、时间轴或使用方向键回看，比较相同影长但不同影向的时刻。支持春秋分、夏至、冬至、五次留影、遮住太阳。

- 纬度29.9°N、1米竖直杆、水平地面。赤纬为0°、+23.44°、−23.44°。
- 时间为**当地真太阳时**，不是北京时间。正午是太阳过当地子午线。
- 地面图北向上、东向右，太阳矢量E/N/U的影子投影为(-E/U,-N/U)。太阳在地平线及以下不画有限影子。
- 地面观察区超出的影子直接裁切并提示，保持1米比例尺，不将长影子偷偷压缩。虚线是晴天参考留影，遮住太阳时可以保留此前证据。
- 天空图的横向仅表示一天进程，不代表精确方位角；太阳高度按模型计算。
- 普通竖杆日影模型不等同于教材照片的赤道日晷，也不将地面等角刻度当作等时刻。日晷与圭表用途分别说明。
- 忽略大气折射、太阳视直径、地形等，不用作精密日出日落预报。

太阳位置公式核对来源：[NOAA General Solar Position Calculations](https://gml.noaa.gov/grad/solcalc/solareqns.PDF)。地面影由同一球面几何和直线投影推导。

## 课堂衔接建议

1. 结合教材讨论自然计时与古代计时方法。
2. 开展真实燃香实验，记录前三个标记处累计时间；教材中的一分钟体验也继续使用真实活动。
3. 将本班数据填入“实测与推算”，观察每格用时并解释差异。
4. 用“燃香时间尺”检验前段预测在不同后续条件下是否成立。
5. 用“日影追踪”讨论日影计时的规律、阴天或夜间的局限，回到计时工具需要稳定变化这一问题。

## 素材与模型替换接口

单文件内部按两层组织，不需构建步骤：

- `window.TimeScience`：纯数值模型。包含`solar`、`incenseSegments`、`burnAt`、`estimateFromCumulative`、`formatDuration`。
- `window.TimeLessonRenderers`：`incense`、`burnGraph`、`recordGraph`、`sky`、`shadow`返回SVG内容。后续可替换香、托座、地景等图形，保持输入状态与物理量语义不变。
