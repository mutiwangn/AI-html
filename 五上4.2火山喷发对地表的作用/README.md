## 两个探究视角

| 页面 | 核心操作 | 增加的观察条件 |
| --- | --- | --- |
| 透视火山 | 剖开山体，拖动追踪点或进度条；播放、暂停、慢放和重新观察 | 跟随同一份物质经历地下岩浆、上升、地表熔岩与冷却，同步放大气体变化；可查看地球圈层比例和实物实验的类比边界。 |

## 课堂使用建议

实物活动后，用第一页补看山体内部，让学生区分“实验中看见的现象”和“模型补充的解释”。第二页先完成一轮并“留作对照A”，再“从原地表重做”，改变流动性，保持原地形和喷发次数一致。拖动测高线讨论物质增加在哪里，再结合真实火山资料解释。

流动性改变只影响下一次喷发；“从原地表重做”保留对照A，切换情境或“重置本页”会清除对照。全部状态仅保留在当前页面会话，刷新即重置。

## 科学模型与边界

- 第一页是机制示意，空间尺寸和过程时长不按真实比例。地下称岩浆，喷出地表称熔岩；地幔总体以固态为主，岩浆不直接来自地核。
- 第二页是一维有限体积网格上的二维剖面模型：固定喷口等量供料，未冷却熔岩随总表面高差流向邻格，并逐步固结；已冷却地层保留。守恒量为单位宽度下的**剖面面积**，不是整座火山的体积。
- 高度和横向距离使用“模型格”；流动性是定性调节值，不是实测黏度。固定供料、冷却规则和两端不流出的边界用于比较，不能把动画速度或格数换算成真实喷发时间、米数。
- 本版聚焦熔岩流动、冷却与覆盖，不计算爆炸、火山碎屑、塌陷、侵蚀或三维分支。海底情境不计算水下淬冷、枕状熔岩及水汽爆炸；不能据此认定所有火山喷发都会抬高山顶。
- 番茄酱受热沸腾与真实岩浆喷发机制不完全相同。模拟计算不能作为独立验证其预设规律的证据，也不能预测真实火山。
- 地球圈层图使用教师用书约17、2870、3450千米的近似数据归一化；外缘描线加粗便于识别，不作为精密地球测量。

## 运行与维护

直接用浏览器打开 `index.html` 即可运行。样式、脚本和SVG均内嵌，无外部库、字体或图像依赖；核心功能可离线使用，只有外部资料链接需要联网。页面不显示学校和姓名，仅保留低干扰的 `mutiw` 水印。全屏能力取决于浏览器，提供失败反馈。

| 维护入口 | 当前设置或作用 |
| --- | --- |
| 首个脚本中的 `VolcanoModel` | 科学计算与网格参数；`N=141`、横向范围20格，每次供料面积4格²。 |
| `STEPS` / `INJECTION_STEPS` / `COOLING` | 每轮800步、前140步供料、每步冷却系数0.008；迭代步不是现实时间。 |
| `mobility` | 模型内部范围0–1；界面连续调节。每轮固定总量，最多累积6轮。 |
| 第二个脚本中的 `P` / `T` | 分别管理过程观察、地形实验与对照状态。 |
| `processSvg` / `earthHTML` | 山体、岩浆、局部放大及地球圈层的SVG资产入口。 |
| `COLORS` / `profileSVG()` | 地层配色与地形表现入口；替换纹理或外观时保留计算得到的 `surface`、`deposit`、`hot` 数组。 |
| `VolcanoLab.getState()` | 只读审阅入口，用于检查界面和模型状态。 |
