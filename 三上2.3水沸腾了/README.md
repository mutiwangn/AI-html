# 三上 2.3 水沸腾了

独立重制的基础辅助稿。全新 HTML/CSS/SVG/JavaScript，无外部依赖、学校及个人署名，不复用被下架版本的图像、模型或代码。教材正文及配套教参仍待核对，不视为整课教学验收。

## 活动
- 拖动预设阶段，观察加热、沸腾与温度曲线；解释层区分看不见的水蒸气与白雾小液滴。
- 独立录入真实实验温度，空缺不连线，按固定读数间隔制图和导出 CSV；不把模型预设填入实测表。
- 模型解释与实验安全提示。

## 边界
纯水、标准大气压、持续加热且仍有液态水时的概念示意；阶段不代表真实时间。不计算传热、蒸发速率、液面下降或气泡数量。早期气泡也可能含溶解空气。气压等因素影响实际沸点。热源由教师按实验规范管理。
数据仅在页面内存保存，刷新丢失；导出前请检查记录。无网络提交。
