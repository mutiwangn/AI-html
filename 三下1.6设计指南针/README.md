# 三下1.6《设计指南针》

教科版三年级下册第一单元第6课。T2（Canvas 二维绘图），单体离线 HTML，无外部字体、图片、脚本和网络服务。

## 教学依据
已对照用户提供的学生教材印刷第17–19页，以及配套《科学教师教学用书 三年级下册》第6课。核心任务是设计一个小巧且指向准确的指南针，先明确标准，再选择材料、绘制方案、评估改进并准备材料。教材明确版权版次尚待进一步核实。

## 三个课堂环节
1. **定标准**：讨论灵活与准确、材料成本、轻巧方便、方位和外观。班级可勾选采用标准，并在黑板补充具体限制、检查方法和评价等级。
2. **画方案**：水浮式、支撑式、悬挂式分别保留自由草图、材料及文字说明。可临时显示结构提示，不强制照抄。保留初稿后可以继续改图。
3. **比改进**：初稿与当前方案并排呈现，材料变化同步对照；学生给出计划评议，并下载包含图画与材料的 HTML 方案记录。

建议课堂安排：约8分钟讨论任务与标准，约18分钟小组构思、绘图和材料选择，约10分钟组内及组间评议修改，约4分钟准备下一课材料。按实际课表调整。

## 数据与边界
- 图画、材料、初稿和评议仅保留在当前打开页面；刷新、关闭后清空。结束前下载方案记录或截图。
- 三种支撑方案各自独立。每个方案首次保留的初稿不会被后续修改覆盖；清空画板只清当前图，保留初稿。
- 这是工程设计表达工具，不是物理性能仿真。不自动给出磁针实际指向、准确率或作品分数。需要制作后测试。
- 需要教师指导尖针、剪刀等工具使用；避免磁铁或铁制材料干扰磁针。网页不读取设备指南针或地理位置。

## 课堂修订与记录安全
单点笔画显示圆点；空图不能保存初稿。重设本方案初稿需二次确认，不清当前图、材料、评议与其他方案；初稿与当前材料理由分别显示并导出。

记录仍仅保存在打开页面内存，刷新会丢失。升级前请在旧页先下载或截图，勿强制刷新；已下载的旧HTML静态记录请保留，不覆写。部署不会自动迁移旧页记录。未新增个人署名，技术评级及科学内容不变；真实设备待验。
