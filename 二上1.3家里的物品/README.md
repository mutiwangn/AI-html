# 二上1.3 家里的物品

教科版二年级上册2025年版，第一单元《造房子》第3课。单体离线HTML，原创SVG图卡，无外部依赖，不要求打字，不上传信息。

## 课堂用法
1. 按材料分：8种编号图卡、7类常见材料。先选物品，再点材料；可多选，再点可取消，不确定可标△。甲乙两组独立记录，支持两次点击确认清空当前组。
2. 找找不同：并列两组记录，材料选择不同的物品标黄，保留△。不同不等于错误，尚未分类也会形成差异，需先检查完成情况，再用证据交流。
3. 用证据说话：讨论透明塑料与玻璃不能只凭透明区别；联系同一材料在房屋与餐具中的用途，讨论废旧材料安全再利用。

建议配合安全实物使用：聚焦5分钟、观察与分类20分钟、对照研讨10分钟、再利用准备5分钟。图卡名称与资料明确例子的材料，目标是练习分类与组合材料，而非猜材质竞赛。纸盒涂膜、瓶盖、物品包覆层等在真实物品中可能不同，以实物和可靠资料为准。

## 安全及信息边界
不得靠摔、烧、强挤未知容器验证材料；不敲打易碎物品。裂口玻璃不用于制作，请成人安全处理。真实观察不预填；图卡选择不是实测数据。记录只存当前页面内存，刷新即清空，课堂记录可另用纸笔保存。
