课名来自项目教科版五下Notion目录（页面3fa945e5f61e815b943be5fdd12e326c，依据学生教材PDF第4–5页目录，年份待核）。匹配版正文和教参未取得，当前只作通用观察辅助，不声称复现全部教材活动。全部界面代码与图形原创，不复制扫描页或第三方课件。

设计光照对照方案、固定观察归属；录入一对代表植株两次真实高度、叶色及茎状态；同刻度图和高度变化支持讨论。已有记录不能替换绑定方案，编辑设计页不污染原观察归属。日期递增、高度0至200厘米；图和差值显示一位小数，导出原始输入。负差值保留，不擅自修正实测。发芽和后续生长不混同，更高不等于更健康；软件不作因果判断。

建议课堂先设计与约定标准，再数日观察，返课比较证据。两组种类、初态、水温等尽量相同；不同光照放置也可能引入温度差异。教师安排适宜通风环境，不密封或高温暴晒，实验后恢复正常养护。记录代表植株不替代多株重复。
