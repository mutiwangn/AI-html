## 设备兼容性检测与等级标识

- [打开设备兼容性检测](./compatibility.html)：自动检查 HTML/CSS、JavaScript、Canvas、WebGL、媒体与设备环境，另有二维/三维压力测试、摄像头和联网资源测试。诊断在用户设备的浏览器本地执行，不上传设备数据。
- 每节课在册次目录中显示最低技术需求，并在课件入口页面左下角显示一个不阻挡操作的等级角标。检测结果保存在该设备浏览器的 `localStorage`，7 天内返回教材目录可查看本机匹配提示。
- **T1 基础交互**：HTML、CSS、JavaScript、SVG；**T2 二维绘图**：在 T1 基础上增加 Canvas；**T3 轻量三维**：WebGL 1；**T4 进阶三维**：WebGL 2。摄像头、HTTPS、资源体积等是独立附加条件，不由 T 数值代表。
- 目前等级依据已入库课件的实际代码依赖初步分类，并不是所有设备的实测保证。特别是大型 3D 模型，即使检测到 WebGL 2，也需检查实际渲染性能和可用内存。
- 新增作品时在根目录的 `lesson-levels.js` 登记课程目录名和等级，然后运行 `node annotate-compat-levels.js` 批量更新入口页角标。脚本只写入 `AIHTML-COMPAT-GRADE` 标记块，不改动原课件实验代码。
