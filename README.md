# AI-html · 小学科学互动课件

每一课使用独立项目目录，仓库根目录的 `index.html` 只作为课程导航。总览按“教材封面（年级与册次） → 该册具体课次”两级分类，不按教师来源区分。

- 2.4《气味告诉我们》【镇海区鲲池小学 王宁】：[打开课件](./一上2.4气味告诉我们/index.html) · 三页单体互动版 v1.0：先闻一闻、闻味辨物、再找线索；保留真实猜想与开袋结果，支持本地记录和CSV导出。
