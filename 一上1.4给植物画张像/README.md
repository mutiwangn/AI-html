# 一上 1.4 给植物画张“像”

教科版一年级上册（2024 年版），第一单元《周围的植物》第 4 课。植物观察手册 v10.1，保留原版完整功能。

打开 `index.html` 即可使用，无需安装。默认 10 组植物彩图及配套线稿已内嵌。建议横屏平板或课堂大屏使用。

## 课堂建议
先观察实物及它生长的环境，口头说出最明显的特点；用页面放大观察叶形、颜色、纹理和连接位置，再给学生保留约 10～15 分钟绘画时间。可以画整体，也可以画局部，不以画得漂亮作为科学记录的评价标准。最后对照、圈记、返回补画。

学生主流程仅需点按和描画，无须键盘输入。教师素材管理位于“提示”中的教师设置；更换素材后请重新导出课堂单文件，原 HTML 不会自动随文件夹更新。浏览器暂存不是永久备份。

## 素材与科学说明
默认图片是 AI 生成的实拍风格示例，不是校园实拍记录。请以真实植物和本校环境核对；线稿仅供描画参考，不代表每片叶和花瓣与彩图逐像素重合。复杂交叠处可能需要补线，不能把自动描边当作植物识别。不清楚的环境、不见的根不凭空补画。

教师导入的照片请自行确认使用许可，并避免包含学生面孔、姓名、校牌或其他私人信息。课堂单文件在本机处理素材；分享或发布自行导出的文件会一并包含其素材和选定内容，请先检查。

## 验证范围
已复核桌面云浏览器中的默认素材、观察问题、描画模式、配套线稿载入、封闭区域填色、绘画撤销、两图对照、同步缩放、圈记及返回补画。此次未重新实测系统文件选择、导出下载、打印、双指触控、真实平板和希沃一体机。
