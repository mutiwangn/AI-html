# 五下2.4 热在金属中的传递 · 基础辅助稿

## 互动
比较端部/左上角与中心热源；推进1或10模型阶段；移去/重新保持局部热源；显示相邻区域净传热方向。金属条中心向两侧传，金属片中心向周围较冷区域传。热源取消后当前温度保留，内部继续传热。100阶段上限可重置。

## 模型假设
同种均匀材料、相等格点热容、绝热边界，仅邻接区域的传导。条形13格、片形7×7格。每步 v'[i]=v[i]+k×Σ(v[j]−v[i])，k分别0.2/0.15；热源开启时对应格固定为1，其他初始为0。数值归一化，不是摄氏度；颜色使用平方根映射增强低温升可见性，不可读取真实温度。阶段不对应实际时间，两个形状也不能据此比较真实传热速度。格网离散可能造成分布的网格形状。

取消热源后全格数值和守恒，仅内部趋向均匀；不模拟向空气冷却。箭头温差显示阈值0.005，未显示不代表完全无传热。模型不含对流/辐射/材料差异/相变，无蜡熔化预测。金属整体不随能量迁移。无实际火焰操作指导，实验由教师安排。
