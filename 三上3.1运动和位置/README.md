# 三上3.1 运动和位置
独立重制辅助稿，HTML与app.js同目录，原创SVG，无第三方素材、学校和真实姓名署名，无可见技术层次。教材教参待核，非整课验收。

比较两个时刻相对固定旗杆的位置，保留起始位置叠影；区分单一位置与位置改变证据，不从两帧推断路线或速度。方位网格6个位置点选练习，每格1米，参考点、四正方向和距离同时描述。两条实际观察记录，参照物与对象必填检查，CSV导出，模型数据不混入。

仅内存保存、不上传，不用蒙眼追跑或道路活动。前后位置相同不能证明期间完全静止。

验证：JS语法；Chrome前后时刻与叠影、证据反馈、位置空答案/东2米/北3米切换复位、实际记录缺参照物时阻止导出、补全后CSV下载、桌面截图。未验实体触屏/旧浏览器/整课教学。
