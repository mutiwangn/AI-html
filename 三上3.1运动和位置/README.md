# 三上3.1《运动和位置》

面向教科版小学科学三年级上册第三单元第1课的单体 HTML 互动课堂初稿，版本 v1.0。课件入口为 `index.html`，可通过 GitHub Pages 打开，也可下载后在浏览器中离线运行。

## 三个课堂任务

| 页面 | 操作 | 课堂用途 |
| --- | --- | --- |
| 看变化 | 点选小车、小狗或长椅，播放、暂停或拖动时间轴，显示轨迹，再判断运动或静止 | 固定旗杆和地面背景，比较观察时段内的位置变化。小狗绕旗杆的距离不变，但方向发生变化。 |
| 说位置 | 拖动同学的位置，结合朝向读取方向和两点之间的距离 | 先说“和谁比”，再用前后左右等方向和距离描述某一时刻的位置。 |
| 找朋友 | 蒙眼找朋友，逐步展开方向和距离线索，再寻找目标 | 比较只知道方向、只知道距离和同时知道两条线索时能确定的位置范围。 |

页面为教师一体机展示与学生触控操作设计。按钮和时间轴可用鼠标、触控或键盘聚焦操作；人物操作以页面提供的拖动与按键交互为准。全屏由浏览器权限决定，设备不支持时可使用浏览器自带全屏功能。

## 教材依据与科学边界

- 教科版三年级上册《科学》第58—60页（所提供 PDF 第60—62页），第三单元《物体的运动》第1课《运动和位置》。
- 所提供《教学用书》“第1课 运动和位置”的教材解读、教学目标与课堂教学实施建议。
- 本课按教学用书范围，用地面上不动的物体作比较；学生界面不以“参照物”等术语增加认知负担。
- 位置由相对于比较对象的方向和距离共同描述。人物朝向应保持清晰，前后左右随所指人物理解，不等同于地图的东南西北。
- 测距表示两个位置标记之间的直线距离，不是先横走、再竖走的路线长度。显示的距离来自教学模拟比例，不是对真实教室的测量。
- 距离不变不能推出位置不变。运动判断面向观察时段内的位置变化，暂停动画只是便于观察。
- 缺少一条线索时应保留多个合理候选，不能在信息不足时把唯一猜中目标作为正确标准。

教材和教学用书用于核对内容；公开网页采用自行绘制的场景，没有嵌入教材整页图片。

## 技术与素材替换

- 技术等级：T1 基础交互，使用 HTML、CSS、JavaScript 与 SVG。无第三方脚本、在线字体或远程图片依赖。
- 入口页面保留 `AIHTML-COMPAT-GRADE` 等级标记，根目录的 `lesson-levels.js` 登记课程最低技术需求。
- 场景素材与位置计算分开维护。后续可替换 SVG 人物、车辆、小狗、旗杆、长椅等图形；应保留互动元素的 `id`、坐标锚点、`transform` 和事件绑定。
- 改换更精细的图形时，先核对点击区域、触控区域和测量线端点，再检查人物朝向及对象脚下的位置标记。
- T1 是技术依赖说明，不代表所有旧设备都已实测。页面不需要摄像头、麦克风或 WebGL。

## 本版验证

- 浏览器实测三页切换、对象选择、时间轴、运动判断、人物拖动、角色互换、方向/距离线索与寻找结果。
- 在同一浏览器中检查1920×1080、1366×768、1024×768、768×1024、390×844、375×667、844×390、740×390八种CSS视口，控件均位于一屏内。该检查不等同于在所有系统和实物设备上测试。
- 逻辑验证包括小狗恒定半径、直线距离计算、方向互换、信息不足保留多个候选、触控事件回退与键盘定位。
- 人物素材入口为 `LessonApp.assets.avatarSVG`；第一页图形定义集中在 `m-car-art`、`m-dog-art`、`m-bench-art`。替换图形保留坐标中心和交互ID。
