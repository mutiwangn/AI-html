# 三下2.4 幼蚕在生长

三年级下册，第二单元“动物的一生”，第4课。离线单体 HTML，无外部图片、脚本或网络请求。

## 课堂使用
- **观察结构**：先观察真实幼蚕，再点击头、胸、腹和气门展开说明。原创侧面示意只画可见一侧的足，不按比例，不可代替实物观察；不要求按示意数体节。
- **测量与变化**：输入同一只蚕的实测体长、日期、姿态和生命活动。按实际日期间隔绘制散点，自动比较首末两条实测值，不连线、不补造数据。未测可留空并写观察现象，不绘制为零值。纵轴会按当前对象数据调整，比较不同对象时须读数值。
- A、B、C须稳定对应同一只蚕。不能持续辨认个体时不要拼成个人生长曲线。图中青点为自然伸展，橙点为弯曲；姿态和测量方法变化可能影响长度，不能直接推断生长、缩小或蜕皮。
- 同对象同一天只保留一条，可通过列表的“修改”更正。最多30条，不提供删除与导入；需要备份或长期归档时请下载全部记录。

## 保存与限制
已保存的测量记录存在本浏览器本地；切页保留输入。刷新后未保存输入与“结构观察”文字不保留。下载HTML含全部记录与当次结构观察文字，可查看，不支持导入恢复。不同设备、浏览器、来源地址或清理缓存不会自动同步。

日期由观察者按北京时间填写。体长输入0.1–150毫米、最多一位小数，此范围仅用于防误输，不是正常生长标准。不含示例观察数据，不自动生成孵化、蜕皮或增长结论。

结构与功能、真实测量和持续观察依据用户提供《小学科学 三年级 下册》39–41页及配套教学用书“第4课 幼蚕在生长”。目录与Notion三下页对应；教材文件确切出版年份未单独确认。未复制教材照片，以原创概念示意呈现。

保持安静、清洁、通风及适宜环境，提供洁净且表面无水的桑叶。不要拉直、按压或反复刺激蚕。不吃不动可能是“眠”，请教师协助判断，不能据此丢弃。

主要桌面一屏布局，长记录列表局部滚动；小屏改为纵向布局。核心采用 DOM/SVG，不使用 Canvas/WebGL；真机兼容仍需课堂设备核验。
