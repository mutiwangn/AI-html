# 二上2.3 我们周围的空气

教科版2025二年级上册第二单元《地球家园》第3课。依据对应教师教学用书的三地点收集空气、空气与水及木块比较、证据描述和空气保护活动设计。

## 课堂使用
直接打开 `index.html`。原创 SVG/CSS/JavaScript 单体离线课件，无字体、CDN 或其他网络依赖。

1. 找空气：校园示意、收集方法和安全提醒，结合实际活动寻找空气。
2. 比一比：比较空气、水、木块在不同容器中的示意，讨论观察证据，可切换辅助色和比较提示。
3. 爱护空气：辨析花香来源，讨论保护空气的行动。
4. 观察记录：教室、走廊、操场的真实观察独立记录，初始空白，可主动导出 TXT 或打印观察卡。

记录仅在本次页面内保存，刷新会清空。请主动导出或打印留存，不上传数据。窄屏采用单列滚动布局。

## 教学与安全边界
- 真实观察与示意分开，示意不会填入实测记录。
- 空气默认不可见；辅助色不是空气真实颜色，水的蓝色也仅为辅助。换容器图示是非定量、非微粒示意，不用于推断物质量。
- 污染物可能无色无味，不靠近或嗅闻不明气体；收集活动应由教师指导，在安全地点开展。
- 网页辅助讨论和记录，不替代真实实验。

## 验证与兼容性
建议能力等级 T1（基础交互），不需要 WebGL。脚本语法及逻辑回归通过。真实云浏览器已验证地点独立保存、材料及容器切换、空气辅助色、提示展开收起、花香辨析、保护空气行动反馈，以及 TXT 下载。

1180×757 视口下四页均一屏呈现，比较提示展开时未出现整页横向或纵向溢出。打印仅验证触发和样式，未进行实机打印。实体希沃、平板及手机真机未测。
