# 五上3.1《拆解我的小车模型》

三工作区互动课堂 v1.0，纯 HTML/CSS/JavaScript + SVG，单文件约43KB；无 CDN、远程图片、字体或第三方运行依赖。保存 `index.html` 后可离线打开。适用于希沃触控大屏、桌面与平板浏览器。

## 教学主线

1. **拆开看**：连续展开同一辆电动小车，虚线保留部件原有连接位置；点击外壳、车架、电池、电动机、齿轮、车轴、车轮、导线与开关，联系结构和功能。课前猜想与真实拆解发现独立保留。
2. **追动力**：电动机、小齿轮、大齿轮、车轴与驱动轮联动；支持慢放、暂停、单步、时间回看。比较完整连接、开关断开、齿轮脱开和轮轴松开的结果。保留一种连接状态为 A，与当前 B 在同一模拟时刻比较转数。
3. **比结构**：观察玉兔型月球车的六轮、活动悬架、太阳能电池板、相机和天线，联系月球环境与任务；自由分类两种模型的结构卡，添加自己的卡片，区分观察证据与功能解释。

建议40分钟：聚焦5分钟、实物拆解15分钟、传动解释8分钟、结构比较8分钟、研讨4分钟。安全准备与详细建议在页面“课堂建议”内。

## 模型边界

- 数字模型用于显露遮挡、跟踪连接、放慢传动；不替代学生真实拆解与观察。分层展开不是实际拆卸动作。
- 以一种电动小车为例，不声称所有玩具结构相同。机械转动示意为一对外啮合齿轮，12齿驱动24齿；大齿轮转速为小齿轮的一半，方向相反。
- 转速是固定教学参数，不是实测量；不计算车速、力、摩擦、惯性和动力学过程。不模拟前轮随车滚动。断电状态从静止开始，实际运动小车断电后可能继续滑行。
- 传动故障用于可控比较，不指导学生在通电实物上操作故障。拆解前关闭开关、取出电池；不拆电池，不强撬封闭部件。
- 月球车为玉兔型结构简图，非工程尺寸或越障仿真。六轮与悬架有利于接触与支撑，不意味着不会翻车或能通过任意地形。太阳能电池板转换能量，电池储能。
- 分类卡不作唯一答案判分；以当前两种示意模型和学生实际观察为依据。

## 记录、隐私与兼容性

- 本机 `localStorage` 保存文字及卡片位置，没有网络上传，不收集姓名。
- 可以导出 TXT 课堂记录及当前 SVG 示意图。共享设备建议导出后清空；清空前有确认提示。
- 不支持本机存储的浏览器仍可使用互动和导出，页面会提示。
- 基础运行使用 SVG、原生表单、requestAnimationFrame，建议登记 **T1 基础交互**。
- 全屏为增强功能，需要浏览器允许；不使用 WebGL、麦克风、摄像头或外部模型。
- 浏览器原生下载与全屏支持取决于设备；不代表已经在实际希沃硬件上实测。
