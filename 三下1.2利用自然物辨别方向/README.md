# 三下1.2《利用自然物辨别方向》

单体HTML课堂辅助，打开index.html，无需登录、传感器、定位或外部资源。

## 教学用途

1. 审查线索：融雪、树冠、苔藓、年轮示意配合“加入另一种原因”，比较同一现象是否有遮挡、浇水、修剪、移位等替代解释。先提出有条件的猜想，再讨论是否足够。
2. 记录证据：三条独立真实观察，区分实际现象、干扰条件、猜想和工具复核。不把模型选择当实测，不自动多数投票决定方向。具体方位及现场草图请配合纸质记录。
3. 八方向：先确定北，再旋转学习盘并显示八方向名称，区分画面朝向与现场方位；补充北半球正确识别北极星的条件。

## 科学与安全边界

自然物不是可靠罗盘。苔藓/树冠/年轮都受多种因素影响，不能凭单一特征确定方向。向阳背阳的条件推理以我国北回归线以北为背景，不套用于所有地区。年轮仅用作审查证据案例，不提供“宽必南、窄必北”的结论。

老师选点带队，不进入密林、爬屋顶、砍树剥皮或搬动物体取证。迷路不靠猜测乱走，应在安全处联系同行成人或救援。学习盘不是真指南针，本页不用于户外导航。
