## 功能与教学限制
固定光照/湿润程度对照方案；逐条手动记录左、中间/跨界、右、未确认。只记实测位置，不以点击动画充当动物实验。支持3–5条，计数始终守恒。未确认必须说明原因，全部未确认不保存。快照时点递增，保存后清空选项，避免沿用上一轮答案。原快照不覆盖；需要新条件另开页面。导出原方案与全部快照TXT。页面内存保存，刷新或关闭会清空。

30分钟是记录字段的软件上限，不是推荐实验时长或安全保证。教师按动物状态安排短时观察，有异常立即停止并恢复适宜环境。避免强光、极干、盐、热和密闭刺激，不在身上标记；外来或购买种不随意放生。位置差异不直接证明普遍选择，同批动物重复时点不能当独立样本相加。
