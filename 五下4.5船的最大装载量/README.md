# 五下 4.5 船的最大装载量
原创课堂辅助探究稿，教材教参细节待核。

## 探究链
预测同船同载荷、不同液体密度下吃水；保存六组以内理想结果，提醒变量未控制或超船边不能直接比较；独立记录同条件三次小船逐个装载，先约定停止标准，区分缺项、异常、未到上限、真实0；讨论最大装载标准和真实安全边界。

## 模型
刚性直壁箱形船，底面积200 cm²，高10 cm，质量200 g，均匀载荷0–2000 g；密度1.00/1.03/1.10 g/cm³是设定值，不代表特定配方。静水不倾斜防水，忽略壁厚。d=(船质量+货物质量)/(密度×面积)。同载荷漂浮时浮力仍等于总重量，较密液体所需排水体积较小。到达或超过10 cm停止稳定漂浮解释，不模拟进水后的运动。示意为侧面剖面，水面参考线跨船不表示船内进水。计算小数不是测量精度。
实测最大数不自动变为安全载荷；实际载重线、稳定性、风浪等不在模型能力内，禁止用于载人真船。
