# 三下2.7 昆虫的一生

三年级下册，第二单元“动物的一生”，第7课。离线单体HTML，无外部资源。

## 两页课堂活动
1. **阶段与世代**：分别排列蚕、菜粉蝶、蜻蜓的主要发育阶段，撤回和资料核对帮助修订。蚕与菜粉蝶有蛹期，蜻蜓没有。成虫繁殖产生下一代，不是原个体重生。图标是概念符号，不是真实观察影像或统一大小比例；蜻蜓另用水生稚虫与成虫示意。
2. **真实日期算时长**：填写同一只蚕或来源明确的一套资料的五个边界日期，实时相减并按最长已知阶段绘制比例条。每个阶段需要相邻两个日期；缺项保持未知，不按0天、不补教参平均天数。五日期齐全才计算总时长。

日期按北京时间填写，按日期差计算，不把起止两天各加一次。相同日期的差为0，表示不足一天的日期精度，不代表没有该阶段。逆序会暂停全部计算、保存及下载。卵产下时间未知时不能用收到卵的日期代替；结茧时间不能代替化蛹时间。只知道首次发现日期时请注明不确定性。

不要把不同个体的最早孵化和最晚死亡拼成一生；时长因环境、品种和观察误差等不同，不能据图判断所有蚕的正常时长。程序只做日期计算，不验证所填生物学事件是否真实可信。

## 保存与下载
- 阶段排列和资料显隐仅在本次页面保留，不保存、也不导出。
- 日期、对象来源和说明可保存一套到本浏览器；刷新恢复已保存值，未保存输入会丢失。
- 下载的是**当前输入**及其计算，不要求先保存；含空项与计算口径，不包括阶段排列。导出HTML可查看，不支持导入。
- 无多小组管理、重置或删除功能，不跨设备同步。请下载备份。
