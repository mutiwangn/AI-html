# 三下3.4 我们来造“环形山”

教科版三年级下册，第三单元第4课。实物实验辅助记录工具，全部原创SVG，不使用教材或第三方图片。

## 使用方法
1. 对照教材或教师提供的真实环形山照片，讨论形态特点。
2. 平铺细沙，用球在托盘内安全释放制造坑，观察结果。
3. 在第一页选择示意大小，点击沙盘记录坑的位置。可依次叠加、撤回，并填写形态描述。数字表示记录顺序，后圈遮前圈只是绘图规则，不是撞击模拟。
4. 如开展量化比较，记录释放高度、坑口直径、球和沙层条件，第二页自动生成散点图。每个点来自输入的实测值，不自动生成结果或趋势。
5. 导出JSON保存坑位、形态描述与测量记录。

限制：只记录相对圆形坑位，不能代替真实绘画或照片；无碰撞物理计算。最多30个示意坑、12次测量。测量高度1–100cm；使用低高度、安全的课堂实验。图表不自动判断因果，不同球或沙层条件不能仅归因于释放高度。

记录只保存在当前浏览器，不跨设备同步。单文件，无网络依赖。

## 来源与兼容
依据所提供三下教材第67–69页、相应教学用书和三下目录。教材明确出版版次待核。核心 DOM/SVG，无 Canvas/WebGL，T1；希沃、平板及窄屏实体设备未核验。

JSON 导出含已记坑位、测量与形态输入框当前文字，不支持导入恢复；未保存文字刷新会丢失。数值轴按记录范围调整，重叠数据点可从列表核对。
