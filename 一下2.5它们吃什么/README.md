# 一下 2.5《它们吃什么》

一年级下册第二单元第五课互动辅助网页。单体 HTML，直接打开 index.html，无需登录、打字或外部资源。

## 课堂使用

- 说说进食：先回忆蜗牛、小鱼怎样吃，再切换蝴蝶、大熊猫、乌龟、莺等例子。点击展开知识，不把例子当完整食谱或野生动物投喂菜单。图标仅为识别符号，不代替真实影像。
- 看蚂蚁：放食物前、放食物后、继续观察三阶段分别选择观察来源，记录靠近食物、触角动作与搬运。未观察、看不清、没看到行为分别保留。不同来源不能直接当同一次实验比较。
- 画与讨论：自由画下看到的路线、食物和搬运动作，支持撤销和确认清空。讨论触角感受信息与证据，避免用单次靠近直接推断只靠眼睛。

教师确认安全蚁种和环境后，轻放少量适宜食物。不抓不摸不挖巢，不招惹未知或蜇人蚂蚁，不伤害触角，不随意在教室撒食物。活动后教师清理，洗手。也可使用教师提供的真实视频；网页不附视频，不伪造实验结果。
