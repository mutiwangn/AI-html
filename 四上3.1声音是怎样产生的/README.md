# 四上3.1 声音是怎样产生的
独立重制辅助稿，HTML+app.js，原创SVG，无第三方素材、学校/真实姓名署名、可见技术层次。教材教参待核，非整课验收。

猜想—橡皮筋放大慢放—制止/重拨—两种材料真实观察链。追踪固定中点，区分经过原位与停住；单张照片不能证实振动或发声。模型不播放声音，不生成真实音量/频率，不模拟完整声波。实测橡皮筋/尺子轻拨后声音、运动和制止后声音，未观察/看不清/环境干扰分离，证据提示和CSV导出，仅内存不上传。
