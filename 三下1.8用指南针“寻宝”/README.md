# 三下1.8 用指南针“寻宝”

教科版三年级下册，第一单元《辨别方向》第8课。依据提供的教材第23—25页及教学用书本课。扫描件明确版权版次尚待核实。

## 使用

打开 index.html，单体离线课件，无外部图片、字体、框架或网络接口。

- 认识与辨向：点击外壳、磁针、支架、刻度盘观察结构。用左右按钮转动刻度盘，让“北 N”与红色磁针北端对齐。磁针方向固定，是放平、无干扰、已稳定的理想操作示意，不是磁场仿真或真实指南针。
- 绘制寻宝图：教材四条提示，各自从旗杆起步。每点一次方向走一格（5米），10米需两步，15米需三步。四任务独立保留路线，支持撤回、二次确认清空当前任务、逐步核对与主动显示参考。不会预先自动画出答案。
- 实践与记录：教师查看安全提示；学生可记真实实践问题。下载四任务文字和路线图、反思记录。网页练习正确不代表已实地找到目标。

## 数字增益

用不随刻度盘转动的磁针帮助区分磁针指向与刻度盘标识；把文字方向与距离即时转换成方格路线；指出首次不符合提示的步骤而非仅判断终点，便于定位方位或距离误读。参考路线须主动显示，学生原路线保留。

四条路线依次为：东5南10；东10北10；西10北5西5；南10东15北5。路线核对检验是否依次遵循文字指令，不把“终点相同”当作“过程正确”。

## 课堂边界和安全

图上北方与旗杆位置是纸面练习约定，不读取设备方位、地理位置或传感器，不能替代实物指南针。对实物应核对磁针北端标识，水平放置、等稳定、远离磁铁和铁制品干扰，再对齐刻度盘。

校园场地、路线与距离须由教师另行核定，不能将本图当成真实校园导航。教师先查安全场地，分区分组。小磁铁球由教师保管、清点，严禁放入口鼻，不随意挖掘。磁针异常只能提示可能有磁性物体或铁制品，不证明一定找到目标。

所有记录仅在本次页面内存中，刷新或关闭会丢失，请先下载或截图。不上传任何学生信息。
