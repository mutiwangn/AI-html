# 一下 2.4《水中的动物》

一年级下册第二单元第四课课堂辅助网页。单体 HTML，打开 index.html 使用，无需登录、外部资源或打字。

## 使用

1. 找身体：先看真实的鱼，再点选鳍与尾、口、鳃部定位。图仅示意，鳃盖不是鳃，不能直接透过鳃盖看见鳃。
2. 画下来：画真实观察到的鱼，支持触控/鼠标绘画、撤销与确认清空；也可在纸上画。
3. 看活动：分别记录身体/尾、鳍、口和鳃盖的动作。三次独立记录，未观察、看不清、没看到明确区分，不自动填入实验结果。观察后可展开运动与呼吸知识讨论。

不拍缸、不抓鱼、不捞出水、不掀鳃盖。鱼留在合适的水中，由教师照顾。不能根据一次未见动作判断健康，水中的动物也不都是鱼。
