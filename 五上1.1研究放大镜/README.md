# 五上1.1 研究放大镜

两页单体互动网页 v1.0，用于真实镜片观察之后的同点比较与结构解释。HTML、CSS、JavaScript、SVG 均内嵌，无外部运行依赖；核心功能可离线使用。课件内不显示学校和姓名。

## 教材依据

- 本项目提供的《五上》教材，第一单元《微小世界》第1课，印刷页2—5（PDF第6—9页）。
- 配套《教师用书》五上第1课：认识放大镜的透明、中央厚边缘薄等结构特点，通过不同镜片比较建立结构与功能联系；不要求学生掌握成像原理。
- 本次未读取或编写任何作业本专属题目。导出的“我的发现”留白仅用于自主表达。

## 两页的作用

### 同点观察

原图观察圈与放大画面同步，可连续选择2—10倍模型倍率。保留对照后，两个相同大小的圆形窗口显示同一材料的不同倍率或位置；原图用实线、虚线标明两个取景范围。位置不同会显示提醒，并可返回同一点。

内置方格字卡、织物、叶脉示意图；支持导入本地 JPG、PNG、WebP 照片。照片仅在当前设备处理，未标定的照片不显示毫米数值。可导出 PNG 观察图，保留图像和观察条件，不自动生成结论；PNG不受支持时回退为SVG文件。

### 镜片剖面

正面、侧面剖面与观察效果联动。可以直接拖动中央控制点，或使用滑条改变镜面弯曲；整片加厚单独控制中央与边缘共同增加的基础厚度。平面玻璃、凸透镜、凹透镜提供可随时调整的初始形状。透光开关比较透明与不透明状态。

保留对照后，左侧切换为与右侧同窗口、同字卡、同字号基准的对照图；中间叠加保留的剖面轮廓。横屏以三图并列，窄屏改为观察图在上、剖面在下。复位清除两页的对照和导入照片。

## 科学模型与边界

第一页面是图像取景模型，不是对某一型号真实放大镜的校准。坐标每20单位代表1模型毫米；固定观察窗口的取景直径为400/倍率坐标单位，即20/倍率模型毫米。倍数表示相对于模型基准窗口的缩放，不表示与屏幕左侧原图的实际像素比例。真实视野还受镜片口径、眼睛位置、观察距离等影响。照片数字放大无法增加原照片中不存在的细节。

第二页面使用同材质、同直径的对称球面薄透镜近轴近似：半口径18mm，单面弧高的绝对值不超过3mm，折射率1.5；球面半径 R=(18²+s²)/(2s)。物距30mm，眼睛在镜片另一侧250mm处。相对同一位置、不放镜片时的视角大小比例为 (u+e)/(u+e−euΦ)，Φ=2(n−1)sign(s)/R。正透镜全范围焦距不小于55.5mm，保持物体在焦内。该比例不是商业标称放大倍率，学生界面不显示其精确数值。

在薄透镜近似中，整片加厚不改变曲率及光焦度；忽略真实厚透镜和玻璃平板的次要修正、像差、景深、人眼调节等。剖面的横向厚度适度夸张，以便触控；厚度数字为模型尺寸，不能用屏幕尺反推。模拟不能作为独立证据去证明预设规律，应回到实物实验检验解释。

## 操作与兼容

- 鼠标、单指拖动、滑条和键盘方向键均有操作入口。原图方向键移动，Shift加大步长；镜片控制点也支持方向键、Home、End。
- 横屏核心内容一屏呈现；窄屏重排并允许纵向滚动。
- T1 基础交互：核心为原生HTML/CSS/JS/SVG；照片缩图与PNG导出是可选Canvas功能。
- 无摄像头、麦克风或传感器权限需求。全屏、下载及文件格式支持依浏览器而定。刷新不会自动恢复未保存的对照。
- 不要用真实放大镜观察太阳。

## 本次实际验证

在受管 Chromium 浏览器运行本地页面，检查1366×768、1024×768两种横屏视口及390×844窄屏容器（传统滚动条占用后有效内容宽375px）。两种横屏的页面宽高均未溢出；窄屏无横向溢出，内容纵向重排，剖面拖动命中区域48×48px。

实际操作通过：两页切换；2/5/10倍及连续滑条；保留、更新、清除对照；移动观察点、不同点提醒、返回同点；内置材料切换；本地PNG照片导入及未标定提示；内置图与照片的PNG实际下载；镜片三预设；弯曲/基础厚度独立调节；透明开关；手机布局下剖面直接拖动；全部复位；说明窗口及Esc关闭。导出文件已解码检查为1400×870 PNG。核心脚本语法与登记文件解析通过。未在希沃真机、iPad Safari或旧iPad实测，不将视口检查等同于设备兼容认证。
