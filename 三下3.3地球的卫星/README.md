# 三下3.3 地球的卫星

教科版科学三年级下册，第三单元第3课。

## 课堂使用
- 原创SVG正背面概念示意，可同步放大。明确不表示真实月表位置、数量或尺度；实际观察须另行对照教材或教师提供的真实照片。网页不包含教材图片。
- 保存观察，再展开资料提示。照片所见与查阅资料得知的内容分开处理。
- 将8张比较卡放到“地球／共同／月球”三栏。三栏对应维恩图的左区、重叠区、右区，可回选修改。
- 查阅卡片依据后修订判断，保留最初判断，不自动评分。
- 导出观察及前后判断，用作月球小档案和科普海报素材。

单文件，无网络依赖；仅在当前浏览器保存，重要记录请导出。示意放大不产生新的真实观测细节。较多比较卡可在各栏内局部滚动。

正面、背面不是白天、黑夜的名称；“月海”不是海洋；“未发现生物”不写成绝对无生命；月球没有适合人呼吸的大气环境，不把这一点解释成气体严格为零。

本工具聚焦观察和有依据的比较，不替代教材的完整探月史教学。
