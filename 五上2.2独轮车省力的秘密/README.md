# 五上2.2 独轮车省力的秘密

独立原创辅助探究稿，教材教参细节待核，不等同整课验收。

载荷重力10/20/30 N，载荷力臂0.2–0.6 m，手的力臂0.8–1.2 m。静止理想模型 F=W×载荷力臂/手力臂；轮轴支持力W-F。双手合力不是每只手的力；忽略车重摩擦，不计算推行阻力。力臂为支点到作用线的垂距，图示竖直力使其等于水平距离。箭头长度不编码大小。

三种工具位置关系比较，说明支点居中不必省力、镊子费力而有利于控制；省力不等于省功。2组×3次真实桌面轻载荷对照，缺失与0分开，比较范围/均值、条件确认和异常，CSV导出。

全部代码SVG原创，无第三方素材、学校姓名署名。安全桌面模型，不用真人重物、不超量程；不能将模型当实车承重建议。

已验：JS语法、预测门槛、20N/0.4m/1m=8N，移近0.2m=4N，再延长施力臂1.2m=3.33N；生活工具切换；缺失实测、1N对2N均值、未确认条件反馈、CSV下载及清空。修正支点和力臂文字重叠并复核截图。实体触屏、旧浏览器、教材教参和完整课堂验收待完成。
