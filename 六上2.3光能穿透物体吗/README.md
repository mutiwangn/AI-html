# 六上 2.3《光能穿透物体吗》

单体 HTML 互动初稿 v1.0。使用原生 SVG、CSS 与 JavaScript，技术等级为 **T1 · 基础交互**，无外部运行依赖；下载 `index.html` 可离线打开。署名只登记在总目录，课件界面和浏览器标题不显示学校与姓名。

## 教材依据与定位

依据项目提供的六年级上册教材第 **42—45 页**、教师用书第 **168—177 页**。教材安排材料透光比较、黑盒观察笑脸，以及清水与加入少量牛奶或面粉后的光路比较；教师用书将液体实验现象的分析和解释作为难点。

网页用于实物实验后的解释与证据比较：把盒内不可同时观察的光路剖开，把水中散射过程放大，并保存不同条件下的观察。日食、月食作为教材的遮挡迁移问题，留给后续讨论，本页不另设天体模拟。

## 三个探究任务

### 1. 黑盒探光

提供六种选择：无材料、普通玻璃、浅色薄布、厚纸板、磨砂片、深色透明片。“无材料”用于对照；教材原实验使用玻璃、薄布和纸板。

先从观察孔看笑脸，再按“剖开黑盒”，追踪光源到笑脸、笑脸到眼睛的两段路径。材料可拖到另一卡槽，也可用按钮切换位置。教材中的材料在**入光口**，主要改变笑脸受到的照明；移至**观察窗**属于拓展，比较观察路径受到的影响。

这一对照避免把“照得暗”直接解释为“隔着材料看得模糊”。磨砂片和深色透明片进一步帮助区分图像清晰程度与进入眼睛的光量。解释光路按需出现，并可慢放追踪。

### 2. 看见光路

保持同一光源和同一路程，调节水中微粒多少，同时观察侧面光路与前方直达光斑。再按“放大追光”，拖动放大点，观察一处微粒使部分光改变方向、进入侧面眼睛的过程。

数字价值是把“向前穿过的光”与“侧面眼睛接收到的光”同步呈现，支持学生解释：光路更容易看见，是否意味着更多光直达前方？耶鲁大学的散射水槽演示也指出，适量散射剂有助看见光束，加入过多可能使光束过于弥散。[1]

### 3. 证据对照

保存模型状态，再独立填写本组实物观察；两种来源始终分别标注。最多保存 **12 条**，桌面默认每页 6 条，窄屏每页 3 条，低高度横屏每页 1 条。模型记录可以回看，全部记录可以删除；点击条件或现象可查看完整内容。

记录包含材料或水的情况、位置、光源状态、定性现象及备注。讨论区只保留“哪些证据支持你的解释？”和可选文字，不自动评分或代写结论。CSV 与 SVG 导出包含**全部分页记录及解释**，不是仅导出当前页。

## 课堂使用建议：约 8—12 分钟

1. **3—4 分钟**：真实黑盒实验后，选一组有分歧的观察，在网页还原；学生先解释，再剖开黑盒检查光路。
2. **3—4 分钟**：真实水槽实验后，同时比较清水、少量微粒与较多微粒，放大一处散射，讨论侧面光路和前方光斑的差别。
3. **2—4 分钟**：保留两种条件，补充实物观察，用证据写下或口述自己的解释；需要时导出课堂记录。

实物比较应尽量保持光源、位置和其他条件一致。真实激光实验由教师管理，严禁照射眼睛。

## 科学模型边界

- 黑盒设在暗环境中，忽略观察孔漏入的杂散光。材料参数和画面亮度是定性示意，不代表固定或实测透过率；薄布织孔可能保留部分清晰轮廓。
- 水槽使用透射与侧向散射的定性模型：前向直达光随光程衰减；局部侧向亮度同时受微粒多少、到达该处的光和侧向出射衰减影响。内部光学厚度参数不对应真实牛奶浓度。
- 清水保留微弱散射背景；微粒较多时，光路可能前强后弱。前方光斑只表示直达光，不代表全部透射光；不能把侧面可见性当作总透光量。
- 放大层只展开代表性的单次散射，未逐条计算多次散射、角分布、界面反射与波长差异。微粒被放大，慢放光点只帮助追踪方向，不表示真实光速或可见的光粒实体。

## 操作、保存与后续替换

主要操作支持点击、滑块及拖动，提供键盘操作和全屏按钮。页面按一屏布局设计，证据以分页控制数量；说明和完整记录弹层可单独滚动。记录保存在当前浏览器，本机存储不可用时仍可临时记录与导出。

`window.LightLabModels` 暴露 `materials`、`liquids` 参数表及 `box`、`water` 计算函数，便于后续按计算与展示分工调整模型、替换素材。SVG 展示集中在 `renderBox`、`renderWater` 等函数，替换时应保持材料位置、源点、接收位置和方向关系一致。

T1 表示技术依赖等级。真实希沃全屏、旧 iPad、Safari、实体触控及文件下载行为仍需按实际设备核验，不能由等级推定全部兼容。
