# 三下2.3 迎接蚕宝宝的到来

教科版三年级下册第二单元《动物的一生》第3课。依据所提供教材第36—38页及教学用书本课。扫描件明确版权版次尚待核实。

## 用于真实课堂
单体index.html离线打开，无外部字体、图片、库或网络请求。

- 观察蚕卵：先观察实物，再画图，填写真实日期、颜色、形状、是否见到蚁蚕与其他发现。未填写的结果保持未知。日期按北京时间人工填写，不自动假定观察时间。
- 测量辅助：可选输入同方向紧密并排的一组蚕卵的个数与总长，用总长÷个数估算单卵大小，保留原始测量值。不要剥取粘附的卵或挤压活卵；无法安全测量时留空。
- 对照记录：任选两次已保存记录，并排看图画、文字、测量与孵化观察，不自动断言颜色变化意味着死亡或孵化。不同测量批次的平均值不能当作单个卵的生长曲线。
- 照料与计划：约定饲养地点、观察频次、分工、记录方法，落实桑叶来源及周末假期照料。提供安全条件与不干扰生命的提醒，不模拟或承诺固定孵化时间。

## 数字增益
保留带日期的原始观察、画图和测量，重复选择两次对照，避免以记忆替代观察。计算只处理学生实测数据，不生成仿真孵化结果。图可放大，绘图不构成实际尺寸证据；照片视频需另行保存。

## 保存与限制
点击“保存本次观察”新增记录，最多12条；表单和画板保留，继续保存会新增而非覆盖。已存记录与已保存计划使用此浏览器localStorage，重载后仍可读；未保存表单、画板和未保存计划不会恢复。

不跨设备、浏览器或网址同步；本地文件模式是否持久保存取决于浏览器。空间不足或禁用存储时页面提示立即下载，当前数据仍保留在页面内存。HTML下载包含全部已存记录、原始测量与计划，可离线查看；不支持回导。保存前请核对，当前版不编辑/删除已存记录，修正可另存并在备注写明。每次使用后建议下载备份。

所有内容在本机处理，不上传，不要求姓名或学生身份信息。
