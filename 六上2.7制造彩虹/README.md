# 六上 2.7《制造彩虹》｜互动课件

**教材**：教科版小学科学六年级上册第二单元第7课，第58—61页。  
**课堂定位**：真实实验之后的透视、验证与迁移，不替代用三棱镜、水和镜子制造彩虹的活动。  
**署名**：镇海区鲲池小学 王宁。  
**运行方式**：直接打开 `index.html`；单体 HTML，无第三方依赖，不联网、不请求设备权限。

## 三项任务

1. **分开白光**：先用实物三棱镜、水中斜镜寻找彩色光带。再在网页拖动器材，观察白光经过两个界面发生折射，或在水中折射、镜面反射、再次折射。切换红、蓝单色光对照，不把反射镜误解为“制造颜色”的部件。
2. **走进雨滴**：拖动太阳高度，看主虹在反太阳方向的可见范围；点彩虹或按“放大一滴水”，拖动光线入射点，观察一次内部反射和两次折射。红光、紫光出射方向有差异，不同雨滴把不同颜色送到眼睛。
3. **重合颜色**：自由拖动红、绿、蓝光斑，按需关闭任何一束；在指定位置取样，比较两色、三色叠加的结果。色光加法与颜料减法混色不同。

## 科学模型边界

- **棱镜**：采用二维均匀玻璃模型，分色使用七组随波长变化的近似折射率；光线由斯涅尔定律确定。器材尺寸、屏距和投影放大条带仅供课堂观察，不代表教材实验实物比例。
- **水和镜子**：采用平面水面、理想平面镜模型，光线按入水折射、镜面反射、出水折射计算。真实实验还受水容器形状、光源方向和屏的位置影响；镜子本身不进行色散。
- **雨滴**：球形雨滴的二维过球心截面，展示主虹的一次内部反射；没有计算真实雨滴的非球形、水汽散射、次虹和干涉光学。红光约42°、紫光约40°是典型主虹几何方向的近似角度，角度数值会随入射位置改变。天空绘图采用球面方向几何，色带线条适度加粗，便于教室后排观察。
- **RGB 色光**：以显示器加色混合模拟三束等亮度红、绿、蓝光。三束叠加产生的屏幕白色属于视觉上的白，并不意味着只有三个离散波长就能复现太阳白光的完整光谱。
- **证据性质**：页面导出的文件名带“模拟图”；不应把软件演示结果当作学生真实实验的测量数据。

## 操作与兼容

- 希沃一体机：点击上方三个探究页，可按 `←`、`→` 切换，右上角可全屏。
- 触控设备：拖三棱镜顶端、镜子右端、太阳或雨滴入射点；RGB 光斑可直接拖动。
- 下载：支持 SVG 模拟图、PNG 色光叠加图；下载行为依赖具体浏览器权限。
- 技术等级：**T2（Canvas 二维）**。核心分光与雨滴采用 SVG，色光叠加采用 Canvas 2D；无 WebGL、模型文件、字体和网络依赖。
