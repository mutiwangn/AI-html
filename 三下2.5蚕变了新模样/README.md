# 三下2.5 蚕变了新模样

三年级下册，第二单元“动物的一生”，第5课。单体离线 HTML，无外部素材或网络依赖。

## 课堂使用
1. **茧中有什么**：先保存初始推测与依据，再展开茧壳和蛹的概念分层。拖动“显示强度”只改变图层，不代表时间、X光或真实检测。模型呈现化蛹后的情况，不表示刚结茧就已化蛹。
2. **同处对照**：同步选取幼虫与蛹的外形、体节、足的外观、气门作为观察线索。两幅原创示意视角与比例不同，不可量屏幕长度、数总节数或判断真实颜色。
3. **证据修订**：区分实物、真实影像、教材和概念示意，写下具体证据并保存现在的判断。保留初始想法，不用得分代替科学讨论。

“看不到幼虫那样伸出的足”不等于没有任何足的结构。吐丝不是生命终点；一般生命过程与手中个体是否存活须分开判断。不要仅因静止就判死。

## 数据与限制
当前版本为一份小组记录。初始推测保存后锁定，修订可以更新，仅保存最新修订，不保存历次修订历史。输入切页保留；保存后存在本浏览器本地，未保存输入刷新丢失。不同设备、浏览器或地址不会同步。

下载包含**已保存**的初始推测与证据修订，未保存输入不会加入。导出HTML可查看，不支持导入。本版没有重置、删除或多小组账户功能；请下载备份。

核心 DOM/SVG，无 Canvas/WebGL。桌面两页一屏，窄屏改纵向布局；真实课堂设备兼容性须另外核验。

## 依据与生命保护
依据用户提供《小学科学 三年级 下册》42–44页、配套教学用书“第5课 蚕变了新模样”和Notion三下目录；教材文件具体出版年份未单独确认。使用原创概念示意，未复制教材照片。

优先用教师提供的影像、模型或既有窗口观察。不按屏幕操作剪茧；需开茧由教师评估并操作、保护蛹，不针刺、不摇晃、不加热来检测存活。抽丝拓展优先以已羽化空茧认识材料，不把有活蛹的茧放入热水；空茧可能断丝，抽出长度不能等同完整丝长。
