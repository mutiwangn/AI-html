# 五上1.2 怎样放得更大

教科版五年级上册第一单元《微小世界》第2课，v1.0。打开 [index.html](./index.html) 即可使用，也可下载后离线打开。单体文件约80 KB，HTML、SVG、Canvas实现，无外部运行依赖；项目技术需求为 **T2 · 二维绘图**。

## 教材依据与课堂使用

依据本项目所附新版教材印刷页6–9及教师教学用书“第2课 怎样放得更大”。核心要求是将两个凸透镜平行、同轴组合，调节镜距，在图像较大且清晰时固定并测量，再与单镜观察比较。教参特别提醒学生避免只追求图像大而忽略清晰度。附件未提供作业本，本页不预设作业本答案。

适合插入40分钟课堂中的探究与研讨环节：先用实物尝试组合，再用模型解释调镜时的变化，最后回到实物观察和记录。

| 页面 | 主要操作与教学增益 |
| --- | --- |
| 调镜找像 | 拖动上镜或调节镜距，同时看装置位置和眼中图像；切换单镜与双镜，保留最多3张快照。“成像透视”揭示实物观察难以同时看到的中间像与光路，支持暂停、回溯和复位。 |
| 观察对照 | 把模拟快照或本地实拍放入A/B栏，缩放、圈注并写下自己的发现，导出PNG。通过相邻图像说明“多看清了什么”，自主形成证据记录。 |

## 科学模型的条件

双镜采用近轴薄透镜计算：下镜焦距3 cm、物距4 cm，上镜焦距6 cm；下镜和物体固定，上镜与眼睛一起移动，眼距上镜2 cm，镜距可调14–20 cm。模型眼设瞳孔直径3 mm、远处至25 cm的调焦范围。这些是建模选择，不是教材给定距离、器材推荐值或儿童眼睛的统一参数。

单镜是独立调到清楚位置的参照，切换时同时调整其物距。双镜透视只追踪样本上一个点的光，经下镜会聚成对应的中间像点，再经上镜进入眼睛；不是显示样本的全部光线。追踪动画仅示意传播顺序，不表示真实光速。

像的大小和失焦由同一组参数计算。说明中的倍数是相对25 cm处裸眼观察的角放大率，不能把任意两片放大镜的铭牌倍数直接相乘。模型未涵盖全部像差、衍射和照明影响，模拟结果不能作为独立验证其预设规律的实验数据。

自带字样、叶脉和织物均为示意样本；模拟快照与用户实拍分别标明来源。图片缩放不会增加原始细节，不同裁切也不能直接比较光学倍率。

## 观察记录保护修订

换图先成功解码再确认替换，取消或解码失败会保留原图、圈注、发现及缩放。保存对照图按完整文字长度增加图像高度，不再截断发现或来源。

本次在云端 Chrome 实际导入正常及损坏 PNG，验证取消替换、模型快照替换，并下载和查看七行发现的 PNG；另外用隔离测试核对七十行文字及迟到请求保护。记录仍仅在当前页内存中，请在刷新、关闭或升级前导出，不能自动迁移未保存输入。尚未覆盖全部图片格式、真实大图超时、旧 iPad、Safari及希沃实机。
