# 六上 1.5 睡眠要充足
原创课堂辅助探究稿，教材教参细节待核。

## 探究链
虚构跨午夜上床、入睡等待、夜醒、醒来与起床时间尺，区分在床和估计睡眠；比较两组平均9小时但范围9–9/7–11的五晚数学示例；虚构作息方案、风险判断与方法笔记。

## 边界
时间尺夜醒居中仅示意，不是真实发生时刻或睡眠阶段。入睡/夜醒通常估计，模型不诊断睡眠。示例时长非适龄推荐，不判定个体是否充足。平均数不反映全部分布，不能据此推出健康相同或补觉抵消因果。无个体日志、姓名、健康评分或个人数据上传。不自行用药，持续困扰求助可信任成人及专业人员。
