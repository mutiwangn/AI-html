# 六上 1.5 睡眠要充足

面向六年级科学课堂的单体 HTML 互动课件。围绕“怎样用调查证据判断睡眠是否充足，并提出可以复查的改进计划”，支持学生计算、比较、解释和持续观察。

## 教材依据与教学定位

- 《科学》六年级上册，第一单元“健康生活”，第5课《睡眠要充足》，教材第18—21页。
- 配套教师教学用书第87—103页，重点参考教学目标、课堂实施建议和数据统计指导。
- 本课主线为制订调查计划、实施调查、整理比较数据、依据证据提出建议。网页用于放大传统调查活动中的时间关系、数据分布和持续观察价值。

学生完成活动后，应能区分在床时间与估计睡眠时间，采用统一口径整理匿名调查数据，发现平均数可能掩盖的个体差异，并提出具体可行、能够复查的行动计划。

## 三个探究场景

### 1. 夜晚时间尺

拖动“上床”和“起床”两个时间点，观察跨午夜的时间段。先估计，再点击“比较时长”，进一步调整入睡等待、夜间清醒总时长与实际午睡时长。

页面同时呈现在床时长、估计夜间睡眠与每天睡眠合计，帮助学生发现：上床与起床之间的时间不能全部计作睡眠；午休时间也不能直接当作午睡时间。

核心计算关系：

```text
在床时长 = 起床时刻 − 上床时刻（按跨午夜的同一晚计算）
估计夜间睡眠 = 在床时长 − 入睡等待 − 夜间清醒总时长
每天睡眠合计 = 估计夜间睡眠 + 实际午睡时长
```

这是一种根据记录进行的估计，不是对真实睡眠状态的仪器测量。计算应检查时间的有效范围，不能接受清醒时间超过在床时长的无效组合。

**可讨论的问题：**两个人都在床上10小时，估计睡眠时间会相同吗？如果只记录上床和起床，我们遗漏了什么？

### 2. 班级证据

先查看明确标注的24人演示数据，再切换“同均值、不同分布”的对照例子。点击分布柱，可以查看落在该区间的人数与匿名编号，追溯图形背后的记录。

本班调查支持匿名录入、CSV导入与CSV导出。每条记录采用统一口径：**同一调查周内，近7天平均夜间睡眠小时数，以及近7天平均每天实际午睡分钟数**。没有午睡可填0，未调查到的数据留空，不能用0替代。

图表可切换“夜间睡眠”和“一天合计”。10小时参考分界仅用于“一天合计”；不能把夜间睡眠图中的不足10小时人数直接解释为每日睡眠不足人数。

**可讨论的问题：**平均睡眠达到10小时，是否说明每个人都达到目标？平均数之外还需要查看什么？样本数量、缺失记录和统计口径会怎样影响解释？

### 3. 一周小实验

带入第一屏的条件，固定起床时间、入睡等待、夜间清醒和实际午睡，只改变上床时间，比较不同计划在这些假设下能够预留的睡眠时长。

学生选择一条可行行动，也可以自行填写，例如提前整理书包、调整临睡前的活动，或与家长和老师商量时间安排。系统推算表示“如果这些条件成立，时间会怎样变化”，实际效果须通过后续记录检查。

独立的“两周观察”弹层用于记录**同一个人**改变前后各7天的每日睡眠合计。两周都填写完整7天后，才显示均值比较；未填写的日期保留缺失状态，不按0计算，不补造数值。记录保存在本机，并支持导出计划与观察记录。

**可讨论的问题：**实际结果支持原来的预测吗？除了计划中的行动，两周里还有哪些条件可能发生变化？如果没有明显变化，我们下一步可以怎样记录和调整？

## 数字技术带来的教学增益

| 传统活动中的难点 | 网页提供的观察或比较方式 |
|---|---|
| 跨午夜计算不直观，在床时长容易与睡眠时长混淆 | 同一时间尺上拖动、扣除和合并时间，立即比较三种时长 |
| 汇总后只看到平均数，个体差异不容易被发现 | 在平均值、分布柱和匿名记录之间来回查看，用同均值例子检验解释 |
| 改进建议容易停留在“早点睡” | 固定条件比较计划，再用前后各7天的观察检查结果 |
| 手工统计负担较大，讨论证据的时间被挤占 | 自动计算和图表反馈，把课堂时间留给口径判断、数据解释与研究反思 |

## 40分钟课堂建议

| 时间 | 教学活动 | 建议使用方式 |
|---|---|---|
| 0—5分钟 | 交流睡眠经验，提出研究问题 | 先让学生估计一组跨午夜时间，不急于显示全部计算 |
| 5—13分钟 | 区分三种时长 | 操作“夜晚时间尺”，先预测，再改变一个变量进行比较 |
| 13—26分钟 | 分析调查证据 | 明确调查周期与口径，查看本班数据；用演示对照探讨平均数与分布 |
| 26—35分钟 | 提出可行计划 | 在“一周小实验”中比较时间安排，写出一条具体行动与预期 |
| 35—40分钟 | 交流依据，安排持续观察 | 说清楚哪些是记录、哪些是推算；明确前后两周的观察方法 |

本班调查可以提前一周开展。若课前没有完整数据，可先使用标注清楚的演示数据学习方法，再布置观察任务；演示数据不能作为本班调查结果。两周观察应由学生自愿选择自己的记录开展，也可由教师使用匿名案例组织讨论。

## 模型边界与科学表达

1. **10小时是本课的教育目标参考。**依据教材与教育部要求，用于讨论每日睡眠安排，不据此给个人作健康诊断或能力评价。
2. **夜间与每日合计采用不同口径。**每天合计包括实际午睡；“午休30分钟”只有在实际睡着30分钟时才可记作午睡30分钟。
3. **所有时长都依赖输入记录。**网页不能感知实际入睡、觉醒或睡眠质量，也不据时长推断深睡眠、记忆力、反应速度或身高变化。
4. **示例、计划推算与实际观察须明确区分。**改变上床时间产生的推算结果，不会自动写入后续观察数据，也不能当作行动已经生效的证据。
5. **前后比较不能单独证明因果。**两周可能存在课程安排、身体状况、环境等其他变化。均值变化可以支持讨论，仍需结合记录解释。
6. **完整记录优先于自动补全。**缺失值不按0处理；两周均值比较只在前后各7天完整记录时显示，且需确认属于同一个人、采用相同口径。
7. **睡眠充足也涉及质量与规律。**本课件聚焦时长和调查方法；不能把达到某个数字理解为睡眠的全部要求。观察活动采用自然记录与改善作息，不安排故意减少睡眠的实验。

教育部同时提出，小学生就寝时间一般不晚于21:20，应结合个体睡眠状况和午休等实际安排。时间模型中的自由调节用于比较和讨论，不表示页面中所有时间组合都是推荐作息。

## 使用与数据

- 交付形式：单体 HTML，可直接在浏览器中打开；不依赖外部脚本、字体或网络服务。
- 课堂呈现：优先使用电脑或希沃一体机横屏全屏；以一屏呈现核心操作与图表为布局目标。
- 交互：支持鼠标拖动、触控拖动、方向键微调和可聚焦的表单控件。
- 数据：采用匿名编号。本班录入与个人观察分开使用，不把演示数据混入真实统计。
- 本机保存：指当前设备与浏览器中的本地保存，不代表其他设备自动同步。导出后可保留计划和记录，浏览器清理本地数据可能移除本机保存内容。
- CSV：每行填写“夜间小时,午睡分钟”，或“编号,夜间小时,午睡分钟”；支持中文表头、逗号/中文逗号/制表符和本页导出文件。编号为不重复的正整数，最多200人。缺失或非法行会明确报错，整批导入暂不应用，已有数据保持不变。近7天平均值按1分钟精度折算；CSV往返保留精度和匿名编号。

## 开发与素材替换

使用二维 SVG、HTML与CSS呈现时间和统计关系。科学计算与界面绘制分离，为后续细化图形与替换素材保留接口。

单体文件内的公开接口：`SleepCore` 提供 `formatClock`、`formatDuration`、`nightSummary`、`recordFromHours`、`parseSurvey`、`exportSurvey`、`summarize`、`sample`；`SleepView` 提供三页重绘函数与只读快照 `snapshot()`。

| 模块 | 职责 | 后续修改约束 |
|---|---|---|
| `SleepCore` | 时间换算、有效性检查、CSV处理和调查统计分组 | 修改视觉素材时保留计算口径，不将缺失值改成0 |
| `SleepView` | 时间尺、分布图、完整两周比较及交互状态的呈现 | 可替换图形、图标和动画；保留匿名数据回溯与状态反馈 |
| 主题CSS | 配色、字号、间距、布局和焦点样式 | 优先保持课堂后排可读、一屏呈现和触控目标大小 |

本课不需要三维模型。后续素材替换不应增加与教学任务无关的装饰，也不应把关键数据烘焙到不可编辑的图片中。

- 纯计算模块：12组测试通过，包含跨午夜、清醒扣除与午睡合计、负数/缺失/超24小时、CSV分钟精度往返、200人上限、相同平均与不同分布、分箱边界及空数据。
- Chromium 133 离线浏览器：三页切换、先预测后揭示、鼠标跨午夜拖动、滑块键盘操作、A/B示例切换、统计口径切换和柱形回溯通过。
- 真实数据：匿名编号41/99导入、错误行整体拒绝、实际CSV下载及再次读取、刷新保留编号通过。存储单一区块异常不会丢弃其他有效记录；超出UI范围的旧参数被拒绝恢复。
- 计划与观察：计划调整不生成观察值；选择行动、本机保存、缺失日期保持空白、完整7+7天比较、实际TXT导出与刷新恢复通过。
- 1024×768触控模拟：真实触控事件拖动上床手柄，时刻与模型同步更新通过。
- 常用布局：1366×768、1920×1080、1024×768、768×1024的三页及调查/两周记录弹层已作截图与溢出检查；核心内容可见。手机390×844、844×390亦作回归检查。
- 离线加载与整个核心操作流程无外部网络请求、无课件JavaScript运行错误。只有主动点击资料来源链接需要联网。
