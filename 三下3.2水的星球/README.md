# 三下3.2 水的星球

教科版科学三年级下册，第三单元第2课。单文件互动工具，无网络依赖。

## 使用
1. 先观察教材照片及实物地球仪，识别海洋、江河、湖泊、冰川和地下水。
2. 用轻软地球仪进行安全的“数十指”活动。每次输入海洋、陆地、未辨清三个真实次数，总和为10；多轮自动汇总。允许更正录入错误，不改写观察以迎合预期。
3. 对照教材约71%的海洋表面积资料，讨论样本与面积的区别。记录列表可局部滚动。
4. 切换“地球表面／地球上的水”，区分表面积比例与水量组成。填写一项保护水的行动，导出观察记录。

100格不是世界地图；水量条是大致比例示意，淡水不等于可直接饮用的水。程序不自动模拟抛接，也不替代真实实验。

数据仅保存在当前浏览器；换设备不自动同步。重要记录请导出。

## 来源与兼容
依据所提供三下教材第61–63页、相应教学用书及三下目录。教材明确出版版次待核。采用 DOM/CSS 原生交互，无 Canvas/WebGL，评级 T1；希沃、平板和窄屏实体设备未核验。

已保存观察与行动存在当前浏览器；导出 TXT 包含已记录轮次及行动输入框的当前文字。未保存的行动刷新会丢失；导出文件不支持回导。
