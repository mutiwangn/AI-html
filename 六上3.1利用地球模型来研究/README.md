# 利用地球模型来研究 · v1.0

[打开互动网页](./index.html)

六年级上册第三单元“地球的运动”第1课。单体 HTML，Canvas 2D 绘图，无外部脚本、字体、图片或网络请求依赖。技术等级 T2。课件及本课首页条目均无校名和署名。

## 教学立意

依据所提供教材第66—69页、教师用书第228—236页。本课从已有的昼夜和四季观察出发，提出问题，观察地球仪信息，认识不同模型的用途，并尝试用乒乓球、黏土等制作模型。

网页重点补充实物地球仪较难提供的观察条件：在同一地点与同一视角下随时删除辅助信息，透视赤道平面与地轴的关系，以及同步比较两个信息量不同的模型。学生先明确研究问题，再决定保留哪些信息和需要哪些证据。

## 三个工作区

### 拆看模型

- 拖动改变观察方向；轻点球面放置观察点；方向键也可改变视角。
- 分别开关海陆、赤道、经纬网和地轴，保持观察点的地理位置不变。
- 从北极上空观察经线汇合；透视赤道平面、球心和假想地轴的空间关系。
- 先观察，再按需打开含义提示；不在初始画面展示全部结论。

### 对照研究

参考模型与学生模型始终使用相同视角、观察点和光照条件；右边的信息层由学生选择。提供三个研究问题：

1. 怎样判断观察点在南半球还是北半球？
2. 怎样让别人准确找到这个观察点？
3. 观察球面的亮区与暗区，需要海陆图案吗？

“核对证据”帮助比较描述依据，不以固定勾选组合或星级分数替代学生的解释。学生可以提出其他表达方法。

### 研究记录

保留模型画面及“观察到的现象—想研究的问题—模型方案与缺少的信息”，按模型、昼夜、四季、其他分类。支持多条记录、编辑、删除与撤销、浏览器本地保存、单条 PNG 导出和全部 TXT 导出。

有内容的草稿在新建、切换或再次捕获前会自动收录；导出全部文字包含当前草稿的最新内容。最多保存40条。记录只存于当前浏览器，换设备、清理浏览器或使用隐私模式前应导出。

## 40分钟课堂中的建议位置

| 时间 | 活动 | 网页作用 |
|---|---|---|
| 0—8分钟 | 分享昼夜与四季观察，整理已有问题 | 可在研究记录中留下初始问题 |
| 8—18分钟 | 小组观察实物地球仪，说明标记的用途 | 选择性使用“拆看模型”，比较隐藏前后 |
| 18—28分钟 | 为一个问题选择模型信息，解释依据 | 用同步对照保持条件一致，快速比较方案 |
| 28—38分钟 | 用乒乓球、黏土等制作或改进模型 | 将数字模型中的想法转回实物制作 |
| 38—40分钟 | 交流模型能回答什么、还缺什么 | 导出记录，为后续课程留下研究线索 |

可只使用其中5—10分钟；页面不替代真实观察、讨论与动手制作。

## 模型约定与科学边界

- 地球用球体近似；海陆数据经过简化，统一填色不是卫星真实颜色，也不显示行政边界。
- 地轴是描述地球自转的假想直线；模型中的杆不是地球内部真实存在的实体杆。赤道和经纬线是参考标记。
- 赤道平面经过球心并与地轴垂直；其在屏幕中的投影随观察方向改变。
- 透视只帮助观察空间关系；真实地球不透明。不透明状态隐藏背面的极点和观察点；透视时背面极点有明确标注。
- 拖动仅改变观察方向；不作为真实地球自转方向、速度或周期的演示。
- 受光问题采用固定于地理坐标的同一光源，表面法向与光向量的点积决定亮暗。观察角度变化不会改变同一地点的受光状态。暗面保留微弱环境色以便定位，不代表那里有太阳直射光。
- 同一时刻的亮暗分布不能独立验证昼夜交替成因，也不能解释四季。本课保留后续研究的问题空间，不提前完成第2—7课的教学任务。
- 本页不标注无参照的“23.5°”，不要求学生掌握地球内部各层参数或海陆面积比例。

## 独立模型替换接口

球体渲染器 `EarthModelCanvas` 与页面状态、记录系统相互分离。实例支持 `set(options)`、`getState()`、`draw()`、`destroy()`。坐标约定为东经、北纬取正值。

`EarthModelCanvas.replaceLand(geoJSONOrPolygons)` 可替换海陆素材；接受 GeoJSON FeatureCollection 或 `[polygon][ring][point][lon,lat]` 数组。静态 `project()`、`inverse()` 提供球面正射与逆投影。后续若替换为更精细素材或其他渲染方式，应保留图层、观察点及视角接口，不改变课堂记录结构。

## 验证与兼容性

- JavaScript 语法检查通过。
- 6702组球面投影与逆投影往返校验通过；背面遮挡、零经纬线格式及固定光照跨视角一致性已检查。
- 在浏览器中检查三个工作区的切换、鼠标拖动、图层开关、透视、极地视角、证据显示、草稿保留、记录编辑与保存。正式部署后验证 PNG 生成及多行内容完整性、TXT 包含当前尚未提交的最新编辑；截图导出按原始宽高比绘制。
- 使用同源 iframe 的真实 CSS 视口检查1920×1080、1366×768、1024×768、768×1024、390×844，主要画布、按钮和输入框均在一屏内；另做证据区文字与按钮的重叠检查。大屏与窄屏有不同布局。
- 鼠标、Pointer 触控、键盘和旧版 mouse/touch 后备路径均已实现。浏览器检查不等同于希沃、旧 iPad 等全部实机测试；特别旧的 WebView 仍需现场试用。
- 不使用 WebGL，不需要相机、麦克风或账户登录。离线运行时，只有主动打开“教学说明”里的外部资料链接需要联网。
