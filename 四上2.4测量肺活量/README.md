# 四上2.4《测量肺活量》互动实验室 v1.2

本课按教师本轮确认的三页结构更新：**学会测量 → 肺活量与健康 → 简易测量仪器**。用于希沃一体机全屏展示，以及学生平板触摸操作。

在线入口：[打开《测量肺活量》](https://mutiwangn.github.io/AI-html/四上2.4测量肺活量/)。保存本课 `index.html` 后，可直接用浏览器离线打开。模型、器材图、样式、程序和解压备用代码全部内嵌，无需启动课堂服务或连接CDN。

## 第一页：学会测量

参照用户提供的实物照片，将器材改为**竖直长条测量袋与插入袋口的短直吸管**。

1. 展开测量袋，排空袋内原有空气，再插入吸管。
2. 尽力吸一口气，含住吸管，并捏紧吸管周围的袋口。
3. 一次尽力呼气后停下。此时袋体仍可能松软、起皱。
4. 拔出吸管，马上捏紧并密封袋口；用手向内拖动袋口，向充气方向卷，直到剩余袋体饱满、卷不动。也可用“演示卷袋”按钮观察过程。
5. 读取鼓起部分的最大刻度。支持局部刻度放大、触屏数字键盘、正确与错误反馈，以及更换演示气量。

卷袋期间收集的气量保持不变；缩短松软袋体时，剩余气囊变饱满。不同演示气量具有不同的松软充气形态与卷袋终点。刻度0在封闭端，数值向开口端增大，每小格250mL。器材动画是操作示意，实测读数以手中器材为准。

“想一想”随当前步骤提出原有空气、补吹或卷袋后的气量问题。真实课堂仍应两人合作、每人使用自己的吸管或吹嘴，轮换并稍作休息；测三次，取三次有效测量的最大值。

## 第二页：肺活量与健康

直接复用用户附件《20261025认识呼吸器官_界面优化（去除四年级）.html》中的 **Z-Anatomy / BodyParts3D真实解剖网格**。保留五个肺叶、气管、支气管、膈肌、胸廓、脊柱和胸部体表。解剖网格与后加的教学呼吸动画分别说明。

- 支持安静时与运动后两种情境，观察呼吸深度、频率及肺和膈肌的变化。
- 支持独立的“一次最大吸呼”，区分平常一口气与最大可呼出气量；尽力呼气后，肺内仍有气体。
- 用“较少—较多”滑杆比较同一体型下最大可呼出气量的定性示意。基础人体大小与镜头不变，滑杆改变最大吸呼幅度与气量示意带。
- 支持拖动、方向键旋转，角度复位与胸廓显隐。WebGL不可用时自动显示由同一批真实网格生成的呼吸投影，并明确说明二维状态。

肺活量反映呼吸功能的一个方面。页面将其与身高、生长发育、测量方法和配合程度一起解释；活动表现及恢复还受心脏、训练程度和运动强度等因素影响。运动情境不会自动增大肺活量边界，也不以滑杆计算健康等级、血氧或恢复秒数。动画节奏便于观察，不要求学生模仿呼吸。

## 第三页：简易测量仪器

默认展示可自制的**倒置瓶排水式测量仪器**，并提供测量袋及常见流量式电子仪对照。每种器材有三个可点的部件热点，解释材料、结构和读数方法。

排水式采用两条清楚分开的管路：进气长管通到倒置瓶上部，排水短管在下部。瓶内先灌满水并倒置，气体进入后在上部聚集，水面下降，水从短管排出。瓶身刻度根据模型的容积几何标定，250—4500mL演示气量与最终水位一致。排水量等于收集气量是在忽略漏气、温差和压差等因素时的原理关系。实际操作不通过嘴吸水。

电子仪仅解释常见流量式仪器将气流随时间累计为体积，具体构造与校准按实际仪器说明执行。

v1.2在1920×1080、1366×768、1024×768、768×1024、390×844五种尺寸下逐一切换第三页的三种仪器，检查实际SVG可见性、主舞台尺寸、控件可达和整页溢出。三个模式每次仅显示对应器材，五种尺寸均无整页溢出。核对电子仪2250mL累计终点、排水式2250/4500mL读数、测量袋250/4500mL收卷终点与部件高亮，以及演示中切换、重置和离页返回。

v1.1此前已检查第一、二页的实际拖拽卷袋、2250mL读数反馈、不同呼吸情境、最大呼出与余气、气量滑杆。本轮第一、二页的器材和模型实现保持原版本。

模型数据两种离线解压路径均验证成功；14个网格、161413个顶点、321054个三角形，索引与顶点属性范围有效，使用Uint16索引。当前验收浏览器明确禁用了WebGL，已验证真实网格投影的降级路径；该环境无法验证实际GPU三维旋转。尚未在学校的具体希沃设备及实体平板上运行，使用支持WebGL的浏览器可启用三维显示。
