# 四上2.4 测量肺活量

互动实验室 v1.0，用于希沃一体机全屏展示和学生平板操作。依据本项目《【教师用书】四上word》第二单元第4课（印刷152—161页）及教材39—41页制作。

在线入口：https://mutiwangn.github.io/AI-html/四上2.4测量肺活量/

## 三个课堂页面

| 页面 | 主要操作 | 教学落点 |
| --- | --- | --- |
| 学会测量 | 五步演示；拖动卷袋；250 mL刻度放大与读数；预测未排空、漏气和补吹的影响 | 规范收集一次尽力呼出的气体，理解操作怎样影响数据 |
| 记录比较 | 每人三次实测、触屏数字键盘、无效标记、最大值；班级点状图；运动习惯讨论；过程照片与教师点评 | 三次规范测量取最大值，保留原始证据，先检查方法再讨论差异 |
| 解释与应用 | 倒置瓶排水法；改变有限演示气量；先解释再揭示体积关系；形成坚持运动的观察方案 | 空气占据空间；用排水体积估测收集气体的体积；关注同一人的长期变化 |

默认不预填学生数据。演示用2250 mL与真实记录分开；不会把按钮按压时长、吹气声音或麦克风音量换算成肺活量。页面保留mutiw标识，学校姓名只在课程总览显示。

## 单体文件直接使用

`index.html` 已内置全部CSS、JavaScript和SVG，无外部字体、CDN、图片下载、WebGL或框架依赖。保存为HTML后可直接离线打开，三页演示、本机记录、照片整理及CSV/JSON导出均可使用。

浏览器本机保存可用时会保存数值、照片与点评；存储受限或空间不足时会明确提示。课后应导出完整记录以便留存；完整JSON可以重新导入本机。CSV包含三次值、有效性、最大值、完成状态、运动习惯和教师点评。

真实器材仍需准备简易肺活量测量袋、每人自己的通气管或吹嘴及密封用品。两两合作，相互核对操作，轮换并稍作休息。感到头晕或不适时停止测量并告诉老师。读数精度以实物刻度为准。

## 局域网课堂

静态GitHub Pages及单独的本地HTML不能独自完成不同设备之间的数据同步。配套运行包提供本地课堂服务，网页使用同一份单体HTML。

1. 下载并解压 `肺活量局域网课堂_v1.0.zip`；教师电脑需有Python 3.8或更新版本。
2. Windows双击 `启动课堂.bat`；macOS运行 `启动课堂.command`。也可以在解压目录运行 `python server.py` 或 `python3 server.py`。
3. 保持服务窗口打开。教师和学生连接同一局域网，用浏览器打开窗口显示的 `http://教师电脑局域网IP:8787/` 地址。
4. 教师点“课堂 → 我是教师 → 创建课堂”，得到6位课堂码。学生点“我是学生”，填写课堂码、组号和成员代号。
5. 学生上传实测值及照片；教师查看全班图、点开组员点评或标记展示。教师可以增减组数、暂停提交、继续课堂或结束课堂。
6. 退出服务前点“导出 → 下载完整记录”。服务数据保存在教师电脑的运行内存，关闭服务会清空；结束课堂按钮只改为只读，仍可继续导出。

最多12组，每组A—H八个匿名成员。教师身份与学生身份分别使用随机令牌；课堂码不等于教师权限。学生只能修改自己的成员记录。减组会拒绝移除已有记录的组；掉线保留身份并提示上传失败，不会把上传失败的数据悄悄改成另一套本机记录。

照片在客户端压缩为最长边1280px的JPEG，服务接受JPEG、PNG或WebP，每张不超过1.2 MiB。课堂不要求姓名或人脸，数值、照片和点评不会写入GitHub。浏览器必须从本地课堂服务地址打开网页；只在GitHub页面填写同一个码并不能互联。

若平板无法访问本地地址，应检查是否同一网段、校园无线是否开启终端隔离以及教师电脑是否允许该本地服务的局域网连接。相同Wi-Fi名称本身不保证设备可互访。

## 科学表达

- 肺活量是一次尽力吸气后再尽力呼出的气体总量，单位mL；它不等于呼气时长、响度或吹气速度。
- 每次测量前排空旧空气，吹完立即密封，再卷去未鼓起的袋体；不要挤掉已经收集的呼出气体。
- 三次有效测量取最大值；操作有问题的一次不计入最终结果。三次未完成时显示“暂最大”，不计入全班完成样本。
- 点状图用于比较测量证据。密集结果以带人数的圆汇集，点击可逐一查看组员，避免同值学生被遮挡。
- 人体示意在尽力呼气后仍保留肺内气体。排水法中的气体聚集在上部，瓶内水面下降，水从另一通路排出；显示等式时说明是理想体积关系，忽略漏气、温差和压差。
- 运动习惯不是影响肺活量的唯一因素。不从一位学生的数值推断健康，不把一次运动与肺活量立即增加关联。
- 教材参考窗口保留2014评分口径：四年级男生60/100分参考值1100/2600 mL，女生900/2000 mL。它们是评分参考，不是医学正常范围上下限；高于100分参考值不会标异常。

2014标准来源：[教育部原始发布](https://www.moe.gov.cn/jyb_xxgk/xxgk/neirong/fenlei/sxml_twyjy/twyjy_tyws/tyws_xgzc/201407/t20140708_171692.html)。实际体测以学校当期要求为准。

## 课堂安排参考

开课约3分钟提出“一次能呼出多少空气”；用第一页面约5分钟示范、预测和纠错；约15分钟完成真实器材测量并录入；约8分钟用第二页面检查证据并讨论差异；约7分钟用第三页面解释排水法并提出长期观察方案；最后约2分钟回顾与导出。时间由教师按实验实际调整。

## 验证记录与边界

使用内置浏览器和本地预览，检查1920×1080、1366×768、1024×768、768×1024及390×844的三页主界面。修复了笔记本高度下的记录区、排水控制区拥挤问题，默认四人记录与主要功能在页面内呈现。增加组员后记录列表可在局部区域滚动；主教学页无整页上下滚动。

功能检查包括五步操作、实际指针拖动卷袋、2250 mL读数反馈、1500/1750/1600三次取1750、无效测量处理、点图和照片点评、排水法分步揭示、导出与重新导入，以及局域网教师学生数据同步。Python服务通过6组真实HTTP集成验证，真实room.js客户端也通过两会话集成验证。

视觉使用Image Gen生成的完整主屏概念作为构图参考，并通过浏览器截图逐项检查导航文案、主舞台与侧栏比例、字号层级、冷灰/白/蓝绿色、按钮和间距。刻度、肺体积和气水边界由精确SVG替代概念图中的示意素材，属于科学准确性所需的有意调整。主屏补充的通气管、卫生与器材精度提示来自教材操作要求。

上述为浏览器与服务软件验证，未直接连接学校的具体希沃机型、校园Wi-Fi或学生实体平板。旧浏览器仍应先在课前打开测试。

## 文件组成

- `index.html`：完整单体课堂网页。
- `肺活量局域网课堂_v1.0.zip`：同一HTML、Python服务及Windows/macOS启动入口。
- `server/`：可审查的局域网服务源码、接口合同与说明。
- `parts/` 和 `build.py`：网页开发源文件与单体打包脚本。

对网页继续修改时编辑parts片段，再使用build.py生成dist/index.html，并将它作为本课的index.html发布；课堂使用无需执行打包脚本。
