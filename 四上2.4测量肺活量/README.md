# 四上 2.4 测量肺活量
原创课堂辅助探究稿；教材教参细节待核。页面不替代真实肺活量实验、教师规范指导或体检。

## 教学链
读虚构容量刻度（100 mL 分度，0–4000 mL量程）；区分零点与人体测量；依据漏气而非数字大小排除无效示例；比较有效最大值与平均值口径；讨论超量程不能给精确数、单一数值不能诊断健康；导出方法笔记。

## 安全与隐私
仅示例甲乙丙及虚构重复数据，无真实学生数据录入表。读数框用于识读示意刻度，不是上传实测肺活量。方法笔记不得填姓名、病史、身体数值；不保存或联网上传，刷新清除。无排名、健康判定、强制吹气、憋气、深呼吸或自制器材要求。真实活动由教师按适用规范和健康情况组织，器材卫生、量程、重复次数和休息间隔不套用本模型。
肺活量不等于总肺容量、平静一次呼吸量或憋气时间。零点不是人体零肺活量；平均值计算不增加仪器精度；不提供个体正常标准。
