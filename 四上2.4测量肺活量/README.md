# 四上 2.4 测量肺活量

深蓝观察式单文件课件，嵌入 Three.js r160，无配音、无外部运行资源、无文字/数值输入。1600×900 基准画布按窗口等比缩放，左右操作、中央观察。正文无学校或真实姓名，不收集、存储或上传个人数据。

## 教学链与科学核查

已直接核用户提供的《义务教育教科书 科学 四年级 上册》印刷39–41页（PDF43–45）及《2026秋教科版四年级科学上册教师用书》152–161页。对教材使用原创重述与程序化示意，不嵌教材截图。

1. 肺活量：一次尽力吸气后再尽力呼出的总量；不是肺总容量、平静一次呼吸量或憋气时间。模型呼气后仍保留体积，不把肺画成空袋。
2. 测量袋：排尽袋内原有空气→插入通气管→一次连续呼气→抽管并封口→从袋口朝充气部分卷拢至自然绷紧→按实际器材方法读数。禁止继续挤压充气部分“追求大数”。
3. 误差：袋内原有空气未排尽可能偏大，漏气可能偏小，多次换气补吹改变测量对象。虚拟数字只演示方法，不从数字大小判断有效性。
4. 三次有效样例1750、2000、1750 mL取最大2000 mL。不相加、不用平均值替代，也不把多吹一口获得的2500 mL当作有效最大值。
5. 健康：身高、年龄、发育和方法等都会影响数值；不做个人诊断或健康排名。教材2014评分跨度不等同医学正常范围，因此不设置正常/异常阈值。

辅助核查：
- 美国胸科学会肺功能检查资料：https://site.thoracic.org/advocacy-patients/patient-resources/pulmonary-function-tests
- ATS/ERS 2019测量标准、漏气与污染控制：https://pmc.ncbi.nlm.nih.gov/articles/PMC6794117/

临床肺功能检查不同于课堂测量袋实验。这里只用其约束概念和安全边界，不照搬临床测试规程。

## 安全与模型边界

始终强调只观察、不跟随屏幕吹气或憋气。真实实验由教师结合学生情况与器材说明组织，个人专用或规范处理吹嘴，不共享吹嘴、不回吸、不为大数字过度用力；需要重复时充分休息，头晕、咳嗽或不适立即停止，亦可只观察。

肺、气道与测量袋均为原创程序化几何，不是扫描或第三方下载模型。刻度250 mL为示意分度，袋身形变、鼓起长度与体积对应为教学映射，不是产品标定或精密流体仿真。真实袋型读数以说明书为准。动画只表示过程，不规定真实呼气时长。
