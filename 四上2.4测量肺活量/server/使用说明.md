# 测量肺活量 局域网课堂

单体HTML可以直接离线使用。需要学生平板上传三次读数、过程照片并接收教师点评时，由教室里一台电脑启动本服务；教师和学生必须使用服务显示的同一个局域网网址。

## 开课

1. 把整个文件夹放在教师电脑上，保留 `server.py` 与 `index.html` 在同一文件夹。电脑需有 Python 3.8 或更新版本，不需要安装任何第三方库。
2. Windows 双击 `启动课堂.bat`；macOS 双击 `启动课堂.command`。也可以在此文件夹的终端运行 `python3 server.py`（Windows可用 `py -3 server.py`）。
3. 在教师电脑用浏览器打开窗口显示的地址，例如 `http://192.168.1.10:8787/`。点击网页里的“课堂”创建课堂码。
4. 平板连接同一局域网，用浏览器打开同一个地址；选择加入课堂，输入教师给出的6位课堂码，选择组号和成员A–H。每人或每台平板使用不同成员代号。
5. 教师保留服务窗口，使用网页查看全班记录、照片并点评。需要换组或换学生时先导出已有数据。

第一次启动时，如Windows询问防火墙网络访问，只需允许教室所用的受信任局域网。若平板打不开地址，先确认使用的是教师电脑显示的学生平板地址，而不是 `127.0.0.1`。学校Wi-Fi的客户端隔离也可能阻止平板互访；此时可使用允许设备互访的同一路由器网络。

## 课堂数据

每个成员记录3次读数；“有效”标记决定是否参与最大值。只有3个有效读数齐全才算完成。录入核对范围为100–8000mL，此范围不用于判断身体健康。活动频率用于讨论影响因素，不用于给学生排名或诊断。

照片会缩小后上传至这台教师电脑；支持JPEG、PNG、WebP，单张不超过1.2MiB。不要上传无关学生人脸或姓名，拍测量装置与操作即可。

教师可以暂停封存、继续课堂或结束课堂。结束后保留只读查看和导出，直到服务窗口关闭。所有课堂数据和照片都只保存在服务进程内存，关闭服务或电脑重启会清除，**请在结束服务前导出需要的记录和照片**。

## 使用边界

GitHub Pages 页面用于在线展示，下载的单体HTML用于离线展示。这两种方式没有运行中的局域网服务器，不能仅凭相同课堂码自动互联。启动本服务并通过它的地址打开同一HTML后，课堂互联才会启用。

本服务只用于受信任教室局域网。无需设置公网端口映射，也不需要填写任何API密钥。不要把教师身份令牌分享给学生。课堂码用于加入；教师权限由创建课堂的浏览器单独保存的随机令牌控制。

如8787端口已被占用，可运行 `python3 server.py --port 8788`；所有设备使用新的端口。已有测量数据不会写入GitHub或外部云端。
