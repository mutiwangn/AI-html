## 功能
图画观察练习：三物体比较颜色/形状；揭示只说颜色不能唯一辨认物体；手感、轻重明确需要真实操作，不从图画自动推断。
实物记录：A/B两件老师确认安全的物体，分别记录颜色、表面、软硬；选项之外用“其他/待比较”口头补充。二次确认清空。无打字、评分、网络依赖或预填实物结论。安全提示不尝、不闻不明物体、不摸尖锐/过热物体。
