- 九物齐备：小木块、作业本、红砖、塑料笔筒、乒乓球、圆柱橡皮、长条橡皮、钢尺、塑料尺。原创SVG，与1.2采用同编号。

- 不输入文字；不自动画/填答案。T1保留，刷新记录清空。
