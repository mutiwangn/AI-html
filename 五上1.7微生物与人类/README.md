对应教科版五年级上册第一单元《微小世界》第7课。已核对本项目提供的教材第26–29页，以及教师用书中本课的教学目标、教材解读与实施建议。

网页用于40分钟课堂中的阶段性观察、比较和讨论。真实资料阅读、实物观察与交流照常进行，网页补充难以同时看见的宏观与微观变化，以及可回溯的接触传播路径。

## 三个工作区

| 工作区 | 核心操作与课堂价值 |
| --- | --- |
| **追踪作用** | 选择酵母发面、面包霉变或落叶堆肥；点画面打开内部透视，拖动进程、播放、暂停或复位。保留 A 条件后改变 B 条件，沿同一模型进程比较外部现象与内部机制。 |
| **阻断传播** | A 为私筷取共用菜；B 可选公筷专用或公筷也入口。两边可同时从“甲的口腔”或“共用菜已有标记”开始，逐步回放、回退，并点选对象追踪标记来路，讨论措施的适用范围。 |
| **整理联系** | 留存关键观察，自主选择“人的目的—希望怎样改变—做法或解释”，关联观察依据，形成可撤销的关系图；支持下载所选观察与关系图 SVG，不自动代写或判定解释。 |

最多保留6帧观察、4条关系，保存在当前设备浏览器中，不上传。浏览器限制本地保存时会提示；全屏为可选功能，不影响核心操作。

## 科学模型边界

- **这是定性示意。** 比例、颜色、数量和模型进程均不是实测数据；不同情境的进程不能换算成实际分钟或天数。模拟展示预设机制，不能作为独立验证该机制的实验结果。
- **改变条件会重算整段过程。** 相当于重新设定一次对照，不能解读为中途冷却或中途通气。冷藏使本情境中的活动减慢，不代表灭菌；酵母的“温暖”表示适宜条件，并非越热越好。
- **宏微对应保留关键机制。** 酵母产生的二氧化碳被面团结构保留，面团蓬松不等于酵母个体变大；霉菌菌丝可能伸入多孔食品内部；落叶场景聚焦好氧分解，通气不足不等于全部分解停止。养分小点仅示意部分物质去向，不表示植物直接“吃掉”腐殖质。
- **传播标记不等于感染。** 橙色只表示所示接触中来自同一起点的可达路径，不表示菌量、感染概率或已经患病。专用公筷的假设是只夹共用菜、放下菜而不碰口和已用餐具；公筷不能解决已有食品污染，也不能覆盖空气传播等其他途径。
- **普通面包发霉不能靠去掉表面判断安全。** 不打开、闻嗅或品尝霉变样品；网页不能用于判断食品毒性或可食用性。
