辨别回路

安全：实体实验只使用教师指定、与小灯泡匹配的低压电池和器材。严禁接插座或市电；不要用导线直接连接电池两极，不做短路试验。

模型假设：电池和灯泡正常且匹配，导线与接点理想。只有这一条串联回路，没有旁路或短路。现实中灯不亮还可能有其他原因；电流不是到灯泡就被“用完”。
