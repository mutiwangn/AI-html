# 五下1.1 种子发芽实验 · 基础辅助稿

单文件 `index.html`，T1 基础交互，无 Three.js、外部库、图片下载、账号或网络请求。按本项目五年级下册第一单元第1课登记，默认不署名。

## 教学功能
- 并排设计A/B两组，调整土壤、水分、光照、温度、种子数量，突出差异。
- 检查是否只改变拟研究条件。不预设某组必定发芽，不自动生成数据或实验结论。
- 固定本次观察的方案、预测和自查，再录入三次真实观察。空白与零分开；负数、小数及超出种子总数的数据不能导出。
- 设计页后续修改不会改写已经固定的观察方案；已有记录时不可直接替换方案，避免把数据归到另一实验。
- 导出TXT实验计划或观察记录。当前页面内存保存，刷新/关闭会清空，使用前明确提醒导出。无导入和云存储功能。

## 使用建议
约40分钟：预测5分钟、设计12分钟、交换检查8分钟、准备材料与约定观察15分钟。观察应延续数天，下一课再分析；本页不要求当堂“长出”种子。用同批健康绿豆，不密封、不加热、保持湿润不等于浸没。不可食用实验种子，霉变请教师处理。

## 依据与限制
课号、课名对应项目教科版五下目录《生物与环境》；目录年份尚未核实。**匹配版教材正文及教师教学用书未取得，当前是通用科学探究辅助稿，不声称完整复现新版教材活动。**
参考教育科学出版社[《科学活动与测评》五下公开参考资料（2022）](https://cms.esph.com.cn/webfile/upload/2022/02-24/16-09-410061-602070688.pdf)关于对比方案和多粒种子观察的组织方式，不沿用其中预测栏作为科学结论。未复制课本扫描页、第三方插图或网络课件。

绿豆发芽与幼苗后续生长不可混同，不将某一种种子的结论推广到所有种子。方案检查只覆盖所列条件；真实实验还需考虑种子状态、容器、摆放、观察时段等。室温与较低温只是方案标签，实际温度需测量并由教师安排适宜场所。
