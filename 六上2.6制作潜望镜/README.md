# 六上 2.6《制作潜望镜》｜光学透视调试台

单文件课堂互动页：[`index.html`](./index.html)。打开文件即可离线运行，无网络请求、第三方脚本、Three.js 或视频素材。作者：镇海区鲲池小学 王宁。

## 课时定位

教材第54—57页依次安排：**分工制作、组装并调整镜片 → 展示与说明 → 根据任务测试、记录问题和改进**。本工具用于学生完成纸盒潜望镜后，观察真实装置不便直接看到的**镜筒内部光路**，以可操作模型解释故障，再返回实物调试。它不替代动手制作和真实观察。

与第5课《设计潜望镜》的分工：第5课侧重设计路径、选择材料和讨论用途；第6课侧重**验证、故障诊断与改进证据**。

## 两个课堂任务

1. **透视调试**：拖动镜片中央移动平面镜；拖动金色端点旋转镜片。观察入光口、上下镜与目镜之间光路同步变化。可直接切换“上镜歪了 / 下镜移位 / 内壁挡光 / 两镜对准”，请学生先预测再验证。
2. **测试改进**：在隔墙、水下、暗管场景中，结合相同的光路，分析“镜筒材料是否适用”“前端是否需要补光”。记录 A/B 方案，另填**实物测试发现**并导出带有模拟数据标识的 TXT 记录。

## 科学模型与边界

- 采用二维几何光学：光在同一均匀介质内沿直线传播，镜面反射方向以反射定律计算；每面镜子是**有限长度**线段，光碰镜筒壁/挡板即停止。
- 为从观察者角度显示“能看到哪里”，程序**从目镜逆向追踪21条视线**，与几何光路可逆性等效。画面中的箭头表示**物体到眼睛的真实传播方向**，并非表示光由眼睛发出。
- `19/21` 等光束数字仅是软件抽样的**模型通过率**，不是照度、亮度、通光量或实际测量值；画面清晰度为教学用定性表达。
- 未模拟玻璃厚度、折射、镜面材质、真实透镜成像、空气散射与水密封结构的工程细节。防水、补光条件代表实际设计约束，不是对材料性能的实验测定。
- 眼睛只有当光路通畅、目标进入视野且环境允许时，才被展示为能看见目标；暗管无光时，即使镜面角度正确也看不清。

## 使用和兼容

- 推荐大屏横向全屏，支持鼠标、现代平板 Pointer Events，兼容未实现 Pointer Events 的触摸设备（Touch Events 后备）。
- 无摄像头/麦克风/权限要求；课内记录通过浏览器 `localStorage` 保存于本设备；可导出 `.txt` 供汇报或提交。
- 输入的实物观察应由学生实际填写，不会自动写入模拟结果。
- 作者署名在课程导航页展示，课件内不显示作者署名，保持观看区域简洁。
