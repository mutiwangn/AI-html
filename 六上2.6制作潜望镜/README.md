# 六上2.6 制作潜望镜

独立原创课堂辅助设计稿，教材教参细节待核，不等同整课验收。

设计两面45度镜的方向，先预测再三段追踪；缺镜、镜方向错误、中段遮挡均保留失败光路，不能穿透外壳继续显示成功。特定直筒结构用两平行镜将水平光先向下、再向右反射进入眼睛。实物反射面必须朝向内部。

原生SVG剖面仅展示一条代表光线，不模拟完整视野、亮度、精确像、放大、防水或夜视。独立五项制作检查与改进前后真实记录，CSV导出，不自动把模型写成实测。一次变化不直接判定因果。

原创代码和SVG，无第三方资产、学校或真实姓名署名。安全镜片、教师指导切割、不看太阳激光强光、不入水、不窥探隐私。

已验：JS语法；预测门槛、双镜成功、下镜方向错误、中段遮挡终止、5项检查、缺失记录、前后变化、CSV下载和清空，桌面截图。修正外部挡板高度使直达目标光路受阻而上窗口光路通畅。实体触屏、旧浏览器、教材教参及完整课堂验收待完成。
