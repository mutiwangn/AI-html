# 六上 1.3 营养要均衡
原创课堂辅助探究稿；教材教参细节待核。

## 探究链
给虚构三餐选菜，拆分主要食材、跨餐去重、观察简化类别覆盖；保存原方案快照再修改，保存改进方案，比较新增与移除食材并说明理由、尚缺信息；判断菜名数不等于食材数、类别齐全不等于达标、单一食物不能代替多样饮食。

## 营养和隐私边界
不采集真实饮食、体重、过敏、病史或姓名。仅虚构讨论材料，无个人推荐量、热量、健康评分、限制性饮食或减重建议。五类为教学简化，不是完整膳食指南；奶与豆制品同列不意味等量替代。主要食材未包含油盐调味料、饮水及真实份量，不能据此判断营养充足或油盐适量。实际供餐须另按适用指导与个体需要，课堂不要求试吃。
所有选择和快照仅在页面内存，刷新清除，CSV手动导出，无联网提交。

## 资产和验证
独立 HTML/CSS/JS，无第三方素材、学校姓名署名或可见技术等级，原归档保留。
修复初稿语法后 node 检查通过。桌面验证白粥/米饭和蒸蛋/番茄炒蛋跨餐去重为大米鸡蛋番茄3种；原快照保持不变，加入青菜豆腐苹果后6种；新增清单、CSV下载、清空对照、概念反馈与截图已验。实体触屏旧浏览器及课堂验收待完成。
