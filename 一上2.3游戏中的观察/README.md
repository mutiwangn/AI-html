# 一上 2.3 游戏中的观察 v2.0

三个可直接玩的单屏课堂游戏，支持单人挑战与同屏双人。内容结合本项目提供的教科版一年级上册教材第32—34页及教学用书本课分析，并按教师需求扩展游戏计分与设备反应时间体验。

## 三个页面

1. **抓住了吗**：尺子落下后抓取，五轮比较成功次数。
2. **刻度得分**：越早抓住分数越高，五段游戏分值为100、80、60、40、20；抢按或没抓住为0分，五轮比较总分。彩尺分值不是厘米。
3. **反应时间**：随机等待后亮绿灯，记录本设备上从信号到按键的近似毫秒数。双人逐轮比较有效响应，五轮比较赢局数；无效结果保留为抢按或超时，不加入有效时间中位数。

## 操作与感官条件

- 先按下方开始按钮，再用玩家的大按钮抓取。键盘蓝队 A、红队 L；单人也可按空格。采用各自的 pointerdown 监听，兼容同屏多点触控设备，不因随后生成的 click 重复计分。
- 前两页独立切换“可见/蒙住画面”与“倒计时声音开/关”，形成四种条件。声音为三声短音加长放尺音，首次开始由用户操作解锁音频。
- 蒙画面从准备至双方结束保持静态遮挡，不展示放尺瞬间的文字、颜色、手势、倒计时、局部结果或局部结算声音。画面和声音都关闭时，不提供额外的放尺提示。
- 双人共享同一个放尺时刻和下落曲线。各自首次输入独立判定，一方抓住或抢按不改变另一方的尺子。
- 设置可切换慢速、标准、挑战三档尺速。第三页始终使用随机亮灯，不沿用前两页的声音倒计时，避免把节奏预判当作反应测试。
- 切页、换人数或条件会开始新局；已经完成的轮次保存在记录中。失焦、隐藏页面会取消未完成轮，停止排队的声音。

## 记录与使用范围

内置最近40局本地记录，按游戏、人数、画面、声音和速度标注；查看记录显示当前游戏最近12局，可导出全部记录CSV。无姓名、无服务器上传，浏览器不允许存储时仍可使用当前页面并导出。

网页提供视觉和听觉线索，触屏按键不等同于皮肤感知尺子的触觉实验。第三页是设备上的近似响应时间，包含显示、声音和输入条件的影响，不作为反应能力诊断或跨设备严格排名。课堂可配合实物抓尺子，讨论不同感官提供的信息。

## 实现与验证

单个HTML内嵌CSS、JavaScript及透明手部图片；尺子刻度为原生SVG，信号灯为可变状态控件，无CDN、无WebGL或网络素材依赖，支持离线打开。隐藏兼容等级为T1，声音需要浏览器支持Web Audio。

核心规则19项测试、DOM/时钟/音频集成11项测试全部通过，覆盖公平时刻、独立抓取、五轮结算、抢按、超时、重复输入、跨轮长按、取消旧回调、蒙画面提示隔离、声音取消与分模式记录。云端Chromium实际操作通过抓尺、双人刻度计分及反应计时；按1920×1080、1366×768、1024×768、820×1180、390×844、844×390、320×568检查三页布局。实体一体机多点触控、外接键盘组合与Safari尚未进行硬件实测。
