# 六下 1.6 多样的古生物｜基础辅助稿
证据类型比较：叶片印痕、行走足迹、水流波纹。可揭示/遮挡12格图像，结合明确的假想资料辨别体化石、遗迹化石和非生物沉积构造。不是实际化石鉴定、测年或挖掘模拟，不等于完整古生物多样性课。
