## 课堂使用
先做真实实验，再由学生点选记录。食盐、红糖、小石子各有独立的“原来颗粒是否可见”和“水的颜色”记录。图卡随记录变化，并排保留材料示意与观察后记录图。第二页同时展示三种材料的两类观察，便于指认相同/不同，并讨论看不见颗粒是否表示物质消失。

数字增益是保持各材料的观察证据并可视对照，不是预设结果的溶解动画。未观察、看不清可保留；教师应鼓励如实记录，不把不同记录改成标准答案。

## 科学边界
图中材料颗粒仅为符号，数量、大小和形状不代表具体实验用量。选择“有颜色”用统一淡棕色表示类别，不对应实物真实色相、浓淡或溶解程度。选择“仍能看见”仅表示有可见颗粒，不意味着原来颗粒数量、形状未改变。右图明确标记为记录图，不是物理模拟。

看不见原来的颗粒不能单独证明消失或全部溶解。本工具不自动分类“溶解成功”；食盐溶解后仍在水中，不是变成水。放大镜能帮助看较小颗粒，不意味着能看到已经溶解的物质。本课不引入微观粒子动画，不要求一年级掌握微观解释。

由教师准备少量材料、透明塑料杯和常温水；分杯、分棒避免混入；实验液体不入口、小石子不入口。没有加热蒸发或品尝验证操作。需要进一步证据由教师另行设计安全活动。
