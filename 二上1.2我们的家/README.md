# 二上1.2 我们的家

教科版2025年版，二年级上册第一单元《造房子》第2课。单体HTML，原创SVG，无外部依赖，不要求打字，不上传数据。

## 课堂组织
- 房屋找材料：逐一观察砖墙、木门、玻璃窗面、金属窗框，联系材料与用途。
- 实物比一比：选择实际金属样品，与木头比较纹理、表面和轻重；记录初始为空，点击循环选择实际发现。不是模拟测量，不能用图形替代掂、摸。
- 按需要选：针对“透过窗户看见外面”的需要，比较透明玻璃、木板与不透明金属板，继续讨论窗框与门的材料选择。

使用教师准备的安全、大小大致相同的实心样品。不弯玻璃、砖或锋利金属片。所有记录仅存当前页面，刷新清空；更换金属样品也重置记录，教师使用前须告知学生。

依据《二年上册 科学 教师教学用书 教科版 25秋》印刷第51–60页。认识常见金属，区分自然物与人造物，强调根据需要选材，不概括所有金属均比所有木材重。
