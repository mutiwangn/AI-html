# 五上1.4 用光学显微镜观察

版本：v1.0。入口为 `index.html`，面向五年级科学课堂中的阶段性探究，教师主控，兼顾学生触控操作。

## 教材依据

依据项目提供的五上教材第一单元第4课，印刷第14—17页（PDF第18—21页）；教师教学用书“第4课 用光学显微镜观察”；配套材料说明书第08—09页。本课关注规范使用显微镜、比较可见结构、记录名称与放大倍数。网页补充实物操作中难以同时看见的关系，实物显微镜仍应由学生亲手使用。

## 两个工作区

**调光与对焦**：侧面仪器、照明路径、物镜与玻片间隙、目镜视野同步变化。学生可以区分视野暗与图像模糊，观察反光镜和调焦旋钮分别改变什么；换高倍后通过细调寻找清晰像。

**视野与定位**：固定照明和焦点，同屏显示玻片局部俯视及倒像。拖动同一标本、标记目标、保留移动起点，比较运动方向；切换物镜观察取景范围变化，解释为什么应先在低倍下寻找并居中。

## 操作与记录

- 拖动反光镜、粗调或细调旋钮，也可使用底部控件；长按细调按钮可以连续微调。高倍关闭粗调，接近玻片时限制继续下降。
- 在定位页拖动玻片，或聚焦玻片后使用方向键；“另选目标”设置定位点，“保留位移起点”显示方向对照。
- “保留这一帧”保存当前画面与参数，最多4帧。观察记录支持自主画图、导入照片和导出PNG，不自动填写观察结论。
- 复位只重置当前工作区。记录暂存在本次页面内，刷新或关闭前请导出；全屏是否可用取决于浏览器。

## 核心模型与边界

总放大倍数为目镜10×乘以物镜10×或40×，即100×或400×；这是镜头标称组合，不是屏幕实物尺寸的放大倍数。固定目镜视场数 **FN＝18 mm**，模型视野直径为FN除以物镜倍数，分别为1.80 mm、0.45 mm。该设定不适用于测量导入照片。参见 [Nikon视野说明](https://www.microscopyu.com/microscopy-basics/field-of-view) 与 [光学系统说明](https://www.microscopyu.com/microscopy-basics/components)。

标本坐标与玻片位移相加后进行双轴反向变换，生成目镜倒像；两种倍数使用同一标本和观察中心。调焦共用一个镜筒位置，采用近似齐焦模型，换镜后可能需要微调。镜筒位置是相对刻度，不是毫米或镜片焦距；间距、模糊程度和亮度均为教学示意。

固定灯光从左方水平入射，最佳反光镜角度随本模型光源确定，不是实物通用角度。头发、蝶翅为结构示意，字母F为定位片；放大不保证增加可辨细节，参见 [Nikon有效放大说明](https://www.microscopyu.com/microscopy-basics/useful-magnification-range)。导入照片保持原方向，不再次倒转；倍率由用户标注，未填写时保留“未标注”。

## 技术与维护

单体HTML，SVG、Canvas及记录模块均内嵌，无运行时外部依赖，可离线打开；来源链接需联网访问。技术等级 **T2 · 二维绘图**，不使用WebGL或Three.js。课件无学校、姓名署名，仅保留低干扰的`mutiw`水印。

素材替换入口为 `drawSpecimen()`；模型参数集中在 `PARAMS`，状态分别存于两个工作区。替换纹理时保留共享坐标、裁剪范围与倒像变换，避免不同倍率生成不对应的标本。
