# 五上2.1《各种各样的工具》

双页单体互动网页 v1.0。打开 `index.html` 即可运行；全部样式、SVG和逻辑内嵌，无字体、图片、框架或网络运行依赖。课件不显示学校和姓名，仅保留低干扰 mutiw 水印。

## 教材对应与用途

依据本项目提供的五年级上册教材第二单元《工具与技术》第1课，教材正文第34—37页（PDF第38—41页），以及教师教学用书本课“教学目标”“教学重难点”“课堂教学实施建议”和“疑难问题解答”。教师用书明确提醒：不能停留在“手推车最好”的单一结论，应根据山区、楼梯、装卸、操控等条件比较工具的适用性。

本页补充真实运书活动之后难以齐备的场景对照，以及独轮车工作状态与结构功能的联动观察。实物书写工具比较、真实装卸与个人身体体验由课堂活动保留。未引用未提供的作业本。

## 两个工作区

### 1. 换个场景

- 同一批书，同一通道，背篓、扁担、普通四轮平板车同步呈现。
- 可换走廊、窄路、楼梯；用滑块或直接拖动橙色边缘修改最窄处宽度。
- 修改书本总数和每趟装载量；扁担前后两端均分，末趟只装剩余书本，返程空载。
- 点击工具保留自己的选择；支持动画暂停、进程回看、恢复初始条件。
- 最多保存6组条件和选择，查看不同场景下的趟数与通行限制，导出SVG观察记录。记录带全部比较条件，不替学生填写解释。

### 2. 拆看独轮车

- 直接选择车轮、车身、扶手、驻车支架，展开/合拢结构。
- 一次取下一种部件，与原轮廓对照；选择另一种缺件时，先前部件自动装回。
- 扶住推行时支架离地；松手停放时轮与支架共同支撑。
- 缺驻车支架仍可扶住推行，松手停放则后端倾低；缺车轮失去滚动支撑；缺车身不再装书；缺扶手失去原来的握持位置。
- 支持一次动作的暂停/继续、恢复完整和SVG观察图导出。

## 模型条件与边界

- 示例整体占宽：背篓55cm、扁担55cm、平板车80cm；通道模型每侧预留5cm。这些不是器材的统一标准或安全承诺。
- 总书数12—120本、步长2；每趟装载量4—60本、步长2。默认12/20/36本是可修改任务假设，不是儿童安全承载能力。
- 趟数为总书数除以每趟装载量向上取整；同一进程轴呈现去程、卸载与必要返程。最后一次送达即完成，不计多余返程。
- 动画只是流程示意，不代表真实速度或总用时；未计装卸、操控、转弯、休息和个人能力。不计算虚构体力、能耗或省力比例。
- 扁担沿行进方向前后布置。第一稿只比较直通道，不把长杆长度误用为横向宽度，也不推断最小转弯半径。
- 楼梯限制针对普通平板车正常推行、无坡道、不抬车的条件；不泛化为所有推车都不能上楼。
- 结构页为示意，不做定量受力计算，不把缺件操作作为实物活动建议。

## 使用与兼容

- 技术需求 T1：HTML、CSS、SVG与基础JavaScript。图形不需要WebGL、Three.js、Canvas或外部素材。
- 适配横屏大屏、平板和窄屏重排；鼠标与指针/触摸拖动均有处理。
- 全屏与下载取决于浏览器支持；失败时提供反馈。对照记录保留在当前页面，刷新清空，请先导出。
- 源代码分为教学假设/算术模型、运输视图、独轮车视图、公共界面逻辑，保留SVG素材替换入口。
