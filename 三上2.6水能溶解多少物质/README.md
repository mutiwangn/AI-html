# 三上 2.6 水能溶解多少物质

用于希沃一体机全屏课堂教学的互动网页。依据《【教学用书】三上》第二单元第6课，印刷页156—163制作；辅助设计实验、观察现象、汇总证据与联系生活，课堂中仍需开展真实实验。

## 打开与操作

通过课程目录在线打开，或下载HTML后用浏览器打开。点击“全屏”，也可使用浏览器全屏功能。主要操作支持触控；切换三个页面即可组织整节课。

## 三个页面

1. **公平实验台**：先比较实验条件，再按每杯50毫升水、每份2克、同温度进行逐份操作。先做一种物质，再做另一种；充分搅拌、观察后记录完全溶解的份数。20℃为模拟选定的常温，教学用书未限定常温必须是20℃。
2. **全班证据**：8组真实数据默认留空。使用数字键盘登记0—10个完整份数，并确认充分搅拌后是否仍有剩余；柱形图用于比较，支持CSV导出。10份全部溶解但未出现剩余时，只能说明尚未找到限度。
3. **生活拓展**：比较达到限度的盐水继续搅拌与加水后的现象；再以相同物质、水量和加入量，对比20℃与40℃，观察食盐和小苏打的不同变化。

## 实验依据与模型边界

教学用书要求：两个200毫升烧杯各装50毫升常温清水；食盐、小苏打各20克，分别均分10份。前一份完全溶解后再加下一份；最后未完全溶解的一份不计作完整溶解份。教材强调设计公平实验、记录真实数据，并提出用温水重复实验的拓展。

模拟采用近似溶解量：食盐20℃与40℃分别为36和36.5克/100毫升水；小苏打分别为9.6和12.7克/100克水，50毫升水近似按50克计算。食盐参考[ACS教学资料](https://www.acs.org/middleschoolchemistry/lessonplans/chapter5/lesson6.html)，小苏打参考[PubChem](https://pubchem.ncbi.nlm.nih.gov/compound/Sodium-bicarbonate#section=Solubility)。

这些参数用于教学示意，不能作为各组实验的标准答案。完整份数×2克不等于精确的最大溶解质量；最后一份可能部分溶解。动画压缩了等待时间，不反映真实溶解速率。微粒为解释性示意，不表示真实数量、形状、比例或肉眼可见颗粒。

## 保存与使用限制

记录保存在当前浏览器的本地存储中，不会跨设备同步；浏览器清理数据后可能丢失，建议课后导出CSV。离线文件的存储行为也可能因浏览器而异。

单文件使用SVG和Canvas，不依赖WebGL、外链字体或CDN。具体希沃设备、内置浏览器与操作系统的兼容性仍以现场试用为准，建议课前检查全屏、触控、动画和记录导出。
