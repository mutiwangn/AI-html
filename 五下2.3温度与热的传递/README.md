## 模型
同种材料、同质量、恒定比热、各物体内部均温，与环境隔热、无外界做功及状态变化。用户设置初温，判断净传热方向，推进最多8个模型阶段，比较理想完全隔热与允许热交换，或单独查看平衡极限。

每步：q=(A-B)/4；A'=A-q；B'=B+q，因此温差减半，A+B不变。在两者热容相同的假设下，能量收支相等。人为阶段尺度不代表真实时间或传热速率。平衡极限=(A初温+B初温)/2，虚线为极限示意，不是测得的曲线。不同质量/材质/环境散热/相变时不可套用均值。温度与热量不是同一物理量。

关闭交换代表理想完全隔热，不等于简单拉开实际物体。数值非实验记录，颜色非热像，不按图碰触热物体；真实测温由教师指导。
