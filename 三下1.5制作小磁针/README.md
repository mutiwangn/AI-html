# 三下1.5 制作小磁针

教科版三年级下册第一单元第5课课堂互动辅助工具。单文件 HTML，无外部依赖，建议兼容级别 T1。

## 课堂用法
1. 学会摩擦：用四步静态分解放大操作，比较单向摩擦与来回摩擦。回程抬离针。此页只示范动作，不计算磁性、不预判磁极。
2. 公平比较：在同一磁铁部位、3次/15次、单向/来回三个研究因素中选一个。每个因素有独立两条件三次原始数据及控制条件核对；空白与实测0不同。方向实验事先统一单程计数。只比较数据范围，不自动取最大值、均值或强行归纳预设结论。
3. 辨认磁极：记录自由转动或已知磁极试验，核查证据与结论关系。特别提醒只有吸引不足以排除未磁化的铁针；鼓励重复、核对另一端。

建议40分钟安排：动作及安全5分钟，实验设计8分钟，真实制作与三次检测17分钟，辨极与交流10分钟。由教师根据器材、班级调整。

## 教材与科学边界
已对照用户提供的教科版三年级下册学生教材印刷14–16页，以及对应教师教学用书第5课《制作小磁针》。学生教材确切版权版次仍待确认。

教参对重复测量的统计存在不同表述。本工具保留全部三次数据，班级应在实验前统一检测及统计办法，不能看过数据后择优或为符合预期而改写记录。磁性不会随摩擦次数无限增加，实际效果取决于材料、状态及操作；针的初始磁性应控制。网页不作物理测量或真实方向导航。

## 安全与数据
针由教师发放、固定、回收，谨防扎伤；磁铁不入口，远离电子及医疗植入设备。不提供加热或敲击消磁操作。实测后妥善保管供后续指南针制作。

所有记录只在当前页面内存中，刷新或关闭即清空；请在结束前抄录或截图。无上传、无账号、无个人信息收集。
