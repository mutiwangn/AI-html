# 三下 3.8 制作地球科普海报

教科版三年级下册第三单元第8课。单体HTML，双击 index.html 离线使用，无外部依赖。

## 用于真实制作，而不是代写成品
小组先确定集中主题，将收集的证据分成三个模块，填写标题、科学内容和资料出处，最后写行动倡议。数字工具提供两种即时版式、模块换位、原创符号和可下载矢量成果，内容与取舍仍由学生决定。

1. **内容编辑**：主题18字、倡议32字；每模块标题12字、正文80字、出处36字。字数限制帮助凝练内容、维持版面，不是完整资料的保存区。
2. **版面比较**：三栏并列或横向分区；选模块后“与下一模块换位”，标题、内容、出处、图标一起移动。可放大当前模块讨论，返回整张海报比较布局。
3. **检查交流**：来源填写检查只查是否填写，不验证事实。小组对照来源，人工复核数字、单位及图文表达；写同伴意见和改进计划。
4. **修改**：保留修改前快照（不自动淘汰历史）。恢复会覆盖当前编辑，先保留快照或导出重要内容。改正文、标题、出处、图标或换位会取消自查标记；换版式取消图文自查。
5. **导出**：SVG为1200×800纯矢量完整海报，放大模式下导出仍为整张。浏览器可打开并打印；文字可搜索。未完成的作品标为草稿，已勾选仍仅标“小组已自查”，不是自动认证。

## 保存与边界
- 保存修改将作品与快照存在当前浏览器，不云同步。导出研讨记录包含当前三模块内容、出处、倡议、同伴建议、改进计划。
- 默认空白，不预装本次测试数据。输入内容用转义文本写入SVG，不执行输入HTML。
- 原创水滴、叶片、太阳、月球符号仅作版面示意，不是实物照片或精确科学图像。未复用教材图片。需要照片或手绘时可打印后添加，先核素材使用权限。
- 整张预览适合检查布局；阅读文字可放大模块或打开导出SVG放大。课堂后排可读性需结合真实投影确认。
- 桌面主区一屏，编辑与检查侧栏局部滚动；窄屏纵向排列。无Canvas/WebGL，T1基础交互，未作实体希沃/平板验收。

依据用户教材第79—81页及配套教参第8课：确定内容、设计版面、制作装饰、复核数据、展示交流。工具不替代小组查资料与真实展示讨论。

教材明确版次尚待核实。未作独立打开导出SVG及真实打印验收；本地保存受浏览器存储可用性影响。


## 本次修订
恢复快照必须确认，取消不改变编辑。确认后先把当前草稿追加为快照并持久保存，失败则不恢复、回滚内存新增历史，不覆盖当前编辑。恢复目标仍需另存主档；原主档和恢复前草稿均可找回。
不再自动截断/淘汰旧快照，保留现有全部历史。新增快照失败不会显示成功、不会计入历史。
实际浏览器：改题为QA恢复前未保存稿；取消恢复后题仍在；确认恢复后新增快照2，刷新仍能看到旧快照1和恢复前快照2。隔离VM模拟localStorage quota抛错：新增快照与恢复两条路径都回滚新增历史，旧历史与当前编辑保留且显示失败。未故意破坏浏览器真实存储。
