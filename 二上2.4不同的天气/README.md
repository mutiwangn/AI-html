## 数字补充价值
同一校园两个观察窗独立切换晴/阴/雨/雪和风，避免跨照片混杂；可以并排对比、先表达再显示线索。风为独立开关，不错误地将“风”设为排斥晴雨的天气类别。对比适量雨水与长期积水下人与动植物的不同影响，不设唯一“好/坏天气”答案。不是模拟气象数据，不给观察代填答案。

## 课堂与设备
三活动：找不同／说影响／真观察。低年级大按钮、默认20px文字、平板窄屏单列，触屏指针绘图，动画暂停和系统减弱动态适配。真实记录默认全空，仅当前内存保存，刷新清空；可下载含时间地点、记录人、主题、文字、图画的PNG，不上传。
