# 三下1.7 制作指南针

教科版三年级下册，第一单元《辨别方向》第7课。依据所提供教材第20—22页与教学用书本课。教材扫描件明确版次尚待核实。

## 课堂使用

直接打开 index.html，单文件离线运行，无外部字体、图片、库或接口。

1. 按图制作：对照上一课方案，清点材料、分工与工具安全检查。
2. 实测记录：先核实参照北方及磁针北端，观察实物后点选粗略方向或“不能稳定/卡住”。改进前后各保留最多三次，可撤回上次。三次是网页记录建议，不是教材要求。
3. 评估改进：对照叠加方向记录，填写外观、准确、材料、过程自评与他评，下载记录。沿用上一课班级共同标准，未做测试不填成结果。

## 数字价值与边界

将改进前后多次实测方向叠加展示，帮助区分“指向集中”与“指向正确”。结果全部来自学生手动输入，不读取设备磁力计、位置或朝向，不模拟实际磁针，不自动判断作品达标。方向是八方位粗分，不是角度测量。准确性还应实物检查灵敏转动、八方位标注与辨认。

网页记录针对当前一个小组的一件作品；作品类型只是记录标签，不是多组数据库。所有记录仅保留在当前页面内存，刷新或关闭会丢失，请先下载HTML记录或截图。下载文件不会上传。

尖针和剪刀由教师指导操作并清点收回；水远离电子设备；测试远离磁铁与铁制物品，放平避风。改进可在课后继续。

## 兼容与验证

核心使用标准 DOM、内联 SVG、原生表单；无需 Canvas、WebGL、音频或传感器。下载使用 Blob/object URL，受限终端可截图代替。

云端 Chromium 1180×757：三页一屏、两轮记录、未确认条件/未选结果/满额防护、撤回、独立前后记录、自他评、空记录与完整记录下载已验证。希沃、平板及其他浏览器真机尚未验证；窄屏采用纵向布局，允许滚动。

## 课堂修订与记录安全
水浮、支撑、悬挂类型的实测、参照条件、改动说明和评价分别记录，切回恢复。下载仅当前类型，请逐类型分别下载。

记录仍仅保存在打开页面内存，刷新会丢失。升级前请在旧页先下载或截图，勿强制刷新；已下载的旧HTML静态记录请保留，不覆写。部署不会自动迁移旧页记录。未新增个人署名，技术评级及科学内容不变；真实设备待验。
