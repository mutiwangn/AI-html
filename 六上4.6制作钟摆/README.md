# 六上4.6 制作钟摆

独立原创课堂辅助稿，教材教参待核，不是完整课堂验收。

理想小角度单摆模型T=2π√(L/g)，g=9.8m/s²，L从悬点到小球重心，保持L时质量不改变模型周期。明确轻线、小球、无阻力等条件；木条圆片摆的质量分布不可直接套用单摆公式。静态逐相位演示，不虚构实时计时或一小时误差。

四分之一相位步进，区别左右经过中点的方向，从0起计数，往返一次为完整周期。2组有效摆长，各3次真实10周期总时间，除以10得周期；保留缺失与异常，显示范围/均值比较与共同条件门槛，CSV导出。记录仅内存，离开前导出。

原创SVG代码，无第三方素材、学校真实姓名。固定支架、小角度轻放、不推重摆，教师监督；模型数据不是安全装置尺寸指令。
