# 制作钟摆 · 互动实验室

六年级上册第四单元《计量时间》第 6 课《制作钟摆》的课堂互动网页。用同步比较、完整周期标记、时间压缩和重心透视，支持学生在实物探究的基础上调整方案、比较证据、解释现象。

- **交付形态**：单体 `index.html`，HTML、CSS、JavaScript、SVG 全部内置；无需安装依赖或构建。
- **课堂场景**：40 分钟小学科学课，希沃一体机全屏展示，兼顾电脑和学生平板。
- **工作区**：调校钟摆、放大误差、木条挑战；第三个工作区是教材拓展，可按课堂进度选用。
- **版本**：1.0.0；T1 基础交互。
- **记录原则**：模型结果来自计算；实物数据由学生实际测量后填写，两种来源明确标识。

## 1. 运行与基本操作

下载发布目录中的 `index.html`，用浏览器直接打开即可。也可将该文件作为静态页面发布到 GitHub Pages。应用运行不依赖外部字体、脚本、图片、服务接口或网络连接；“教学与模型说明”中的参考资料链接供教师联网查阅。

进入课堂后先点击“全屏”。主要操作如下。

| 操作 | 方法 |
| --- | --- |
| 调整摆绳 | 上下拖动右侧摆锤，或使用滑条、± 按钮；步长 0.1 cm |
| 保留对照 | 点击“把当前 B 保留为 A”，再改变 B 的一个条件 |
| 比较质量 | 选择 20 g、40 g、60 g；球形外观和中心位置保持相同 |
| 调整释放角 | 选择 5°、10°、15° |
| 选择测量任务 | “30 秒探究”或“60 秒调校” |
| 观察完整往返 | 慢放、1×、4×；暂停后或测量结束后可回看已发生的过程 |
| 查看长时误差 | 切换“放大误差”，拖动时间，或选 1 分钟、10 分钟、1 小时 |
| 移动金属圆片 | 在“木条挑战”拖动右侧圆片，或使用滑条、± 按钮 |
| 留存证据 | “记录”中填写实物三次测量，导出 CSV 或当前观察图 SVG |

键盘支持 `1`、`2`、`3` 切换工作区，空格开始或暂停当前任务，`Esc` 关闭记录和说明窗口。操作输入框时保留输入框的正常键盘行为。切换工作区、打开窗口、进入浏览器后台时暂停正在进行的测量。

记录和 A、B 条件保存在当前浏览器的本机存储中，不会跨设备自动同步；浏览器不允许本机存储时，页面会提示导出。课末可用 CSV、SVG 留存本课证据。

教材任务原句为“制作每分钟摆动60次的摆”（第 121 页）。这里的“一次”按从一侧出发、返回同侧的**完整往返**计数，初始释放时记 0 次。

教师教学用书第 364 页把“探究摆的摆动快慢与摆锤质量、摆绳长度的关系”列为重点，把应用结论、反复调试到每分钟 60 次列为难点。网页据此支持四个学习目标：

1. 能提出与摆动快慢有关的猜想，选择一次只改变一个条件的公平比较。
2. 能依据多次实物测量及模型对照，解释摆绳长度变化与摆动快慢的关系。
3. 能在外形、中心位置和摆长保持一致时比较不同质量，辨认实验中的混杂因素。
4. 能根据测量结果提出下一次调整方案，理解有限时间内的整数计数与精细计时之间的区别。

教师教学用书第 372 页建议保持较小摆幅，防止旋转和碰撞支架；改变质量时，可在固定的球形或圆柱形外壳中加配重，尽量保持外形及重心位置稳定。页面的 20 g、40 g、60 g 对应“初始值、2 倍、3 倍”，统一球形和中心位置就是为落实这一公平比较。

## 3. 数字技术增加了什么

| 课堂中的观察难点 | 网页提供的观察方式 | 学生可形成的证据 |
| --- | --- | --- |
| 不同方案往往先后操作，微小快慢差异难以同时比较 | 保留 A，将 B 与 A 从同一时刻、同一相位释放；完整往返在时间线上留下标记 | 同一经过时间内谁先返回、相位差如何逐渐出现 |
| 人工数摆容易把单程当作一次，或遗漏边界上的一次 | 慢放、暂停、回看，计数只在完整返回时增加 | 每一个计数与具体运动过程对应 |
| 30 秒或 60 秒内差异很小，课堂无法持续观察一小时 | 按同一周期把 1 分钟至 1 小时的计时偏差连续展开 | “同样数到 60 次”仍可能存在不同的累计走时偏差 |
| 木条和圆片的整体重心不可直接看见 | 可选重心透视，移动圆片并与裸木条同步比较 | 圆片中心与整体重心不同；质量分布改变时摆动也会变化 |

网页提供可检验的预测和观察角度。学生的真实实验负责检验这些预测；模型输出不自动填入实物记录，也不伪造重复测量波动。教师应让学生先猜测、操作、留下证据，再组织解释，不在任务开始时给出公式解出的目标长度。

## 5. 三个工作区与状态规则

### 调校钟摆

A 是保留下来的对照方案，B 是当前可调整方案。初始两者条件相同：绳长 35.0 cm、质量 40 g、释放角 10°。学生需要根据自己的证据确定调整方向。

- 绳长可在 8.0–70.0 cm 间调整；显示“支点到摆锤中心”的计算长度。
- 质量可选 20 g、40 g、60 g；球形、中心位置和长度不随质量选项变化。
- 释放角可选 5°、10°、15°。角度不是本课必须同时探究的第二个变量，可保持 10°开展主要活动。
- 30 秒模式衔接教材的因素探究；60 秒模式衔接制作与调校。
- 计数显示完整往返的整数；测量结束后同时给出“60 次用时”，精确到 0.01 秒显示。
- 每次改变条件或测量时长都会重置当前计时，已保存的记录继续保留。
- 完成一次模型测量后自动保存 B 的条件、计数、60 次用时及当时的 A 条件。暂停、回看和切页不重复生成完成记录。
- 速度选项只改变屏幕播放与模型时间的比例，不改变同一模型时长对应的结果。

### 放大误差

沿用调校工作区当前的 A、B 条件。横轴是真实经过时间，纵轴是按约定折算的累计计时偏差；上方表示走快，下方表示走慢。时间范围为 **0–3600 秒**，快捷位置为 1 分钟、10 分钟、1 小时。

本页把“每完整往返记作 1 秒”作为教学计时约定，曲线连续折算，包含尚未完成的往返比例。因此它与实验台的整数计数是两种不同的量。当前实现展示到 1 小时，播放一小时采用 120 倍时间压缩。

### 木条挑战（可选）

左侧是均匀木条，右侧是同样的木条与固定金属圆片，均以 10°释放，测量 60 秒。

| 参数 | 模型设定 |
| --- | --- |
| 木条长度、质量 | 30 cm、10 g |
| 圆片质量、半径 | 20 g、2 cm |
| 圆片中心位置 | 从支点向下量，4.0–28.0 cm；步长 0.1 cm |
| 木条与圆片关系 | 刚性固定，作为整体绕同一支点转动 |
| 观察功能 | 同步计数、60 次用时、最近 3 次模型结果、可选整体重心透视 |

木条挑战采用复摆模型。圆片移动同时改变重力矩和转动惯量，不能只把整体重心距离代入单摆公式。靠近支点时，改变位置与快慢的关系可能反转，教师应让学生依据具体区间和观察证据表述。

## 6. 实物记录、平均值与导出

“记录”窗口为实物实验提供独立的填写区域，可选择绳摆或木条与圆片，填写长度或圆片中心位置、质量、可选释放角，以及 30 秒或 60 秒计数时长。

同一条件下提供三行重复测量。每行可填完整往返次数，也可填实际测得的“60 次用时”。整组保存后：

- 每次测量分别保留，并标为“实物测量”。
- 计数平均与用时平均分别按**对应字段的已填数据**计算，并显示参加平均的测量次数。
- 空白表示未测，不按 0 计算；真实的 0 次可以填写并参加平均。
- 若只填写一次或两次，页面会计算已填数据的平均，但课堂仍应按教材要求完成三次重复。
- 模型测量标为“模型测量”，不参加实物测量批次的平均。

**CSV** 导出逐次原始记录，包括来源、器材、长度或圆片位置、质量、角度、计数时长、完整往返次数、60 次用时、实测轮次、时间，以及模型记录中的对照 A 条件。CSV 使用 UTF-8 BOM，便于常见表格软件识别中文。页面上的实测平均值不另导出为汇总行。

**SVG** 导出打开“记录”前所在工作区的当前观察图，附条件、当前时间、计数或误差等证据信息，并标明模型观察图。SVG 是静态矢量图，不包含整段动画；可用于板书复盘、报告或打印。

## 7. 科学模型与适用边界

本节面向教师与后续开发者。课堂主界面不展示求解公式和预设目标长度，学生通过调整和测量获得证据。

### 7.1 绳摆：计算长度、质量与有限角修正

设页面输入的摆绳长度为 $s$，单位 cm。固定的摆锤挂点到中心距离为 1 cm，因此计算用的有效长度为：

$$
L=\frac{s+1}{100}\ \mathrm{m}, \qquad g=9.8\ \mathrm{m/s^2}.
$$

模型把摆锤质量集中在中心，忽略绳的质量、伸长及摆锤自身转动惯量。小摆幅极限的周期为：

$$
T_0=2\pi\sqrt{\frac{L}{g}}.
$$

质量在这种单摆模型的运动方程中约去，20 g、40 g、60 g 在相同 $L$ 与释放角下具有相同周期。它们保持同一球形和中心位置；可以理解为外壳固定、内部对称改变配重。屏幕摆锤为便于观察而放大绘制，不能用屏幕球的直径反推实际长度。单摆定义与小角度周期公式见 [OpenStax 第 15.4 节](https://openstax.org/books/university-physics-volume-1/pages/15-4-pendulums)。

周期计算保留有限摆幅修正。若释放角 $\theta_0$ 以弧度表示：

$$
T=T_0\,C(\theta_0),\qquad
C(\theta_0)=\frac{1}{\operatorname{AGM}\left(1,\cos\frac{\theta_0}{2}\right)}.
$$

算术几何平均 AGM 使用迭代：

$$
a_0=1,\quad b_0=\cos\frac{\theta_0}{2},\qquad
a_{n+1}=\frac{a_n+b_n}{2},\quad b_{n+1}=\sqrt{a_n b_n}.
$$

实现迭代 9 次后取 $C=1/a_9$。代码接口接收角度值，内部先转换为弧度；UI 限制为 5°、10°、15°。这个表达式由完整第一类椭圆积分的 AGM 恒等式得到，参考 [NIST DLMF 第 19.8(i) 节，公式 19.8.1、19.8.5](https://dlmf.nist.gov/19.8)。有限幅度周期的推导亦见 [MIT Chapter 24，附录 24A](https://ocw.mit.edu/courses/8-01sc-classical-mechanics-fall-2016/mit8_01scs22_chapter24.pdf)。

动画角度使用：

$$
\theta(t)\approx\theta_0\cos\left(\frac{2\pi t}{T}\right).
$$

因此**周期含有限角修正，周期内的运动形状仍采用小摆幅近似**。本稿不用于精确研究瞬时角速度、能量随相位变化或大摆幅运动。小摆幅下的近似等时性也不表示任意角度的周期都严格相同。

### 7.2 完整周期计数与累计计时误差

从一侧极点静止释放，$t=0$ 计数为 0。实验台计数为：

$$
N(t)=\left\lfloor\frac{t}{T}\right\rfloor.
$$

代码在边界处加入 $10^{-9}$ 秒的数值容差，避免浮点舍入使已经到达周期边界的计数少一次。显示的“60 次用时”为 $60T$。

“放大误差”设每个完整往返对应 1 秒刻度，其连续折算读数与偏差为：

$$
t_{\text{显示}}=\frac{t}{T}\times 1\ \mathrm{s},\qquad
\Delta t=t_{\text{显示}}-t.
$$

代码中的时间、周期均以秒为单位，数值函数写成 `time * (1 / T - 1)`。当 $T>1$ 秒时偏差为负、走慢；当 $T<1$ 秒时偏差为正、走快。

这是一种教学计时约定，不模拟某一种机械钟的擒纵机构、半周期齿轮步进或传动比。即使 60 秒内都完成了 60 次往返，周期仍可能略有不同；整数计数不足以证明两种方案完全等时。

长时推算假定摆幅稳定、有持续能量补充，并忽略摩擦、空气阻力、支点损耗、温度、当地重力差异和驱动机构误差。真实的无外部驱动自由摆会逐渐衰减，不能把页面的一小时曲线当作实物钟的走时检定。

### 7.3 木条与圆片：复摆转动惯量

设木条长 $l=0.30\ \mathrm{m}$、质量 $M=0.010\ \mathrm{kg}$，圆片质量 $m=0.020\ \mathrm{kg}$、半径 $R=0.020\ \mathrm{m}$，圆片中心到支点距离为 $x$。

采用细均匀木条与薄均匀圆片模型，圆片平面与摆动平面一致。绕垂直于摆动平面的支点轴，系统的转动惯量、质量一阶矩与整体重心距离为：

$$
I=\frac{Ml^2}{3}+m\left(x^2+\frac{R^2}{2}\right),
\qquad
Q=\frac{Ml}{2}+mx,
\qquad
d=\frac{Q}{M+m}.
$$

重力矩为 $-gQ\sin\theta$。周期为：

$$
T_{\text{木条+圆片}}
=2\pi\sqrt{\frac{I}{gQ}}\,C(\theta_0)
=2\pi\sqrt{\frac{I}{(M+m)gd}}\,C(\theta_0).
$$

裸木条令 $m=0$，重心在 15 cm。复摆方程及平行轴定理的使用参考 [MIT Chapter 24，第 24.2–24.3 节](https://ocw.mit.edu/courses/8-01sc-classical-mechanics-fall-2016/mit8_01scs22_chapter24.pdf)。

由上述模型可推得，复摆的等效单摆长度是 $I/Q$，一般不等于整体重心距离 $d$。圆片中心、整体重心和等效长度分别表示不同的量。页面的重心透视只显示整体重心，不能单凭这一点解释全部快慢变化。实际器材的木条密度、圆片尺寸、固定方式不同，达到目标的位置也会不同。

### 7.4 模型证据的边界

理想模型在相同条件下重复运行，会得到相同结果；页面不添加随机波动来冒充实验误差。实物中的释放、读表、数摆、尺寸测量等误差，应在真实三次测量中讨论。

学生可以用模型发现规律、提出预测、检查控制变量，再用实物检验。若实物与模型不同，应检查长度定义、摆幅、摆锤外形和中心、支点及计数规则，而非用模型数值覆盖实际数据。

## 8. 代码接口与素材替换

物理计算集中在 `MODEL_API_START` 与 `MODEL_API_END` 注释之间，对外提供 `window.PendulumPhysics`。这些函数不依赖 DOM，可单独检验；接口使用的单位如下。

| 接口 | 输入 | 输出或用途 |
| --- | --- | --- |
| `g` | — | 重力加速度，9.8 m/s² |
| `correction(angle)` | 释放角，度 | 无量纲 AGM 周期修正因子 |
| `stringPeriod({length, mass, angle})` | 绳长 cm、质量 g、角度 度 | 周期，秒；此模型周期不依赖 mass |
| `rodPeriod(position, hasDisc, angle)` | 圆片中心位置 cm、是否带圆片、角度 度 | 复摆周期，秒；未给 angle 时默认 10° |
| `rodCenter(position, hasDisc)` | 圆片中心位置 cm、是否带圆片 | 整体重心到支点距离，cm |
| `cycles(time, T)` | 已过时间和周期，秒 | 完整往返整数 |
| `drift(time, T)` | 已过时间和周期，秒 | 连续折算的计时偏差，秒 |

接口按页面支持的参数域设计。后续扩展参数范围时，应同时补充输入校验和科学适用范围。替换物理模型时修改这一独立区块并重新加载页面；初始化后的应用已捕获模型引用，单独重新赋值 `window.PendulumPhysics` 不会自动替换该引用。

`window.PendulumLesson` 提供应用接口：

| 接口 | 用途 |
| --- | --- |
| `version` | 当前版本 |
| `model` | 当前使用的物理模型引用 |
| `getSnapshot()` | 返回状态的深拷贝，含工作区、A/B 条件、计时及记录 |
| `renderers.string(p, t, isB)` | 初始绳摆 SVG 渲染函数 |
| `renderers.rod(position, t, hasDisc)` | 初始木条 SVG 渲染函数 |
| `replaceRenderer('string', fn)` | 注册绳摆渲染函数并重绘 |
| `replaceRenderer('rod', fn)` | 注册木条渲染函数并重绘 |

渲染函数返回 SVG 标记字符串。后续可替换摆锤、支架、木条、圆片等图形，同时保留物理与状态层：

- 绳摆可拖动部位保留 `data-drag="length"`，木条圆片保留 `data-drag="disc"`。
- 当前拖动换算依赖现有 SVG 坐标和比例：绳摆按 4.15 个 SVG 单位/cm，木条按 10.6 个单位/cm。若改变场景几何尺度，应同步修改 `bindDrag` 的换算。
- 使用 `replaceRenderer` 注册新函数；直接修改 `renderers` 对象字段不等同于替换内部渲染函数。
- SVG 中继续使用当前资源定义，或在渲染输出中提供必要资源，确保单文件离线运行和 SVG 导出完整。
- 更换素材时保留中心、固定点、质量和尺寸的定义，避免视觉形状暗示与计算条件冲突。

页面使用原生 JavaScript、`requestAnimationFrame` 和 SVG；没有框架和打包运行时依赖。鼠标、触控统一由 Pointer Events 处理，并提供鼠标和触摸事件回退。记录使用 `localStorage`，导出使用 Blob 与浏览器下载能力。

以下列出可复查的验收方法。视口检查属于浏览器响应式布局检查，不等于对同分辨率的所有硬件作兼容保证。

### 科学与数据验证

| 检查 | 方法与预期 |
| --- | --- |
| 质量公平比较 | 相同绳长、角度下计算 20 g、40 g、60 g，周期与完整计数相同；屏幕球形及中心不变 |
| 长度定义 | 检查计算长度始终为输入绳长＋1 cm；加长绳子使周期变长 |
| 有限角修正 | `correction(0)` 应为 1；5°、10°、15°的修正依次增大；与独立积分或权威公式核对 |
| 计数边界 | 初始为 0；略小于一个周期时为 0；在一个、两个周期处分别为 1、2 |
| 速度与测量时长 | 0.25×、1×、4×达到相同模型时长时，结果一致；30 秒与 60 秒选项正确重置计时和时间标记 |
| 误差正负 | $T=1$ 秒时偏差为 0；周期增大时走慢；相同周期下偏差与时间成正比 |
| 复摆 | 裸木条重心为 15 cm；带圆片时与 $I$、$Q$、$d$ 公式独立核对；检查位置区间内可能出现的转折 |
| 三次平均 | 30、31、29 次应平均为 30.00 次；空白不参加平均；填 0 则参加；计数与用时分别计算 |
| 来源与保存 | 模型和实物标识正确；改变条件、回看、切页不生成重复完成记录；刷新后记录按存储状态恢复 |
| 文件导出 | CSV 中文、空白、0 值、单位及对照条件正确；SVG 能独立打开且标题、条件、图像和证据信息完整 |

可在浏览器控制台读取纯函数和状态，进行独立数值比较。例如：

```js
const physics = window.PendulumPhysics;
const conditions = { length: 35, mass: 40, angle: 10 };
const period = physics.stringPeriod(conditions);

console.log({
  periodSeconds: period,
  cyclesIn30Seconds: physics.cycles(30, period),
  timeFor60Cycles: 60 * period,
  driftAfterOneHour: physics.drift(3600, period)
});

console.log(window.PendulumLesson.getSnapshot());
```

这些输出都是模型数值，不是实测结果。
