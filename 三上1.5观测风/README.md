# 三上 1.5 观测风
独立重制辅助稿；HTML与app.js须同目录。无学校或真实姓名，无第三方素材依赖，不复用旧版代码图形。教材及教参待核，不算整课验收。

八方位固定俯视图区分空气流向、风向标指向和风名；无风时不判方向。旗带下风方向的反推练习。真实三次风向与依据记录，区分有风/无风/未观察、方向不确定。CSV导出，仅页内内存，不上传。

范围：方向概念模型，不模拟风速、风级、器材稳定或建筑扰动。不把动画作为真实数据，不作天气预报。实际观测先辨方向，恶劣天气不外出。

验证：JS语法；云端Chrome东北→西南关系、无风隐藏方向、旗带向南反推北风、实测东风与无风/未观察区别、CSV下载、桌面截图。实体触屏、旧浏览器、课堂与教材对齐待验。
