# 地球的公转

教科版小学科学六年级上册第三单元第6课的单文件互动网页。课堂主线是：观察公转模型，辨认轨道的真实比例，再用南北半球同一时刻的季节资料检验解释。

直接打开 [index.html](./index.html) 即可使用。页面中的图形、样式和程序均在同一个文件内，无需安装依赖或连接外部资源。

## 教材依据与教学定位

- 《科学》六年级上册，第86—89页，对应教材PDF第90—93页：篝火类比、公转特点、日地距离数据、南北半球季节关系及模拟实验设计。
- 《科学教师教学用书》六年级上册，第279—288页：分析资料、修正类比，认识公转方向与周期、地轴倾斜方向基本不变，并据此设计模型实验。
- 教师用书第287—288页建议用真实距离的比例模型，帮助学生理解近日点与远日点的差异在整体尺度中有多大。

本课侧重“怎样建立与修正公转模型”和“哪些证据能检验近热远冷的解释”。太阳高度、光斑、影长和受热之间的完整关系留给第7课《四季变化》继续探究。

## 三个工作区

| 工作区 | 学生操作 | 数字技术增加的观察条件 |
| --- | --- | --- |
| 追踪一年 | 拖动地球或时间滑杆，播放一年，切换斜看与正上方视角，留下四处位置，对比两种地轴方向模型，单独慢看一次自转 | 同时保留不同时刻的地轴朝向；两种视角共用同一空间模型，区分位置变化、地轴方向与观察视角 |
| 还原比例 | 拖动轨道把手或滑杆改变扁圆程度，恢复地球真实比例，叠加正圆，比较两根同零点的距离尺 | 将夸张轨道与真实尺度直接对照；把亿千米转成米，连接课堂中的绳长测量 |
| 检验解释 | 分别预测一月、七月南北半球的季节，查看教材资料，保留两组证据，选择判断并填写可选依据，导出证据图 | 同时对照时间、日地距离和两个半球，保留预测与证据之间的差异，支持依据资料修改解释 |

证据页不自动判分，也不强制填写文字。学生可以先表达判断，再在比较证据后修改。未查看的资料在导出图中仍标记为“尚未查看”。

## 40分钟课堂实践衔接建议

| 时间 | 课堂任务 | 网页的使用位置 |
| --- | --- | --- |
| 0—5分钟 | 用图片或身体动作讨论“围绕篝火”和“地球公转”有什么相似、不同；保留学生最初的解释 | 暂不揭示季节证据 |
| 5—12分钟 | 学生用地球仪或球体模拟绕行，尝试让地轴北端始终指向教室中的同一个远处方向，比较不同做法 | 先积累实物操作经验 |
| 12—20分钟 | 在“追踪一年”留下四处位置，比较两种地轴模型；切换观察视角，再回到地球仪上修正动作 | 解决实物实验难以同时比较四个时刻的问题 |
| 20—27分钟 | 在“还原比例”先估计、后还原；按1亿千米对应1米，用约1.47米和1.52米的两根绳从同一点量起 | 以真实尺度检验对椭圆示意图的直觉 |
| 27—35分钟 | 在“检验解释”分别完成一月和七月的预测、揭示与记录；讨论同一时刻两个半球是否一起变暖 | 利用两组证据检验“只由距离决定季节”的解释 |
| 35—40分钟 | 修订教材类比记录或自己的公转模型，导出小组证据，提出下一课要研究的问题 | 回到纸面记录、交流与实物模型 |

可用于追问的问题：

- 地球换了位置，地轴北端的朝向是否也必须改变？
- 轨道“看起来很扁”，可能与哪些条件有关？
- 如果只用“离太阳近就更热”解释，两个半球应该怎样变化？资料是否支持？
- 目前的证据排除了什么解释？还需要研究哪些条件？

## 模型参数与科学边界

1. **公转轨道与日期。** 半长轴取1天文单位，即约1.49598亿千米；地球轨道偏心率取0.0167。公转周期取365.256天，课堂可概括为一年。程序用开普勒方程计算轨道位置，日期采用非闰年的近似教学标尺，近日点设在一月初，不对应某一年的精确星历。
2. **太阳的位置。** 太阳位于椭圆的一个焦点。距离尺与轨道几何按各自明确的统一比例绘制，太阳、地球图标均放大，不能据图标大小比较天体实际直径。
3. **视角与轨道形状。** 轨道比例工作区始终从正上方观察。第一工作区的斜视会使近圆轨道呈椭圆投影，这不能作为真实轨道很扁的证据。
4. **假设轨道。** 改变扁圆程度时，页面明确标为“假设轨道”；只有恢复地球参数后，才显示近日点、远日点及其大致月份。假设轨道不表示地球过去或未来某一年的真实轨道，也不据此计算季节或气温。
5. **地轴方向。** 地轴与轨道面法线的夹角取23.44°。“同向倾斜”使用一年内基本不变的空间向量；“总向太阳倾斜”是用于比较的假设。模型不模拟岁差和长期轨道演变。四处留影表示同一颗地球的四个时刻。
6. **自转与公转。** 地球真实地同时自转、公转。为了看清，网页分别慢放：播放一年时追踪公转，慢看自转时暂时定格公转。不能从动画速度推算真实的自转、公转速度比。大陆轮廓仅为简图。
7. **季节证据。** 一月、七月的资料指两半球温带的季节关系，不表示某地的天气或气温实测，也不概括赤道与极地的全部气候表现。近日点不等于冬至，远日点不等于夏至。
8. **距离与受热。** “只用距离解释不了四季”不表示日地距离对太阳辐照完全没有影响。真实距离变化会影响辐照强度，但不能单独解释两半球相反的季节。本课不把距离直接换算为气温。

## 操作与离线使用

- 下载完整的 `index.html`，用浏览器打开即可离线运行。无需构建步骤、CDN、在线字体、图片素材或三维库。
- 教师可使用网页“全屏”按钮或浏览器全屏；图形支持鼠标和触摸拖动。聚焦轨道后可用左右方向键改变日期；聚焦比例图后可用左右方向键改变扁圆程度。
- 平板横屏便于并排比较主场景与资料。界面按屏幕宽度调整布局；课堂实际字号可结合投屏距离与浏览器缩放确认。
- “说明”内的NASA链接仅供核验资料，点击这些外部页面需要联网，不影响课件本身离线操作。

## 记录与导出

预测、已经查看的证据、判断和可选依据通过浏览器 `localStorage` 保存在当前设备、当前浏览器环境。网页没有向服务器上传记录的逻辑。页面位置、公转日期、轨道扁圆程度不属于自动保存的数据。

“导出证据图”生成独立的SVG文件，保留预测、已查看的资料、个人判断与依据，可在浏览器打开、投屏或打印。“重新预测”会先确认，再清空本课已存记录。浏览器不允许本地存储时，页面提示通过导出保留；清除浏览器站点数据也会清除本机记录。

## 独立模型与素材接口

科学模型与SVG图形绘制分离，便于后续修改画面而保留轨道与地轴逻辑。

| 入口 | 职责 |
| --- | --- |
| `OrbitModel.orbit(day, eOverride)` | 返回公转位置、日地距离、轨道角度；长度单位为天文单位 |
| `OrbitModel.inverseDay(theta, eOverride)` | 将拖拽得到的轨道角度反算为教学日期 |
| `OrbitModel.axisVector(day, mode)` | 返回地轴空间向量，用于同向模型与假设模型 |
| `OrbitModel.project(vector, elevationDeg)` | 将同一空间向量投影到不同观察视角 |
| `RevolutionLab.Model` | 公开上述科学模型 |
| `RevolutionLab.Renderers` | 地球、太阳、轨道、比例图、季节图等绘制函数入口 |
| `RevolutionLab.getState()` | 获取当前状态的副本，便于调试和核验 |

地球绘制函数 `globe(cx, cy, r, day, mode, beta, spin, id, lightText)` 集中处理球面轮廓、大陆简图、昼夜面、经纬线、地轴和自转标志点。后续精修应保持其输入含义，让光照方向、地轴方向和日期继续来自模型。季节装饰图集中在 `seasonGlyph`，太阳图集中在 `sunGlyph`；教材季节资料集中在 `actual(month)`，应与装饰素材分开维护。

绘制流程通过 `RevolutionLab.Renderers.globe`、`sun` 和 `seasonGlyph` 委托调用，可直接替换对应函数后调用 `RevolutionLab.refresh()` 重绘，也可在源码中替换实现。例如：

```js
var originalGlobe = RevolutionLab.Renderers.globe;
RevolutionLab.Renderers.globe = function(cx, cy, r, day, mode, beta, spin, id, lightText) {
  // 在此替换地球素材；示例沿用原始绘制。
  return originalGlobe(cx, cy, r, day, mode, beta, spin, id, lightText);
};
RevolutionLab.refresh();
```

新函数应返回SVG片段字符串并保持参数含义。只改变图形时，不应改写轨道参数或把假设条件标为真实。

## 科学资料

- [NASA Earth Fact Sheet](https://nssdc.gsfc.nasa.gov/planetary/factsheet/earthfact.html)：轨道半长轴、偏心率、公转周期、近日点与远日点距离、地轴倾角。
- [NASA Space Place — What Causes the Seasons?](https://spaceplace.nasa.gov/seasons/en/)：地轴倾斜、两半球季节相反、一月近日点与七月远日点等教学说明。
- [NASA — Milankovitch Cycles and Their Role in Earth's Climate](https://science.nasa.gov/science-research/earth-science/climate-science/milankovitch-orbital-cycles-and-their-role-in-earths-climate/)：日地距离约3.4%的变化与太阳辐照约6.8%的差异，支持“距离有影响，但不是四季交替主要原因”的边界说明。
