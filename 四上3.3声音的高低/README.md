# 四上 3.3《声音的高低》

依据项目提供的教科版《科学》四年级上册第三单元第 3 课，教材印刷第 64—66 页及配套教师教学用书本课章节制作。单体 HTML，内嵌 SVG、CSS 与 JavaScript，无字体、图片、CDN 或其他网络依赖。课件不显示学校、姓名或邮箱。

## 两个可独立使用的探究页

| 页面 | 操作 | 教学增益 |
| --- | --- | --- |
| 钢尺探究 | 连续改变伸出长度；点击尺端拨动；保留 A、B；同倍率同步慢放、暂停、拖动时间、依次回听 | 把肉眼难以分辨的振动快慢放到同一时间尺度上比较；侧视钢尺和尺端运动曲线对应，帮助学生比较、解释 |
| 高低与强弱 | 分别调节 A、B 的振动频率和相对幅度；单独或依次听音；标出一次完整振动 | 一次改变一个变量，用声音与同尺度曲线辨别音调和强弱，避免把“高”理解为“大声” |

网页围绕真实钢尺实验之后难以观察的部分设计，不代替学生实际拨动、倾听与记录。教材第 65 页的记录按“较长、中等、较短”分类，没有指定厘米数。本页的 8—20 cm 是连续模型操作范围，不声称是教材规定的长度。教师用书建议使用不同伸出长度、保持拨动力度尽量相同、反复观察，并区分钢尺自身振动声和碰到桌面的杂声。网页固定起始拨动幅度，以便只比较长度这一变量。未使用或编造未提供的作业本题目。

## 模型与音频说明

钢尺采用均匀悬臂梁的小振幅基频近似：

`f₁ = β₁²/(2πL²) × √(E h²/(12ρ))`

模型参数：`β₁ = 1.875104`，`E = 200 GPa`，`ρ = 7850 kg/m³`，厚度 `h = 1 mm`，`L` 为伸出长度（米）。这些是教学模型参数，频率不是对真实器材的测量或标定。相同材料、截面和固定方式下，基频随伸出长度的平方反比变化。梁形使用固定端位移和斜率为零的简化弯曲轮廓；侧面位移放大呈现，不表示真实毫米数。

基频公式参考：[SOLIDWORKS 官方悬臂梁频率分析](https://help.solidworks.com/2026/english/simtutorialonline/Dynamic_Analysis_of_a_Cantilever_Beam.htm?id=1.0.1.3)，以及 [Washington University 均匀悬臂梁实验说明](https://classes.engineering.wustl.edu/2010/fall/mems431_lab/lab6.html)。模型位移使用 `A₀ exp(-2t) cos(2πft)`；A、B 初始相对幅度相同。简化模型没有求解高阶振型、桌面碰撞和真实材料阻尼。

| 伸出长度 | 模型基频 | 钢尺页合成音基频 |
| --- | ---: | ---: |
| 8 cm | 127.4 Hz | 509.6 Hz |
| 12 cm | 56.6 Hz | 226.5 Hz |
| 16 cm | 31.9 Hz | 127.4 Hz |
| 20 cm | 20.4 Hz | 81.5 Hz |

钢尺页合成音统一乘以 4，即升高两个八度，便于设备呈现低音，同时保留频率比例和高低顺序。页面显式说明该处理。声音不是实录，也不代表真实钢尺一定发出同样音高或音色。没有添加“20 cm 钢尺没有声音”这一不恰当结论。

原速图形用上下虚影表示快速振动，避免屏幕刷新率引起假慢速。慢放展示起始 100 毫秒并放慢 80 倍，慢放静音；A、B 曲线也使用同一个 100 毫秒及相同纵轴比例。曲线上下变化与钢尺侧视位置对应。观察窗口结束不意味着实物恰好停止振动。

第二页使用 100—600 Hz 的合成纯音，不移调。频率与幅度分别控制，改变幅度不改变频率；A、B 图形均展示 20 毫秒。标记区间从一个最高点到下一个最高点，表示一次完整振动。相对幅度不是分贝；相同的信号幅度不保证不同频率在人耳和设备上听起来完全一样响。保持设备音量不变进行比较。

以上图形均为振动位移示意，不是声波在空气中传播的空间形状。模型不能作为独立证据证明其预设的规律。

## 运行和操作

- 技术等级 **T1 基础交互**；声音另需 Web Audio。现代 Chrome、Edge、Safari 等浏览器可尝试运行，未据此保证所有旧设备兼容。
- 单文件可离线打开；无需摄像头、麦克风授权或外部服务。浏览器不支持音频时会提示，图形探究仍可使用。
- 先将设备音量调低，再点击听音。切页、复位、改变参数、暂停以及页面转入后台均停止当前音频并取消待播序列。
- 长度可用金色控制点或滑块调整；金色点支持方向键、Home 和 End，蓝色尺端支持回车和空格。
- A、B 临时保存在本页内存；切页保留，当前页复位或刷新后清空。全屏能力由浏览器决定。

## 验证范围

已在浏览器中执行长度端点调整、尺端拨动、A/B 保留、条件改变后防止误存、同步慢放、暂停、0.1 毫秒逐帧调整、第二页频率和幅度独立变化、周期标记、切页与复位等操作。检查了 1366×768、1024×768、390×844、844×390 的浏览器视口布局。核心函数及音频取消逻辑通过定向检查，包括迟到的音频恢复不会在停止后启动。

这些是浏览器与模型验证，不代表已在实体希沃一体机、iPad 或其扬声器上测试；合成音的硬件响度和低音表现需在实际设备上试听。

## 维护

单文件内部按 `PitchCore`（参数、频率、位移和音频）、页面状态与交互、SVG/CSS 三部分组织。更换素材时保留固定端、伸出长度和尺端坐标映射；调整听音音域时对全部钢尺长度使用同一个移调倍数，并更新页面说明，避免改变音高关系。
