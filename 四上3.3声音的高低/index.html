怎么用，怎么看

钢尺探究

先在真实实验中压紧钢尺，改变伸出桌面的长度，并尽量保持拨动幅度相同。网页可拖动金色圆点或长度滑块改变伸出长度，点蓝色尺端拨动。保留 A、B 后，可依次回听，或用相同的慢放倍率同步比较。同样长的时间里，一个完整来回算一次振动。

声音与慢放各表示什么

图形按均匀悬臂钢尺的小振幅基频模型计算：钢材弹性模量 200 GPa、密度 7850 kg/m³、厚度 1 mm，保持材质、宽厚和固定方式不变，基频与伸出长度的平方成反比。尺寸、固定方式和真实材料都会影响实物声音，图中的频率是模型值，不是实测值。钢尺曲线采用简化的弯曲形状，位移为放大示意。

为了便于设备呈现低音，钢尺页的合成音频率统一乘以 4（升高两个八度），仍保留两次声音频率的比例；不是钢尺录音，也不表示真实钢尺一定发出相同音高。原速画面用虚影表示快速振动，避免屏幕刷新造成假慢速。慢放展示起始 100 毫秒，放慢 80 倍并静音；两张记录图也展示同一个 100 毫秒。暂停后可拖动时间逐帧观察。振动呈衰减示意，画面观察时段结束不代表实物此刻停止振动。

高低与强弱

第二页的快慢值直接用于合成声音，不移调。两张图均显示 20 毫秒内的振动位移示意，横纵比例相同；每秒的振动次数用 Hz 表示。改变“振动快慢”只改变频率，改变“振动幅度”只改变幅度。点击“标出一次完整振动”，观察从一个最高点到下一个最高点的间隔。图形不表示声音在空气中的传播形状。

播放时保持设备音量不变。幅度百分比是模型相对值，不是分贝；不同频率在扬声器上的输出和人耳感受也会不同，因此相同的幅度设置不保证听起来完全一样响。模型用于解释关系，不能替代真实实验的证据。

运行与操作

本页无外部依赖，可离线运行，不使用麦克风。发声需要浏览器支持 Web Audio，并由点击触发；初次使用请将设备音量调低。左右方向键可调整金色长度控制点；蓝色尺端支持回车或空格。复位只清空当前页；切换页面保留探究记录并停止发声。全屏由浏览器能力决定。

教学依据

依据项目提供的教科版《科学》四年级上册第三单元第 3 课《声音的高低》，教材第 64—66 页及教师教学用书本课章节。8—20 cm 是本网页的连续探究范围，不是教材规定的实验长度。真实实验应反复观察，区分钢尺自身振动声与碰到桌面的杂声。未使用未提供的作业本题目。v1.0
