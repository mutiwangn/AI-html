# 三上 1.2 认识气温计
独立重制辅助稿，无学校或真实姓名署名，无外部图像与程序依赖。教材正文及教参待核对，非整课验收。

活动：原生 SVG 气温计结构提示、−20 至 50 ℃的整数液柱调节、每格 1 ℃刻度、零上零下中文读法、平视辨析、10 题循环读数练习与提示。练习值不会显示在图形旁，答案由学生填入。无成绩收集、无上传。

验证：JS 语法通过；云端 Chrome 操作检查最低刻度限位、部位标注、空答案反馈、−7/23/0 ℃练习与中文读法、换题和提示；桌面截图检查。实体触屏、旧浏览器和课堂尚未验收。
