# 四上 3.6 改进我们的乐器

单文件课堂互动网页，v1.0。对应本项目教师用书第三单元第6课，核心是测试、寻找原因、改进、再次测试和交流评价。页面不显示学校、姓名，保留低干扰 mutiw 水印。

## 课堂价值

真实乐器被改变后，通常难以回到原状作同条件试听。本网页保留改前和每次改进的快照，让学生比较同一旋律、力度和速度下的声音，再决定哪些证据支持自己的判断。模拟不替代真实制作，另设实物录音入口辅助真实前后对照。

- **改进实验台**：橡皮筋琴、封底吸管排箫、水杯琴。连续改变绷紧程度、水量；先预览裁剪位置，确认后只能剪短，换新才恢复长管。裁剪模型包含重新封底。
- **结构观察**：琴码与箱面接触、软布触碰振动段、纸条遮挡管口；可查看放大的慢放振动示意。
- **演奏与比较**：基本六音统计，7和高音1为扩展；保留不准确的音，不自动校准。支持简单公共领域旋律、逐音练习和前后轮流试听。同量程曲线为合成模型的相对声幅包络，不是实测波形或分贝。
- **迭代记录**：留存版本、选择对照版、记录问题与可能原因、自动记录改动、人工判断；支持 JSON 作品和 CSV 记录导出。
- **实物录音**：改前、改后各最多12秒，只留在当前网页，不上传。刷新前需要保存音频。请求关闭自动增益等处理，但浏览器可能不支持，不能作为声压级测量。

## 与上一课衔接

读取同源浏览器中的 `mutiw-instrument-design-2d-v1`，或导入已发布二维《设计我们的乐器》的 `mutiw-instrument-2d` v1 JSON。载入前校验全部参数，并要求确认替换本课数据；只读取副本，不修改上一课缓存。

保留上一课原有频率公式和音区，不悄悄改调或吸附到标准音。旧三维版导出格式不兼容。前一课5音作品可补音；若改前版缺少对应音，不用其他音替代，可比较已有音或选完整留存版作对照。

## 科学与模型边界

- 橡皮筋采用理想弦近似；长度与其他条件固定时，频率随张力平方根增加。真实橡皮筋拉伸还会影响其他量。
- 新建排箫采用一端开口、一端封闭空气柱，含简化端部修正；剪短提高频率。图形不是精密裁剪模板。
- 新建水杯示例采用不同尺寸杯子的基频，使用示意加水降调模型；不声称可预测任意实物杯子的准确频率。
- 琴箱耦合改变辐射效率和衰减，不凭空产生能量；软布触碰降低声幅并加快衰减。参数是教学模型，不是测量所得系数。
- ±35音分为网页的“接近目标”提示范围，不是教材评价标准；统计只计1—6六个不同目标音。
- 材料具有不同合成音色；听感近似不等于原始实物采样。实体结构牢固、美观、方便演奏等仍由师生实际观察评价。

声学参考：[UNSW 弦振动](https://www.phys.unsw.edu.au/jw/strings.html)、[开口与封闭管](https://phys.unsw.edu.au/jw/flutes.v.clarinets.html)、[琴弦与琴箱](https://newt.phys.unsw.edu.au/music/guitar/guitarintro.html)。录音 API：[MDN MediaRecorder](https://developer.mozilla.org/en-US/docs/Web/API/MediaRecorder)。

## 使用环境

`index.html` 内嵌全部 CSS、JavaScript、SVG 和合成音频代码，无运行时外部资源。普通模拟与声音可离线使用；第一次发声需要点击。实物录音需要支持 MediaRecorder 的浏览器、安全页面（例如 GitHub Pages 的 HTTPS）、麦克风与用户授权。拒绝或不支持录音不影响模拟。

建议先在教师实际使用的一体机、平板上检查音量和触控。玻璃杯轻敲，破损不用；剪刀由教师指导使用；吹奏管不要交叉使用。

## 本稿验证

- 浏览器实际操作：材料切换、音高随调节变化、裁剪预览与不可逆确认、结构切换、留存版本、前后轮流演奏、自主演奏提示、不支持录音的反馈。
- 浏览器窗口/固定尺寸嵌入布局：1363×936、1920×1080、1366×768、1024×768、768×1024；主要操作无页面溢出。390×844 手机模式无横向溢出，允许纵向阅读。
- 模型与音频节点单元测试23项、交互状态回归测试12项、SVG几何及映射断言909项通过。
- 尚未实测：希沃/实体iPad、真实扬声器听感、真实麦克风录音。浏览器自动化在本地HTTP预览的Blob下载环节报错，因此不能把该测试视为导出文件落盘成功。

视觉采用暖白主舞台、蓝色操作色和改前赭色/现在青色对照。相较概念图，使用与参数联动的原生SVG、修正弦与编号对应、以声幅包络替代装饰波形，保持科学信息可解释。
