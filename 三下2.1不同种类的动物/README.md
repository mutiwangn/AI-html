# 三下2.1 不同种类的动物

独立原创课堂辅助观察稿，教材教参细节待核，不是完整课时验收。

8种指定成年动物事实卡：蝴蝶、蜘蛛、鲫鱼、青蛙、麻雀、蝙蝠、乌龟、蚯蚓。区分身体特征、生活信息、所属类群；两对象比较。按主动飞行、有羽毛、昆虫三标准重分组，切换清空旧判断，错误回看证据，不把未分组当否。

关键限制：成体与幼体区分；会飞不等于鸟，蜘蛛非昆虫，水中活动非鱼；图为原创简化选择图标，不用于精细结构或物种鉴定。事实卡不是实测。真实观察独立记录来源、特征和标准，不自动鉴定。
