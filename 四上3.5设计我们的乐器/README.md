# 四上3.5 设计我们的乐器

二维互动工坊 v1.0。入口为 `index.html`，完整单体 HTML，原生 SVG 与 Web Audio，无外部运行依赖。课件内无学校、姓名，只保留低干扰的 mutiw 水印。它是独立的二维课堂版本。

## 教学依据与用途

已核对本项目《教材 四上》印刷页70—72（PDF第74—76页）和《教师用书 四上》第5课。核心任务是把设计想法落实为可说明、可制作的图纸：所需材料、发声方式、音调变化方式。教材示例旋律使用1—6六个音；评价表的“优秀”示例为达到5个音调，两者不混为同一硬性评分要求。

网页补充真实实验中不易同时完成的结构标注、连续调音、保留对照和设计图同步。它不替代真实材料制作，不自动评价牢固、美观或真实音准，不把模型输出作为独立验证科学规律的实验证据。

## 两页功能

1. **设计工作台**：纸盒琴、水杯琴、封底排箫三种材料；5—8个发声部件；直接拖动琴码、水位或管底，滑条和键盘可替代操作；自由草图标注、撤销、复位；各材料独立保存当前设计与方案A。
2. **试奏与改进**：模型频率和参照音同时显示；连续音高不会吸附音阶；参照音可逐部件设定；统一20毫秒时间窗展示基频示意轨迹，时间光标慢放80倍；A/B先后试听；按当前设计演奏《小星星》选段，并可暂停、继续。

制作单包括当前结构图、材料、发声方式、音调调节方法、各部件参数、方案A和空白的实物试听/修改记录。设计图导出为SVG，可在浏览器中打开和打印。作品导出JSON，可在本二维工坊重新载入。自动保存仅在当前设备浏览器中进行，不上传数据。

## 科学模型与参数

### 纸盒琴

采用理想弦近似 `f = sqrt(T / μ) / (2L)`。有效长度12—40厘米，线密度0.00032 kg/m，张力为8 N乘以0.5—2.0的相对系数。

移动琴码改变主振动段长度，固定端保持不动。真实橡皮筋拉伸可能同时改变张力和线密度，网页将它们理想化。琴码后的灰色段不作所显示的主发声段。数值不能直接保证实物音准。

### 封底排箫

上端开口、下端封闭，`f = 343 / (4L)`，L使用米。长度12—40厘米；忽略管口修正。C4—A4的理想有效长度约32.8—19.5厘米，材料因此标为“加长吸管或塑料管”。透视提示为沿管轴的往复运动，不能理解成空气穿过密封管底。

### 水杯琴

相同玻璃杯，以敲击杯壁发声。水位比例0—85%，示意频率为 `620 / sqrt(1 + 8×fill)`。620和8是为教学范围选取的示意参数，不是实测拟合值，不是通用调音配方。杯和水共同影响振动。它与吹瓶口的空气柱模型不同。

### 声音、轨迹与评价

- 所有Hz和音分均来自模型，未调用麦克风；声音由合成泛音和包络生成，不是真实乐器录音。
- 参照音示例采用C4—C5八个自然音。±20音分绿色区域为网页自设的调音提示，不是教材评价标准。
- 曲线只显示基频正弦示意，不声称显示含全部泛音的真实声波。曲线时间光标慢放80倍，音频仍按原音高播放。
- 《小星星》选段按各部件所选参照音映射演奏。缺少所需音时提示学生补足设计；不会自动把音调改准。
- 真实作品需再次试听和修改；实物音调数量、演奏效果、结构牢固和外观由师生约定标准后评价。

## 兼容性与数据

T1基础交互：HTML、CSS、SVG、JavaScript。声音另需Web Audio；首次播放须由用户点按解锁。全屏功能依赖浏览器支持。无摄像头、麦克风或网络权限要求。可将单体HTML下载后离线打开。

支持鼠标、触控和键盘：数字1—8试奏；左右箭头切换部件；原生滑条与SVG拖柄可使用方向键。浏览器不支持声音时仍可进行设计，页面会给出提示。

作品格式为 `mutiw-instrument-2d` version 1；不是旧三维工坊文件格式。JSON导入先校验全部数据，正确后再替换；材料键与内容必须一致。绘图最多50笔、每笔800点，坐标保留一位小数；保存紧凑JSON，导入上限8 MB。隐私模式或浏览器清理可能移除自动保存，重要作品请导出。

## 维护入口

单体HTML中的三个脚本块分别为 `InstrumentModel`、`InstrumentArt`、主应用。科学参数、声音、SVG素材和交互状态适度分离，后续可替换图形而不改变模型接口。

根目录 `index.html` 负责课程登记，`lesson-levels.js` 负责T1等级。发布仅新增本课文件并登记本课，不修改其他课程文件。
