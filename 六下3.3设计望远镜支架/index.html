三只脚围住的区域，能支撑重心吗？

设计前先比较：同样三只脚，张开多少、重心偏向哪里，会有什么不同？

俯视图 · 不是望远镜外形图

重心投影是“整架望远镜连同支架”的重心竖直落到地面的位置，不是镜筒前端，也不是单独镜筒的重心。

2 · 比较重心位置

百分比仅指理想静止状态的竖直支撑力占总重力的比例。范围外不显示虚假的“负支撑力”。

试一试，再解释

先点“偏到后方”，再慢慢加大脚到中心的距离，看看重心投影从外部怎样进入支撑区域。再点“落在后边界”：有一只脚的支撑力变为零，此时不能把它当作有余量的安全设计。

设计草图时，还要考虑高度、材料、连接牢固程度、转动方式、便携性与成本。本页只帮助讨论其中的支撑范围，不是可施工的结构设计或承重认证。

模型边界与安全

假设三脚构成等边三角形、刚性支架放在水平坚实地面，只有重力和地面支撑力，没有风、碰撞、滑动、松动或变形。内部仅表示本模型具备静态支撑条件，不保证真实器材安全。高度未纳入本页，不能用它比较抗风、抗推或倾斜稳定性。

实物试验由教师指导，用轻质模型；不要推倒真实望远镜测试，不攀爬支架。绝不能用望远镜观看太阳。
