# 六上1.6 管理我们的情绪

用于六年级上册第一单元《健康生活》第6课的单体HTML互动课件。接续情绪表演、生活情境讨论和疏解方法体验，围绕“我们怎样了解别人的感受”“同一件事为什么可能走向不同结果”“怎样观察一次疏解体验”三个问题展开。

网页把难以同时观察的角色视角、内心想法和行动后续并列呈现，允许暂停、回退和改换路径。学生仍需观察、表达、倾听与实际练习，页面不承担对学生情绪的自动识别或评价。

## 数字技术增加了什么

1. **补足观察不到的视角。** 同一情境中的三个角色可以分别查看。先保留学生对多个情绪的猜测，再揭示该虚构角色的想法与自述身体线索，比较外部表现和本人表达之间的关系。
2. **让短暂过程可以同时比较。** 同一事件展开为两条并排路径，想法与行动可以分别更换，五个时刻同步拖动、暂停和回放。新线索出现后，可以回到原来的判断重新讨论。
3. **把体验过程留下来。** 提供实际计时或步骤引导，由本人填写前后紧绷程度；保留同一轮记录供比较，也接受没有变化或更紧绷的结果。

## 三页功能

| 工作区 | 主要操作 | 用于讨论的材料 |
| --- | --- | --- |
| 情绪线索 | 从三个虚构情境中选择一个，分别查看三个角色；选择一个或多个可能的情绪，再揭示角色想法与自述身体线索。 | 看得见的表现、自己的猜测、角色说出的感受；不按固定答案评分。 |
| 时间分岔 | 从三个事件中选择一个，为两条路径分别选择想法与行动；沿“事件—想法—感受—行动—后续”同步拖动回看，可揭示新线索。 | 哪些内容是已经给出的事件，哪些是解释或猜测；不同做法可能带来的后续，以及仍然不知道的部分。 |
| 疏解练习 | 选择舒适呼吸、转移注意、说给人听或轻轻活动，跟随计时或步骤实际尝试；可以暂停、退出，填写练习前后的自评。 | 一次体验的前后自述及方法记录；演示记录和自愿体验分开标记，不预设改善。 |

三个工作区可独立进入。全屏、低刺激动效开关和老师说明用于适应课堂展示；核心操作直接作用于场景、角色、路径和时间线。

## 40分钟课堂嵌入建议

| 时间 | 真实活动与交流 | 网页的作用 |
| --- | --- | --- |
| 0—7分钟 | 用情绪表演、词语或日常虚构情境交流：我们可能从哪些表现发现情绪？同样的表现是否可能有不同原因？ | 暂不揭示角色自述，保留学生已有想法。 |
| 7—15分钟 | 小组分别观察同一事件中的不同角色，说明自己作出猜测的依据，再倾听角色自述。 | 在“情绪线索”中保留多种猜测，揭示不同角色视角。 |
| 15—26分钟 | 对一个事件提出两种想法和两种行动，讨论可改变的部分；加入新线索后重新判断。 | 在“时间分岔”中同步比较两条路径，按时刻回退，区分事件、解释与可能后续。 |
| 26—35分钟 | 学生自愿选择一种方法体验，也可以观察教师演示；只在愿意时表达自己的感受。 | 在“疏解练习”中提供节奏或步骤，记录本人选择的前后程度，不替学生填写结果。 |
| 35—40分钟 | 回到生活情境：我能怎样表达感受、采取行动、请谁帮助？交流下次想尝试的方法。 | 对照当次记录，保留问题，不以一次结果宣布某种方法最好。 |

不要求学生在全班公开自己的困扰、家庭经历或自评分数。教师可以全程使用虚构情境和演示记录；小组讨论也不以“猜中同学的情绪”为目标。

## 模型与解释边界

- **角色与事件是教学案例。** 页面中人物的内心独白、身体线索和后续情节属于预设故事，不是摄像头观察、心理测评、脑成像或对真实学生的推断。
- **表现是线索，不是判定依据。** 表情、动作或身体感受不能单独确定一个人的情绪。同一事件可能引起不同感受，多种感受也可能同时出现；更完整的理解需要倾听本人表达。
- **情绪需要被认识，行动可以被选择。** 不把某种情绪当作学生的错误，也不把“没有情绪”作为成功目标。讨论重点是表达、调整行动、解决问题与寻求支持。
- **并排路径展示可能性。** “事件—想法—感受—行动—后续”是便于讨论的时间分解，不是对真实心理过程的精确测量；这些过程可能相互影响，也可能交叠。更换一个想法或行动不保证现实一定得到页面所示结果。
- **新线索可以改变判断。** 当事实还不清楚时，允许保留多种解释；不要把猜测当作事实，也不要用“换个想法”忽略确实发生的不当行为或需要解决的问题。
- **0—10是本人自评。** 数字表示本人当时感到的紧绷程度，不是心率、压力激素、情绪健康分数或诊断结果。它适合辅助同一人的体验回顾，不用于同学之间排名或判断谁更会管理情绪。
- **前后变化不等于已证明因果。** 时间经过、当时环境、方法熟悉程度和填写方式都可能影响记录。一次自评分数降低不能证明某方法对所有人有效；不变或升高也不作为失败。

## 练习与记录

四种方法提供的是可选择的课堂体验。呼吸以自然、舒适为准，不要求憋气或用力吸气；活动以轻柔、适合当前空间为准。任何时候都可暂停或退出，身体不舒服时停止并告诉老师。

“说给人听”用于练习向可信任的人表达需要，不要求当众讲述私事。持续困扰、受到伤害或自己难以应对时，应向老师、家长等可信任的成人寻求帮助；网页不能替代真实支持。

记录由本人或教师按实际情况填写，页面不自动生成“练习后降低”的分数。每条记录标明是演示记录还是自愿体验，最多保留8次，支持删除和CSV导出。

记录只保存在当前页面内存中。刷新或关闭后清空；需要保留时，应先导出，并由使用者自行决定是否展示或保存。页面没有姓名输入、摄像头读取、后台上传、账户或在线分析接口。

## 使用与兼容性

下载本课完整的 `index.html` 后，可直接用浏览器打开。样式、脚本和SVG均包含在同一文件内，核心功能没有外部运行依赖。

本课登记为 **T1 基础交互**，使用HTML、CSS、JavaScript与SVG。等级反映技术依赖，不等同于所有希沃设备、平板和浏览器版本均已实测。页面支持鼠标、触控、全屏展示和动效关闭；全屏能力由浏览器及操作系统决定。

课堂首次使用前，建议在实际显示设备上确认主场景完整、重点文字能从教室后排辨认，并检查角色点选、时间线拖动和练习暂停。老师说明集中放置教学边界，避免在主操作区域堆积长文字。

## 内容与素材替换

首稿使用二维SVG人物和场景，数据与绘制入口集中保留，便于后续精修：

| 入口 | 替换内容 | 必须保留的关系 |
| --- | --- | --- |
| `SCENE_DATA` | 情境、角色、可观察表现、想法与自述线索 | 猜测先于揭示；角色内容相互一致；允许多个情绪，不引入自动评分。 |
| `BRANCH_CASES` | 事件、新线索、两条路径的想法与行动选项、可能后续 | 五个时刻同步；两条路径可分别操作；后续保持条件性，不写成现实保证。 |
| `METHODS` | 四种方法的节奏、计时和步骤文案 | 暂停与退出可用；呼吸舒适、活动轻柔；练习不自动改写自评分数。 |
| `ASSETS.renderPerson()`、`ASSETS.backdrop()`与`ASSETS.focusObjects()` | 人物、表情、场景与图标 | 保留元素标识、可操作部位和事件绑定；图形变化不能暗示唯一情绪或心理诊断。 |

新增素材应内嵌到HTML或以SVG代码表示，继续保持单文件离线运行。替换后需要重新检查触控命中范围、文字尺寸、一屏布局和全部核心交互。
