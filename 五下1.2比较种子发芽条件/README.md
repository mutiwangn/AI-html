# 五下1.2 比较种子发芽条件 · 基础辅助稿

T1、单文件、无外部依赖、无署名。整理两组真实发芽记录，以共同百分比尺度展示数量与比例，讨论对照条件和证据边界，导出TXT。空白与零有别；总数1–100，计数须为整数且不超过总数。只保存在页面内存，刷新关闭会清空。

课号课名核自项目Notion五下目录（学生教材PDF目录第4–5页，版次年份待核）。匹配版教材正文与教参未取得，因此明确为基础辅助稿，不声称复现全部教材活动。沿用前课真实对比观察流程，可参考教育科学出版社2022年五下《科学活动与测评》公开组织资料：https://cms.esph.com.cn/webfile/upload/2022/02-24/16-09-410061-602070688.pdf 。不复制原页和插图，全部页面代码原创。

软件不提供预设发芽数据、不自动生成因果结论。只分析课堂实际记录；种子种类、时长、样本状态和其他条件均影响解释。发芽不等同于幼苗生长；一次没有发芽不证明永不发芽。不等总数可算比例但不能消除实验设计差异。复选框是自查而非验证证明。

建议课堂：整理记录8分钟、比较与质疑12分钟、小组解释10分钟、改进方案10分钟。两组日期需一致，若多时点可分别导出。不要填写学生身份信息。无数据导入、长期存储、网络上传。

验收：语法、计数边界、18225种计数组合检查；云Chromium三页切换、不等总数等比例、0值、缺项导出拦截、TXT实际下载核验。桌面截图核验；手机、旧iPad和希沃真机未测试。窄屏允许滚动。
