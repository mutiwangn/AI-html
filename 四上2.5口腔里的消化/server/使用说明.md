# 《口腔里的消化》局域网课堂

## 一体机单独展示

打开本课 `index.html` 即可使用咀嚼观察、牙齿分工和合作消化。没有网络也能使用教学功能。GitHub 在线版适合直接展示或各台平板分别体验。

## 让小组平板与教师互联

1. 将启动包完整解压到教师电脑。保留 `index.html` 与 `server` 文件夹的相对位置。
2. 教师电脑安装 Python 3.8 或更新版本。Windows 双击 `server/启动课堂.bat`；macOS 双击 `server/启动课堂.command`。也可在终端运行 `python3 server/server.py`。
3. 保持启动窗口打开。教师使用窗口显示的“教师本机”网址，学生使用窗口显示的“学生平板”网址，例如 `http://192.168.1.20:8787/`。
4. 教师在网页“课堂”中创建课堂并设置小组数，告诉学生六位课堂码。学生在本地服务网页输入该码并选择小组。
5. 小组提交真实观察记录和一张过程照片；教师在课堂面板查看汇总、选择展示证据和填写点评。

每组一台平板时，网页使用A作为内部成员代码，学生无需填写姓名。小组退出后可以在另一台设备重新加入；如原设备无法退出，可由教师移除该组记录，再让新设备加入。移除会同时删除该组记录和照片，请先导出需要保留的内容。

## 网络条件

教师电脑与平板须处于能互相访问的同一局域网。允许系统防火墙在当前教学网络上接收 TCP 8787；学校 Wi-Fi 若开启客户端隔离，需由管理员允许设备互访。使用同一个 Wi-Fi 名称不一定代表设备能互访。

**课堂码用于选择课堂；本地服务负责设备通信。** 不能只在各设备打开 GitHub 在线页或双击离线 HTML，再靠相同课堂码完成互联。教师与学生都应从启动窗口显示的服务网址进入。

若8787端口已被其他课堂服务占用，先停止旧服务，或运行：

```bash
python3 server/server.py --port 8788
```

所有设备此时改用8788端口。教师机地址改变后，学生需打开新的地址。

## 记录与照片

观察分别记录咀嚼1次、5次、10次时的大小、软硬与干湿，记录可以留空，也可以修改。动画只帮助解释，不能替代小组实际观察。

每个小组成员最多保留一张照片，再次上传替换旧照片；支持JPEG、PNG、WebP，单张压缩后不超过1.2MiB。不需要拍摄学生姓名或人脸，建议拍摄实验材料、观察单或操作过程。

“封存”暂停学生修改，教师仍能点评并重新开放；“结束”使课堂只读。教师减少组数前，须先导出并明确清空被减少组的记录。

**课堂数据和照片临时保存在教师电脑的服务内存中。退出服务或关机后会清除。请在结束前从网页导出需要保存的课堂记录和证据。** 原始照片仍应保留在拍摄设备上。

服务只公开本课网页与受课堂身份保护的接口，不浏览教师电脑的文件夹。教师身份令牌不能分享给学生；学生只需要普通课堂网址与六位课堂码。
