# 五下2.2 热与水的变化 · 基础辅助稿

目录课名已核项目 Notion 五下页；匹配版教材正文与教师用书尚待核对。仅提供常见状态变化的基础辅助，不声称覆盖教材全部活动。

## 互动与边界
四条路径：融化、凝固、蒸发、凝结。阶段滑块和前后按钮改变两种状态的图示组成；可开启水分子层，20种过程/阶段组合均维持12个示意分子。粒子形状不变，但个数、间距、相对比例与宏观图形都不是测量，不表示真实体积、温度或速度。图中气态区域默认透明；白雾放大框单独解释液态小水滴，不与单个水分子混淆。

吸放热判断显示对应方向。融化、蒸发吸热；凝固、凝结放热。蒸发不以沸腾为必要条件，冷却也不一定立即凝结。未绘升华与凝华。未模拟加热曲线、沸腾和水的热膨胀，不据此推定教材内容。

仅模型操作，不触碰热水/蒸汽、不自行加热密闭容器，真实实验由教师安排。无账号、上传、持久保存或外部运行依赖。全部SVG、界面和代码原创，无第三方图像。
