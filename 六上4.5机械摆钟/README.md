# 六上4.5《机械摆钟》互动课堂

单体 HTML 初稿 v1.0。入口为本目录的 [index.html](./index.html)，可直接用浏览器打开，也可通过 GitHub Pages 使用。核心图形采用 SVG，技术需求登记为 **T1 基础交互**，无三维、无外部运行依赖。

## 教学定位

依据用户提供的六年级上册教材第114—117页（PDF第118—121页）及教师用书第353—362页。本课围绕**同一个摆的小幅度摆动具有近似等时性**展开：统一计数口径，进行重复观察，再依据记录讨论。第4.6课《制作钟摆》才进一步比较摆长、质量等条件，本页不提前铺开这些变量。

真实摆钟观察、自制摆及计时计数仍由学生完成。数字页面补足三个难点：把一次往返拆开回看；让不可同时观看的前后时段在同一时间刻度下比较；把本班真实数据汇总为可讨论的证据。曲线用于分析运动，不要求学生学习微分方程。

## 三页任务

| 页面 | 可执行的操作 | 重点观察 |
| --- | --- | --- |
| 看清一次 | 拖动摆锤在小摆角范围内释放；播放、暂停、逐格、慢放与拖动时间条 | 到另一侧只是半次；返回起始侧才完成1次 |
| 追踪40秒 | 连续观察、回看指定时刻，核对四个10秒区间；对齐前后两段；导出模型图 | 摆幅与完整往返用时是不同的量，摆幅变小不等于往返节奏明显变慢 |
| 实测汇总 | 切换三类实测项目，填写六组数据，选组对照，记录暂时判断，导出数据或图 | 先比较同一个摆的重复记录，再讨论组间差异 |

“看清一次”提供钟摆供能关系的可选说明：重锤或发条提供能量，轮系传动，擒纵间歇放行并补能，钟摆参与调节节律。图中是**功能关系**，不是零件装配图，也不表示所有机械钟的一次往返都对应相同秒数。

建议40分钟组织：计数口径约4分钟；实物观察与记录约18分钟；时间展开与对齐约8分钟；证据研讨约10分钟。教师可随教学进程切换页面，不必依次完成全部按钮。

## 计数与比较规则

1. 释放瞬间记0次。从起始侧出发，到另一侧，再回到起始侧，计1次完整往返。自由摆衰减后不必返回最初的同一空间位置；判断依据是同侧回转点。
2. 连续40秒中不重新释放、不在每10秒归零模型。四段各记该段**新增次数**，不是累计数。程序窗口采用 `(a,b]`，边界事件归入结束于该时刻的窗口，避免重复计算。
3. 对齐比较选择前段0.00—10.00秒，以及30秒之前最近的同侧回转点开始的后段，默认约28.58—38.58秒。仅平移两段时间起点，保留相同秒刻度；不拉伸时间、不逐周期强行同步。因此细小的周期差异仍然保留。
4. 小摆幅下表述为“近似相同”，不是绝对不变，也不是摆锤在运动各处速度相同。相邻10秒的整数次数偶尔相差1次，可能与窗口边界、计数方法或真实条件有关，应保留证据后讨论。

## 实测记录和导出

六个小组分别保存以下三套数据，切换项目不会相互覆盖：

- **钟摆·1分钟×3次**：同一机械钟，三次独立的一分钟计数。
- **自制摆·1分钟×3次**：同一自制摆，三次独立的一分钟计数。
- **自制摆·连续40秒**：一次连续观察，填写0—10、10—20、20—30、30—40秒各段次数。

实测区初始为空，不把模型结果填入真实记录；空白与0分别保留。次数输入接受0—99的整数，错误输入标红。每组可保留“次数接近”“出现差异”或“还需复测”的暂时判断。清空当前项目当前小组需要再次点击确认，并提供一次撤销。

“导出全部记录”生成含三项目、六小组及计数口径的 UTF-8 BOM CSV，可供表格软件读取；“保存本图”导出当前实测项目的 SVG，含图、表和判断。第二页另行导出模型 SVG，并注明“模型计算证据”，不与本班实测混合。

记录通过 `localStorage` 自动保存在当前设备、当前浏览器。文件打开方式、浏览器策略或隐私模式可能影响保存；页面遇到失败会提示导出。CSV与SVG可作为跨设备留存文件，本初稿没有云同步或CSV导入功能。

## 科学模型

第二页使用受弱阻力的非线性单摆方程：

$$\ddot\theta=-\frac{g}{L}\sin\theta-2\gamma\dot\theta.$$

参数为 `g=9.81 m/s²`、`L=0.90 m`、初始角 `θ₀=−12°`、初速度0、`γ=0.032 s⁻¹`。采用四阶 Runge–Kutta，步长 `1/240 s`，预计算44秒以覆盖后段比较范围；角速度过零时插值定位正、负极值。往返次数来自事件，不是预设表格；周期也未锁定。

默认参数首个完整往返约1.908秒，后续周期随小幅度衰减有微小变化。阻力系数为教学模型设定，不是对某一实物摆的测定值。模型将摆锤简化为集中质量、轻绳不伸长，不包含支架晃动、摩擦变化等全部真实条件。

第一页使用同一积分器，阻尼设0，仅播放一次往返；允许6°—14°的小摆角操作。它用于辨认计数过程，不表示没有动力的真实摆能永久维持等幅运动。慢放、快放仅改变观看速度，显示秒数仍为模型时间。

## 维护与替换接口

所有样式、SVG和脚本均内嵌在 `index.html`，无需构建或安装依赖。

- **物理模块：**`PendulumModel.create(options)`。返回 `samples`、`returns`、`opposites`，以及 `sample(t)`、`count(t)`、`windowCount(a,b)`、`cycleDuration(index)`。输入摆角为度；输出角度为弧度。`returns[0]`仅为起点参考，周期下标从0开始。
- **图形模块：**替换 `bigPend`、`tinyPend`、`labPend`、`firstPend`、`lastPend` 等 SVG 组内图形；保留组ID、悬点坐标及变换关系。轨迹由 `makeTrace()` 生成，保持时间横轴与实际模型时间一致。
- **记录模块：**`mountRecords(container)` 挂载记录区；`window.recordsAPI` 提供当前数据快照与选组接口。存储键为 `science-6up-4.5-real-records-v2`。修改三类项目或表结构时需同步迁移存储版本和CSV字段，不能把旧记录错配到新项目。

课内和浏览器标题不显示学校姓名，只保留 `mutiw` 水印；课程列表按规范显示“镇海区鲲池小学 王宁”。未嵌入教材页图、扫描件、外部字体或第三方版权图片。

## 验证与资料依据

物理模块已完成 Node 数值检查：起点及首次到达对侧均为0次；首次同侧返回为1次；相邻四窗合计等于40秒总次数；事件顺序递增；零振幅不产生计数；步长减半结果收敛。整页在 Chrome 中验证了页面切换、逐格到半程与整次、拖拽释放、暂停与4倍播放、区间计数和前后对齐。通过固定视口检查1920×1080、1366×768、1024×768、768×1024、390×844的三页布局，未发现页面滚动或控件越界。实测页验证了小数校验、零值、三类记录独立性、清空与撤销；CSV实际下载并核对，SVG证据内容已生成并检查。实体希沃、iPad Safari及其他浏览器版本尚需现场验证。

- [OpenStax · University Physics Volume 1，15.4 Pendulums](https://openstax.org/books/university-physics-volume-1/pages/15-4-pendulums)：小摆角近似、单摆与实际摆模型的区别。
- [Museo Galileo · Pendulum clock](https://catalogue.museogalileo.it/object/ModelPendulumClock.html)：机械钟动力、轮系、擒纵与调速器的功能。
