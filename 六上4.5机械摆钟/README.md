# 六上 4.5 机械摆钟
原创课堂辅助探究稿；教材教参细节待核。

## 探究链
认识重锤/发条、摆、擒纵、轮系指针协作，明确摆不提供无限能量；预测摆长与钟快慢，在固定每完整往返记2秒的虚构计数机构下对照模型时间；三次独立测20次完整往返，整理平均周期与范围，解释校准边界。

## 科学边界
小角度理想单摆 T=2π√(L/g)，g=9.8，L为支点到重心，不适用于任意木杆复摆。每次点击推进一个完整周期，图示回到同位置同方向，非实时动画或秒表。30次示例钟面60秒；80cm模型实经53.86秒走快，120cm实经65.96秒走慢。改变长度归零。图为功能示意，不提供齿轮齿数、真实擒纵或维修指导。
实测数据和模型完全分开；空值不是0，计算精度不等于设备精度，单独测摆不能推出真实整钟误差。实际装置由教师组织，避免重物悬挂在人上方，不拆钟、不猛推。
