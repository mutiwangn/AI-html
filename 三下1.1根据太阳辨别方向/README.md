# 三下 1.1《根据太阳辨别方向》

三年级下册第一单元第一课互动辅助网页，单体 HTML，直接打开 index.html。无需登录、定位或外部资源。

## 独特数字用途

- 太阳与影子：改变当地太阳时，联动计算太阳方位和直杆影子；标记先后两个影尖，连线后旋转图纸，避免把屏幕左右机械等同东西。改变杆长自动清除旧标记，避免混用不同实验条件。
- 真实操作：手电筒/直杆活动检查与独立草图。模型操作不会代填真实检查或画板；需要学生动手验证并记录。
- 辨向与反思：切换面朝方向、向右转，区分相对左右和固定方位；讨论光照、影尖、日期和时段等限制。

## 模型假设

固定北纬30°、赤纬0°（春分/秋分理想条件）、水平面、竖直杆及平行光；8–16时均为当地太阳时，不是北京时间、当天太阳位置或真实导航。

时角 H=(t−12)×π/12，纬度 φ=π/6。太阳东、北、上方向分量为 E=−sinH，N=−sinφ cosH，U=cosφ cosH。影尖东、北坐标分别为 −hE/U、−hN/U。图纸旋转仅改变画面朝向，不改变真实方位。黄圈表示太阳方位投影，不表示高度。

在该理想条件下两影尖连线为东西线。现实日期、纬度、场地和时段会影响误差，不能把任意两点连线宣称为精确东西线。户外需可靠工具复核。
